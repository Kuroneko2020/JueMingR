# 配置与 F5 窗口位置保存测试卡

测试目的：关闭并重新启动游戏后，保留你选择的“群系显示”开关和 F5 主窗口位置。本次目标为 Terraria 1.4.5.8 Steam 单人；偏好在同一游戏安装内共用，不随角色或世界分别保存。

收到本轮“测试版已安装”后再开始。Agent 负责准备和核验安装文件；你亲自启动、操作和退出 Terraria。无需查看 JSON 或解释日志。

1. 正常启动并进入一个世界，按 F5，在“信息”页关闭“群系显示”。画面上的群系文字应消失；拖动标题，把主窗口放到你容易记住的位置，然后松开鼠标。
2. 留意“群系选择已保存”和“F5 位置已保存”的短提示；“已应用，正在保存”表示尚在处理中。正常退出游戏，再从同一安装启动；不重新安装。进入世界并按 F5，群系显示应仍关闭，主窗口应回到刚才的位置。
3. 开启群系显示，确认群系文字出现，再把 F5 主窗口拖到另一处并松开。看到对应保存提示后，正常退出并再次启动，确认新的开关和位置保留。有方便的其它角色或世界时可换一个进入，确认仍使用同一偏好；未检查则回复“未测试”。
4. 简短检查 F5 显示/隐藏、页签和滚动；点击、拖动和滚轮不应穿透到世界。仅主窗口位置和真实群系开关会保存，页签、滚动、按下状态和窗口是否打开不跨启动保存。若改变分辨率或 UI 缩放，窗口应留在可以拖动、操作的屏幕范围内。

出现无法启动、保存异常、设置回退或窗口不可操作时，正常退出并说明发生在哪一步，不反复重装或删除文件。保存问题应有明确反馈，不能把保存失败写成成功。安装恢复会保留游戏目录中的 `JueMingRData`，其中配置属于用户数据，不属于可删除的测试包文件。

如果日后需要处理单个配置异常：先退出游戏，复制保留问题文件，再只移走该问题配置，下次启动使用该项默认值。F5 位置文件为 `JueMingRData/config/ui.json`，群系开关文件为 `JueMingRData/config/features/biome-display.json`。若提示配置来自较新版本，应先使用能读取它的匹配程序；不要把正常新版本数据当成损坏文件处理。不要删除整个 `JueMingRData`、整个 `config` 或其它用户内容。本轮无需故意制造配置损坏。

完成后正常退出并回复：

> 配置保存测试完成，Terraria 已退出。关闭/开启后的重启结果：……；F5 位置：……；其它角色/世界：……；简短交互回归：……；未测试或异常：……；体验接受 / 不接受 / 需要继续使用后再判断。

Agent 会保存获准范围的证据，并在取得对应授权后使用同一包精确恢复；保留用户配置，不要求额外启动纯原版。本次不证明多人、其它渠道/版本/机器、FPS 或正式发布质量，也不自动授权合并或关闭任务。
