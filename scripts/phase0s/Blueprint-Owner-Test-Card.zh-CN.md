# 蓝图第一步体验卡

当前只有选区和凝胶快捷栏，尚不能保存蓝图。请由本人启动、操作和退出 Terraria。

1. 先只确认能正常进入游戏、F5 能打开、正常退出；这一步有异常就回传，不继续测试功能。
2. 进入测试世界，F5 的蓝图页点“开始”：F5 自动关闭，启动点击不应选中格子。单格点击，再拖两个重叠矩形；重叠格应反选取消。
3. 移动相机跨屏拖动，分别调整到很远与很近的视距及不同 UI 大小：选区应贴住世界格。
4. 采集中换武器／工具并左右点击世界：不应开始攻击、挖放或右键交互。原版背包、物品槽和 R 界面应仍能正常左右点击，拖物不应起世界选区；移动、跳跃和药品快捷键照常。
5. 按住左右键时用绑定退出采集，分别松开：选区应清空，仍按住的键不应漏出世界动作；全部松开后的新点击恢复正常。
6. 开启“手持凝胶显示快捷栏”，实际手持凝胶时看底部居中按钮。采集前是“采集蓝图／打开蓝图库”，采集中是“保存蓝图／退出采集”。切走凝胶或关开关只隐藏条，模式与选区应保留。
7. 保存和库按钮禁用；保存悬停有说明，库没有提示。两个绑定可分别设置，保存绑定不应保存、清空或出现成功闪字。
8. 拖动中打开聊天／地图、切出游戏或打开界面：草稿取消，已选区域保留；恢复后须重新按下。死亡保留模式和选区，离开世界再进入应清空。

回传：异常出现在哪一步、按键与界面操作顺序，以及体验是“接受／不接受／还需继续使用”。好友房主／客机和 FPS 仅按实际测试另记。本次安装供本人继续体验，无需体验后自动卸载。
