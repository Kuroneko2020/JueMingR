# 真实蓝图采集与蓝图库体验卡

请由本人正常启动、操作和退出 Terraria。第一步已接受选区保持；本次新增真实采集与蓝图库。包与现装的准确源码／哈希见本批交付记录。

1. 先确认能正常进游戏、F5 能打开并正常退出。若有异常，回传停在哪一步即可。
2. 再进入世界，F5 → 蓝图 → 开始，松开启动键后选一小块含普通方块／墙／家具的范围。点 F5“保存”、绑定保存键或凝胶条“保存蓝图”，应先看到固定草稿。改名后确认保存，原选区清空但仍留采集模式。
3. 再选纯空气保存，应提示没有可保存内容且保留选区。选到箱子／牌子等时，草稿应说明未采集的物品／文字；若有未确认对象，可按具体原因逐组排除，其余墙线内容仍可保存。
4. 打开蓝图库，查看刚存内容；双击名称改一个中文名。删除先点“删除”、同一项再点“确认”才应消失。导入／导出／放置／材料应明显禁用。
5. 正常退出并重启，确认保留项名称／摘要仍在、已删项不复现。库或命名期间在窗口外点世界不应攻击挖放，原版背包和 F5 仍可用。

回传异常的操作顺序，或“本次采集和库体验正常”。好友房主／客机、真实 IME、FPS 和长期只按实际体验另记。无需体验后卸载；没有一次性诊断记录器。
