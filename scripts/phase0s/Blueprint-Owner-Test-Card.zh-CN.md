# 蓝图本人体验短卡

请本人先确认新普通包能进入游戏、F5能打开、正常退出。工程核验／安装成功不代替本人体验；本卡不要求自动操作真实世界。

本轮聚焦蓝图随实际建造隐藏、恢复和完成后移除；实际候选、包、备份和未测范围见交付记录的本轮章节。用几格方块、一面墙或一件小家具即可。

1. 放一份小蓝图，先只建对一部分：对应那层虚影应隐藏。拆掉这一部分，应恢复虚影；放错方块、形状或涂层，应显示红色。其它未建层仍能看见。
2. 留一处未建时尝试移动：已有建对内容的那份应拒绝移动，但仍可移除。另放一份同模板，空位置的那份应能独立移动。
3. 把最后一处也建对：这份蓝图应自动消失，图库模板和其它实例仍保留。随后拆真实建筑，已经完成的旧投影不应回来。
4. 再用一份跨屏小图，把屏外的一格建对后回到另一端尝试移动；仍应锁定这份实例。把新蓝图对齐已有建筑时，未确认的预览应保留，确认后才按完整建造结果移除。

回传问题时保留截图、操作顺序和建造内容，并分别反馈接受／不接受／需继续使用。真实联机、FPS／长期和本人接受只按实际执行记录，不把暂未发现问题当全部功能通过。
