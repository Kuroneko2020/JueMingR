# 蓝图本人体验短卡

请本人先确认新普通包能进入游戏、F5能打开、正常退出。工程核验／安装成功不代替本人体验；本卡不要求自动操作真实世界。

1. 从同一模板连续取两份，再取一份不同模板；分别固定，观察中心格、真实大小和正常移动／跳跃／攻击。
2. 在有墙、线、液体及家具的图上重叠放另一图：只消对应层，碰家具任一格整件Tile消除；移走／移除上层后旧消除不复活。
3. 点“移动蓝图”先选目标，再移动；抓取点不跳，新点击才确认，右键／Esc恢复。点“移除蓝图”只删新选中的一份，图库仍在。
4. 点击air洞、重叠和已消除家具区域，hover目标应清楚；跨屏大图不因空bbox抢选，也不把未读取当空气选穿。
5. 采集后默认名可直接保存，单击名称可中文输入；低高度仍能访问操作。F5简介不重复；取出等待读取时Esc／返回后不突然跟随。删图库模板前应直接看见将移除的引用数量。
6. 大图小幅移动／回移，观察是否仍出现整窗抖动；失焦／UI接管不误确认。如有好友房主／客机条件分别体验本地overlay，无条件记未测。

回传问题时保留截图、操作顺序、鼠标／图纸位置和模板身份；请分别反馈接受／不接受／需继续使用。OS IME、真实联机、FPS／长期及本人接受只按实际执行记录，不把暂未发现问题当全部功能无bug。
