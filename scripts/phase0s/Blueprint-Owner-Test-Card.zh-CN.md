# 蓝图世界图纸体验卡

请本人正常启动、操作和退出 Terraria。先只确认：能进游戏、F5 能打开、正常退出；准确包与现装身份见本批交付记录。

工程检查不代替真实 OS 输入、最终画面或好友主客机体验；未实际做的项目仍是未测。

1. 从库取出熟悉的大基地，观察中心十字、真实大小和半透明内容；松开启动动作后用新左键固定，走动后图纸留在原处。
2. 看一处半砖／坡／平台和门家具的混合区域，检查相对位置、植物外延、墙液体及漆色。无需逐种家具重测。
3. 用凝胶条或F5动作移动：入口不跳，先取消回原位，再移动确认；取另一模板后取消也应回旧图。
4. 编辑名称时按住键关闭F5，全松后移动／跳跃；摆放时点UI、失焦再回焦不会误确认。固定后正常游玩，箱子／牌子／展示本体不出现范围外缺失黄字。
5. 调整世界／UI缩放及可用反重力场景，查看中心和固定坐标稳定；超屏图随相机显现，没有缩成小图。
6. 如有真实好友条件，房主和客机分别查看本地图纸，对方无需安装；无条件则留未测。移除图纸后库中模板仍在，世界和材料不变。

若有偏差，请保留实际图、位置和资产名称，描述操作顺序。无需体验后卸载；本包没有一次性诊断记录器。
