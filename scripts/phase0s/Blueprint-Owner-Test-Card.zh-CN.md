# 蓝图本人体验短卡

请本人先确认新普通包能进入游戏、F5能打开、正常退出。工程核验／安装成功不代替本人体验；本卡不要求自动操作真实世界。

1. 采集后看同排顶栏：左“保存采集”，右“保存蓝图／返回”；名称左标签点了不输入，右框可输入中文，候选和光标跟随右框。低高度／缩放仍可滚动。
2. 改排除组合或窗口大小后，预览未好时保存按钮和名称Enter都不能提前保存；当前合法名称与预览就绪后，Enter仍保存一次。返回不假撤销已开始的保存。
3. 移动选择／拖动时再按移动键或“取消移动”应恢复原图；移除选择再按移除键或“取消移除”只退出选择。新取出取消摆放不影响已有固定图，别的功能不能冒领取消。
4. 采集、草稿、取出等待、摆放／移动／移除中，工具条／F5／打开库绑定均不可手动开库；完成后只有固定图时可开，保存成功仍正常入库。
5. 进入移除模式后，旁边“移除所有”一击清全部世界投影（含离屏），图库模板与真实建筑都应保留；退出模式后该按钮消失。
6. 放多份可见大图，静止或轻移观察是否仍持续整窗抖动／重读；正常固定不弹“正在固定蓝图…”。如有好友房主／客机条件分别体验本地overlay，无条件记未测。

回传问题时保留截图、操作顺序、鼠标／图纸位置和模板身份；请分别反馈接受／不接受／需继续使用。OS IME、真实联机、FPS／长期及本人接受只按实际执行记录，不把暂未发现问题当全部功能无bug。
