# 笔记功能开发测试卡

收到“笔记完整测试候选已安装”后，再亲自启动同一份 Terraria 1.4.5.8。Agent 不启动或操作游戏。这是开发测试包，实机、多人和最终视觉接受需要你的反馈；无需解释 JSON、评分或故意损坏文件。

1. **卡片与编辑。** 进入世界，F5 → 笔记，点 `+` 新建两篇，允许同名。双击标题/正文编辑，单击另一字段应留在原稿；标题 Enter 保存，正文 Enter 换行，Esc 取消。试一次明确“保存”、空白处保存、切页/关闭后返回；改标题后正文和顺序保留。删除先确认，离页返回后重新确认；正常成功不弹“已保存”。
2. **中文与字符。** 用你平时的中文输入法输入一段话，观察组合预览和候选位置；确认/取消候选不能顺便保存/取消整篇。移动光标、上下和 Home/End 应按显示行工作。在空白测试稿试 `é`、`👩🏽‍💻`、`🇨🇳` 的移动和删除；字体缺字也不应拆坏内容。标题达到 80 个完整字符后新增应提示并保留已有尾文。Ctrl+C/X/V 是整段复制/剪切和光标粘贴，Ctrl+Z 不清空。
3. **悬挂阅读。** 悬挂两篇，关闭 F5 后仍显示已保存正文、不显示标题。默认透明背景下文字仍清楚；悬停后用把手拖动、`<`/`>` 每次减/加 5% 背景不透明度，文字不跟随变透明。长文滚轮只滚鼠标下最上面一张，边界也不切热栏。叉号只取消悬挂；再次悬挂重置默认位置和透明背景。
4. **中断与缩放。** 留一份未保存草稿，试失焦、原版聊天或弹层接管、全屏地图/主菜单，再返回笔记。隐藏时不抢输入，会话草稿可继续；拖动中断使用最后有效落点。调整 UI scale/窗口后，F5 字段点击、光标和候选位置一致，便签阅读尺寸独立于 F5 缩放。
5. **重启。** 正常保存并退出，再从同一安装启动，确认内容、顺序、悬挂和落点恢复；不重装。配置开关和 F5 位置也应保留。未提交草稿仅在本次进程中保留，不承诺崩溃恢复。

多人目标是同一客户端本地自用，无服务器笔记、网络同步或其他玩家共享。若有可用的多人世界，补查一次加入 → 编辑/悬挂 → 离开 → 再加入，确认本地内容保留、输入不干扰游戏；没有该场景就回复“多人未测试”，不要据此推断已经全面支持。群系开关/显示保持原单人边界。

数据在游戏目录 `JueMingRData/notes/notes.json`，UTF-8 JSON schema 1，整份文件包含内容与悬挂状态，标题不是文件名。正常保存成功后才改变已保存内容和执行后续动作。读取或保存失败会留稿/保护文件；若提示“磁盘提交结果未确认”，不要继续反复保存，退出后复制保留整个 notes 目录（含 `.bak`、`.tmp`），反馈当时动作。不要自行删整个 `JueMingRData`；安装恢复只撤程序载荷，保留所有配置和笔记。

规模保护：标题 80 个完整编辑字符；单篇正文 1,048,576 UTF-16 单位；最多 1,024 篇；整份编码 16 MiB；单个异常超长组合字符最多 1,024 UTF-16 单位。达到保护边界时整次拒绝新增或保存并说明，不截正文。长文可能短暂显示“正在排版”，待完成后可继续定位和阅读。本轮不导入旧笔记，也不扫描旧目录。

完成后正常退出并回复：哪些流程通过、异常发生在哪一步、IME 名称/当时按键、是否多人测试。安装保留供你使用；本卡不授权合并、关闭 Issue 或正式发布。
