# 保持收藏与快捷物品开发包实测卡

这是包含 G04 修订及全部前序能力的完整开发包，等待你的实测与外部代码审查，不自动合并。请手动启动游戏，用测试角色和测试世界体验；不需要读 JSON 或打分。

1. **开启与收藏**：F5 → 物品，开启“保持收藏”。用便宜物品试背包拖动、拆堆/合堆、装备后取回、切换装备组、垃圾桶取回。收藏堆分出部分放到新格：新堆不自动收藏，原余量保持；整堆搬动和正常合堆仍保持收藏。主动取消后，再移动也不应补回。装备期间不替你打开“装备组共享”。放进箱子、银行/虚空或丢地后，旧保持关系结束；不会替同款新物品加收藏。关闭功能不会清掉现有星标。
2. **添加与绑键**：在“快捷物品”点“添加”，在同自动丢弃的背包图标网格中点选物品，即可加入。每条只有小图标和键位栏；点击图标可更换/设置，悬停小叉删除。两项总开关右侧的键盘图标、每条键位栏是不同动作，均沿原公共小窗双击设置。新安装两项默认关、条目空、未绑键；总开关键只开关，不使用物品。
3. **电话与兼容**：分别建立贝壳电话的家、海洋、地狱、出生点条目，默认“设置后使用”，各绑一键；模式和兼容开关在点击物品图标后的编辑处。只有另一形态也应可用，结束保留目标形态。“同用途替代”可让魔镜条目使用冰雪镜/手机等，不会暗中代用消耗药水；“仅此物品”仍允许该件电话自身切形态。被动指南等默认只设形态。
4. **连续输入与归位**：把魔镜放主包，先选一个快捷栏槽，关闭 F5 后按使用键，持续移动/跳跃；结束应归还原选择。再试使用中按数字键、滚轮，最后应保留你最新的选择。两个快捷键快速交替时，真正忙碌会拒绝新用物，不排队；结束后的新按下可立即执行。再正常使用所选物品，不能卡住或无故多用。
5. **编辑与中断**：试启停、编辑、取消、删除、关闭 F5、聊天和中文输入；录入中不能误用物品。按住使用键不能连发。鼠标正拿着物品时拒绝快捷使用。保存失败应有说明，不会假报删除成功或用旧回调复活条目。
6. **普通多人**：普通客机连接现有服务器，试上述收藏移动、四个电话目的地、快捷使用及连续输入，请留意队友看到的选择/效果。无需服务器安装 R。本地自动检查未代替这一项。
7. **前序能力**：简查查询/箱内定位/快捷宣告、物品自动处理、笔记、信息显示、地图和足迹。不要为测试清空真实数据。

如有异常，告诉我所用物品、目标形态、按键顺序、最后选中槽，以及单人还是普通客机；截图/短视频更便于定位。不要用贵重物品重复制造异常。
