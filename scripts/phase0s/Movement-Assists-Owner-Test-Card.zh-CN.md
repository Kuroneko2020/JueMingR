# 移动辅助体验卡

对应 [任务 #126](https://github.com/Kuroneko2020/JueMingR/issues/126)。先确认本次候选及备份恢复入口；安装状态查 Issue，不凭这张卡推断已换装。自动隔离验证不等于以下所有者体验。

本卡只适用于 Issue 已登记通过必要准入并完成换装的新候选。若 Issue 仍记录交付阻塞，请勿用旧安装验证本批新功能；旧安装不因本卡需要回退。

连续跳跃只重复跳跃操作；装备的移动能力和资源消耗仍由原版决定。

先做启动确认：正常启动当前已安装候选，进入世界，打开再关闭 F5，确认「移动」页三项入口可见，然后正常退出。只需报告能否进入、F5能否开关、能否正常退出；这一步通过后再体验下面的功能。

1. 三行开启/关闭同列，冲刺模式钮在「开启」左侧；首次默认全关，冲刺为「双击」。关闭冲刺时切到「按住」，退出重进仍保持关闭及该模式；再次开启沿用所选模式。两模式配合常用冲刺装备和冲刺坐骑可用，松键停止后续辅助，反向/双键和原生 Dash 正常，切模式后旧半截双击不接续。
2. 安全平地开启连跳：无装备持跳反复落地跳，多段跳、翼、火箭靴、飞毯常用组合按原版顺序与资源接力；较长持跳段不提前截断。松键/关闭停止后续辅助，Down+Jump仍能下穿；资源自然耗尽、落地恢复，飞行坐骑不自动飞行。
3. 两把传送杖分别点合法空位、附近物块内及周围没有合法空位的目标；有合法近邻时合理修正，没有时保持原版失败。混沌代价保留，不要求落地、避敌或无伤。
4. 同时开启原有辅助瞄准和轨迹功能，边连跳/冲刺边移动出手，观察原可用能力和路线仍正常；与相同装备的手动动作比较手感、卡顿和帧时，只报告实际观察。
5. 公共热键录制/切换有短提示；普通F5/背包允许移动，聊天、录键及冲突模态尊重输入隔离。正常开关F5、Alt-Tab返回后合法鼠标键盘继续可用，没有旧动作重放。
6. 正常退出；报告装备/坐骑、按键顺序和实际现象即可。多人、输入法和长期帧率只记录本次真实体验，不由自动检查代签。

若再出现「仅游戏鼠标键盘无响应」，记录最后几步操作、F5/聊天/录键状态、焦点、角色/世界情况及相关日志。此前已发生过松开全部键并单按F5仍无效、重启后无法复现的事件，根因未定；不把本候选输入检查通过称为该根因已修。

有异常先关对应开关并正常退出游戏，再按 Issue 安装回执中的对应入口撤销新候选或退回原01aa安装；单独执行新候选 Restore 不等于恢复旧功能包。不要以强退替代正常保存和退出。
