# 足迹开发包实测卡

这是待验收开发包，尚未合并。请手动启动 Terraria；保留正常角色和世界备份。

1. 用一个测试角色进入测试世界。默认自动录制，F5 → 地图 → 足迹 → 开启后，在大地图查看绿色路线和底部时间轴。
2. 连续走动、转弯、短距离移动、停留，再使用传送和经历死亡/复活；观察路线是否连续、停留是否占时间、传送和复活是否断开。
3. 打开大地图后从最新位置点播放，应从最早开始；拖到中间再播放应接着走。试 1×、10×、60×、300×、1800×，到末端应停止。按“最新”应暂停。
4. F5 配置中关闭录制，继续移动，再打开；关闭期间不应添路线。只关闭足迹显示时，记录应继续。退出并重进同一角色和世界，检查设置与路线保留。
5. 在时间轴上拖动、点右键/中键/侧键、滚轮，不应误建标记、拖地图、发地图信号或触发绑定的鼠标动作；条外原有地图行为应保留。F5、死亡点、地图标记及已有功能仍应可用。

**清除只在专门隔离的合成测试数据上验证。不要对真实角色与世界点击最终清除确认。** 本轮自动检查负责清除的三阶段、失败恢复及文件范围；真实数据无需清除来证明功能。
