# 方向指引、装备提示与游商测试体验卡

本完整开发包包含此前已交付功能。三项新显示默认关闭，快捷键默认未绑定；既有开关、绑定、笔记、名单和历史继续保留。

1. F5 → 地图 → 稀有生物方向 → 开启。有原版生命分析能力、且没有隐藏这条原版信息时，围绕一个稀有目标移动：金色图形箭头应连续指向目标，位于玩家周围圆周，人和目标不动时不自行转圈。屏外显示名字和约距离。选择范围严格小于1300像素，优先稀有度，再看距离。
2. F5 → 杂项 → 游商测试 → 召唤：仅限单人白天、非日食且没有正在入侵或活动旅商。它会尝试生成真实旅商、可能更新商品并影响当前世界，建议使用测试世界。一次点击只尝试一次，失败或未确认不会重试。住房和生成位置由原版处理；它不会改变时间、赶走已有旅商或自动打开方向。
3. 手动打开地图页的旅商方向，走进走出旅商所在画面：画面外出现“旅商／约N格／位置说明”，画面内隐藏。位置优先晶塔附近，其次居民聚居处，再给海岸/地下/地狱/地表线索；不足时写位置未知。晶塔附近不保证可以传送。
4. F5 → 战斗 → 装备提示 → 开启。Boss或指定事件期间，换入再换出工具腰带等固定问题用品：出现“当前装备含非战斗用品”，常亮3秒，随后0.25秒淡出；同风险不周期重发，纠正后立即撤下。单独血月不触发，血月加Boss仍可触发。
5. 同时发生自动丢弃、重铸或普通战斗文字时，装备提醒应继续独立计时并在头顶附近避让。极密文字仍可能重叠，不会为了显示提醒删除其它提示。
6. 可用名称旁的“键”自行绑定三个主开关。重启检查开关和绑定保持；游商测试没有常驻开关或默认快捷键。
7. 可安排时，在普通多人房间检查三个显示。客机和服务器不能执行游商测试。此卡不是已完成多人验收的记录。

无需解锁165帧或整理技术计量；描述看到的异常及当时场景即可。Agent不会自动启动游戏或替你点击召唤。
