# 宝箱、牌子与墓碑：开发候选体验卡

本包包含原有功能和本批三项。F5 → 信息页设置；关掉 F5 不会关掉已开启的世界显示。首次三项关闭、快捷键未绑定，安装保留原有用户数据。无需读 JSON、计时或抓包。

1. **箱名与梳妆台**：在实际遇到的常春藤箱、其它箱型、单个及相邻梳妆台前开启宝箱“始终”。需要原版有效金属探测能力；应显示正确类型名，每件梳妆台一个标签。正常改名、清除名字、拆下或替换后应更新。密集仓库最多同时显示 240 个，屏内优先，再按离角色中心的距离选择；左右走动、新放近箱时名额应重新分配。
2. **始终与开过**：没有探测能力时“始终”暂不画，选择仍保留；“开过”不需要探测器。关闭显示后正常打开一个世界箱，再切“开过”，应能看到当前位置的容器。记录的是本角色在此世界开过的**位置**，同址换箱可继承资格，显示当前名字；私人银行和自动存放不登记。身份不足时会提示仅本次有效。
3. **正文与样式**：牌子、墓碑各可选全部／前几行／前几字，不需要探测器，各最多显示 40 块。全部和前几字最多十个折行后的显示行，超出显示省略号；前几行默认 3（1～10），前几字默认 80（1～1200），只出现当前模式对应的数量行。试一次中英文、空行、长行、颜色或物品图标，修改/清空后不应残留旧文。配置独立颜色和字号，默认 70%，50%～180%；HSL 真实松开或完整六位 HEX 提交，取消草稿不改变其它项。
4. **键位与重启**：行末双击小键盘录入，三项和原十二项共用冲突检查。第一次热键开启宝箱为“开过”、牌墓为“前几行”；以后恢复最后非关闭模式。交替按钮与快捷键，调色/Notes/原版输入时不要串触发，点击不能穿透。正常退出并重启后，已提交模式、样式、数量、键位和可靠身份的开过位置应保留。
5. **可安排时的普通客机**：同服对方无需安装 R。核对正常收到的箱名、牌墓文字和本人开箱记录，换世界不留旧字。客户端尚未收到的名字可能先显示类型名，未收到正文暂不画。本包不主动请求远端箱子/牌子/区段；三种多人拓扑仍待实际体验。

宝箱／牌子／墓碑默认颜色分别为 `#FFA500`、`#E6C16A`、`#FF5555`；恢复样式默认只改当前颜色和字号，不清模式、数量、快捷键或历史。

设置按需写入游戏目录 `JueMingRData/config/features/world-object-text.json`；快捷键沿用 `config/hotkeys.json`；记录在 `records/opened-containers/<pair>.json`。不导入旧 Z 数据，不修改正文、物品、世界或原版键位。加载中和保存中保留本次新事实；遇损坏、未来版本或提交不确定时保护原件并提示，内存已记录不等于磁盘已确认。

原版资源隔离预览、代码和有限成本检查不能证明实际游戏 FPS、Windows/IME 或多人体验。需要恢复时先正常退出游戏，保留包与安装回执，运行本包 `Restore-Phase0S.ps1` 恢复自有程序载荷，再安装保留旧包。程序恢复不会倒回或删除后来新增的用户数据。
