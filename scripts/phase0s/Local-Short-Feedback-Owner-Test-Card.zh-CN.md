# 本地短提示与快捷键反馈实测卡

本候选包含当前主线的完整功能和本批反馈修订；不重置任何配置、绑定或角色数据。实现与工程证据见任务 #101；本卡用于体验确认，不替代工程验证。源码和包身份见同目录 manifest 及本次交付记录。

1. 用您愿意使用的键盘键／鼠标键触发几项开关，观察“功能名 已开启／已关闭”。持续按住应只切一次；两项不同键可分别生效。快速反复切换同一项，只保留最新结果。以原功能实际状态为准，提示不是“已保存”的保证。
2. 回血处于关闭时用热键开启，应显示快速；在 F5 自行选择智能后用热键关闭，应说明智能已关闭。NPC／宝箱／牌子等多模式仍恢复原先选择。
3. 在 F5 点击开关、启动／加载设置时，不增加本批开关提示。聊天／IME、笔记改名、绑定录入以及失焦后重新激活时，不误触、不补播旧结果。原错误提示和快捷宣告聊天保持用途。
4. 在正常视角、倒重力、您常用的游戏／UI 缩放下查看头侧描边文字。关闭原版物品文字或打开全屏地图后触发一个合法开关，应在屏幕上方看到短提示；切换地图不重新延长一轮。候选每条最多约1.8秒、最多4条。
5. 若日常本就使用自动丢弃，观察它仍按实际数量反馈；主动开关结果活动时丢弃文字允许退让，丢弃业务照常。关闭丢弃提示后，开关回执仍可见。无需为本卡丢弃重要物品。
6. 首次引导保持原角色的已看标记，不应因升级重复。若您自行决定使用未见过引导的角色，可检查“按 F5 打开决明R”、可读计时及打开界面后的暂停恢复；无需清除任何标记或创建角色来完成本轮。

请反馈具体功能、操作、最终文字和当时界面状态；不用您执行容量／文件失败／原版槽复用等已由工程夹具验证的异常用例。隐藏全部 UI、字体／绘制设备不可用时存在可见性限制，业务不因此回滚。多人、全部设备与 FPS 未由本卡或隔离图形探针证明。
