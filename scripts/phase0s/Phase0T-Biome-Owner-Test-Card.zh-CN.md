# Phase 0-T 群系显示验证卡

这是只供当前项目所有者在已指定 Terraria 1.4.5.8 Steam 单人环境中验证的临时包，不是正式发布，也不证明多人、其它版本、其它渠道或性能。

这个修复测试只安装一次，然后连续启动并退出 Terraria 两次；两次之间不要重新安装、删除或修改验证文件。

第一次启动：

1. 正常启动 Terraria；主菜单不应出现群系文字。
2. 进入一个普通单人世界，确认画面左侧出现浅绿色 `群系: ...` 一行文字。
3. 走到一个不同区域，确认文字约一秒内自动变化。
4. 返回主菜单，确认群系文字消失；随后正常退出 Terraria。

第二次启动：

1. 不重新安装，直接再次启动 Terraria；主菜单仍不应出现群系文字。
2. 再次进入一个普通单人世界，确认群系文字仍然出现。
3. 走到一个不同区域，确认文字仍能约一秒内自动变化。
4. 返回主菜单，确认群系文字消失；随后正常退出 Terraria。

两次测试中都可以正常打开背包和原版菜单，顺便确认鼠标、键盘和滚轮仍由原版正常处理。不要手工移动、覆盖或删除 Terraria 目录中的验证文件。第二次退出后回复：`修复版双启动测试完成，Terraria 已退出`。

若任意一次 Terraria 无法启动、文字不出现、旧文字跨世界残留、原版 UI/输入异常或显示明显错误，请先退出 Terraria，并说明是第一次还是第二次启动以及看到的现象；不要自行重装或修改验证文件。
