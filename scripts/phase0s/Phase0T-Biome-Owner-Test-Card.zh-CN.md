# Phase 0-T 群系显示验证卡

这是只供当前项目所有者在已指定 Terraria 1.4.5.8 Steam 单人环境中验证的临时包，不是正式发布，也不证明多人、其它版本、其它渠道或性能。

1. 由 Agent 完成安装后，正常启动 Terraria；主菜单不应出现群系文字。
2. 进入一个普通单人世界，确认画面左侧出现浅绿色 `群系: ...` 一行文字。
3. 进入至少一个特殊群系和一个不同高度区域，确认文字约一秒内自动变化，没有重复“神圣”。
4. 正常打开背包和原版菜单，确认鼠标、键盘和滚轮仍由原版正常处理。
5. 返回主菜单，确认群系文字消失；随后正常退出 Terraria。
6. 不要手工移动、覆盖或删除 Terraria 目录中的验证文件。退出后回复：`群系显示测试完成，Terraria 已退出`。

若 Terraria 无法启动、文字不出现、旧文字跨世界残留、原版 UI/输入异常或显示明显错误，请先退出 Terraria，并在回复中描述现象；不要自行重装或修改验证文件。
