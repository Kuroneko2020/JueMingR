# 物品页内联选择：本轮体验检查

这是开发候选，不是正式发布。本轮检查名单界面；存、卖、扔后台业务及单人、Host & Play、普通客机尚未获得实机接受，不因本次 UI 反馈自动通过。三项绑定已撤除，使用页面明确“开启/关闭”。

1. 自行启动 Terraria，F5 → 物品。三行与信息页风格应一致，出售和丢弃名单紧接各自功能行。功能关闭时仍能改名单；先用少量无价值物品检查界面。
2. 点“添加”：候选应在该行下展开，该行“添加”暂时隐藏，收起后恢复。点几项可选中或取消，选中仅显示右上小绿对号；底框变小，物品图标保持原大小；“确定”才添加，零选择时按钮弱态。改点另一行“添加”会放弃原草稿，同页只开一处。×、Esc、切页、关 F5 都取消。
3. 悬停已配置图标看名称和“点击替换”；点击本体直接选替代物，不经过中间窗口，点候选立即替换。右上移除叉号为红色、小巧而略有错落，原来的点击范围保留；鼠标移入应显示移除提示，点击只移除该条规则，不能同时打开替换或误动下一图标。
4. 展开后整理背包或让某类物品离开背包，候选位置和已选状态应保持；新出现的类型关闭重开后出现。收藏物可提供名单类型。**对应功能开启时，确认添加或点选替换会影响已有库存。**
5. 长名单正常滚动；短页主滚动条仍显示全长弱态滑块且不能滚动。展开、切换、收起不反复跳顶；滚动不丢已选项，裁切外图标不可点。F5、笔记输入/中文输入和阅读滚轮正常，关闭选择后旧手势不能点穿游戏。
6. 修改名单后正常退出并重进，名单与开关应恢复。旧绑定按键不再切换功能；遇到未可靠保存提示，报告现象即可，不需要查看或修改 JSON。

回复“通过”，或“现象＋简短复现动作”即可；未检查的项目直接说未测。无需评分，也不用为本轮重跑全部后台或多人业务。
