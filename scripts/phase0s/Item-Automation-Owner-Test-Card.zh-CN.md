# 物品自动处理开发候选：实机测试卡

这是本轮开发候选，不是正式发布。三项默认关闭，首次出售名单为破鞋、海草、锡罐；丢弃名单为空。三项快捷键绑定已按所有者决定撤除，改用页面控制。已做的本地测试不等于单人、Host & Play 或普通客机实机验收。

## 使用

1. 自行启动 Terraria，进入便于检查物品的测试角色与世界。Agent 不代替你启动或操作游戏。
2. F5 → 物品，对照信息页看行面板、文字与按钮密度。三项各点“开启/关闭”，重复点已选项不反向切换；旧绑定按键不再切换三项。F5、笔记编辑/中文输入与阅读滚轮应正常。
3. 出售／丢弃行点击“添加”，可多选，“确定添加”才提交；取消不改名单。名单在对应行下显示紧凑图标，悬停看名称，点图标打开明确的“替换/移除”操作。替换选定即提交，移除在松开按钮时提交。收藏物可提供类型，但实际收藏栈仍受保护。**开启时提交名单会影响已有库存。**
4. 出售需要你已打开有效 NPC 商店。丢弃走垃圾桶，可覆盖其中任何旧物，连续处理后只有最后一项能从垃圾桶取回。请使用能承担这种后果的测试物品。
5. 自动堆叠只在真实地面拾取或正常打开可开物品后尝试附近世界箱子；兼容旧数量可以一起存。直接买入、取箱和只打开开关不产生存放来源。钱币、收藏、手持和正在操作的实际来源受保护。

## 简短反馈

分别在单人、Host & Play、本机加入普通服务器检查以下项目；做不到的拓扑直接说未测。

- 开关、批量添加／取消／替换／移除，退出重进后的保存；旧绑定不起作用，笔记编辑和 F5 输入没有串键。
- 商店开／关时的出售与优先级；同时在两份名单中的物品按出售、丢弃、堆叠顺序处理。
- 普通拾取，以及宝藏袋、匣子和其它可开物品的产物；剩余原物、钥匙、收藏、弹药和快捷栏的实际表现。
- 有兼容物的箱子、满箱、部分容量和范围外的箱子；没有目标时不连续重复操作。
- 垃圾桶只保留最后一项；出售收入及商店能保留的有限回购物品是否合理。
- 多人等待期间手动接收、开包、切物和消费；退出／断线后不补一次、不回写旧背包。

回复“通过／现象＋在哪种模式＋简短复现动作”即可，无需解释 JSON 或计算评分。未知、超时不是成功，相关槽可能保留保护到本次会话结束；不要据此宣称跨断线资源严格守恒。

设置独立保存在游戏目录的 `JueMingRData/config/features/item-automation.json`。读取不可靠时默认关闭并保留原件；明确显示未保存时，本次临时修改不代表磁盘已经保存。开发安装保留既有 Notes、配置和恢复材料。验收后默认保留本次安装，不自行恢复旧候选；本轮不合并、不关闭任务、不打 Tag 或发布 Release。
