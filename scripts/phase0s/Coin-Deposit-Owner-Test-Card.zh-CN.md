# 自动存钱与主动取出保护实测卡

完整开发包包含此前 G01–G05 能力。本包等待实测及外部审查，不代表已合并或发布。

1. F5 → 物品 → 自动存钱，默认关闭。开启后靠近个人银行，观察未收藏钱币是否存入；收藏钱币及鼠标持物应保留。双击公共键位图标可绑定开关。
2. 分别从普通箱、存钱罐、保险箱、护卫熔炉、虚空保险库取钱。尝试取出全部、Shift、左键及连续右键。关箱后钱应留在身上；再捡钱也不应被存走。
3. 在保护期间花光钱，离开所有个人银行范围，再获得钱并返回。自动整理应恢复；从一个银行走进另一个重叠范围不应提前解除。
4. 试空存钱罐（可以含非币物品）与全满账户；空保险箱、熔炉、虚空保险库不提供首次放币。观察界面状态是否与实际相符。
5. 与快捷物品 A/B、钱币枪及现有存卖扔组合使用。普通多人客户端也检查上述关键体验。

只需告诉我们“正常／哪里不对”和复现动作，不必阅读 JSON 或评价数字性能分数。结果未确认时停止该功能并保留当前情况，不要反复开关试图重做。F5 只是界面显示/隐藏，不是诊断导出按钮。

本地隔离验证不能代替物理输入、真实服务器联机、长期存档或 FPS 体验；本轮完成安装后停止，等待所有者反馈。
