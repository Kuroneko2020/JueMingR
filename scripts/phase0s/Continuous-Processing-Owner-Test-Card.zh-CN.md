# 完整开发候选：智能防摔体验卡

这是待所有者体验的 Draft 候选。准确源码、载荷与哈希见包内 manifest；既有完整功能和个人设置继续保留。安装完成后由所有者自行启动游戏，先确认能进入、F5 能打开、正常退出。

1. 在可丢弃角色／世界中开启 **F5 → 移动 → 智能防摔**及对应许可，将三个不同族普通二段跳饰品放合法社交饰品槽，先移开其他救援装备，避免被别的能力代救。
2. 重试原来会摔死的下落，观察临落地真实救援，落稳后社交物品和被临换物回原位；同一自然周期不应靠反复换装无限续次数。
3. 正常落地恢复后再试一次；再按实际使用选一件支持的社交火箭靴、飞毯或被动装备确认穿用换回。报告具体装备、下落场景与异常。

二跳、火箭、飞毯仅在真实临借时有限激活；组合／升级共享族额度，其他原版资源、冷却与传送杖代价仍有效。背包飞骑、抓钩和斜平台原有行为继续保留。本卡不表示真实FPS或好友房主／客机已经通过。出现异常先停止该项体验并保留现象，由本任务继续处理。
