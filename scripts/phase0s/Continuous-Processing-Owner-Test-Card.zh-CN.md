# 完整开发候选：战斗观察、NPC 路径与辅助瞄准

本包包含碰撞显示、共享选敌、NPC 路径与本批有限攻击建模和辅助瞄准，以及此前全部主线能力。准确源码 SHA、完整载荷及哈希见包内 manifest。碰撞、路径、目标标记和辅助瞄准首次默认关闭，旧配置缺少新字段时也关闭；已有配置、绑定、角色、世界与记录保留，不导入旧项目数据。本卡是使用说明和待体验项目，不是实机通过记录，安装后由所有者自行启动游戏。

第一张验收卡只确认能进入游戏、F5能打开、正常退出。完成这三项后，可按以下顺序体验；遇到异常保留现象和步骤即可，不需要反复切换试图恢复。

1. **F5 → 战斗**：“辅助瞄准”是独立开关行，可指定开/关并录入快捷键；开启后才展开设置卡，策略、中心、人偶、目标标记四按钮同排，半径在下一行。名称上可看用途说明，正常开关按钮不重复显示同一说明；短窗口可滚动。辅助瞄准关闭会收起卡片，保留设置与半径，原有路径和目标标记开关偏好仍独立有效。
2. **选敌**：最近优先比较范围中心到敌怪受击区域的距离；清线优先先考虑当前通视，再比距离，遮挡者仍可能参与。玩家中心按视野范围；切鼠标中心后可拖0—50格半径，0只选受击区域触及光标的目标。两模式切换不重置半径，追踪人偶另开。没有 Boss 保护锁定或可破坏物永远优先。
3. **五色碰撞**：蓝=本人/本地可知队友及召唤物/哨兵攻击，绿=敌怪受击身体，黄=专门伤害区域，红=不可击破敌方攻击，紫=可击破攻击。虚线表示有目标/视线条件或近似；颜色不表示命中冷却或服务器确认伤害。范围按实际矩形并集、线、圆、椭圆、扇形或离散点绘制。可观察普通近战、长矛、鞭子、六束棱镜、坐骑冲锋/踩踏、盾冲、着地冲击、狱火环、分节敌怪、爆炸前后，以及猪鲨泡泡/猪龙鱼受击阶段变化。
4. **单目标未来路径**：从当前位置向未来延伸，十字间隔代表约半秒，最长约2秒；瞬移不画跨越连线。默认假设玩家延续当前输入、没有新增击退，特殊机制近似和未知截断有提示。无目标/关闭不残留旧线；关闭一个显示不影响另一个。路径不是历史足迹，更不是命中保证。
5. **实际范围**：已核代表包括眼族、噬魂/黄蜂、蝙蝠周期、秃鹫停栖/起飞、六类地面运动、普通史莱姆跳跃、猪鲨阶段、已知瞬移、普通蠕虫及毁灭者整链和可破坏攻击物。已知斜坡/半砖/平台、四类液体和常见持续伤害按实际规则推进；未识别变体保留具体近似，未知目的地、缺失关联或特殊副作用会在对应阶段截断；不能解释成全 NPC、全武器或服务器未来均精确。
6. **标记与路径组合**：先只开标记，当前目标应有标记而没有未来线；再只开路径、两者一起开、两者一起关。切换目标、敌怪死亡或离开世界后不应留下旧标记。重启后开关保留。先在熟悉的场景观察平台、坡边、水岸和传送带；分节目标标记当前部件，未知阶段允许截断，不代表命中保证。
7. **正常组合**：保持日常连点、快切、链球、左轮、魔法绳、独立转向、工匠受击、报告、工具或钓鱼设置，观察原行为继续。F5 拖动半径、切页、缩放/字体变化或 Escape 后旧按下不应误触游戏；普通浏览不会全局停止其它自动功能。重启后观察开关、子设置和原有绑定应保留。
8. **辅助瞄准与红框**：先用普通枪、弓对静止和移动目标正常攻击，再一起开启路径与辅助瞄准观察红框。红框表示本次可用方案的预计接触位置，不是鼠标输入点、NPC 路径末端或已确认伤害；无可靠接触方案时可以没有红框。关闭路径只关闭该显示，关闭辅助瞄准停止借用输入；切武器、换目标或打开界面后，不应沿用旧方案。辅助瞄准不会替你主动攻击，也不会自动开启独立转向。
9. **随后可选的机制体验**：在熟悉场景分别试天降、持续引导、外星泡泡枪、持枪/光束和悠悠球，观察正常阶段、放手、换武器和障碍变化。导航点与真实接触点可以不同；随机散射、天降及部分特殊攻击使用有据代表方案，不能保证每颗命中。未知环境或有限未来未解出时保留手动输入；已出生的普通弹、原生自导和自然回收继续由原版推进。

隔离原版、图形和工作量检查不等于实机、真实多人、系统 IME、长期 GC 或 FPS 验收。预测基于本机已知状态，本批只按明确机制提供有限求解与真实攻击窗口内的输入辅助，不能解释成全部武器和未来场景均精确。目标标记围绕唯一选中目标当前可受击部件显示，即使没有未来线仍可显示；它不标未来末端、不另选目标，也不要求开启辅助瞄准或攻击。游戏实机体验仍由所有者确认，候选保留安装供体验；PR 仍待所有者接受，不自动合并、发布或卸载。

## 既有连续加工使用说明

完整开发包承接现有功能，三项加工默认关闭、没有默认快捷键。本卡是待实测场景，不是实机通过记录；安装后由你自行启动游戏。你可自行选择当前环境或独立测试角色、世界；先用普通物品验证消费和重铸更便于对照结果。

1. **持续开袋＋物品处理**：F5物品页开启持续开袋，打开背包，按住 Shift＋右键。分别开启自动出售、自动丢弃、自动堆叠，再三项一起开；有商店时保持商店打开，有箱子时让附近箱子已有同类产物。检查按住期间袋子和下游处理持续推进，无固定停顿，松手没有补开。再试无商店、箱满、名单不命中、产物并入已有堆及满背包。
2. **来源与停止**：试黄金锁盒的最后一把钥匙、收藏袋和切换袋种。长按中关闭加工、关背包、失焦或开始拖物，检查停止；手动从箱子取出的同类物品不会因之前开袋而自动堆叠；若在出售/丢弃名单中，手动操作结束后会按名单处理。另试原有库存、取消收藏和重新开启，出售/丢弃应生效，收藏栈保持。
3. **自动提炼**：靠近完整普通/叶绿提炼机，开启后放入泥沙等材料，不需按鼠标。检查实际扣料和产物；移远、拆掉一部分机器、用完再补料，应正确停止/恢复，不误放置方块。中途切武器，应保留你的新选择。叶绿机额外兑换仍用原版手动方式。
4. **自动重铸**：杂项页双击同排输入框，输入完整词缀名，回车或点添加。词缀横排小格居中显示，悬停看全名及右上角删除叉；普通浏览不挡 WASD/空格。空名单不自动重铸，错误/不适用目标有提示。
5. 打开原版哥布林重铸界面、放入测试物品，第一次按住原版重铸按钮就应连续操作；刷到较好但未命中自选名单的词缀也不暂停，每次正常扣费，多个目标任一命中即停，同次长按不会多滚。松手再按可重新操作，已经命中的物品保留一次普通手动重铸。换物、改名单、关界面应终止旧长按。
6. 检查正常与较大缩放、小窗口、长名单滚动、输入法、Esc和失焦；按下删除后改变布局不应误删另一格。重启后开关和名单保留，原有笔记/配置/地图记录仍在。
7. 顺带检查快捷物品、存钱、恢复/增益/护士/家具/收税，以及原版正常手动开袋、提炼和重铸。

自动证据仅覆盖隔离原版程序集与合成数据；真实多人、长期游玩、系统IME、其它设备/字体材质及FPS需要另行实测。出现扣料/付款结果未确认时不要反复开关尝试重放；保留现象及步骤用于核查。候选保留安装，等待你的实测与外部审查，不自动合并、发布或卸载。
