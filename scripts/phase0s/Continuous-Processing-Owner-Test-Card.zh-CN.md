# 完整开发候选：智能防摔体验卡

这是待所有者体验的 Draft 候选。准确源码、载荷与哈希见包内 manifest；既有完整功能和个人设置继续保留。安装完成后由所有者自行启动游戏，先确认能进入、F5 能打开、正常退出。

1. **F5 → 移动**：智能防摔首次关闭。“配置”展开十二项允许／禁用；关主项后保留选择，正常退出重进确认仍在。
2. **熟悉的安全测试场地**：准备可用的防摔装备或道具，感受触底前动作是否够晚、够短；飞行坐骑应仍落上本来能落的平台。
3. **斜向下降与抓钩**：分别感受迎坡、顺坡和快慢钩。及时免摔后穿普通／斜平台、保持挂钩是正确表现；由你手动按跳跃解除。临时物品／热栏归还及模拟连跳都不应替你松钩。
4. **归还与手动接管**：观察临时装备、道具选择、原坐骑和重力回到合适状态；你手动换热栏、装备或配装后，不应被旧恢复扳回。
5. **普通好友联机**：方便时分别以本机房主和客机体验救援与归还，确认对端能看到应同步的动作。连接方式不改变开关资格；自动 CPU／编码证据不代替这项联网体验。
