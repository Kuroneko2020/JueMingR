# 物品浏览器、箱内定位与快捷宣告开发包实测卡

这是等待实测和外部代码审查的完整开发包，尚未合并。请手动启动 Terraria，用有备份的测试角色和世界体验；不需要读 JSON、测帧率或判断内部技术。

1. **查询**：F5 → 查询。留空看全目录，再按中文名、内部名或 `#9` 搜索；试分类、排序和图标左右键。详情中切换获取/用途、资料类别，点材料图标连续追查，再返回/前进。材料的“替代”应显示可任选成员及数量；上下箭头和滚轮查看完整说明。商店按钮只读取当时条件下的分批快照，不代表 NPC 当前在场。
2. **短窗口**：在 1280×720、150% UI 缩放下，试“看目录/看详情”、材料替代页和定位详情；不应需要提高分辨率才能使用。更小窗口有明确提示。
3. **只读点选与查询键**：点“查询键”设置自己的绑定，或点“点选”后先松开鼠标，再点背包物品、空槽和世界目标。应回到查询并显示目标，空槽不穿透到世界；不拿起、丢出或使用物品。Esc/右键取消，聊天、输入中文和打开对话时不应延迟触发。
4. **箱内定位**：底部独立输入名称或 ID，可选精确候选，也可用物品详情的“定位”；浏览区与输入之间应有细分隔线。试附近普通箱、梳妆台与其它真实容器；成功后关闭查询，绿色框上只显示“N个”。先按 F5 重开并点“清除”，确认高亮消失且 F5 仍可开关，再试继续浏览、再次定位。完整箱名、每种物品、槽数与总量在定位详情查看；打开任意普通箱或离开世界后也应撤销。宽泛名称匹配超过 24 种应要求缩小范围。
5. **普通多人客户端**：由普通客户端连接正常服务器，先在已正常接收的附近区块测试定位。结果必须标明“最近接收的数据”；尚未收齐的库存应明确未知，不能冒充空箱或新鲜服务器库存。无需管理员或服务器插件，不能通过自动开箱“刷新”。请说明是否从未打开过目标箱，以及结果与队友看到的内容是否一致。
6. **快捷宣告**：F5 → 地图，左侧框显示触发键，双击设置；开关右侧键盘图标双击设置功能开关键。试把两者设为相同组合，应提示冲突；不同组合应分别执行开关与发送。开启并关闭 F5 后，对背包物品/空槽、玩家、NPC、掉落物、种植中的草药、展示框物品、可见方块、液体和线路试一次按键；物品应为“这里有 x 个 xxx”，不可见、空气及本地“宣告冷却ing”提示沿用旧版。普通背包悬浮可用，文字输入、聊天、NPC 对话、大地图和点选期间不触发。首次指向家具可能短暂准备对应资料，移动指针可取消。单人查看本地聊天，多人请队友确认实际收到内容；正常发送不额外刷成功提示。空气提示更慢；重启后应保留开启状态及两个独立绑定。
7. **前序能力**：简查 F5 物品自动处理、Notes、已有快捷键，信息页及位置/颜色，方向与装备提示，地图标记/探索/死亡点以及足迹时间轴仍可用。不要对真实记录执行删除、清除，也不必用贵重物品制造异常。

查询资料是只读信息，不生成物品、不自动制作、购买、取货或微光。当前普通配方与 NPC 声明掉落来自原版；部分开包、钓鱼和世界资料是有限收录的线索，各分类会说明缺口，缺少记录不表示没有来源。

本轮反馈修复请优先复查：

- 展示框、武器架、物品瓶分别试空置和放入物品；有内容应同时报“放在xx的xx”，空置应报家具。人体模型、帽架、餐盘也按同样规则显示实际内容；尚未收到内容的客户端应说明未确认。
- 向日葵上、下各格和物品瓶左右可见边缘；再试不同挂向展示框、不同款式物品瓶、开关前后的有色火把或灯具，不能把同物件不同格当成其他物品。
- 将两种便宜物品放在同一位置，应该一条宣告合计为“这里有x个xxx和y个yyy”；数量取鼠标命中掉落周围一格，不包含更远物品。
- 顶部先搜索并改分类/排序，底部输入定位并出现候选。点“清除”后，两个输入框、候选和高亮都清空，恢复全部物品的初始图标目录；“返回”可找回此前浏览内容，定位不会复活。正常开箱或标记超时只撤标记，不替你清查询。

请按步骤回报“正常”或具体差异，附相关截图即可。包保留安装等待反馈与外审，不自动合并、发布或开始下一组。
