# 五项附近目标：开发候选实机卡

本包包含已有 F5、Notes、物品自动处理、公共快捷键、三项显名及本批五项附近目标。首次五项全部关闭、快捷键未绑定，安装保留全部现有用户数据。无需看 JSON 或抓包。

1. F5 → 信息页：开启实际遇到的生命水晶、生命果、世界魔力水晶、睡眠碎岩龟或巨型龙蛋。龙蛋指能开出疾旋鼬的世界蛋。具备原版有效金属探测能力时显示；暂时没有能力仍能设置开关/颜色/快捷键，恢复能力后按原选择显示。关闭F5不关闭功能。
2. 每件应有三个实心粗箭头，约7秒顺时针一圈、2.7秒上下浮动一轮、振幅6世界像素（上下总行程12px），浮动后仍指向固定中心。箭头比首包大约三分之一，环绕距离收近约4～5.5px；相邻目标各有稳定错开的相位，转完一圈时浮动不会回到原相位。观察相邻两件是否各有一组、大蛋箭头是否压住主体；合法取走、唤醒或打开后不应留下旧标记。按实际遇到的目标验证，不必一次找齐极端场景。
3. 每行“配置”只调该项颜色，没有字号。HSL拖动预览，真实松开生效；完整六位HEX自动生效；切窗/失焦取消未提交草稿。“恢复默认”只恢复本项颜色，不关闭、不清绑定、不改其它七个颜色目标及显名字号。正常重启后已提交的颜色应保留。
4. 行末双击小键盘录入。五项与原七项共用绑定；内部重复拒绝，原版冲突允许提示后保存。交替用按钮和新旧快捷键，调色HEX及Notes输入时不要串触发；拖动不应穿透世界。可安排时补一次普通多人客机，移动/缩放或换世界后不留旧标记。

默认颜色：生命水晶 #FF69B4，生命果 #7CFC00，魔力水晶 #66CCFF，碎岩龟 #FFC460，巨型龙蛋 #9370DB。普通设置按需存到游戏目录下 `JueMingRData/config/features/world-targets.json`；键位沿用 `config/hotkeys.json`。不导入旧Z坐标，不采集/挖掘/开蛋/唤醒或改变世界。

本次调整已通过实际XNA箭头绘制与后续UI/资源检查，并查看了选定原版贴图的多个动画时刻；隔离预览不是实际游玩。当前参数的游戏内观感、Windows/IME、材质与多人体验仍由所有者验收，本地检查不证明FPS收益。

需要恢复时正常退出游戏并保留本包/安装回执，按同包 `Restore-Phase0S.ps1` 的精确归属恢复自有载荷，再使用保留旧包安装；不手动删EXE或用户数据。项目代码/文档由AI协作生成，产品决定与实机接受由所有者负责；这是开发候选，不是正式发布。
