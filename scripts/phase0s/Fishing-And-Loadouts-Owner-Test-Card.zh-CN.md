# 钓鱼、过滤、配装与快捷改名体验说明

对应 G10 [#107](https://github.com/Kuroneko2020/JueMingR/issues/107)。这是当前完整开发候选的操作说明，既有功能和数据目录继续保留；具体二进制身份以包内 manifest 为准。自动检查不代表所有者已接受，也不代表真实多人、系统 IME、云同步或 FPS 已验证。

1. F5 **信息**页可分别开启完整鱼获、过滤鱼获，并独立改颜色、字号。手动抛竿入水后显示当前条件候选；它不是概率或本次必得清单。没有声呐时，过滤提示会说明实际条件。
2. F5 **钓鱼**页先开启自动钓鱼，再手动抛第一竿。它沿原钓点收竿、重抛；自己换物、掉血等会结束本次循环。切杆跳过仅对过滤拒绝的鱼获工作，临时切槽后回竿，保持原钓鱼会话和装备借用；不开切杆时等待其自然逃脱。头顶会显示开始/停止提示；松露虫使用“开始鲨猪／鲨猪啦！”等旧提示，后者不代表确认 Boss 生成。
3. 名单题头统一显示“当前过滤模式：”及模式、匹配方式两个切换按钮。模式循环白名单、黑名单、关闭过滤，**此处没有快捷键绑定**；匹配方式仍叫精确匹配/关键词，四种作用域各自保存。关闭过滤时名单操作灰显。特殊规则“要／不要”忽略名单，即使名单为空也生效；实际过滤仍需要声呐。添加当前和 ＋ 搜索可多选；小叉删除、清空、保存预设和预设列表只作用于当前名单。精确条目宽度足够时一行三项，三个特殊规则按钮等宽。二级窗口按内容收缩，点主 F5 可关闭且不会顺带执行底层按钮；预设直接显示可换行图标或关键词胶囊。
4. 自动存放鱼的“所有”处理本次自动钓获类型的合格同类库存；“任务鱼”检查今日未完成的当前任务鱼。附近要有已存同类物品的原版世界箱。收藏、手动拿回或在途物品受保护；自动卖出、丢弃仍优先。
5. 自动换装选择原版装备组；自动配装从身上/时装、背包、当前可用虚空袋选渔具，两者互斥。普通 F5 浏览时也可应用，按住鼠标、输入文字、开箱或鼠标拿物等仍会等待；松露虫不自动换装/配装。结束后尝试归还，正常归还不再发橙色提示。成堆渔具需要同容器安全空格来拆出一件，归还后可以保留为独立单件。自己更改受控装备、收藏或共享时，新的操作优先；待归还或上一会话未归还的说明可在钓鱼页查看。
6. 快捷改名仅单人可用：直接点按钮让末尾数字加一；双击名字框可编辑，确定/回车走原版保存，Escape 取消草稿。名字最终最多 20 个 .NET 字符；确认成功后在玩家头顶提示，失败或部分结果仍在菜单说明。无需编辑配置、接触实际角色文件或清除记录。
7. 五个自动功能和两个鱼获显示的键盘图标可双击录入快捷键，默认空。长按只切一次，松开再按切回；存鱼恢复上次模式，换装/配装继续互斥。可保留日常自动捕捉、恢复、快捷物品等，观察借网后是否只补抛一次并继续钓鱼。

反馈时说明使用模式、手中工具、当时是否开界面及实际现象即可。无需人为损坏数据、连接特殊服务器或进行长时间压力测试。Issue 与 Draft PR 保持开放，等待所有者实际体验后决定接受。
