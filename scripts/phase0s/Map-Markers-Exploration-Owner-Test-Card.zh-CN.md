# 地图标记与揭示区域统计 · 实测卡

这是 #85 的完整开发候选，包含此前已接受功能。默认关闭地图标记与动态统计；地图标记快捷键默认未绑定。安装后保留现有设置、笔记、死亡记录和其它用户资料。完成以下观察后，用普通文字告诉我结果即可，不需要解读 JSON 或打分。

## 标记

1. 正常启动游戏进入常玩的角色和世界，按 F5 到地图页，打开地图标记。打开全屏地图，在容易辨认的位置右键，选择一种图标。对照选点是否准确，试一次地图边缘、非整数缩放和平移后立即点击。
2. 依次看看八种图标；取消一次选择，确认没有新增。试长按右键，确认不会连续新建。检查原版拖图、ping、玩家图标和已开启的死亡点及悬停文字仍可使用。
3. 在 F5 的标记管理中双击名称，输入中文和组合字符。名称最多 10 个完整字符；Enter 先确认输入法，再次独立按 Enter 保存，Esc 取消草稿。试翻页、关闭和定位，确认保存完成后才执行。
4. 定位应只移动地图视角，不移动角色；有效缩放应保留。试删除并取消确认，再确认删除；切换世界后不能出现另一世界的标记。
5. 正常退出再进入，核对图标、位置、名称仍在。需要快捷键时，通过现有公共快捷键窗口绑定地图标记；检查全屏地图里按键可以关闭选择器及标记。

## 揭示区域统计

1. 新世界会话使用性能模式。没有完整结果时会显示“统计中…”，完整扫描进度与揭示比例是两件事。性能模式小世界约 1.4 分钟、大世界约 5.6 分钟；快速模式约 3～11 秒（按每秒 60 次更新、无暂停和竞争估计）。
2. 在详情中切换快速模式，暂停、继续，再重新统计。确认暂停不被切换模式或动态开关偷偷解除；同一会话关闭 F5/地图再开不会重置模式。
3. 开启动态后正常去一片未揭示区域，再停止移动等待追赶。应从“更新中”回到“当前揭示”，不会因为只是走动就反复增加。探索比例很小时，两位小数暂时不变是正常的。
4. 有可靠结果后手动重新统计并暂停，在动态仍开启时继续探索，动态结果应继续更新。首次完整扫描尚未结束时不应冒称已有完整比例。
5. 关闭动态后继续探索，显示保留“上次统计”；重新开启应重建，不能直接把历史结果当实时值。重进世界重新从性能模式开始，动态开关按已保存偏好恢复。
6. 如方便，再观察普通多人客机的本地地图。此候选没有新增网络请求；多人正确性仍需实际观察，当前未宣称实机多人通过。
