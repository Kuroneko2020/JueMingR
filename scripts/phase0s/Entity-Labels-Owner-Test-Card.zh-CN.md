# 敌怪、动物与 NPC 显名：开发候选实机卡

此包包含原有 F5、Notes、物品自动处理、公共快捷键和本批三项显名，等待所有者实机接受。三项首次默认关闭、快捷键未绑定；保留旧设置和全部用户数据。无需查看 JSON、抓包或给分数。

## 1. 看显示

F5 → 信息页前三行：分别开启敌怪、动物和 NPC。敌怪显示名称和当前/最大生命；动物一行名称，金色动物保持金色；NPC 可选“名字”或“类型”。分别开和一起开，确认没有重复或串色。多段敌怪只用可靠主体生命，不把身体相加；特殊对象按实际遇到的场景反馈即可。

## 2. 调颜色和字号

点对应行“配置”，标题应明确当前目标。HSL 拖动只预览小窗，鼠标真实松开才使世界颜色生效；拖动时按 Esc 取消这次编辑。HEX 首次输入替换原色码，完整六位自动生效；不足六位 Enter 留下提示，Esc 取消未提交草稿。外部 # 不属于六位正文。字号 −/+ 每次变化 0.10，范围 0.50–1.80；敌怪生命字小 0.13，最低 0.50。“恢复默认”只影响当前项颜色与字号。

交替调整三项、切页、关 F5、切出游戏再回来。未提交草稿不应复活；已经提交的值不应被取消。正常退出并重启后检查设置保留。若提示配置受保护、保存冲突或结果未确认，请保留文件和恢复材料并反馈，不手工改文件。

## 3. 快捷键和输入

行末双击小键盘，沿用同一个公共绑定窗。新三项和旧四项共同检查重复；原版重合仅提醒。敌怪/动物切换开关；NPC 关闭后恢复最后一次“名字/类型”，首次恢复“名字”。按钮和快捷键交替使用应一致，恢复样式不清绑定。

调色字段输入、滑条拖动或快捷键录入时，不应触发游戏按键、背包物品或下层按钮。样式窗和绑定窗互斥。旧四项无需重录，只做一次开关与 Notes 文本输入的针对性回归，不必重测全部物品交易。

## 4. 相机和生命周期

移动相机、调整游戏/UI缩放，观察长名字和两行间距。死亡后只要世界仍有效，显名继续；复活、换世界或断线不应留下旧标签。可安排时补一次多人客机。特殊多段敌怪无需一次搜齐。

本候选在交付环境中未能创建 XNA 图形设备；实际预览未查看，真实绘制外观、Windows IME 与多人场景仍待实机。隔离 Host/输入/存储证据不能代替上述接受。发现问题请描述哪组、哪一步及现象，必要时附图。

普通显名偏好由程序按需保存到游戏目录下 `JueMingRData/config/features/entity-labels.json`；键位仍在公共 `config/hotkeys.json`，安装不会预写或导入旧数据。

需恢复时先正常退出游戏，保留本包和安装回执，使用同包 `Restore-Phase0S.ps1` 按对应回执恢复自有载荷；不会回退或删除 `JueMingRData`。不要手动删游戏 EXE 或用户文件。
