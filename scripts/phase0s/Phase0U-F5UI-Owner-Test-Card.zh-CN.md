# Phase 0-U F5 视觉修正版测试卡

这是 Terraria 1.4.5.8 Steam 单人临时测试包。自动和静态检查不能证明实机体验通过。Agent 安装后不会启动或操作 Terraria，请你亲自测试。

收到“测试包已安装”通知后开始。只安装一次，正常启动并退出游戏两次；两次之间不要重新安装或修改验证文件。F5 只负责打开和关闭窗口。

## 第一次启动

1. 进入单人世界，按 F5 打开窗口，再按一次关闭。按住 F5 不应连续开关。默认进入“信息”，顶部两行分类始终可见。
2. 先使用默认原版材质：窗口、内容和按钮应保持协调的原版色调，无大面积异常白底；标题没有独立底框，外缘轻微圆角，十二个页签都有对应图标，滚动条细且端头圆润。文字和按钮组应居中、清晰，不重影、不裁字。
3. 窗口和鼠标提示中都不应显示“结构占位”“未接入”、示例或开发说明，普通功能行不留空白第二行。目前仅“群系显示”可实际操作，其它控件只展示外形，不能执行业务；没有内容的分类保持空白。关闭群系显示后画面上的群系文字应消失，重新开启应恢复。
4. **点击**：鼠标从窗外直接移入按钮、空白和非交互控件，分别点击左右键。窗口下面不能攻击、使用物品或放置。窗内按住，移到窗外再松开；也试一次按住时用 F5 关窗，都不能补出世界操作。松开后重新在窗外点击应正常。
5. **滚动**：滚轮与拖动细滑块应能到达长页最后一行，顶部和底部夹紧；窗口内滚轮不能改变快捷栏，短页也一样。滑块仍应容易抓取，旁边按钮不能误变成滑块抓取区。
6. **纯悬停**：鼠标停在覆盖 NPC/生物和掉落物的窗口内，下层名称、旧气泡和交互提示不能出现或残留；移出或关窗后提示应恢复，正常光标保留。
7. 拖动标题，确认绘制与点击位置一致，释放不会卡住；缩小游戏窗口高度，内容视口应缩短且仍能滚动，被裁掉的控件不能点击。检查设置、背包和大地图仍正常，再返回主菜单并正常退出。

## 第二次启动

1. 不重新安装，直接再次启动并进入单人世界。重新检查 F5、真实群系开关，以及点击、滚轮、纯悬停三项。
2. 启用你实际使用的第三方材质/字体包，检查皮肤仍跟随、颜色没有被强制变成原版紫蓝或黑色；按钮、图标和文字位置仍正确。检查常用和较高 UI 缩放，留意裁字、重影和旧字体定位。再切回原版查看是否正常。没有覆盖的项目回复“未测试”。
3. 留意窗口静止、拖动和滚动时是否明显卡顿。关闭 F5 后确认原版输入正常，再返回主菜单并正常退出。

如果无法启动、输入卡住或明显异常，请退出游戏，说明第几次启动、哪一步及看到的现象。无需查看日志或 JSON，不要自行重装或删除验证文件。
