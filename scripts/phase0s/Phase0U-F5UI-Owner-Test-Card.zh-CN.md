# Phase 0-U F5 界面测试卡

这是 Terraria 1.4.5.8 Steam 单人临时测试包。自动和静态检查不能证明实机体验通过。Agent 安装后不会启动或操作 Terraria，请你亲自测试。

收到“测试包已安装”通知后开始。只安装一次，正常启动并退出游戏两次；两次之间不要重新安装或修改验证文件。F5 只负责打开和关闭窗口。

## 第一次启动

1. 进入单人世界，按 F5 打开窗口，再按一次关闭。按住 F5 不应连续开关。默认进入“信息”，顶部两行分类始终可见。
2. 在“信息”页关闭“群系显示”，画面上的群系文字应消失；重新开启应恢复。走到不同区域，文字应随后更新。其它页面只有明确的“未接入”占位，不能执行业务。
3. **点击**：鼠标从窗外直接移入按钮、空白、禁用控件和占位内容，分别点击左右键。窗口下面不能攻击、使用物品或放置。窗内按住，移到窗外再松开；也试一次按住时用 F5 关窗，都不能补出世界操作。松开后重新在窗外点击应正常。
4. **滚轮**：鼠标直接移入窗口后滚动，快捷栏选中格不能变化。短页、长页顶部和底部也一样。移出窗口后正常滚轮应恢复，不能补出旧滚动。
5. **纯悬停**：先在窗外指向 NPC/生物或地上掉落物，看见名称或交互提示；再打开或拖动窗口盖住它，松开所有按键，把鼠标停在重叠位置。下层名称、旧聊天气泡和交互提示不能出现或残留。分别检查 NPC 与掉落物；移出或关窗后提示应恢复，正常光标始终保留。如果当前世界恰有可右键解救的特殊 NPC，也在窗口覆盖处检查右键不会触发；没有就回复“特殊交互未测”。
6. 拖动标题栏，确认文字、按钮与点击位置对齐；拖到窗外后释放不能卡住。长页应能滚到最后，被裁掉的内容不能点击。切换到其它应用再回来，拖动不应残留。
7. 打开全屏地图、游戏选项或相机模式，F5 应关闭，原版界面的点击和滚轮应正常。关闭这些界面后应能重新按 F5 打开窗口；F11 隐藏界面时也不能留下一个看不见却吞鼠标的窗口。
8. 返回主菜单，窗口与群系文字应消失；正常退出 Terraria。

## 第二次启动

1. 不重新安装，直接再次启动并进入单人世界。重新检查 F5、真实群系开关，以及点击、滚轮、纯悬停三项。
2. 检查常用 UI 缩放和较高的 125%/150%；再启用一个你实际使用的界面或字体材质包，重复拖动、滚动和点击，留意裁字、重叠、旧字体定位或状态文字看不清。没有合适的包可回复“材质字体未测”。
3. 留意窗口静止、拖动和滚动时是否明显卡顿。关闭 F5 后确认原版输入正常，再返回主菜单并正常退出。

如果无法启动、输入卡住或明显异常，请退出游戏，说明第几次启动、哪一步及看到的现象。无需查看日志或 JSON，不要自行重装或删除验证文件。
