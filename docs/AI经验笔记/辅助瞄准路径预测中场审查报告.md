## 3. 当前真正采用的计算链

实际普通入口是 `HostCombatObservation.Update` 读真实输入并由原 `CombatSelection.Update` 选敌 → `NpcPredictionSource.Prepare` 采样当前所选实例、必要关联及玩家/环境 → 普通目标由 `RollingNpcPrediction.Prepare` 的有界纯值模型计算 → 同一个 `NpcPredictionCache.Publish` 发布 → 原 `CombatObservationWorldLayer.Prepare/Draw` 消费并绘制。已接入工作区默认生产入口，不只是独立模型；未进入安装包。13个已核多部位蠕虫族先走保留的 `SegmentedNpcPrediction` 近趋势；没有第二批武器求解、虚拟鼠标或输入接管。

普通目标采样真实位置/速度/旧速度、ai/local状态、方向、生命/再生/buff、重力和液体状态、碰撞尺寸、目标玩家及世界标志。玩家使用当前输入、速度、重力、跳跃/坐骑状态的条件延续；复杂玩家状态标近似。已有史莱姆、地面/飞行/眼族/关联运动等模型保留，新增/补齐Derpling177、GiantTortoise153运动阶段及176飞行运动近似。按模型和真实相位处理转向、起跳、陆龟缩壳/准备/发射、重力/落地及液体；陆龟前方4×5支撑查询有/无/未知分开。**黄蜂使用NpcMotion.Flying运动近似，不推进完整射击时钟或未来弹幕；已接通的是攻击期运动预测可用性。** 发生击退后，下一实际更新重新读真实位置与速度，不能把未来未发生攻击预先写入模拟。

未专门适配的合法目标走有边界的趋势模型：可从连续两份真实观察估计小幅加速度/转向，在前8/12步衰减，后续仍执行重力/地形接触，而非统一12点截止或补直线凑120。未知阶段、随机目的地、不可解释buff、缺地形等仍可能截断。已附着但未完整建模的伤害效果会标条件；死亡/资格严格判定，不能用高life替代。它只能提供有参考价值的条件预测，不能宣称每种合法NPC都精确预测两秒。

每次实际观察都从当前起点重新计算未来，最多120步；point0是实际当前点，不算未来步数，121点才含120未来更新。采样/捕获tick与生成tick在同步普通路线同次更新；旧轨迹是不可变副本。上一观察只用于有条件估计趋势，不把旧数值轨迹平移/重标时间。`RollingConditional` 明确禁止 `Republish`。纯模型测试仍能调用Cache旧 `PrepareCore` 的等输入复用/补尾，显式精确后端仍有窗口对齐；它们不应被误写为所有代码已删除，也不控制当前普通默认发布。

普通默认构造 `exactComparison=false`，`Native=null`。隔离原版后端是**仅显式精确对照保留**，不是普通主链或按需增强；普通预测不等Ready、单在途、缺页、History或失败回复。旧完整背景AI推进、出生/命中票据、alignment/history键和worker只在该对照有真实消费者；普通默认预测专用安装/请求/History/背景推进为0。共享Projectile Damage/AI/Kill碰撞观察、玩家事件、NPC重置/网络更新仍由碰撞/G11A等实际职责使用；不能宣称全部Hook为0。选敌仍扫描活动NPC，必要玩家/环境仍有活动玩家扫描；关系链最多200对象、几何最多4096单元。这些同步主线程成本没有消失。

发布只有Source所拥有的共享Cache。必要关联运动与 `realLife` 生命owner按真实关系采样，owner只作必要健康/关系计算，不把全部无关背景NPC推进。普通非致命受击不先撤掉结果等回包，而是下一真实采样重算。切目标/同槽换代核完整session/token/slot/generation/type/netID；相关NPC重置或必要玩家瞬移退休旧输入并增epoch，死亡/失活/不可受击不发布；世界退出清Source/Cache/需求/选择/几何。共享入口FailClosed仍整体停用，未因新路线放宽硬安全。
