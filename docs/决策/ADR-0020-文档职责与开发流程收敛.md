- 状态：Proposed；整理方向、本分支实施及正常提交推送已获授权，本轮文档核对、集中独审与主整体判断已完成；最终接受与合并仍待，尚未合入 `main`

## 原因与取舍

同一要求在入口、规范、阶段和历史补充中多点复制，过期状态继续进入启动路径；功能个案成为通用测试义务，身份和资格手续又比撤销多余工作更具体。既有任务的长耗时不仅来自独审，还涉及验证、夹具及等待设施反复修补。网页起草的耦合目标和证明负担也需受约束。此判断依据本次材料，不声称所有长任务同因，也不推断模型心理。

在既有目录原位归并正文，并按必要性、判别力、相称性和收敛性选择工作。代价是负责人必须判断真实影响及证据缺口，不能仅照大组执行；真实关键缺陷仍阻塞依赖交付，停止扩张不等于补签 PASS。规则变化不证明耗时已经降低，也不改变现有工具行为。

## 有限替代与现行落点

1. 文档的职责、维护与退出统一由[文档治理](../规范/文档治理规则.md#二文档类型与生命周期)承担；根 README、AGENTS、文档入口和两类索引归回导航职责，阶段资料只保留必要恢复与历史证据。
2. [工程规则](../规范/工程治理规则.md#职责落点与最小合理范围)明确同因完整修复不等于穷举运行；[风险等级](../规范/工程治理规则.md#风险等级)允许依据新证据撤销高估的责任；[集中审查](../规范/工程治理规则.md#持续实施与集中独审)允许固定稳定差异的独审与慢验证并行，最终结论仍综合必要证据。
3. [测试成本与停止](../规范/测试与审计规则.md#十二时间和成本边界)归并继续、补验与结束的判据；替代普通设施修正一律补完整矩阵、临时隔离一律新建 Issue，以及工具拒绝自动推导业务全跑的要求。[证据原则](../规范/测试与审计规则.md#十四原始证据与正式结论)与[工具格式](../设计/可重复构建与项目骨架.md#普通完整与本人待测候选)分开。
4. 辅助瞄准的动作前冻结、消费分母、缓存和地形租约等判据原义归入[战斗设计](../设计/战斗辅助实现设计.md#辅助瞄准验证与隔离边界)，不重新裁决产品合同。
5. [Codex+GPT 指定配置](../规范/工程治理规则.md#codex-平台使用-gpt-时的执行配置)完整保留并成为唯一现行正文；其他平台暂不规定型号、档位或主子拓扑。ADR-0019 的 High／Max 历史保留，ADR-0018／0019 的实际合并、有限授权与原提案未整体 Accepted 分别说明。
6. [网页约定](../网页Chat协作约定.md#4-开发-prompt-的起草与交付前核对)只维护起草与只读复审的独有责任，区分用户结果、必要约束、技术建议和代表验证，不成为第二套本地制度。

未被上述条款替代的产品、权限、数据、安装、安全、证据真实性和真实独立审查要求保持。本次不接受其他 Proposed，不修改蓝图、测试夹具或构建脚本，不定位28项零复用，不补原蓝图验收。

## 生效与撤销边界

授权本分支实施不等于所有新语义已最终接受，文件进入主线也须有未来明确合并授权。本轮以文档集中审核及原分支推送、原任务事实回写结束，不把机械最终化或再次完整独审另作本轮门。已合并旧有限决定不因本 ADR 为 Proposed 失效。

规则正文只在上述责任位置维护，此 ADR 不复制第二套执行制度。调整可通过普通文档 PR 撤销或修订，不新增工具、长期角色、总账或全局配置；所有者不参与日常技术操作时仍按既有职责推进。
