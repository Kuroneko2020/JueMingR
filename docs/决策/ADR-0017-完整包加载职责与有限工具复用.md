# ADR-0017：完整包加载职责与有限工具复用

- 状态：Accepted；当前已审有限语义已获所有者接受，自 PR #113 合并进入 `main` 后长期生效。
- 对应任务：[#112](https://github.com/Kuroneko2020/JueMingR/issues/112)，[PR #113](https://github.com/Kuroneko2020/JueMingR/pull/113)。
- 2026-10-09 补充即时授权：#112 开发工具减负与 H10 修复（DT01—08）；专项共享准备、实际依赖选组/投影、正常过期分离、受控读租约、显式受限工作区、正式入口收束及集中增量独审。该有限补充已获所有者接受，按上述合并生效边界执行，不改安装/发布及用户数据语义。
- 本轮执行依据：2026-10-02 所有者明确允许先准备受控真实加载候选、复用原包、有限修正测试职责与入口；该即时授权不以本 ADR 先合并为前提。

## 原因

已有分层证据、按影响选组和复用规则足够表达证明义务。问题在实际工具绑定：早期合成 Terraria 已不足以承载当前完整 Runtime；同时核验既有 ZIP 没有独立正式入口，包构建入口要求当前 HEAD 对应的构建。夹具缺型不证明真实受支持游戏缺型，逐功能扩建整套替身也不是合适的维护方向。

<a id="有限决定候选"></a>

## 有限决定

1. 纯逻辑、真实宿主边界、完整包正常加载、所有者体验分别承担证明；保留合理窄替身。当前不兼容的完整合成接收器保留失败及显式历史入口，完整加载职责移至正常原版初始化和本人启动。
2. 身份、隔离、恢复与必要工程证据满足后，可以准备真实加载待测候选；“准备真人加载”不以“真人加载已经通过”为循环前提。无法隔离则停止相关部署，不自动改主安装。真实失败与未验证均不得提升为通过。
3. 已有工件按其原构建身份核验。测试工具或文档改变不自行重包；产品／包内安装资产改变时才生成新身份、新目录，并验证相应影响。正式发行门不变。
4. 仅为职责已经证明独立的核验工具增加精确选组和证据投影；完整输入和原执行身份保留。共享分派器、初始化、断言、构建和运行条件变化继续使实际消费者失效。审查覆盖实际增量与传播，既有有效审查不因窄修全部作废。

5. 专项与局部反馈不承担无依据的累计重跑；最终候选完整相关覆盖不变。构建身份与行为适用性分离，同阶段只读材料复用，必要边界重新校验。已授权非可执行外来资产按精确路径/内容保持 dirty、非发布资格，RequireClean 严格语义不变；正式唯一实现取代活跃私人完整副本，旧证据保留。

## 实际落点与保留边界

规则见[测试与审计](../规范/测试与审计规则.md#完整包验证职责候选)，入口见[构建设计](../设计/可重复构建与项目骨架.md#已有包独立核验入口)，职责投影见[工作量设计](../设计/高频路径工作量回归.md#独立包核验工具的有限投影)。不新增框架、运行依赖、通用分析器或审查角色；普通实施者负责检查与维护，独立审查核对语义和工程结果。

ADR-0006、0011、0016 的其余边界及原始接受记录保持。此有限决定只限定工具绑定，不降低证明义务，不授权未来功能、真实游戏自动操作、合并或发布。可通过普通提交撤销入口与该有限决定，不改写历史工件和失败。当前已审语义经独立审查，所有者已接受并授权状态最终化及窄复核后的普通合并；只有合入 `main` 后才能称长期生效，本次授权不适用于未来任务。
