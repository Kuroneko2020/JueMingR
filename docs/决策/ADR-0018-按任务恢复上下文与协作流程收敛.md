# ADR-0018：按任务恢复上下文与协作流程收敛

- 状态：Proposed，未生效
- 日期：2026-10-10
- 对应任务：[#116](https://github.com/Kuroneko2020/JueMingR/issues/116)
- 生效门：按[工程规则的正式化闭环](../规范/工程治理规则.md#九长期规则与-adr-的正式化闭环)独立审查、所有者接受与授权、机械最终化及窄复核，合并进入 `main` 后才生效。本次起草授权不是对最终措辞的接受。

## 问题与既有基础

入口混入多轮历史交付和安装身份，统一全文冷启动又使已明确的小修、只读核对重复恢复无关背景。工程规则已有单工作区、持续实施、集中独审、窄复审及技能冲突边界，测试规则已有按影响验证与证据复用；这些有效要求需要归回责任位置，不再由每个入口重复叙述。

历史批准、证据和限制继续由原 Issue/PR、ADR、Git、专题设计和经验承担。既有[辅助瞄准阶段文档](../计划/辅助瞄准阶段文档.md)还承担复杂功能决定、接口与恢复线索，不能当作普通过期流水整体退出；其任务线索须回到 Issue/PR 核实，未合并状态读取指定分支。

## 候选决定

1. 有限替代 [ADR-0004 第 6 条](ADR-0004-跨会话连续性与稳定起步路线图.md#决策)的统一读取顺序：新接手先核项目边界、当前任务与权限、Git/PR及适用要求。已定位的同任务小修、文档修改或只读核对直接读合同、规则小节、接缝与必要资料，缺范围、权限、依赖或证据时才向上展开；新功能、陌生领域或方向任务再读适用路线图、架构与历史决定。安全、存储、输入、安装和兼容命中仍须取得有关要求。
2. 已读且未变的背景复用；交接恢复有效决定、未完成步骤和未决证据。工程第十二章作为持续实施、集中独审、交接与技能辅助的唯一责任位置。技能按当前实际任务需要选用，不因已经安装而另跑需求访谈、逐小任务换实施者、逐小任务独审及末尾重复审查。保留必要计划、真实独立结果的拆分、获授权子 Agent 与独立审查；文档不能保证外部插件自动遵从，也不授权修改其配置。
3. 网页指令由草拟者消化讨论，交付当前有效目标、实施必要背景、行为与授权边界、验证目的和终点。期望结果优先；否定约束只保留防止当前真实误操作的必要项。旧误案未交付、也不会由当前资料引导时，不先介绍再禁止；错误仍在任务或必读资料中时，给出明确替代说明。本文不增加本地实施者的逐项 Prompt 审计、纠错账本或额外汇报义务。

## 有限替代与不变边界

- ADR-0004 的事实载体职责、权威、冲突停止、路线图方向/退出条件及受控维护不变；旧 Accepted ADR 保留原文。
- 读取深度和工程新会话/权限变化的固定恢复安排拟按上述候选收窄；已有 ADR-0013 单工作区、ADR-0016 证据复用、ADR-0017 持续实施与集中增量独审不退回草案。新增的技能选用和网页起草语义在实际条款标明候选。
- 项目与只读 Legacy 边界、用户数据与安装恢复、兼容、输入、安全、证据层级、正式化和合并授权均不变；不增加工具、角色、模型、账户、全局配置或审批依赖。
- 原始证据适用性仍由[测试规则](../规范/测试与审计规则.md#十四原始证据与正式结论)负责，复用须核原执行及相关实现、输入、配置、环境和完整变化；换会话或审查者不自动失效，旧 PASS 也不能覆盖已失效部分。

## 落点、代价与撤销

读取路由归[根入口](../../AGENTS.md#跨会话冷启动)、[文档入口](../README.md)及[路线图恢复入口](../计划/稳定起步路线图.md#七新会话冷启动协议)；主流程归[工程第十二章](../规范/工程治理规则.md#十二新会话交接与沟通)，证据归测试规则，网页起草归[网页协作第 4 章](../网页Chat协作约定.md#4-开发-prompt-的起草与交付前核对)。

按任务展开需要实施者识别真实缺口，错误判断可能漏掉必要要求；用命中领域路由、完整相关差异审查和高风险纸面走查约束。未证明节省时间，也不专项调查本机插件状态或开销。无新增系统；可以通过普通文档 PR 撤销或调整，所有者不参与日常工程操作时仍按既有职责运行。
