领域 DTO 在 Features；Infrastructure 仅依赖 Platform 机械文件端口，不新增项目引用。`CaptureToken` 绑定 operation／session／mode／selection revision；Host 另外保存世界、玩家、连接、tiles、sectionManager 实例身份。Selection 冻结为已提交 spans，不包括拖拽；revision 不因重新进入模式碰撞。

`CaptureCell` 仅语义层值，正文保 world 坐标，以固定 summary 原点消费相对坐标；无内容无记录。`CaptureChunk` 至多 2048 条 cell＋对象描述，接收后数组封闭不再改；对象描述随 chunk 流式写。`CaptureSummary` 只含 bounds、long count、起止 tick、有限缺失类别／不可靠原因示例，不持全量内容或对象数组。每个未确认组保留稳定 ID 和完整原因，LibraryState.TryObjects 按需流式提供每页 6 组；UI 逐组显示原因和排除操作，也可额外全排除。`UnreliableObject` 只属于 tile 层；明确排除后保存／预览只去该组 tile 层，保同格确认墙线液体。单独排除用 Host 持有的 immutable ID 集合，全部排除不建立全量 ID 索引。

一个 Features `LibraryState` 领域 worker，经 Platform 机械端口／Infrastructure 文件实现：BeginStage → 单槽 AppendChunk 背压 → SealDraft。Host 最多一构建块＋一提交块；忙则停止世界读取，固定 draft 持 `ContentHandle`，预览／创建流式读 stage，最终不创建整量 byte[]。未保存取消精确清理自己可证明归属的 stage；提交未知和恢复材料保护。领域 worker 独立收尾已接受保存，关闭 UI／换世界不冒称撤销。

Host 唯一 `BlueprintCaptureFlow` 供 UI 投影状态／进度／名字／handle／summary／排除选择／结果。三个保存入口统一 `Save()`；UI 发 SetDraftName／ExcludeObject／SetExcludeUnreliable／ConfirmSave／CancelCaptureOrDraft，不另造模式／选区／保存状态。可靠 Saved 且原 session／mode／revision 匹配才消费原选区并留采集模式；迟到成功仍入库，不清新选区。

UI 只拥有页码／选定 ID／编辑 buffer／删除确认 ID／图形缓存；库 Snapshot／Receipt 持真实 metadata／提交状态。预览 worker 流式将全部内容聚合为有限 `uint[]` 像素（最大 512×128，0xAABBGGRR）；图形线程创建上传释放纹理，稳定 Draw 不扫正文或目录。命名统一 48 个 StringInfo 文字元素、拒空白／首尾空白／控制换行，不截断，允许同名但 ID 不同。
