# 附近目标探测与高亮功能行为合同

**五项新版用户目标已获所有者接受；需求接受不等于实现或实机验收。** 本文第 7、8 节是本批新版合同，其余 Legacy 调查与固定来源仍保持历史静态身份。任务与产品裁决查 [Issue #57](https://github.com/Kuroneko2020/JueMingR/issues/57)，阶段及实施任务查 [#7](https://github.com/Kuroneko2020/JueMingR/issues/7)。

证据口径：**C** 为 UI、配置、实际源码；**B** 为测试源码中的断言意图，本轮未运行；**D** 为旧说明或历史修复记录，不能当作所有者本次确认；**推断/建议/缺口** 单独标出。全部调查为 V0 静态提取，没有观察游戏画面、运行行为测试、测量性能或取得本批验收。按[现行平替规则](../规范/Legacy平替与行为契约规则.md)使用，不新增制度。

## 1. 一页摘要

生命水晶和生命果的旧操作相同：F5 →“更多信息”→对应行“开启”，也可从行尾录入快捷键切换。两项默认关闭；开启并具备原版金属探测能力后，屏幕附近可读的目标方块外出现彩色矩形、白色外框和加粗角标。生命水晶默认粉色 `#FF69B4`，生命果默认黄绿色 `#7CFC00`。不显示名称、血量、距离或方向，不负责拾取、挖掘、自动采集。关闭 F5 不等于关闭高亮。[C：Z01–Z08]

“需要金属探测器”是旧说明的简称：消费者实际检查玩家 `accOreFinder`，并尝试旧兼容字段 `accOreFinderGold`；没有逐物品检查必须是独立金属探测器。当前 .8 的该能力可由对应信息饰品以及满足条件的队友共享取得。没有另加生命/魔力上限、Boss 进度、药水、照明、射线遮挡或地图探索条件。[C：Z05、Z06；原版 T08]

其余三项经消费者与原版身份核对：魔力水晶是世界中的 `ManaCrystal` tile 639；碎岩龟是 `PalworldDigtoiseSleeping` tile 751 的睡眠形态，均与主体共享扫描/绘制。龙蛋旧代码只找 `TileID.DragonEgg`，当前 .8 没有该字段，因而该消费者跳过；实际另有 `PalworldChilletEgg` tile 752，但不能凭中文名直接替换旧用途。掉在地上的同名物品、使用物品召出的碎岩龟 projectile、打开蛋后的产物均不是这些旧查询的数据源。[C：Z07；原版 T07/T08；其余差异见第 3 节]

**新版同批交付五项：生命水晶、生命果、世界中的魔力水晶、睡眠碎岩龟与巨型龙蛋。** 所有者明确龙蛋指能开出疾旋鼬的巨型龙蛋，对应当前原版 `PalworldChilletEgg=752`；这是补齐旧失效映射，不倒写旧版可用性。新版以一组三个环绕、缓慢旋转并轻微上下浮动且始终指向目标的粗箭头替代矩形和角标，五项均可独立调色，包括碎岩龟。

R 已有信息页、公共输入/快捷键、可靠偏好保存、样式颜色编辑基础及世界绘制生命周期。需要补齐本批目标读取、完整对象判断、三箭头呈现和对应行/命令/偏好接线；不重做页面、导航、滚动条或通用扫描平台。旧版没有本批颜色编辑窗口；新增颜色-only 入口是已接受的有意改进，不引入显名字号或血量字段。[C：R01–R06]

## 3. 主体完整行为及同机制差异

### 3.1 操作、启停、保存与失败

| 阶段 | 生命水晶、生命果的旧事实（其余三项同样适用） |
| --- | --- |
| 入口 | F5“更多信息”，各行两个明确的“开启／关闭”按钮，行尾公共快捷键入口。五项都是二态；没有多模式或独立“开始扫描”按钮。 |
| 初次状态 | AppSettings 声明及 CreateDefault 均关闭，默认测试亦断言关闭；本批没有预设专用快捷键。 |
| 点击/按键 | UI 按钮设为指定值；快捷键反转同一值。按下相应键不采集或破坏目标，不依赖敌怪/动物/NPC 显名开启。快捷键录入/冲突/文本让步的完整旧流程引用[快捷键合同](统一快捷键功能行为合同.md)。 |
| 重新开启 | 沿当前设置重新经过上下文与探测门；不是强制重建所有缓存。原缓存未清且签名/时钟满足复用时可以复用，见第 4 节。 |
| 正常重启 | 配置成功保存且下次合法读取时恢复本项开关、四项颜色和绑定。开关/颜色在旧 `config/appsettings.json`，关联 `features.json`；当前统一绑定在 `unified-hotkeys.json`。自然归属是全局玩家偏好，不按世界保存目标位置。 |
| UI 保存失败 | UI 先改内存，再 `SaveAll`，没有检查返回摘要，仍按 changed 记录成功/无变化。快捷键也有调用 SaveAll 而未将保存结果纳入本次显示切换结果的路径；不能把“已开启”或选中态当作可靠落盘。旧存储会保留无法安全读取的原件并记录失败日志。 |
| 退出/切页/失焦 | 本批没有未提交的样式草稿，所以不存在本批颜色确认、松手提交、取消或恢复默认流程。F5 的开关手势与快捷键录入由公共输入处理；页面关闭不回滚已执行的布尔值。没有证据表明失焦会关闭高亮偏好。 |
| 暂不可用 | 主菜单、玩家缺失/不 active、类型/图形资源不可用时跳过；探测状态为 false 时不显示。未见本批专用普通用户“无目标／未加载／读取失败”提示；日志与诊断不能当作该提示。玩家 dead 未被本条上下文独立排除。 |

旧配置根是系统“文档”下 `My Games/Terraria/JueMing-Z/config`，这里只说明代码默认，不读取真实文件。本轮没有证明用户机器上实际保存过哪组颜色或绑定；成功恢复是条件化源码结论。[C：Z02–Z06、Z09、Z12；B：Z14]

### 3.2 高亮究竟画什么

矩形基于合并组的最小 tile 坐标与宽高，每格 16 世界像素；左上锚点为 `round(tile×16-screenPosition)`。外扩 3 画彩色 1 像素边框，再外扩 2 画 alpha=120 的白色 1 像素外框；四角由厚度 3、长度夹在 8–18 的两段组成。尺寸在 Game 坐标域传入，最终显示由宿主 Game 层缩放；不是固定桌面物理像素。[C：Z08]

没有实心覆盖色、原贴图染色、照明增强、目标专用纹理、文字、距离、箭头或鼠标命中。虽然 renderer 计算正弦 pulse=155–235，但普通配置色被解析为 A=255，`max(A,pulse)` 仍为 255，**不能据正弦表达式声称实际有呼吸闪烁**。四项颜色为六位 RGB，无 alpha 字段；线宽、角长、透明度均不可调，没有字号。[C：Z04、Z08]

| 目标 | 默认与可调能力 | 不是该目标的情况 |
| --- | --- | --- |
| 生命水晶 | `#FF69B4`；AppSettings 字符串，规范化/非法值回默认；每通道 0–255，无游戏内调色步长 | 掉落 Item、生命水晶巨石 `LifeCrystalBoulder=665` 等其它 type 不命中 |
| 生命果 | `#7CFC00`；同上 | 掉落 Item、`LifeFruitReplica=702` 装饰复制品不命中；显示不额外要求当前在丛林或已达到生成进度 |
| 魔力水晶 | `#66CCFF`；同上 | 消耗品掉落/背包中的魔力水晶不是本项 tile；旧说明明确不是单纯同名物品提示 |
| 碎岩龟 | 代码固定 `(255,196,96)`，无对应颜色设置 | tile 采下后对应物品5667；使用物品召出的 projectile1098 不属于本项读取，不应写成“持续追踪醒来的NPC” |
| 龙蛋 | 有 `#9370DB` 配置字符串，但无有效当前目标 ID | 不等于识别任意带“蛋”名称的家具、世界物品或孵化后实体 |

**颜色字段存在不等于配置窗可用。** 五条真实行调用均省略 styleFeatureId；公共 Rows 只有 `IsConfigurable` 成立才画“配置”与色块。全生产引用中，主体颜色只用于默认、规范化、签名和绘制，没有调色命令。因此本批旧 UI 没有调节预览、确认、取消、恢复默认、成功/失败颜色反馈；不能借前序显名窗口补造旧流程。源码不提供配置热重载保证；离线改旧配置不是本轮给用户的操作任务。[C：Z02、Z04、Z12]

### 3.3 出现条件、相邻界面与目标变化

共同条件是本项启用、合法当前客户端上下文、图形门通过和原版探测能力。扫描不检查地图探索、tile 光照、墙体遮挡、玩家到目标的独立半径、当前生命/魔力上限、原版是否正在报告此物为“最有价值目标”、hideInfo 或原版探测文本是否隐藏。旧 UI 写“背包有金属探测器”比消费者实际条件窄；原版状态来源见 T08，不能把某个物品的生成条件附加为高亮门。[C：Z01、Z05–Z09]

自然生成与玩家放置没有来源标记，凡当前 active/type 相符都会参与。当前 .8 已确认生命水晶的2×2放置、魔力水晶的原版生成及物品5287“修复的魔力水晶”放置到639；这不表示每类目标都可在正常游玩中任意放置。新生对象在重扫后入选；同位置重放同 type 可能在旧矩形复核时立即再现。完整性、残片、相邻对象和原版更换形态的限制见第 4 节。没有目标时就是无标记；没有标记也可能是开关/能力/资源/读取不满足，不能反推世界没有该物。

正常信息世界层先于主要原版地图、生命魔力、背包/容器与 F5/Notes 绘制，半透明 UI 可能透出下方标记；未按每个 UI 矩形挖空高亮，也没有“开背包便关闭”门。旧层寻找 Map/Minimap、Resource Bars、Inventory、MouseText 等锚点，失败有较晚 overlay 回退，回退不保证原顺序。高亮不注册点击/悬停/拖动；F5 和 Notes 仍处理各自输入。全屏地图、拍照/调试、极端缩放的最终宿主行为未在本轮观察，不能写成旧版已支持地图投影或这些状态必定隐藏。[C：Z09、Z13；D：既有[绘制经验](../AI经验笔记/绘制分层与图形资源.md)]

## 4. 查询范围、完整对象与失效

### 4.1 查询与对象边界

旧查询相对**相机屏幕**，不是世界全图或玩家固定半径。tile 单位边界为 `min=max(0,floor(screen/16)-4)`、`max=max(min,ceil((screen+screenSize)/16)+4)`，两端含端点，X 外循环、Y 内循环。最大端没有在 BuildScanBounds 夹到世界尺寸，typed reader 再用世界坐标边界拒绝，反射数组读取也检查数组长度。上下文尺寸无效时回退 1280×720。玩家 16×16 tile chunk 只参与刷新签名，不是扫描范围。这里没有额外用 ZoomMatrix 逆算真实视口；相机/分辨率变会影响边界，单改缩放未必改变签名，不能把这条近似当作全部缩放下的精确可见集合。[C：Z06、Z07、Z09、Z11]

每次重扫是一次完整矩形遍历，开启一项和开启多项都走同一遍类型分支；没有每项独立重扫、全世界后台索引、分页增量进度或距离排序。但“每次查询共用”不等于每 Tick 绝对只有一次读：Draw 可被调用，签名变化可重扫，复用也逐候选读取矩形，邻接归组另有读取。[C：Z06、Z07]

归组只看 active 和 type，按四邻接 flood-fill、每组最多匹配 64 格。没有 frameX/Y、style、`TileObjectData`、origin 或完整子格校验。由此可推断：两个贴在一起的同类物体可被并成一框；残留一格也可入选；超过 64 格的连通区域可分成多框；屏边只见部分时框对应所扫部分，矩形可包含非目标空隙。Visited 避免本次已访问格重复归组，**不是“每个真实物体恰好一个完整框”的证明**。active 不等于 nactive，执行器隐藏/形变等也未单独处理。[C：Z07、Z11]

### 4.2 缓存、撤销与退出

| 状态或变化 | 旧机制与用户可见影响 |
| --- | --- |
| 缓存 owner/内容 | 静态 InformationTileHighlightService：候选数组、构建与过滤 List、上次 tick/hash。每项存 TileX/Y、Width/Height、TileType、Color，没有真实对象身份/frame/Session generation；scanner 有复用 HashSet 与栈。 |
| 刷新 | 世界名/ID键与世界记录键、屏幕 tile 边界、玩家 chunk、启用 mask、启用的四项颜色进入 hash；签名不同、从未扫描或 tick 回退重扫，否则 60 tick 安全刷新。旧常数是实现信息，不是新版必须等待的产品规则。 |
| 移动/传送/切世界 | 边界、chunk、世界键或时钟变化通常促使下一次有效 Draw 重扫。没有持久扫描进度。hash 不是精确身份保证；未包含连接 generation、Main.tile 引用或独立缩放身份。 |
| 完全挖除/采集/爆炸/变型 | 每次取结果都重查旧矩形，只要没有任何一个匹配 active/type 的格就不画；不必等 60 tick。未追源头是谁改变它，本人/其它玩家变化在本机数据已更新后走同一复核。网络到达时点未验证。 |
| 部分移除/相邻件被移除 | 只要矩形里仍有一个同类 active 格，整份旧框仍有效，尺寸可等重扫才缩小；不能把“存在复核”说成完整对象复核。 |
| 同坐标重放/成长替换 | 同类格返回旧矩形可使缓存框重新出现；不同 type 不续用。缓存过滤不覆盖原缓存，故这种恢复在到期前也可发生。新位置不在旧矩形内需后续重扫。 |
| 全部同类关闭/失去探测能力 | Draw 早退，不扫 tile、不画；旧数组和 buffer 容量保留。其它信息功能开启时，共享 context/箱子记录路径仍可能执行；全部信息世界项都关才在更外层早退。 |
| 菜单/断线/重连 | 上下文无效时跳过；源码中的 Reset 为测试入口，未发现生产退出主动调用。本轮无法证明每种同世界重连都立刻使缓存失效，尤其签名与 tick 仍满足复用时。 |
| 容量/离屏 | 没有总候选数上限或“最近 N 项”排序；64 是每个连通组的格数上限。候选受矩形规模约束，边界外扩格也可进入；renderer 无独立屏外裁剪。不能套用旧显名 120 名额的饥饿结论，但缓冲容量可保留峰值、空隙矩形复核可多读。 |

历史修复 `4258ef07cc5b7efb13b2608191fbfefafa649940` 为这条缓存补上当前 tile 复核；测试 Z14 断言签名变化、60 tick、时钟回退、相邻合组、移除与同坐标返回。测试 helper 绕过真实探测器/图形入口，不能证明 UI 条件、完整对象、网络、真实画面或全部关闭成本。主因与防回归价值是“不把旧候选当当前位置还存在目标”；不需要继承过滤数组、64/60 等具体实现。[B/C/D：Z06、Z07、Z14]

## 5. 多人、只读与性能边界

| 场景 | 可以确认的读取 | 证据边界 |
| --- | --- | --- |
| 单人 | 客户端当前 Main.tile、当前玩家探测状态 | 不读 .wld 文件来补目标，不据单人内存形状宣称全图查询；未实机 |
| 本机房主 | 同一客户端显示读路径，无本批服务器组件 | 进程内主机权威与客户端读取仍分开；没有三拓扑运行验证 |
| 普通客机连接原版服务器 | 使用客户端已有 tile 和探测状态；不主动要求服务器安装 R | 只说明本机当前可读数据，未接收/未准备区段不等于服务器不存在目标；同步延迟与可读区域没有本轮运行证据 |

本批不读探索地图缓存来找目标。地图未探索不证明 Main.tile 必不可读；非 null、可读或 active 也不能被升级为服务器全世界实时事实。旧 scanner 没有区段就绪判定：读不到集合、读不到坐标、字段失败、inactive/不匹配都最终无标记；只有部分失败有节流日志。因此“暂不可用”“尚未同步”“确实没有”在旧用户表现上不能可靠区分。新版应守住这种证据差别，不为消除未知而请求全图同步。[C：Z07、Z09、Z11]

**目标扫描/绘制本身没有发现网络请求、区段请求、tile/实体/照明写入、拾取或目标坐标落盘；整条旧 Draw 链却不是纯只读。** 任一高亮开启就进入 FullRecord context，在探测门之前调用旧箱子键导入和当前开箱记录。它读取原版已有 FileData 的名字/路径等身份元数据（不是读取世界存档正文），可能读写玩家×世界行为 JSON，迁移匹配世界的旧箱子坐标，再 SaveAll。箱子记录和旧列表迁移是其它业务副作用，不能称高亮的必要功能，也不因此授权 R 照搬。详细 store 风险引用[显名合同副作用分析](敌怪动物与NPC显名功能行为合同.md#54-实际副作用与多人证据边界)。本轮没有访问这些真实文件。[C：Z09、Z10、Z12]

成本仅为静态形态：锁内建签名/颜色解析、矩形循环、同类型邻接栈/Visited、候选 ToArray；缓存命中仍复核候选矩形，删去部分候选时可再次分配过滤数组。四项颜色签名逐次遍历文本，重扫时解析 RGB；无目标名称拼接或排序。旧外层有 Stopwatch/诊断更新、节流异常与上述潜在 I/O。没有独立后台扫描线程，没有性能耗时、FPS 根因或“性能通过”结论。本轮不新增探针、基准、日志平台、位置数据库或扫描框架。

### 7.2 完整对象、观察与失效

每个真实完整对象对应稳定原点、类别、当前边界和恰好一组三箭头。多格物体只画一组，相邻独立物体各画一组；遇到任一格可用有限必要邻格解析原点，屏边不要求原点也在扫描框内。完整性按各类当前原版真实帧/样式/尺寸/有效状态确认，不机械要求各格帧相同，也不使用同类格连通合并。残片、错误帧、替代装饰、未就绪区段和读取失败不能当作可靠目标。

合法取走、破坏、睡眠形态移除或开蛋相关变化后，依据当前客户端确认数据撤掉旧标记；不假设五项都支持相同消除方式。同坐标重放重新确认完整对象，不能无限沿用旧尺寸/样式，其它类型不继承标记。世界、玩家、连接、传送越区及读状态变化使旧候选和分片进度失效；不能污染新区域。

Host 在游戏线程按需共享附近 tile 读取，功能规则作目标判断，呈现消费只读确认结果。五开关不重复扫相同区域；只开一项不做无关分类/投影，全部关闭或能力无效停止本批领域工作，不依赖显名开启，也不把 tile 塞进 NPC 快照。发现新候选与已有对象有限复核分开，不以每帧全区重扫解决失效；已确认消失、关闭或丢失资格后不等待旧 TTL 继续动画。

扫描策略按实际成本说明范围、频率、预算、容量和退出；不继承60Tick、16格分区、64格分组常数。分步工作不得由旧区域长队列阻塞当前视口或长期只显示前 N 件。相机/缩放改变范围及时更新；颜色、动画、帮助悬停与重复 Draw 不触发重扫。死亡沿用唯一 Session 的世界观察/物品动作许可分离，不放宽自动化操作保护或取消其它功能在途结果。

普通客机仅读已同步数据，区段未知不等于服务器无目标；不主动请求全图、不改协议、不读 .wld、不加服务器组件。探测全链不采集、挖掘、开蛋、唤醒、改 tile/物品/照明、记录箱子、导入坐标或保存目标位置。

### 7.3 三箭头、坐标与资源

每对象三个简洁实心粗箭头，圆周基准等分120°；位置缓慢环绕，尖端始终指向固定真实中心。初始顺时针约7秒一圈、垂直浮动约2.5秒一轮、振幅约3世界像素；实施者可按真实预览小幅调校并记录最终值，不增加参数页。浮动不是径向/透明度呼吸，浮动后朝向重新指向中心，不沿切线、不做加载图标，不叠矩形/外框/角标。

半径按完整对象边界和箭头尺寸留间隙，最内侧浮动仍尽量在物体外，尖端近外缘；兼顾小生命果与大蛋。主体用当前类别 RGB、细对比描边，无粒子、拖尾、光晕、闪烁、厚浮雕或世界光照/目标染色。密集相邻仍各有三箭头，不合并或新增自动避让。

动画使用已有合适经过时间源，共用时间和必要基础计算；同时间不同帧率形态一致，不逐帧固定角累加，不给目标创建线程/Timer/任务/相位状态。长时间数值稳定；扫描、调色或 F5 开关不重置动画。暂停/隐藏/失焦恢复沿现有呈现生命周期，不多圈追赶，不修改偏好；无可画对象不作多余动画计算。

中心、边界、位置和方向在同一世界坐标空间推导，再一致应用相机、游戏缩放和倒重力；UI 缩放不重复作用，倒重力位置与方向一并转换，最终浮动呈轻微上下。沿既有世界层的菜单、无世界、全屏地图、隐藏UI、拍照等门，在主要原版UI、F5、Notes下绘制，不注册命中。裁切考虑箭头和浮动的外扩边界，对象识别外扩与显示外扩分别处理，不挪动标记适配屏边。

复用少量几何或一份可旋转简单箭头资源，不逐帧/逐对象建纹理、RenderTarget、缓冲或材质，不逐箭头 Begin/End；保持调用者矩阵/混合/裁切状态。自有资源有创建、设备失效和释放入口，借用原版资源不释放；异常按已有局部边界隔离，不截断后续UI。不得用三个文本箭头代替稳定粗箭头。

### 7.4 五项颜色、公共快捷键与持久化

五项分别提供颜色-only 配置与恢复默认，包括碎岩龟。复用 StyleEditor 的 HSL/HEX 草稿、颜色算法、提交回调和 R 控件，窄化目标能力；原三项显名继续颜色加字号，本批不画字号及空白、不写字号或血量字段，不复制窗口或建立任意表单平台。

紧凑副窗显示标题、关闭、色块/六位HEX、H/S/L数值与滑条、恢复默认；无错误不留结果空区，帮助不占主体高度，不加动画大预览。HSL拖动只改窗内草稿，真实有效释放才提交；完整合法六位HEX一次提交。失焦、关窗、切页/目标取消未提交编辑，已提交安全收尾；开窗/RGB转HSL不量化回写或无意义保存。恢复默认只改当前颜色，不关功能、不删绑定、不改另七个颜色目标或显名字号，原名称0.90/血量0.77与已有保存值保持。

颜色窗与公共快捷键录入互斥，遵守文本/鼠标 owner 和释放尾缘；HEX不触发游玩热键，拖动不穿透世界，旧回调不串目标；状态/字体/缩放变化后布局和命中同源。五个稳定动作ID按功能身份注册，调用与页面相同的 Set/Toggle；现有七项加五项通常共十二项，但公共层不写死总数，原ID/绑定/业务保持，新项未绑定。复用精确修饰、录入、冲突和可靠保存；内部同场景重复拒绝，原版重合只在设置提交时完整提醒并允许保存，不后续监听、启动复查或自动停用。

开关和颜色为全局偏好，独立自然文档（建议 `JueMingRData/config/features/world-targets.json`，由有限设计确定）。不塞入显名/UI/热键文档，不保存位置、扫描、相位、草稿或未来动画设置。复用 PreferenceDocument、AtomicFileDocument 的机械原件保护和原子保存，普通偏好内存先生效、后台有界合并；绑定沿用可靠完成后生效。Draw/扫描无I/O，不SaveAll、不改色重写无关文件。

保留缺文件默认、未知格式/字段、外部冲突、写失败和结果未知的区别，不覆盖受保护原件或虚报保存/回滚；旧回调绑定正确目标/revision。正常成功不刷提示，不记每帧日志。首轮不导入旧Z配置，不预填真实绑定、不改原版键位；现有用户数据全部保留。
