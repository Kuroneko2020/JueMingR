# 战斗辅助行为合同

本合同对应 [G11A / #110](https://github.com/Kuroneko2020/JueMingR/issues/110) 的授权开发范围。实现、开发包、安装与所有者体验状态分别查该任务；本文件不宣布已合并或已验收。辅助瞄准算法后置，原有装备提示保持原合同。旧 18 项及旧实现证据仍见冻结的[战斗调查](全功能调查专题/战斗辅助.md)，不改写为旧版已经支持本批扩展。

## 使用与停止

F5 战斗页按自动连点、链球连击、光剑快切、完美左轮、省力魔法绳、自动转向、装备提示、自动汇报、哥布林必死排列。新增八项默认关闭，后方键盘入口使用公共绑定录入、冲突、解绑和可靠保存，默认不占键。按钮和快捷键操作同一设置；快捷键成功短提示等真实提交，保存失败不报成功。开关绑定不是长按攻击动作绑定。

| 能力 | 结果与资格 | 停止及保护 |
| --- | --- | --- |
| 自动连点 | 按住原版使用键，补足原版连发逻辑未覆盖的重复使用；快捷栏或原版合法鼠标槽 58。正 type/stack/useStyle/useAnimation/useTime，排除 channel、释放发射、钓竿、镐斧锤与 2269；不以 damage 总过滤 | 松手、换物、失焦旧手势、真实 UI 消费、其它使用 owner 接管即退役。鼠标拿物只能在合法游戏区域使用，不能穿透 UI |
| 链球连击 | 合格 `aiStyle=15` 链球长按右键，原版发射、释放、收回；实际本地命中接受、碰撞与模拟步停滞参与节奏 | 左键、原版右键副功能及真实交互优先。不改投射物位置、速度、AI、寿命，不主动 Kill，不接管别人的或其它武器的遗留弹体 |
| 光剑快切 | 右键长按，当前格合格且快捷栏至少两格合格物品；升序环绕，同种两格也可。合法释放与实际选槽确认后再开始额外间隔 | 左键与真实交互优先；松手保留最后实际槽。更晚手动选择优先；不从后排搬武器，不把未知/在途物品当候选 |
| 完美左轮 | 快捷栏持原版 2269，长按使用，按原版冷却安排释放/按下，实际弹药和暴击积累仍由原版负责 | 不修改暴击、速度或计时，不保证枪枪暴击；专用策略与通用连点不叠写 |
| 省力魔法绳 | 快捷栏合格悠悠球，当前原版 `magicString` 效果真实生效，长按使用时经原版释放/再用生成分体 | 不自动装备、不制造效果或免费弹体；装备变化、换物、死亡、松手即时重新核资格 |
| 自动转向 | 独立开关；合格武器使用中优先实际左右控制，否则 36 格内普通敌怪，再回有效光标；保留短冷却与水平死区 | 真正调用 ChangeDir 并读回。目标身份变化/失效、换物、关闭清自己的覆盖，不恢复旧方向，不写移动键；107 不因可受击而成为敌人 |
| 哥布林必死 | 仅放宽 107 哥布林工匠在本地玩家近战与玩家投射物的两处友方命中门 | 105 与其它城镇 NPC 不变；碰撞、免疫、owner、伤害及原版权威门保留，不改阵营/AI，不寻人、不自动攻击、不瞬杀。两处补丁不完整就不可用 |
| 自动汇报 | 独立于武器和物理手势；首次观察建基线，新增结束事实合并请求一次原版 BossDamage 命令 | 玩家/世界/连接身份更换清基线；死亡仍可观察逃离。已调用但结果未知不盲重发；不会改聊天草稿或模拟键盘 |

普通背包打开、F5 可见和窗口失焦不构成所有业务统一暂停。长按战斗仍须可靠前台物理意图；失焦不能沿用旧按住。原版暂停不推进节奏。自动汇报没有该手势要求。F5 控件消费其点击和取消尾部，窗口外合法新手势仍可用。

## 快切物品与间隔

锁定 Terraria 1.4.5.8 的 23 项分为三类。默认额外间隔 12 模拟 tick，范围 0—30；0 只去掉额外等待，不绕过冷却、释放或真实 Select。滑块在快切行内，可拖轨道为 108 逻辑像素（由原 54 加倍）；拖动只预览，可靠释放提交一次，失焦、取消或几何变化保留旧值。

| 机制 | 物品（原版 ID） | 原版事实 |
| --- | --- | --- |
| 物品释放发射 | 蓝/红/绿/紫/白/黄光剑 198–203；橙 4258、粉 5535、彩虹 5670；对应光刃 3764–3769、4259、5536、5671 | 旧 18 项；`ShootsOnUseRelease` 的实际 ItemCheck 释放窗口 |
| 同一物品释放发射 | 钥匙剑 Keybrand 671、时尚剪刀 StylistKilLaKillScissorsIWish 3352、颌骨剑 AntlionClaw 3772 | 本批新增三项，沿同一原版释放链，不因名字或基础动画不同排除 |
| 投射物蓄力/释放 | 燧石 DeadCellsFlint 5462、冰川之牙 GlacierFang 6153 | 本批新增两项，分别识别原版 1040 与 1115 的充能/释放阶段；燧石等待返回弹体结束再换槽，冰川之牙保留原版蓄力方向与释放结果 |

弓、悠悠球、链球以及一般 channel 物品不因“蓄力”字样或 channel 标志纳入快切；其释放、返回或再用机制不同。诸如天顶剑及其它近战武器不因名字、伤害或 useStyle 相似加入。目录依据是具体原版链，后续版本必须重新核对。

## 汇报的已确定输出范围

所有者明确选择[沿用原版范围与广播](https://github.com/Kuroneko2020/JueMingR/issues/110#issuecomment-5869918876)：有伤害记录的 Boss 击败和逃离，以及哥布林入侵、雪人军团、海盗入侵、火星暴乱、南瓜月、霜月。每次可重复输出全部近期记录，最多三条，并非只输出新增一条。

单人经原版命令直接显示。普通多人客户端没有本地统计也可根据服务器实际应用的 NPC/事件结束消息请求原版统计；原版服务端向全部活动玩家广播。统计仍按原版名字归组，名字不是 R 的连接身份。客户端没有仅自己/仅新增参数，不增加服务器组件、协议或 ACK。建议同一场游戏一人开启；多名安装者仍可能重复，没有跨客户端严格一次保证。

复合 Boss 等待本客户端已知的服务器活动成员全部结束；未收到过的成员、漏包或加入前历史不能从本地补造。两模拟步合并窗口只是发送时序，不代表服务器统计已就绪。无伤害记录、服务端未生成统计或网络丢失可能没有输出；已经调用后的未知结果不会刷命令追赶。

## 衔接、数据与验证边界

共同使用权仍由现有物品 owner 管理，战斗快切是真实选槽，工具/快捷物品的临时借用仍负责归还。战斗在原版可交接阶段释放使用权，旧按住只在被识别的同一借用中让位；后来的新按键、手动选择、物品保护不被吞。弹药/武器的在途、未知、手动取回、恢复、存放、出售丢弃保护保持；不凭命中制造拾取事实。钓鱼与装备以其实际状态为准。

`JueMingRData/config/features/combat.json` 是独立 schema 1 文档：format `JueMingR.Combat`、version、enabledMask（0—255）、switchInterval（0—30）。文件缺失只用默认值，第一次真实操作才写；只支持该版本，无 Legacy 自动导入。未来版本、未知字段、坏值或冲突保留原件并暂停，不静默归一化。正常设置通过现有原子文件/worker 保存；未确认结果不可作为成功。绑定沿公共绑定文档；旧装备提示设置不迁移或重置。

自动验证覆盖锁定 .8 的实际 Player.Update/ItemCheck、相关 Projectile AI、使用/释放/生成、鼠标槽、借用、公平交接、异常收尾、两处真实命中链、原版统计收发，以及真实字体 F5。工作量检查区分关闭、启用无需求、稳定使用与身份变化。网络夹具使用内存 socket，图形夹具使用隐藏设备和隔离数据，均不操作所有者角色/世界。

这些证据不等于真实多人服务器验收、实际键鼠/系统输入法验收或 FPS 测量。完整自瞄预测、普通攻击瞄点覆盖、释放后追踪和标记 UI 都后置。最小未来消费边界见[实现设计](../设计/战斗辅助实现设计.md)，产品中提供者默认不存在。
