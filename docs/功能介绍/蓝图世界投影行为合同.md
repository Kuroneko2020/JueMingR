## 精确目标的施工资格

原模板、采集、预览、绘制、命中与永久逐层覆盖继续保留全部原生身份。施工资格由同一份原版能力目录解释：有玩家直接生产者的目标保留施工责任；相关声明、形态或能力覆盖无法确认时保持未确定；只有完整覆盖证明该精确类型／形态没有玩家直接生产者，才归仅展示。目录尚未就绪不是准确的零，缺料、超距、缺依托或暂时阻挡也不是仅展示。

仅展示只排目标对应层与其外观；完整展示对象统一排其全部 Tile 成员，同格墙、线与致动器分别保留。它们不计材料、候选、移动锁或施工完成分母。天然原件与可摆复制品即使外观相同，也按实际输出类型分别判断；不能改写旧图身份或将材料解释失败一概吞成展示。玩家能用 flexible 工具重建的复制品仍有材料和最终匹配责任，当前自动施工执行限制独立判断。

材料、世界匹配、移动与完成使用同一资格及当前永久 mask 的有效施工分母。资格变化撤旧分母、隐藏匹配、材料贡献和候选，原始显示缓存仍可复用。有效施工层为零而仍有显示内容时，图纸保留、可移动和手动移除；混合图的有效施工层全部真实符合后，沿原安全出口退休该实例及其展示内容。真正资格未知继续阻止假完成。

## 从库取出与多实例

每次从可靠库卡“放置”异步读取模板，资格有效后关闭 F5，形成独立候选；确认后同一 world session 可保留同模板及不同模板的多份图纸。每份原点、提交顺序及消除状态独立，共享不可变模板。不设置实例数量、模板宽高或 bbox 面积上限；实际读取与显示按有界窗口分批推进。已固定且尚未完成的图纸在正常退出、同一可靠角色×世界重进后原位恢复，图纸库原件不改变。Following、未确认移动、输入／施工／网络在途责任不保存；未确认移动恢复最后已提交的位置。已移除、完成或永久消除归空的实例不复活。

新取出按保存 Summary 裁空后有效宽高 W/H 的中心格 `((W-1)/2,(H-1)/2)`，整数除法、偶数取左／上中央格；源格减 Summary.Left/Top 得局部格，origin=mouseTile-anchor。89×32 鼠标(100,100)对应 origin(56,85)。中心空气仍保中心小十字，小图／超屏图同规则，真实 tile 大小，不缩图塞屏幕、不自动贴地。相机、反重力及世界缩放使用既有 world transform，UI scale 不改变 tile 尺寸。

## 后提交永久逐层消除

只有确认放置／确认移动才提交；移动是该实例最新的一次提交。按双方尚未被永久 mask 消除的有效目标逐格对齐：新 Tile 消旧 Tile，新 Wall 消旧 Wall，新 Liquid 消旧 Liquid，新每色 Wire 只消同色位，新 Actuator 独立消旧 Actuator。世界 Match 的暂时隐藏不退出覆盖输入。新图缺少的层与空气透明，不按 bbox 擦整片；半砖坡的语义覆盖仍占正常 Tile 格。

新 Tile 碰到旧实例 ObjectId>0 的有效成员时，旧实例该对象全部成员的 Tile 整件消除，包括屏外、窗口外和重叠 bbox 外的成员；同格墙、线、液体、致动器保留。对象身份为(instanceId, objectId)，不能串到同模板或不同模板的另一实例。ObjectId=0 的自然逐格内容、半砖和坡不当残缺对象。

消除是随固定实例保存的永久 mask：后放实例移走／移除，旧层不自动复活；旧实例被消的 mask 随其移动，正常退出重进也不重算或还原；从图库重新取同模板得到完整新实例。全层均空的实例退休。已 mask 内容既不绘制、不命中，也不再遮别人。Following／Moving 预览不写旧 mask，取消、越界、读取失败不留沿途消除；确认在后台完成整个真实重叠后，由 Host 一次提交全部 mask、origin、顺序和空实例退休。

## 选择、抓取与可信输入

移动入口先进入“点击需要移动的蓝图”；新的可信世界点击命中目标才进入 Moving，保留点击抓取偏移，起点不跳。选目标那次按住不能同时确认，真实释放后新的左键才提交；右键／Esc 恢复原场景。移除入口先提示“点击需要移除的蓝图”，新点击只退休所选一份，不删库、不恢复其曾消除的内容。选取态右键／Esc 仅退出选取。

命中按最新提交且该处有有效目标优先，air 洞和已 mask Tile 不抢目标；半砖、四坡按目标形状。世界 Match 隐藏后仍可在移除模式凭目标和轮廓选取。未读取不当空气选穿，等待有界窗口；hover 轮廓、实际点击与确认读取同一份当前移动资格，未知保留准确目标，不选穿到下层。启动、选择、确认是独立新手势。Selecting、Following、Moving、确认计算中及 Open 等待均经既有世界动作门；Fixed 被动显示，正常移动／跳跃／攻击不被占用。

失焦、聊天、地图、F5／UI 接管仅暂停可信手势和位移，恢复先取得可信全松，不补点击、不重放接管期间位移。focused=false 不证明释放。Open 等待的明确 Back／Esc 取消退休该事务，迟到 Opened 不复活候选、不关闭新页面。取消 Open 不撤销已受理 Save。

原点不夹进世界；预览显示与世界的交集，确认核完整有效 bounds。越界保留当前候选并提示移回，不因可见片段入界就固定。

## 入口、采集与模板生命周期

F5 标准行、公共默认未绑定快捷键和凝胶工具条共用 Host 命令。普通文字按钮不重复名称静态简介，图标用途和真实 disabled 原因保留。库放置的 busy、页保护、资产保护、采集／草稿／冲突编辑态和无有效 world 原因对应实际资格；无实例允许新取出，多个 Fixed 不构成禁用理由。

移动的SelectingMove、Moving及其Committing来源在原位置显示“取消移动”，同一移动绑定取消自身并恢复旧origin／order／mask和资源；移除选择在原位置显示“取消移除”，同一移除绑定仅退出选择。新取出pending／Following及其Committing来源属于“取消摆放”，原操作可以取消自身；不同功能不冒领取消、不静默切换。Fixed本身不显示取消。正常确认固定保持受理但不显示“正在固定蓝图…”；真实错误仍报告。

手动打开蓝图库的工具条／F5／绑定／Host共用资格：采集模式、待存草稿／受理保存或任一主动投影操作未结束时禁开；只有Fixed时可开。拒绝不取消当前工作，正常打开无教学提示。保存成功的内部转库仍独立有效。SelectingRemove时工具条在移除旁显示“移除所有”，一击清当前world全部同／异模板投影（含离屏）并退出选择，退休在途读取和确认资格；不删模板、不改世界，无新F5行或绑定。

未保存 selection、固定 draft、在途采集／保存时 Place／Move／SelectRemove 同门禁用，提示先保存或退出采集，不清数据、不取消受理工作。空采集可显式退出后摆放，Fixed 可与采集被动共存。关闭 F5、换手持物或隐藏工具条不清 Fixed；真实离开 world／session 释放全部运行实例、候选、旧动作与读资格，已接受的固定 scene 由原保存 owner 收尾，不把资源释放写成业务删除。

固定 scene 只在可靠角色文件身份×世界 GUID 的 scope 内恢复，重新验证原模板身份和永久 mask，再由真实世界重新匹配；不读旧完成缓存。初读／模板核验尚未结束时不受理会与恢复冲突的投影编辑。损坏、未来格式、身份不符、保存失败或提交未知保留原文件并停止该 scope 写回，不能以空场景覆盖；某一模板已不存在或不再可靠时保留整档原件，仍恢复独立合法实例。本次运行中新改动在保护状态下仅本次有效，错误沿既有本地提示报告；不提供跨角色共享、联网或跨设备同步。

世界移除只减一实例引用，最后引用才释放共享模板资源。Rename 只改 metadata，不重 parse 正文、不清实例。图库删除确认态直接显示将影响的 N 份引用及候选；唯一 worker 先停止关联新读并释放 reader／Pin，再走原文件删除流程。成功退休该模板全部实例／候选；仅已证明未提交失败可恢复，Protected 与提交未知不一律恢复。未知结果停关联读、保护文件，不盲重建；其他模板及独立事务保留。

## 外观、只读与范围

## 世界匹配、移动资格与完成退休

匹配以这一份实例在当前原点、当前永久 mask 后仍有效且资格已确定的施工目标为准，与相机、驻留窗口和绘制命令数量无关。Tile、Wall、每色 Wire 和 Actuator 独立比较：缺失的层保普通虚影，相符的层隐藏，已经存在但不相容的层红色反馈。模板没有要求的世界层透明；额外墙、方块、另一色线不成为清除要求。已保存的半砖／四坡、Inactive、paint、隐形和全亮仍参与对应层判断。依所有者2026-10-27决定，液体继续采集、保存、预览和展示，不参与材料、匹配进度、移动锁定或施工完成；种类、量不同或持续流动不单独阻止非液体完工。

家具须完整证明同一实际对象的建筑种类、样式、位置、方向／形态和全部成员外观，零散同类型格不能拼成完成。目标与世界各用实际原版解释，不以 raw 随机帧或绘图动画硬等；也不因为字段名叫 Random 就忽略真实结构。合法门开闭按同一铰链建筑解释，仍读取当前实际 1×3／2×3 的全部成员。不可读、未收 section、源批未到或无法可靠解释时保持 Unknown，不当空气、Match 或零匹配移动资格。

实例未全部完成时，真实内容拆掉或改错会撤销原匹配并恢复普通／红色虚影。世界匹配只改变可失效显示和操作资格，不写永久 mask；源邻接、投影覆盖、模板、真实建筑、库存及材料均不因此修改。

固定实例只要有任何当前有效 Match，便不能移动，包括离屏部分；完整资格未知时保留目标与核对进展，使用已有反馈等待新的可信点击。移除单独判断，仍可移除该实例或移除所有。同模板其他原点独立判断。Following 与 Moving 候选不因路过已有建筑自动消失；新摆放允许对齐已有内容，固定之后再判断完成。移动的开始、最终确认及实际提交再核原位置 restore 的完整资格，拖动期间原位置出现 Match 就拒绝本次移动并保留原位置，不能用新位置的 Match 冒充原位置锁定。

## 材料与基础自动建造候选
