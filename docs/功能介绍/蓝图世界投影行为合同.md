# 蓝图世界投影行为合同

适用于 [#134](https://github.com/Kuroneko2020/JueMingR/issues/134)／[Draft PR #135](https://github.com/Kuroneko2020/JueMingR/pull/135)，依据所有者明确委托 `JMR_BLUEPRINT_MULTI_INSTANCE_REPAIR_20261024_v1`。它有限替代旧单 world 单图、立即移动／移除合同。实际候选、证据、包和安装见[交付记录](../计划/蓝图真实采集与蓝图库交付记录.md)，合同不代证本人体验、合并或真实联机。

## 从库取出与多实例

每次从可靠库卡“放置”异步读取模板，资格有效后关闭 F5，形成独立候选；确认后同一 world session 可保留同模板及不同模板的多份图纸。每份原点、提交顺序及消除状态独立，共享不可变模板。不设置实例数量、模板宽高或 bbox 面积上限；实际读取与显示按有界窗口分批推进。它们不跨会话保存，图纸库原件不改变。

新取出按保存 Summary 裁空后有效宽高 W/H 的中心格 `((W-1)/2,(H-1)/2)`，整数除法、偶数取左／上中央格；源格减 Summary.Left/Top 得局部格，origin=mouseTile-anchor。89×32 鼠标(100,100)对应 origin(56,85)。中心空气仍保中心小十字，小图／超屏图同规则，真实 tile 大小，不缩图塞屏幕、不自动贴地。相机、反重力及世界缩放使用既有 world transform，UI scale 不改变 tile 尺寸。

## 后提交永久逐层消除

只有确认放置／确认移动才提交；移动是该实例最新的一次提交。按双方当前仍可见的实际内容逐格对齐：新 Tile 消旧 Tile，新 Wall 消旧 Wall，新 Liquid 消旧 Liquid，新每色 Wire 只消同色位，新 Actuator 独立消旧 Actuator。新图缺少的层与空气透明，不按 bbox 擦整片；半砖坡的语义覆盖仍占正常 Tile 格。

新 Tile 碰到旧实例 ObjectId>0 的有效成员时，旧实例该对象全部成员的 Tile 整件消除，包括屏外、窗口外和重叠 bbox 外的成员；同格墙、线、液体、致动器保留。对象身份为(instanceId, objectId)，不能串到同模板或不同模板的另一实例。ObjectId=0 的自然逐格内容、半砖和坡不当残缺对象。

消除是永久的 session mask：后放实例移走／移除，旧层不自动复活；旧实例被消的 mask 随其移动；从图库重新取同模板得到完整新实例。全层均空的实例退休。已 mask 内容既不绘制、不命中，也不再遮别人。Following／Moving 预览不写旧 mask，取消、越界、读取失败不留沿途消除；确认在后台完成整个真实重叠后，由 Host 一次提交全部 mask、origin、顺序和空实例退休。

## 选择、抓取与可信输入

移动入口先进入“点击需要移动的蓝图”；新的可信世界点击命中目标才进入 Moving，保留点击抓取偏移，起点不跳。选目标那次按住不能同时确认，真实释放后新的左键才提交；右键／Esc 恢复原场景。移除入口先提示“点击需要移除的蓝图”，新点击只退休所选一份，不删库、不恢复其曾消除的内容。选取态右键／Esc 仅退出选取。

命中按最新提交且该处有剩余可见内容优先，air 洞和已 mask Tile 不抢目标；半砖、四坡按可见形状。未读取不当空气选穿，等待有界窗口；hover 轮廓与最终选择同一目标资格。启动、选择、确认是独立新手势。Selecting、Following、Moving、确认计算中及 Open 等待均经既有世界动作门；Fixed 被动显示，正常移动／跳跃／攻击不被占用。

失焦、聊天、地图、F5／UI 接管仅暂停可信手势和位移，恢复先取得可信全松，不补点击、不重放接管期间位移。focused=false 不证明释放。Open 等待的明确 Back／Esc 取消退休该事务，迟到 Opened 不复活候选、不关闭新页面。取消 Open 不撤销已受理 Save。

原点不夹进世界；预览显示与世界的交集，确认核完整有效 bounds。越界保留当前候选并提示移回，不因可见片段入界就固定。

## 入口、采集与模板生命周期

F5 标准行、公共默认未绑定快捷键和凝胶工具条共用 Host 命令。普通文字按钮不重复名称静态简介，图标用途和真实 disabled 原因保留。库放置的 busy、页保护、资产保护、采集／草稿／冲突编辑态和无有效 world 原因对应实际资格；无实例允许新取出，多个 Fixed 不构成禁用理由。

移动的SelectingMove、Moving及其Committing来源在原位置显示“取消移动”，同一移动绑定取消自身并恢复旧origin／order／mask和资源；移除选择在原位置显示“取消移除”，同一移除绑定仅退出选择。新取出pending／Following及其Committing来源属于“取消摆放”，原操作可以取消自身；不同功能不冒领取消、不静默切换。Fixed本身不显示取消。正常确认固定保持受理但不显示“正在固定蓝图…”；真实错误仍报告。

手动打开蓝图库的工具条／F5／绑定／Host共用资格：采集模式、待存草稿／受理保存或任一主动投影操作未结束时禁开；只有Fixed时可开。拒绝不取消当前工作，正常打开无教学提示。保存成功的内部转库仍独立有效。SelectingRemove时工具条在移除旁显示“移除所有”，一击清当前world全部同／异模板投影（含离屏）并退出选择，退休在途读取和确认资格；不删模板、不改世界，无新F5行或绑定。

未保存 selection、固定 draft、在途采集／保存时 Place／Move／SelectRemove 同门禁用，提示先保存或退出采集，不清数据、不取消受理工作。空采集可显式退出后摆放，Fixed 可与采集被动共存。关闭 F5、换手持物或隐藏工具条不清 Fixed；真实离开 world／session 清全部实例、候选与读资格。

世界移除只减一实例引用，最后引用才释放共享模板资源。Rename 只改 metadata，不重 parse 正文、不清实例。图库删除确认态直接显示将影响的 N 份引用及候选；唯一 worker 先停止关联新读并释放 reader／Pin，再走原文件删除流程。成功退休该模板全部实例／候选；仅已证明未提交失败可恢复，Protected 与提交未知不一律恢复。未知结果停关联读、保护文件，不盲重建；其他模板及独立事务保留。

## 外观、只读与范围

保留既有真实静态 Tile／Wall／Wire／Actuator／Liquid、raw frame、半砖／四坡／平台、家具方向、Inactive、paint、隐形／全亮规则。半砖保留源片顶部、目标下移8px；家具保成员 raw frame／实际行高／PaddingFix；自然内容 source parity 不随目标 origin 改。晶塔等静态本体不创建实体。墙旧数据无随机 frame，按当前有效蓝图邻接推导；树旧数据无生态上下文，用已定同类型静态代表，不读目的地生态猜源貌。

不运行粒子／模拟／展示物或生物，不采库存、牌墓文字、箱名或运行实体负载；历史 Missing UI 不恢复，旧字段严格校验及真实坏文件保护保留。所有投影本地只读，不改 world、实体、玩家、库存或材料，不发送 TileManipulation。普通好友房主与客机均为本地 overlay，对方不需安装；实际联机／OS输入／FPS和本人接受分别记录。旋转、镜像、贴地、材料、导入导出、实例落盘与施工未授权。

## 未来世界匹配原则（待下一次批准，未实施）

拟按Tile／Wall／Liquid／各线色／Actuator及half-brick／slope结构比较，家具按整件身份与结构，不用随机变体／动画raw frame硬等。相符world内容隐藏、冲突标红；尚未建造部分保留普通虚影属于待确认建议。匹配是可失效重算的显示派生状态，与投影间永久mask分开，world拆掉后虚影应恢复。有相符world内容时拟禁止移动／镜像（资格须看离屏），仍允许移除；全隐藏投影在移除模式仍须有轮廓与命中路径。首次分批、后续局部失效，不逐帧扫全图／重读正文。本节不授权matcher接口／hook／配置／DTO、镜像、施工或本轮验证；仍不写world／实体／库存或消耗材料。
