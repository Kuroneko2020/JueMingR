## 从库取出与多实例

每次从可靠库卡“放置”异步读取模板，资格有效后关闭 F5，形成独立候选；确认后同一 world session 可保留同模板及不同模板的多份图纸。每份原点、提交顺序及消除状态独立，共享不可变模板。不设置实例数量、模板宽高或 bbox 面积上限；实际读取与显示按有界窗口分批推进。它们不跨会话保存，图纸库原件不改变。

新取出按保存 Summary 裁空后有效宽高 W/H 的中心格 `((W-1)/2,(H-1)/2)`，整数除法、偶数取左／上中央格；源格减 Summary.Left/Top 得局部格，origin=mouseTile-anchor。89×32 鼠标(100,100)对应 origin(56,85)。中心空气仍保中心小十字，小图／超屏图同规则，真实 tile 大小，不缩图塞屏幕、不自动贴地。相机、反重力及世界缩放使用既有 world transform，UI scale 不改变 tile 尺寸。

## 后提交永久逐层消除

只有确认放置／确认移动才提交；移动是该实例最新的一次提交。按双方尚未被永久 mask 消除的有效目标逐格对齐：新 Tile 消旧 Tile，新 Wall 消旧 Wall，新 Liquid 消旧 Liquid，新每色 Wire 只消同色位，新 Actuator 独立消旧 Actuator。世界 Match 的暂时隐藏不退出覆盖输入。新图缺少的层与空气透明，不按 bbox 擦整片；半砖坡的语义覆盖仍占正常 Tile 格。

新 Tile 碰到旧实例 ObjectId>0 的有效成员时，旧实例该对象全部成员的 Tile 整件消除，包括屏外、窗口外和重叠 bbox 外的成员；同格墙、线、液体、致动器保留。对象身份为(instanceId, objectId)，不能串到同模板或不同模板的另一实例。ObjectId=0 的自然逐格内容、半砖和坡不当残缺对象。

消除是永久的 session mask：后放实例移走／移除，旧层不自动复活；旧实例被消的 mask 随其移动；从图库重新取同模板得到完整新实例。全层均空的实例退休。已 mask 内容既不绘制、不命中，也不再遮别人。Following／Moving 预览不写旧 mask，取消、越界、读取失败不留沿途消除；确认在后台完成整个真实重叠后，由 Host 一次提交全部 mask、origin、顺序和空实例退休。

## 选择、抓取与可信输入

移动入口先进入“点击需要移动的蓝图”；新的可信世界点击命中目标才进入 Moving，保留点击抓取偏移，起点不跳。选目标那次按住不能同时确认，真实释放后新的左键才提交；右键／Esc 恢复原场景。移除入口先提示“点击需要移除的蓝图”，新点击只退休所选一份，不删库、不恢复其曾消除的内容。选取态右键／Esc 仅退出选取。

命中按最新提交且该处有有效目标优先，air 洞和已 mask Tile 不抢目标；半砖、四坡按目标形状。世界 Match 隐藏后仍可在移除模式凭目标和轮廓选取。未读取不当空气选穿，等待有界窗口；hover 轮廓、实际点击与确认读取同一份当前移动资格，未知保留准确目标，不选穿到下层。启动、选择、确认是独立新手势。Selecting、Following、Moving、确认计算中及 Open 等待均经既有世界动作门；Fixed 被动显示，正常移动／跳跃／攻击不被占用。

失焦、聊天、地图、F5／UI 接管仅暂停可信手势和位移，恢复先取得可信全松，不补点击、不重放接管期间位移。focused=false 不证明释放。Open 等待的明确 Back／Esc 取消退休该事务，迟到 Opened 不复活候选、不关闭新页面。取消 Open 不撤销已受理 Save。

原点不夹进世界；预览显示与世界的交集，确认核完整有效 bounds。越界保留当前候选并提示移回，不因可见片段入界就固定。

## 入口、采集与模板生命周期

F5 标准行、公共默认未绑定快捷键和凝胶工具条共用 Host 命令。普通文字按钮不重复名称静态简介，图标用途和真实 disabled 原因保留。库放置的 busy、页保护、资产保护、采集／草稿／冲突编辑态和无有效 world 原因对应实际资格；无实例允许新取出，多个 Fixed 不构成禁用理由。

移动的SelectingMove、Moving及其Committing来源在原位置显示“取消移动”，同一移动绑定取消自身并恢复旧origin／order／mask和资源；移除选择在原位置显示“取消移除”，同一移除绑定仅退出选择。新取出pending／Following及其Committing来源属于“取消摆放”，原操作可以取消自身；不同功能不冒领取消、不静默切换。Fixed本身不显示取消。正常确认固定保持受理但不显示“正在固定蓝图…”；真实错误仍报告。

手动打开蓝图库的工具条／F5／绑定／Host共用资格：采集模式、待存草稿／受理保存或任一主动投影操作未结束时禁开；只有Fixed时可开。拒绝不取消当前工作，正常打开无教学提示。保存成功的内部转库仍独立有效。SelectingRemove时工具条在移除旁显示“移除所有”，一击清当前world全部同／异模板投影（含离屏）并退出选择，退休在途读取和确认资格；不删模板、不改世界，无新F5行或绑定。

未保存 selection、固定 draft、在途采集／保存时 Place／Move／SelectRemove 同门禁用，提示先保存或退出采集，不清数据、不取消受理工作。空采集可显式退出后摆放，Fixed 可与采集被动共存。关闭 F5、换手持物或隐藏工具条不清 Fixed；真实离开 world／session 清全部实例、候选与读资格。

世界移除只减一实例引用，最后引用才释放共享模板资源。Rename 只改 metadata，不重 parse 正文、不清实例。图库删除确认态直接显示将影响的 N 份引用及候选；唯一 worker 先停止关联新读并释放 reader／Pin，再走原文件删除流程。成功退休该模板全部实例／候选；仅已证明未提交失败可恢复，Protected 与提交未知不一律恢复。未知结果停关联读、保护文件，不盲重建；其他模板及独立事务保留。

## 外观、只读与范围

保留既有真实静态 Tile／Wall／Wire／Actuator／Liquid、raw frame、半砖／四坡／平台、家具方向、Inactive、paint、隐形／全亮规则。半砖保留源片顶部、目标下移8px；家具保成员 raw frame／实际行高／PaddingFix；自然内容 source parity 不随目标 origin 改。晶塔等静态本体不创建实体。墙旧数据无随机 frame，按当前有效蓝图邻接推导；树旧数据无生态上下文，用已定同类型静态代表，不读目的地生态猜源貌。

不运行粒子／模拟／展示物或生物，不采库存、牌墓文字、箱名或运行实体负载；历史 Missing UI 不恢复，旧字段严格校验及真实坏文件保护保留。所有投影本地只读，不改 world、实体、玩家、库存或材料，不发送 TileManipulation。普通好友房主与客机均为本地 overlay，对方不需安装；实际联机／OS输入／FPS和本人接受分别记录。旋转、镜像、贴地、材料、导入导出、实例落盘与施工未授权。

## 世界匹配、移动资格与完成退休

匹配以这一份实例在当前原点、当前永久 mask 后仍有效的完整目标为准，与相机、驻留窗口和绘制命令数量无关。Tile、Wall、Liquid、每色 Wire 和 Actuator 独立比较：缺失的层保普通虚影，相符的层隐藏，已经存在但不相容的层红色反馈。模板没有要求的世界层透明；额外墙、方块、另一色线不成为清除要求。已保存的半砖／四坡、Inactive、paint、隐形和全亮仍参与对应层判断，液体种类和非零量精确比较。

家具须完整证明同一实际对象的建筑种类、样式、位置、方向／形态和全部成员外观，零散同类型格不能拼成完成。目标与世界各用实际原版解释，不以 raw 随机帧或绘图动画硬等；也不因为字段名叫 Random 就忽略真实结构。合法门开闭按同一铰链建筑解释，仍读取当前实际 1×3／2×3 的全部成员。不可读、未收 section、源批未到或无法可靠解释时保持 Unknown，不当空气、Match 或零匹配移动资格。

实例未全部完成时，真实内容拆掉或改错会撤销原匹配并恢复普通／红色虚影。世界匹配只改变可失效显示和操作资格，不写永久 mask；源邻接、投影覆盖、模板、真实建筑、库存及材料均不因此修改。

固定实例只要有任何当前有效 Match，便不能移动，包括离屏部分；完整资格未知时保留目标与核对进展，使用已有反馈等待新的可信点击。移除单独判断，仍可移除该实例或移除所有。同模板其他原点独立判断。Following 与 Moving 候选不因路过已有建筑自动消失；新摆放允许对齐已有内容，固定之后再判断完成。移动的开始、最终确认及实际提交再核原位置 restore 的完整资格，拖动期间原位置出现 Match 就拒绝本次移动并保留原位置，不能用新位置的 Match 冒充原位置锁定。

全部有效目标得到当前、完整的 Match 证明后，Host 在安全更新出口实际移除这一份世界实例，效果等同玩家单实例移除；不是保留永久隐藏实例。确认中先延后退休，到提交成功／失败／取消后的安全点重新核身份与证明，不取消无关操作。退休释放命中、绘制、窗口、匹配账本与在途引用，最后模板引用才释放共享源；不删除模板，不影响同模板其他实例，不撤销既有永久 mask。之后拆掉真实建筑不会使旧投影复活；从图库再取出则是新的完整实例。有效目标因永久 mask 归零仍走原空实例退休规则，不计为世界建造完成。

首次按稀疏有内容记录有界覆盖，真实局部变化先撤销旧证明，再有界重核；最终完成不能拼接跨 tick 的过期 Match。完整当前证明建立并持续有效时自然收尾，不依赖点击、移动、视野变化、停止家具合法运行或强制重复全图第二遍。稳定无变化不周期重读全正文或逐格扫 bbox，Draw 不推进世界比较，最后实例退出后停止匹配工作。致命模板读取失败按失效身份清理世界实例及活动检查，其他模板继续；模板原件保留，普通用户取消移动仍恢复原实例。不新增开关、完成列表、计数面板、成功弹窗或确认框；镜像、施工、材料和实例落盘仍不在本任务内。

初始已完整与缺一块后补齐都在确认后主动持续核对；补齐可复用其它仍有效证明，首次建立全量覆盖仍承担必要工作。多个小家具可以合并有限运输并在同次更新剩余预算内连续采样，每件保独立完整证明；局部变化不撤无关兄弟。移动查询的有限优先不消耗普通轮转资格，持续变化、待源或大批仍给其它可执行实例有限服务机会。实际响应按建筑目标、对象、供源和有效覆盖记录，不承诺任意规模同一帧完成。

## 材料与基础自动建造候选

世界材料按所有 Fixed 实例在当前原点与永久 mask 后的有效目标核算。完整家具计一件，已有正确本体不重复收取；同型本体的油漆、涂层、坡形、半砖、Inactive 等差异仍保留后处理需求与最终不匹配。异种冲突不授权拆除，未知不当空气或齐料。全部实例先合并需求再对照同次主背包 0–49 的可用库存；单份查看只解释这一份，不预留材料、不改变施工范围。未读取与已读取后数量为零分开。

自动建造首次默认关闭，由 F5 或公共绑定改变同一设置。开启后普通方块、墙和具有可靠原版放置描述的完整家具，使用真实主背包物品，沿原版选槽、互动距离、支撑、动画和 ItemCheck 放置。不移动玩家，不补材料，不替换冲突，不复制容器或实体内容。普通平台本体可以先放置；尚未符合的锤形等目标保留。后处理实际执行不在本轮，能可靠解释的对应材料仍展示。

缺料、超距或无支撑的一项让出其它有效目标；补料、走近或相关世界变化后自动继续。关闭停止新动作，在途原版使用及选槽归还仍收尾；手动用物、左右键、SmartSelect 和新换槽优先。主动采集、移动、选择移除、提交和删除期间不启动施工；普通 F5 与材料查看不单独暂停自动玩法，实际文字、拿物、容器等占用仍约束它。

一次原版墙动作可补邻洞，自动油漆／致动器饰品可消耗额外来源；按真实消耗和世界变化解释，不强制每次只扣一件，也不恢复合法消耗。物品使用开始、扣料或发包均不单独证明完成。普通 Tile／Wall 与对象同步按原版实际机制解释；容器存在原版放置回执时，当前请求未明确收尾前保留这一份退休协调。异常或消耗后无可确认本体时保护真实相关来源，关开设置不解锁未知结果。最终仍由完整当前 world match 在稳定出口退休单一实例，不写第二完成表、不放宽外观标准。
