# 蓝图世界投影行为合同

本合同适用于 [#134](https://github.com/Kuroneko2020/JueMingR/issues/134)／[Draft PR #135](https://github.com/Kuroneko2020/JueMingR/pull/135) 的同批世界投影扩展，依据所有者确认的 `JMR_BLUEPRINT_WORLD_PLACEMENT_20261023_v1`。实际候选、验证、独审、包和安装回任务与[交付记录](../计划/蓝图真实采集与蓝图库交付记录.md)；合同不证明本人体验或合并。

## 从库取出与中心格

蓝图库卡片“放置”异步读取可靠资产，身份有效后关闭 F5，在世界按真实物块大小显示半透明图纸。空气透明，不覆盖真实世界。相机、UI 缩放和世界缩放只改变屏幕呈现；已固定的世界原点不随玩家移动。

取出时按保存 Summary 裁空后的有效宽高 W/H 取中心格 `((W-1)/2,(H-1)/2)`，整数除法，偶数取左／上中央格。源格减 Summary.Left/Top 后成为局部格；原点为鼠标世界格减中心格，目标格为原点加局部格。89×32 的锚点为(44,15)，鼠标(100,100)对应原点(56,85)。中心是空气也不改锚点；同一规则适用于小图和超屏大图，不缩图、不找最近实块。摆放显示中心十字和完整 bounds 的可见轮廓。

## 确认、移动与取消

同一世界会话最多一幅图纸，不持久化实例。取出新模板时保留旧固定身份与原点作为可恢复事务；仅候选显示。启动动作必须真实释放，之后新的合格世界左键才固定。右键或 Esc 取消，恢复旧固定图或回到无图。读新模板失败保留旧固定图。

Fixed 被动显示并释放普通世界输入。移动沿同一 Host 命令进入 Moving，入口保持原位，在可信世界中性样本建立鼠标基准，以后只加鼠标格增量。UI 启动坐标不成为基准；取消恢复原固定原点，新左键才提交新原点。失焦、聊天、地图和 UI 接管暂停位移与确认，恢复后须真实全松再接受新动作，不补点击或接管期间位移。失焦本身不证明松键。

原点不夹到世界内。预览显示与世界的交集，左键确认按完整有效宽高作常数时间边界检查；越界保留跟随／移动并简短提示，不能因为当前可见块在世界内就确认整幅越界图。

## 入口与采集互斥

手持凝胶快捷栏在有图时增加“移动蓝图／移除蓝图”，摆放或移动中前者变“取消摆放”。F5 蓝图页增加标准“移动蓝图／移除蓝图”动作及公共绑定，默认未绑定；关闭凝胶条也能操作。移除只移除世界图纸，库资产保留；切换手持物或隐藏条不改变 Fixed。

有未保存选区、固定草稿或已受理在途采集／保存时，Place／Move 共用同一资格门，提示“请先保存或退出当前采集”，不清数据、不撤销已受理保存、不加弹窗。空采集且无在途可以先退出空采集再摆放；完成／取消后不自动恢复采集。Fixed 不禁止明确开始采集，Following／Moving 则要求先完成或取消。

按钮、工具条与绑定共用 Host 命令；UI 点击保持正常，不能被当成图纸确认或世界攻击。关闭 F5 不清 Fixed，离开真实 world／session 清本次图纸与资格，迟到回执不能在新会话复活。

## 保存内容与静态外观

保留 Tile／Wall／Wire／Actuator／Liquid 各层，以及半砖、四坡、平台、raw frame、家具方向、Inactive、paint、隐形与全亮。电线按四色细线、致动器按小符号绘出，不改变真实世界电路可见规则。图纸态隐形内容仍可辨识，空气不擦除。

半砖裁去源上半并下移，坡面按原版条带规则；平台走专用分支。家具保每格 raw frame，并按原版元数据解释真实行高、PaddingFix、绘制偏移；闭门成员随机 frameX 不被强制一致。草／药草／长草保原版外延，源坐标奇偶决定的 flip 不随目标原点改变。晶塔使用纯静态建筑本体，不创建实体。墙缺失的原随机 frame 由蓝图邻接确定，树缺失生态上下文用确定性同类型代表，不从目的地生态猜源貌。

不要求运行原版粒子、火焰、风摆或展示物／生物。库存、牌墓文字、箱名、展示物及运行实体负载不在范围，正常建筑不发 Missing 或替代黄字。旧字段仍严格校验，真实未知 section、残缺组、变化和坏文件不降级成功。外观规则与成本见[实现设计](../设计/蓝图世界投影实现设计.md)。

## 资产与安全边界

改名只改库 metadata，不改变投影身份、原点或重读正文。删除引用模板沿原有二次确认，并提示同时移除当前图纸；唯一 worker 先释放 index 句柄，再执行可靠删除。成功移除关联图纸；明确未提交失败可按旧位置重新读取，提交未知停止读取受影响 ID 并保护文件，不伪称恢复或成功。删除无关模板不清当前图纸。

投影完全本地，不改世界 tile、实体、玩家或库存，不扣材料、不施工、不发送 TileManipulation。普通好友主客机同为本地 overlay，对方无需安装；真实联机、OS 输入、最终图形与性能只按各自实际证据记录。旋转、镜像、贴地、锚点菜单、材料、实例持久化和自动施工未授权。
