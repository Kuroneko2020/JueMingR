# 玩家使用指南

对应本批完整 ContinuousProcessing 开发候选包；本文件是仓库离线指南，游戏内不设帮助页面。更精确的能力边界见[功能索引](功能索引.md)。

打开与查看：按 F5 打开或关闭决明R。点击顶部分类，拖动标题栏移动窗口；长页在内容区滚动。普通功能名称悬停可看用途，复杂功能在自己的配置入口调整。

设置快捷键：双击功能旁的键盘图标，点击“录入快捷键”，再按主键；组合键先按修饰键。Esc 取消录入，F5 保留给主窗，不支持滚轮绑定。清除绑定不会关闭功能。原版按键冲突会提醒，R 内重复绑定会拒绝；退出录入后先松开按键再重新操作。

快捷物品：物品页的“保持收藏”和“快捷物品”各有总开关，默认关闭。总开关按键只切换功能，每条物品的“使用键”才执行那条操作，还需启用该条目。只使用背包中的快捷栏和主物品栏，不从银行取物；替代物品范围以配置为准。

整理物品：自动堆叠、出售、丢弃默认关闭。它们处理可确认的新拾取或开启物品产生的输入，不会一开启就扫掉整个旧背包。出售需要你先手动打开 NPC 商店；丢弃会覆盖垃圾槽，原垃圾槽物品会被替换。

持续开袋与提炼：物品页分别开启。打开背包按住 Shift＋右键连续开袋，松开停止，合法商店中也可开主包袋并进行已启用的物品处理。自动提炼靠近有效机器后处理材料，不需持续按鼠标；52项叶绿额外兑换保持原版手动。

自动重铸：杂项页双击同排输入框编辑完整词缀名，回车或点添加。下方是横排居中的词缀小格，悬停看完整名称，右上角叉号删除。自行打开哥布林重铸、放入物品并长按原版按钮；每次正常扣费，任一有效目标命中停，空名单不自动付款，命中后须松手再按。三个加工开关默认关闭，普通名单不占移动键。精确停止与未知结果边界见[连续加工合同](连续加工行为合同.md)。

收藏与存钱：保持收藏跟随有证据的物品流转，新拆出的堆叠不会自动收藏，放入容器、银行或交易后不会凭名字补回收藏。自动存钱默认关闭，只处理背包中未收藏的钱币并存入当前可达的个人银行，不存世界箱子；手动取出的钱币有保护，不会立刻被存回。

查询与宣告：查询页查看原版物品、合成和用途，不会生成物品或替你合成、取物。附近箱子查询有范围限制；普通多人客户端只能使用本连接已收到完整内容的箱子，未知不等于空箱。地图快捷宣告默认关闭，开启并设置触发键后通过原版聊天发送；本机调用成功不保证别人已经收到。

信息与地图：信息页管理显名与信息窗；群系显示默认开启，世界感染、幸运值和渔夫任务默认关闭。地图页查看标记、探索比例和死亡记录等。显示与记录是不同开关：足迹默认记录开启、展示关闭；关闭展示不会停止记录，关闭记录不会删除历史。清除足迹需连续确认，完成后不可恢复。

笔记与保存：笔记页点“+”新建，双击标题或正文编辑。标题 Enter 保存，正文 Enter 换行，Esc 取消当前字段草稿；保存失败会保留草稿并阻止依赖保存的离开。笔记位于当前 Terraria 安装目录下 JueMingRData/notes/notes.json，同一安装可跨角色和世界使用，不会自动同步到另一台电脑。

保留数据：配置及功能记录保存在当前安装目录的 JueMingRData 中。更新或排错时保留整个目录及备份，不要随意删除。首次入门提醒按本机可靠角色跨世界记忆；身份无法确认时只保证当前会话不重复，仍可随时查阅本指南。

单人和多人：关于页与群号复制属于本地操作，普通多人客户端可用，无需服务器安装 R。各玩法仍有自己的单人或数据可用边界，不能把页面可用理解为所有功能均已通过联机验证。

反馈问题：返回关于页，复制 QQ 群号，说明现象和操作步骤；截图由你自行选择发送。本工具不会自动上传资料、发群消息或打开支付。

## 自动恢复、增益与邻近服务

增益页提供自动回血/回蓝、护士、家具与自动增益，杂项页提供自动收税，默认均关闭。回血可选智能或快速，回血/回蓝旁的“配置”打开独立药品窗口；允许类型仍需真实持有合法药品。增益名单默认显示，左右分可选与已选，点击添加或移除；跟随加/跟随删在清空左侧，开启时显示短线。已选物品有库存显示勾，缺货显示叉并保留名单等待补货。名单打开不影响移动；游戏在后台仍实际运行时，自动增益也会补充缺失效果，真正暂停时不运行。护士按原版扣款，收税掉落世界金币；实测消费请使用独立测试角色和世界。本批能力及上述界面、输入和后台修订已获所有者接受，随 [PR #98](https://github.com/Kuroneko2020/JueMingR/pull/98) 合并进入 `main` 生效。精确门槛、来源、失败和验证边界查[行为合同](自动恢复增益与邻近服务行为合同.md)。
