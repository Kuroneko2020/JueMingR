# Legacy 物品

**Legacy 行为参考，尚不代表 JueMingR 已实现或已接受全部合同。** 来源：旧功能根 `物品页/` 十篇，自动堆叠正文更新标记为 26-08-20-1344；[来源口径](功能索引.md#来源覆盖和限制)。入口为 Legacy F5 物品页。

## 自动堆叠与存钱

详细事实、证据及需求裁决见[自动存放功能行为合同候选](自动存放功能行为合同.md)，包括物品页十行与真实热键入口；候选尚待所有者确认，不代表 R 已实现。

**自动堆叠是有可靠来源的选择性 QuickStack，不是全背包整理。** 普通世界拾取前须无同 type+prefix 物品；受控持续开袋另有例外，可把原有同类合格整栈一并纳入，并非只移动新增数量。主背包前 58 槽按资格判断，不整栏排除快捷栏/弹药；装备样物品、收藏、不可堆叠物不作候选。世界箱或四类个人银行单取、LootAll、拆分或经 cursor 取出不会建立可靠拾取意图，关闭容器不改变该来源；但先前取出已被处理后，后来的受控开袋可能重新选入同类整栈，不能承诺永久保留每个旧取出数量。提交请求不等于存妥。

实际普通物品目标是附近有世界 Chest 的容器，包含符合原版条件的梳妆台；个人银行只进入旧前检，不进入这条实际存放路径。先补兼容栈，再可在已有同 type 的箱内空位建立新栈；部分来源减少就可能结束整个批次，不等于全批完成或端到端守恒。

自动存钱只处理钱币，普通物品不受影响。开启时钱币归它处理，自动堆叠不抢；关闭后钱币才按同一可靠来源合同进入自动堆叠。取出保护不按固定秒数或数量随身额度释放，仅在可靠观察离开全部银行范围、玩家-世界身份改变或自动存钱关→开时解除。读取失败不能当“已离开”。空银行首币补救只覆盖可证明的 player.bank，不扩到其它银行或普通箱。

鼠标拿物、世界箱/个人银行/未知负容器状态、聊天/NPC 对话有明确阻挡；只有 player.chest=-1 表示无容器 UI。不能扩大为笔记、商店、地图或失焦后一切旧请求都已安全暂停。自动出售/丢弃等待自动堆叠 pending；保护拒绝后没有 pending 时仍可按自身名单处理。自动捕捉/收获正在用物品时后台事务让路，但新来源拒绝或身份变化也可能删除待存，不能无条件说等待永远保留。机制与版本 ABI 见[箱子与权威](../AI经验笔记/物品箱子与多人权威.md)。

## 其它物品能力

| 功能 | 用户操作与重要选项 | 副作用/相邻边界 |
| --- | --- | --- |
| 保持收藏 | 已收藏物品换装、替换、垃圾桶往返后尽量恢复收藏 | 手动取消收藏必须尊重，不移动物品或成为出售/丢弃来源 |
| 快捷物品 | 配物品列表和独立使用键，按一次用一次；同类多形态按匹配规则查找 | Esc 取消、录入时 Backspace 清空；最右主开关键只开关该能力，不使用物品 |
| 持续开袋/快速开袋 | Shift + 真实长按右键重复打开可开袋/匣物品 | 消耗原物并产生原版结果；分批让路给堆叠/出售/丢弃，不在普通 hover 自动开 |
| 自动出售 | 名单默认旧鞋、钓鱼海草、锡罐，靠近可开商店 NPC 尝试出售 | 排除收藏/钱币，使用原版商店路径；可能留下商店 UI，不承诺严格多人已验证 |
| 自动丢弃 | 名单默认空，之后把名单物品送入原版垃圾桶 | 排除收藏/钱币，原垃圾桶替换有丢失风险，不能说成无副作用转存；堆叠/出售优先 |
| 自动提炼 | 携带合适原料靠近提炼机/叶绿提炼机时自动加工 | 消耗原料，不直接造产物；原文“重复右键”与原版笔记 ItemCheck 使用路径存在措辞差异，后续须核对，不能把右键当已证实机制 |
| 自动收获 | 带再生法杖/再生之斧靠近盆栽成熟草药，收获并尝试同种复种 | 不误收未成熟，缺种子/范围不可达不直接改 Tile；与捕捉公平让路，产物交可靠拾取来源处理 |
| 自动捕捉 | 自动/手持/关闭，配置八类：鱼饵、仙灵、金色、宝石、普通、松露虫、七彩草蛉、其它，默认八类全选 | 特殊类优先互斥归类，关鱼饵不等于关松露虫。手持不自动切网；背包打开仅“手持且已选快捷栏虫网”窄例外。按原版挥网范围，钓鱼后需恢复鱼竿/抛点 |

名单、模式、分类与绑定属于 Legacy 配置；待存事务、容器来源、临时选槽/恢复不等于长期用户文件。具体旧存储/导入需在对应功能任务核对，R 当前数据入口见[配置设计](../设计/配置持久化与用户数据布局.md)。来源说明没有给出的默认值不猜。原版路径的目标兼容不等于所有多人拓扑已验证，本轮没有动作或游戏测试。
