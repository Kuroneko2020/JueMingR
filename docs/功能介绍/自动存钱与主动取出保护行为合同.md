# 自动存钱与主动取出保护行为合同

本合同来源于所有者本轮 G06 开发 Prompt；实施与验收状态以 [任务 #93](https://github.com/Kuroneko2020/JueMingR/issues/93) 为准。它不修改冻结的全功能调查，也不证明已经通过实机验收。

## 用户能力

- 默认关闭，独立保存偏好。F5 物品页提供“自动存钱”开关、公共快捷键入口和名称悬停说明。快捷键切换开关，不强制执行交易。
- 来源为本地角色真实 inventory 0..57 的正数量未收藏铜、银、金、铂金币；鼠标、槽 58、装备及银行不是来源。收藏钱币仍计入完整守恒检查。
- 目标仅为当前原版范围与资格内的四类个人银行，按原版发现顺序去重。普通箱不是目的地；不打开、召唤或使用物品制造银行入口。
- 正常整理遵循原版进位、部分容纳和余量退回。只有存钱罐允许无币起步：存在合法空槽时选择最高币种的一整栈，同币种按来源槽顺序。另三种无币银行不提供此补充能力。
- 文本输入、NPC 对话、打开容器、鼠标持物、失焦、暂停、死亡、相关原版锁或实际物品冲突时不开始交易；只打开背包不整体禁用。

## 主动取出

开启期间，从普通箱或四个人银行实际取出钱币到钱包或鼠标，保护全部自动存钱，包括随后新获得的钱。覆盖 LootAll、Shift、左键、连续右键及嵌套转移。点击或钱包单独增长不是来源证据。

保护无倒计时、无金额额度；关闭容器、背包或 F5，消费、换币、换槽和新拾币均不解除。任一有效银行入口仍在范围内就继续；只有完整可靠的零入口观察才解除。无币期间仍观察保护退出。关闭再开启显式重置意图，但不清除未知交易；明确新角色、世界、连接不继承旧意图。临时身份读取失败不冒充离开或新会话。

## 结果与故障

比较完整钱包与目标账户的铜币等值，钱包减少必须等于银行增加；保护非币、收藏来源、鼠标、槽 58 和独立实物关系。业务结果区分部分完成与未执行，不将普通结果逐次通知。返回值不是完成证据。

正规操作后的零返回、异常或无法读回不自动允许补充交易。已经或可能写入但不能确认的交易暂停新存款，不补币、不恢复整包、不重放；无副作用的暂时拒绝可在相关事实变化后恢复。普通多人客户端沿原版个人账户同步和角色保存，无虚构逐笔服务器确认。服务器角色模式另作局部限制。

## 物品页呈现

所有者在 #93 的 UI 追加指令中明确替代原 G06 Prompt 第 8 节及先前合同对“简短状态”的过宽解释：正常开关由选中态表达；加载、保存、保存完成、F5／容器／手动让路、无币、无银行和普通无进展均不占下方状态行、不预留高度，也不改成聊天刷屏。原业务准入、保存暂停和可靠提交时序不变。

名称悬停平时只说明用途；主动取出保护或已确认的无空间等当前有用原因按需显示。真实保存失败、功能不可用、交易结果未确认通过既有本地出口一次提醒，当前未解决原因仍可从名称悬停查看。无关成功、开关或移开鼠标不解除别项错误或未知交易保护；新的独立失败仍会提醒。普通状态变化不使物品页重新排版，名称悬停不触发银行、背包或文件读取。

## 本批首存空槽规范化的限定澄清

所有者已在本轮继续实施授权中澄清 Prompt §6.3，依据与授权见 [#93 的限定澄清](https://github.com/Kuroneko2020/JueMingR/issues/93#issuecomment-5725175285)。Terraria 1.4.5.8 的 MoveCoins 在目标无钱币时，先将 `stack < 1 || type < 1` 的目标槽替换成 plain `new Item()`，再正常返回 0，不进入钱包写入循环。仅本批存钱罐无币起步允许这一已证实的空槽重建；不扩展到其它三种无币银行，也不改变全项目身份保护原则。

必须逐槽严格证明未转移钱币：钱包59槽（含收藏来源与槽58）、鼠标、目标非空物品和其它三个账户的引用、数量、所在槽及全部属性不变；只有目标原合法空槽允许换成独立的新引用，且所有字段符合固定原版 plain Item。金额相等、返回0或IsAir各自都不足以放行。玩家、会话、账户、数组及有效入口继续有效，取出意图、手动操作、原版锁和共享占用仍须检查。

异常、无法读回、实际转移、非空等值替换、金额不变但槽内容改变或其它无法解释变化均不进入该例外。证明通过后废弃原空槽和首存依据，基于操作后的真实来源、目标与代次重新捕获证据；释放已完成的原版操作许可后，重新核验这份证据仍有效并取得独立许可。不得写回旧空对象凑不变。首存仍只转移最高币种的一整栈，同币种按来源槽序；写后证明两端守恒、独立实物及原版同步/保存。部分写入不明时停止，不补币、不整包恢复、不换账户重放。

本轮不实现关于页面、通用帮助或反馈平台；本功能自身说明和上述反馈属于交付范围。旧 Prompt 与历史回执保留原貌。完成本地验证、独立只读审查、完整包和安全安装后等待实测及外审，不自动合并或发布。
