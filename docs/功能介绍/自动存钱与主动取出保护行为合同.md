# 自动存钱与主动取出保护行为合同

本合同来源于所有者本轮 G06 开发 Prompt；实施与验收状态以 [任务 #93](https://github.com/Kuroneko2020/JueMingR/issues/93) 为准。它不修改冻结的全功能调查，也不证明已经通过实机验收。

## 用户能力

- 默认关闭，独立保存偏好。F5 物品页提供“自动存钱”开关、公共快捷键入口、名称说明和简短状态。快捷键切换开关，不强制执行交易。
- 来源为本地角色真实 inventory 0..57 的正数量未收藏铜、银、金、铂金币；鼠标、槽 58、装备及银行不是来源。收藏钱币仍计入完整守恒检查。
- 目标仅为当前原版范围与资格内的四类个人银行，按原版发现顺序去重。普通箱不是目的地；不打开、召唤或使用物品制造银行入口。
- 正常整理遵循原版进位、部分容纳和余量退回。只有存钱罐允许无币起步：存在合法空槽时选择最高币种的一整栈，同币种按来源槽顺序。另三种无币银行不提供此补充能力。
- 文本输入、NPC 对话、打开容器、鼠标持物、失焦、暂停、死亡、相关原版锁或实际物品冲突时不开始交易；只打开背包不整体禁用。

## 主动取出

开启期间，从普通箱或四个人银行实际取出钱币到钱包或鼠标，保护全部自动存钱，包括随后新获得的钱。覆盖 LootAll、Shift、左键、连续右键及嵌套转移。点击或钱包单独增长不是来源证据。

保护无倒计时、无金额额度；关闭容器、背包或 F5，消费、换币、换槽和新拾币均不解除。任一有效银行入口仍在范围内就继续；只有完整可靠的零入口观察才解除。无币期间仍观察保护退出。关闭再开启显式重置意图，但不清除未知交易；明确新角色、世界、连接不继承旧意图。临时身份读取失败不冒充离开或新会话。

## 结果与故障

比较完整钱包与目标账户的铜币等值，钱包减少必须等于银行增加；保护非币、收藏来源、鼠标、槽 58 和独立实物关系。部分完成与未执行分别反馈。返回值不是完成证据。

正规操作后的零返回、异常或无法读回不自动允许补充交易。已经或可能写入但不能确认的交易暂停新存款，不补币、不恢复整包、不重放；无副作用的暂时拒绝可在相关事实变化后恢复。普通多人客户端沿原版个人账户同步和角色保存，无虚构逐笔服务器确认。服务器角色模式另作局部限制。

## 待裁决的原版空槽语义

Terraria 1.4.5.8 的 MoveCoins 在“目标无钱币、返回 0”前，会把目标空槽替换为新的 Item。Prompt 6.3 要求槽状态没有变化，因此已向所有者询问是否允许“严格证明只有规范空槽引用归一化后，废弃旧许可、重新核验”的窄例外。在裁决前不实现依赖此例外的首存放行，不以零返回代替证据。

本轮不实现关于页面、通用帮助或反馈平台；本功能自身说明和状态属于交付范围。完成本地验证、独立只读审查、完整包和安全安装后等待实测及外审，不自动合并或发布。
