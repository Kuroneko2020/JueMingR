# 旅行菜单行为合同

本合同来自所有者委托的 `JMR-JOURNEY-MENU-20261018-v1` 及按钮收尾决定。所有者已反馈功能实测未发现问题；本批接受随 PR #123 合并进入主线生效，实际候选、合并、安装及未验证范围查 [#122](https://github.com/Kuroneko2020/JueMingR/issues/122)。

## 入口与支持范围

隐藏资格与旅行开关分别管理。取得当前进程隐藏资格后，F5 杂项页在游商测试附近提供“旅行菜单”的开启、关闭两个按钮和绑键入口；默认无绑定。普通玩家提示不公开隐藏手势。锁定时整行和绑定入口均不出现，既有保存绑定不注册、不吞掉普通按键。解锁不会自动开启。

所有者在 [#156](https://github.com/Kuroneko2020/JueMingR/issues/156) 撤销仅限单人的入口限制：完整本地角色/世界会话就绪后，单人或联机客户端（含 Host & Play、加入朋友或独立专服）均可尝试，原版权限及服务器环境决定实际效果，不要求服务器安装 R，不保证所有服务器可用。服务端角色（SSC）及未验证的人物云存档仍在副作用前明确拒绝；单人世界云存档保护保留。联机世界描述符只作原版资源身份，不要求远端世界存在本地可写文件，不改云账户、文件位置或世界匹配准入。原生旅行角色和旅行世界在 R 关闭、隐藏锁定时仍走原版。

开启及开关快捷键调用同一业务入口；原版窗口确认可用后 F5 才让出。已开启时再次点击“开启”只重新展开同一原版窗口，保留原激活与力量基线及已选择的持续力量；窗口已经可见时保持可见。快捷键仍切换功能开关。失败显示真实失败，不把设置值或请求已提交视为已打开。快捷键按既有短提示约定反馈，普通按钮成功保持静默。

若原版保存已在旅行关闭时进入实际串行化，开启会在能力生效前提示稍后重试；不等待保存I/O、不自动排队重开。已经开启后的保存及关闭仍可继续。

## 原版能力

原版界面负责分类、搜索、研究与复制、滑条和力量按钮，不建立第二个取物面板。本会话中的有效研究物品显示为研究完成，实际物品沿原版鼠标/背包交接和使用规则产生。不可研究 ID 不开放，真实研究记录不写满；对虚拟已完成的物品执行研究不消耗物品、不写回虚拟进度。

本批包含时间跳转、时间速度及冻结，风雨及对应冻结，敌怪生成率，原版运行时难度滑条，无敌及原版关联效果，原版扩大操作范围和感染蔓延控制。各项效果由锁定 1.4.5.8 的真实消费者应用。难度滑条改变原版有效难度及后续规则，不改世界保存的基础模式；已有 NPC 沿原版生命周期处理，不逐只回滚历史属性。

首次开启保持当前正常行为，不自动开启无敌、冻结或范围，不把专家/大师世界降到旅行默认倍率。联机不主动改写已收到的共享难度、时间等世界力量，不更改原版力量权限；有效难度沿真实世界的原生资格，普通世界不会因打开菜单激活未生效的旅行默认倍率，真正旅行世界继续消费服务器同步难度。原生菜单的请求及服务器拒绝仍按原版处理。原生旅行组合保留已有研究和力量；单人关闭增强时恢复原基线，联机关闭仅归还本地借用的个人能力，不以旧世界基线覆盖后到的服务器共享状态，不提交额外还原请求。调用、局部力量变化或菜单已打开均不代表服务器已经接受。

## 生命周期与保存

旅行状态只属于本次世界会话，不写长期开关或力量预设。收起原版窗口保留本会话的持续力量；关闭功能、离开世界、换角色/世界或局部故障结束会话并撤去借用状态。关闭与必要恢复不依赖 F5 仍可见或再次解锁。

人物原始 difficulty、世界基础 GameMode 和文件元数据始终保持原身份。保存继续沿原版序列化和文件提供者，人物真实研究保持原记录，本地人物借用的持续力量写入开启前的原版持久视图；单人世界同样使用原基线。联机不捕获或替代远端世界力量持久子流，世界序列化保留原版当时状态。正常退出才恢复内存不是本地存档保护的前提；即使进程未执行退出清理，受保护的本地人物及单人世界保存也不含本功能的临时身份或持续力量设置。服务器保存及其已接受的力量不在客户端还原责任内。

人物保存从原版外层保存入口起持有该人物/文件的不可变视图，包含尚在等待原版I/O锁或人物文件写入之前的阶段。此间断连、退休或新一次开启不能把原保存的基线换成空值或下一代；同文件/人物的嵌套写入继承该次视图，完成或异常时退出。关闭时仍属于同一本地人物、文件和实际玩家槽的个人能力及时本地归还，不依赖连接模式或远端世界仍相同。人物或槽已换归属时不向新槽写旧个人值，已开始的保存仍由其不可变视图保护。保存与恢复不临时翻转模式/本地玩家索引、不等待后台I/O。

复制后已取得/消费的物品、已建造/挖掘/击杀结果、已经推进或跳转的世界时刻及已发生的天气变化保留。不覆盖启用前的整份旧存档，不停用正常保存，不回滚世界历史。恢复力量参数不等于恢复整份天气快照或删除生成物。

断连、换连接端点或模式、换人物/世界会退休旧会话；相同人物与世界对象被重用，也不能把旧端点的共享世界基线还到新端点。个人能力归还和人物保存保护独立于这项世界恢复资格，不延长旅行运行资格。新会话不会自动再次开启。尚未提交的共享滑条目标仅撤销借用期间产生的部分，启用前已有且未变的原版目标保留；关闭不产生网络提交。

保护结论针对本功能不写错受保护字段；不承诺原版文件写入、硬件或文件系统在任何损坏情况下无数据丢失。OS 强制终止、模拟未清理和真实物理掉电的证据分别报告，绝不要求所有者拔电。

## 与其它功能共存

旅行开启、原版窗口显示、真实鼠标/文本占用和游戏暂停是四种事实。窗口收起后其它辅助按原条件继续，持续力量仍生效。窗口占用时仅让出争用相同输入/物品的新动作，观察、已确认结果和工具/配装归还继续；占用结束后自然恢复，不要求重开全部开关。

鼠标上的复制物品受既有手动持物保护；真正入包后按已启用的存/卖/扔等规则处理，不取得永久豁免。无敌时无需补血、真正暂停时模拟停止属于正常条件变化。快捷改名沿既有保存链，与旅行持久视图共存；生产不调用完整 LoadPlayer 读回并重置旅行力量。

## 验证边界

真实复制与使用、每类力量消费者、Active 保存及无 R 独立回读、无退出清理、代表辅助进展/归还、输入占用及关闭成本由本任务证据承担。字段检查不能替代原版实际命令消费，自动/模拟多人不能替代真人多人，工程测量不能代证所有者体验、全部设备或量化 FPS。
