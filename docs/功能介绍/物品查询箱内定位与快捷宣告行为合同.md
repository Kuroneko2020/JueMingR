# 物品查询、箱内定位与快捷宣告行为合同

状态：#89 的开发候选合同，等待所有者实测与外部审查；未实机验收或合并。实际交付身份查任务 Issue。前序功能与 #48 的原限定延期保持不变。

## 玩家能力与边界

- F5「查询」提供当前原版的完整正 type 目录、图标、当前语言名称、内部名与 ID；空查询显示全目录。属性分类允许交叉，排序稳定。资料样本不代表拥有量，不调用原版拿取、出售、制作等入口。
- 详情分「获取」「用途」，按配方、掉落、容器、商店、钓鱼/世界线索、微光区分。普通配方保留产量、每槽数量、全部替代成员及原版条件。替代组替换原材料槽，不新增虚假的一件材料。条件未满足不隐藏资料。
- 图标可连续追查，左右键分别查获取/用途，亦有可见方向按钮。返回/前进保留查询、分类、排序、滚动、选中项与关系方向；历史最多 64 条。短视口可切换目录/详情。
- 点选暂时隐藏 F5，等待真实释放后接受新点击；新鲜 UI 槽优先，空槽阻止穿透世界。只有完整消费拿物/使用手势后才接收目标；失败或超时取消，不延迟重放。
- 附近箱内定位使用独立草稿，只在提交后工作。匹配超过 24 种先拒绝，不读箱或请求网络。搜索屏幕外扩 96 像素且距玩家不超过 1696 像素，X 外 Y 内稳定枚举；最多 64 内容候选、24 命中，实际发现额外候选才称截断。梳妆台合并 3×2，其他容器只认真实记录。
- 单人读取真实容量；普通多人客户端只计本连接真实收齐的槽，明确标「最近接收的数据」及观察时间。未知/缺槽不等于空箱。159 对已知 section 不会刷新库存，不自动开箱、不改玩家 chest 或 section 状态。无服务器插件/管理员要求。
- 绿色世界提示是有时限的查询结果；显式清除、打开任意正常箱、超过 3600 游戏更新、时间回退、世界/连接变化或已知内容改变即撤回。稳定高亮不读物品数组或发请求。
- F5「地图」的快捷宣告默认关闭，动作默认未绑定，复用公共绑定界面。只响应一次新沿；文本、IME、F5、点选、聊天、NPC 对话及模态状态阻止且不重放；允许普通背包悬浮。优先 UI 物品/空槽，再同位置玩家与 NPC、世界物品、可见格/液体与独立线路、背景墙/空气。隐藏信息不因线路而泄露。
- 多人走原版普通聊天出口；单人走本地普通聊天。反馈仅称提交，实际送达由其他玩家确认。名称去标签/控制字符及命令风险，以完整文本元素与完整目标条目限量；受控金色标签计入最终 UTF-8 预算。每条消息 500ms，空气另加 2000ms 限频。

## 数据覆盖与不支持的操作

目录与普通配方取当前原版注册表；NPC/global 掉落只读声明报告，global 只处理一次。没有原生声明接口的开袋、世界或钓鱼资料采用注明 1.4.5.8 来源的有限线索；商店区分可能出售与明确刷新时的当前条件快照；微光列明别名、直接转换/反向关系与前置条件，不能把所有配方反转为微光。各来源族独立失败、显示覆盖和缺口，不能把缺少资料称作没有来源。

不生成物品，不自动制作/购买/取货/微光，不杀怪开袋抽奖，不构建全世界仓库或最优规划；不运行真实游戏/服务器，不触碰真实库存/存档/公共聊天来证明实现。

## 验证与接受

自动正确性、真实原版适配、工作量、原资源图形、真实单人、普通多人和所有者接受分别记录。正式候选需完整 Debug/Release 与相邻回归、独立只读审查、干净提交的全功能开发包及安全安装。#89 和 Draft PR 保持开放；所有者实测和外部审查前不合并。
