# Legacy 钓鱼

**Legacy 行为参考，尚不代表 JueMingR 已实现或已接受全部合同。** 来源：旧功能根 `钓鱼页/` 六篇；[来源限制](功能索引.md#来源覆盖和限制)。入口为 Legacy F5 钓鱼页，减少收杆、重抛、筛选和换装的重复操作。

| 功能 | 操作与关系 | 必须保留的限制 |
| --- | --- | --- |
| 自动钓鱼 | 玩家先手动抛竿才进入收杆/重抛循环；F5 可见时暂停相关自动动作 | 收杆回执和旧鱼漂结束后再重抛，不能只凭请求提交认定成功；不无限改背包或直接生成鱼 |
| 钓鱼过滤 | 配置白/黑名单、精确/关键词和特殊规则，结合预设选择候选；信息页“过滤鱼获”只预览 | 需要实际声呐 Buff，识别未知时保留；不切杆的跳过等待原版自然逃脱，不按固定 90 tick 自动收杆。切杆路径另有受控恢复，F5 打开暂停动作 |
| 自动存放鱼 | 所有、任务鱼、关闭等模式，处理自动钓鱼确实观察到的鱼获 | 不等同手动鱼获或全背包整理，收藏物品不作候选；与[自动堆叠/存钱](Legacy物品.md)的来源和所有权不能混用 |
| 自动配装 | 按钓鱼场景临时使用装备组，并在退出后恢复 | 与自动换装互斥；真实 loadout/用户操作变化时不能强行覆盖 |
| 自动换装 | 按真实入水状态及水/蜂蜜/熔岩条件临时穿戴所需钓具 | 飞行中不冒充入水；恢复原物被移动、鼠标拿物或条件不安全时保留待恢复/暂停，不用猜测物品替代 |
| 快捷改名 | 单人输入名字并确认，可按数字后缀加一 | 空名或超过 20 字拒绝；刷新渔夫相关名称列表不代表原本已经交过的新名字又能交。不是多人改名合同 |

过滤规则与 TerrariaHelper 原说明是不同来源，不能把 Helper 的通配/正则语言直接写成 Legacy 支持语法。配置与预设属于 Legacy 钓鱼设置，当前 session 的鱼漂、回执、临时装备恢复状态不应被当作长期偏好。原文未明确的默认值/精确存储位置在未来钓鱼任务核对，不移植旧配置文件或自动导入。

关键机制见[钓鱼身份与版本签名](../AI经验笔记/战斗移动与钓鱼机制.md#鱼漂身份过滤条件与版本签名)：.7 完整 ProjectileKey 可为负，选槽请求不等于已切杆。源码记录与本地测试不证明多人同步或实机稳定；新版数据合同仍查[配置设计](../设计/配置持久化与用户数据布局.md)。
