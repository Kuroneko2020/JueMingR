# Legacy 地图与足迹

**Legacy 行为参考，尚不代表 JueMingR 已实现或已接受全部合同。** 来源：旧功能根 `地图加强页/` 十篇；[来源口径](功能索引.md#来源覆盖和限制)。

## 记录与显示

| 能力 | 用户目的与入口 | 记录/显示边界 |
| --- | --- | --- |
| 死亡信息 | 地图页看当前玩家-世界死亡次数，“详情”分页看现实时间/原因 | 可靠无记录为 0、身份不可用为 --；旧 UI 未完整处理读取失败，可能假 0/假空；不从原版最后死亡点拼历史，不提供删除/搜索 |
| 世界天数 | 固定显示当前玩家在此世界被观察到的整数游戏天数 | 从 0 起，不是世界创建年龄或现实游玩时长；身份未知为 --，旧读失败却可能显示 0 天，不能视为可靠值 |
| 揭示区域 | 看地图已揭示比例，点百分比开详情，性能/快速、开始/停止扫描 | 只读原版地图、分片统计；不是揭开未探索地图，也不能反推玩家路线 |
| 死亡点常驻 | 默认关闭，开启在全屏地图显示文件顺序最后 256 个有效候选死亡点 | 先取候选再裁切，较早屏内点不补位；关闭只停画，死亡仍采集，不删除更早记录 |
| 足迹 | 默认关闭的是**展示**，开启在大地图画绿色路线并可播放回看 | **关闭展示仍记录**；不改变采样/保存/保留策略，不改玩家位置或原版存档 |

足迹打开地图默认位于最新端且暂停；播放到最新自动停，倍率 1x/10x/60x/300x/1800x。拖进度条会暂停并回看截至该时间的路线；暂停历史时冻结显示时间轴末端，后台追加不把滑块挤走，最新端则跟随新记录。断段不连线，控制条内隔离地图拖动/缩放/ping，离开它后交还原版。

旧文档描述 `footprints.json` 保留滚动最近 200h，cache 候选 200000、详细绘制 20000 只是显示成本边界，不删除存储数据。低倍率轮廓不能把省略的非相邻点当真实直线路径；同时可见断段多于预算时只能明确降级。本轮不采用这些数字为 R 预算，也未验证旧路线的视觉/性能。

## 方向、标记和宣告

R 的连续全向圆周、可信位置说明及显示/样式修订已获接受，见[当前实现与验证边界](稀有生物旅商方向与装备提示行为合同.md#12-r-已接受实现的使用与验证边界)。以下两条仍保留旧行为及缺口，R的接受不补造Legacy验证。

- 稀有生物显示方向默认关闭；原版生命分析能力生效且 hideInfo[11] 未隐藏时，从本客户端 active、未 hide、rarity>0 且玩家中心距严格<1300px 的候选中选高 rarity、再近距离目标。玩家旁短箭头，屏外加名称/约距离；不是所有小动物或金属探测，不自动捕捉或请求全世界 NPC。完整规则与缩放/身份缺口见[合同第4节](稀有生物旅商方向与装备提示行为合同.md#4-稀有生物方向)。
- 旅商方向默认关闭、不需信息装备；对本客户端已知活动旅商给屏外金色三行标签，屏内隐藏。位置依晶塔、居民计数、粗高度/海岸到未知回退；旧“城镇聚类”并非真实聚类，内陆地表叫“森林”也不可靠。没有使用本地 Zone 不等于远端群系正确；它不触发到访，与游商测试独立。精确来源/回退与候选纠错见[合同第5节](稀有生物旅商方向与装备提示行为合同.md#5-旅商方向与位置解释)。
- 地图标记默认关闭；开启后大地图右键选图标，左键确认建立标记，再次右键取消；打开/取消都等本次物理右键释放，关图丢弃未确认选择。F5 列表可命名、删除、翻页与“跳转”。**跳转只移动地图视图**；导航、传送、智驾仍是占位。每 pair 最多 120 条，旧名字限制 10 文本单位，默认时间名；数据保存失败保留旧文件。
- 快捷宣告按三格组合键（旧默认 Alt+Shift+左键）：前两格为键盘前置键，第三格可键盘或鼠标按下沿；双击录入、Backspace 清空，持续按住仅触发一次。目标优先 UI 物品，再玩家/生物、掉落、方块层等；通过原版聊天发送，有实际对外文本副作用。主开关键只切开关，不宣告；不可见 tile/wall/liquid 不能通过文本泄露，电路线索不授权揭露同格其它内容。
- “大地图加强”旧登记入口是未实现占位，与后来独立地图标记不能混成一份已完成总能力。

这些记录按 Legacy 的玩家-世界 pairId：`player-worlds/<pairId>/` 下 `death-summary.json`、`deaths.jsonl`、`playtime.json`、`exploration-summary.json`、`footprints.json`、`map-markers.json`。身份不可用不写 unknown 桶，但旧身份解析存在显示名 fallback，不能据此宣称所有 pair 可靠；开关/热键与记录分开。R 自然归属和未来数据布局查[配置设计](../设计/配置持久化与用户数据布局.md)，不自动导入旧数据。

冻结源码的死亡录入在 KillMe postfix 同步追加明细、全量重数并写摘要；详情和地图各自从 Draw 读文件，缓存命中仍有全历史或候选复制。天数也在 Tick 持锁同步存储，读失败可能退成可写零对象。旧“Draw 不读写磁盘”的笼统概括不适用于这些路径。完整调用链、坏行分歧、原版 `.8` 原因副作用、计时/身份边界见[四项行为合同](死亡信息死亡详情世界天数与死亡点常驻行为合同.md)。R 首轮目标已接受，四档数量和同窗全文阅读属于新版决定；需求接受不表示实现或验证完成，也不改变上述旧事实与 V0 边界。

机制与失败见[信息地图与持久状态](../AI经验笔记/信息地图与持久状态.md)。旧客户端只读路线或 Implemented 标签不能证明多人、GPU/FPS、全范围可用或用户验收，本轮没有重验。
