# Legacy 地图与足迹

**Legacy 行为参考，尚不代表 JueMingR 已实现或已接受全部合同。** 来源：旧功能根 `地图加强页/` 十篇；[来源口径](功能索引.md#来源覆盖和限制)。

## 记录与显示

| 能力 | 用户目的与入口 | 记录/显示边界 |
| --- | --- | --- |
| 死亡信息 | 地图页看当前玩家-世界死亡次数，“详情”分页看现实时间/原因 | 无记录为 0、身份不可用为 --；不从原版最后死亡点拼历史，不提供删除/搜索 |
| 世界天数 | 固定显示当前玩家在此世界被观察到的整数游戏天数 | 不是世界创建年龄、角色现实游玩时长，不补历史；身份/读取失败为 -- |
| 揭示区域 | 看地图已揭示比例，点百分比开详情，性能/快速、开始/停止扫描 | 只读原版地图、分片统计；不是揭开未探索地图，也不能反推玩家路线 |
| 死亡点常驻 | 默认关闭，开启在全屏地图显示最近 256 次候选死亡点 | 关闭只停画，死亡仍采集；256 是显示限制，不删除更早记录 |
| 足迹 | 默认关闭的是**展示**，开启在大地图画绿色路线并可播放回看 | **关闭展示仍记录**；不改变采样/保存/保留策略，不改玩家位置或原版存档 |

足迹打开地图默认位于最新端且暂停；播放到最新自动停，倍率 1x/10x/60x/300x/1800x。拖进度条会暂停并回看截至该时间的路线；暂停历史时冻结显示时间轴末端，后台追加不把滑块挤走，最新端则跟随新记录。断段不连线，控制条内隔离地图拖动/缩放/ping，离开它后交还原版。

旧文档描述 `footprints.json` 保留滚动最近 200h，cache 候选 200000、详细绘制 20000 只是显示成本边界，不删除存储数据。低倍率轮廓不能把省略的非相邻点当真实直线路径；同时可见断段多于预算时只能明确降级。本轮不采用这些数字为 R 预算，也未验证旧路线的视觉/性能。

## 方向、标记和宣告

- 稀有生物显示方向默认关闭；具备生命体分析仪且未隐藏相应信息时，在客户端已知候选里选高 rarity、再近距离目标，屏内短箭头，屏外加名称/约距离。不自动捕捉或请求服务器全世界 NPC。
- 旅商方向对客户端可见的活动旅商给屏外金色标签，屏内隐藏；位置标签区分晶塔、城镇聚类、低置信群系附近与未知，不能拿本地玩家群系代替旅商位置。它不触发到访，与游商测试独立。
- 地图标记默认关闭；开启后大地图右键选图标，左键确认建立标记，再次右键取消；打开/取消都等本次物理右键释放，关图丢弃未确认选择。F5 列表可命名、删除、翻页与“跳转”。**跳转只移动地图视图**；导航、传送、智驾仍是占位。每 pair 最多 120 条，旧名字限制 10 文本单位，默认时间名；数据保存失败保留旧文件。
- 快捷宣告按三格组合键（旧默认 Alt+Shift+左键）：前两格为键盘前置键，第三格可键盘或鼠标按下沿；双击录入、Backspace 清空，持续按住仅触发一次。目标优先 UI 物品，再玩家/生物、掉落、方块层等；通过原版聊天发送，有实际对外文本副作用。主开关键只切开关，不宣告；不可见 tile/wall/liquid 不能通过文本泄露，电路线索不授权揭露同格其它内容。
- “大地图加强”旧登记入口是未实现占位，与后来独立地图标记不能混成一份已完成总能力。

这些记录按 Legacy 的玩家-世界 pairId：`player-worlds/<pairId>/` 下 `death-summary.json`、`deaths.jsonl`、`playtime.json`、`exploration-summary.json`、`footprints.json`、`map-markers.json`。身份不可用不写 unknown 桶，Draw 不读写磁盘；开关/热键与记录分开。R 自然归属和未来数据布局查[配置设计](../设计/配置持久化与用户数据布局.md)，不自动导入旧数据。

机制与失败见[信息地图与持久状态](../AI经验笔记/信息地图与持久状态.md)。旧客户端只读路线或 Implemented 标签不能证明多人、GPU/FPS、全范围可用或用户验收，本轮没有重验。
