# 挂机模式功能行为合同

对应[任务 #180](https://github.com/Kuroneko2020/JueMingR/issues/180)。本合同落实所有者明确委托的挂机开发包；源码实现、工程验证、普通候选、真实实机／多人及所有者接受分别以任务证据为准，不因收录正文而宣称全部通过。

## 玩家入口

杂项页“挂机模式”使用标准开关和统一快捷键；功能提示为“开启功能后，手持道具，按一下左键开始持续使用这个道具”。默认关闭、快捷键默认未绑定。开启、加载已开启配置和重进世界都只待命。

开关左侧为固定单位 `ms` 的空档框，空值显示“双击输入空档”，不增加 tooltip。双击编辑，Enter 确认后立即改变内存设置；清空或 0 表示无附加等待。仅接收非负 Int32 整数毫秒；格式错误或溢出保持旧值并在行内说明。单位不属于可编辑文本。切页、关闭或失焦取消未提交草稿，IME 的确认 Enter 不兼作提交。

## 一次运行与暂时让出

世界操作中一记新的、未被 UI／热键／世界编辑消费的物理左键记录实际槽位、物品来源与类型、世界点及当前角色／世界会话。松开后可持续使用；移动、镜头、缩放和窗口变化只改变该世界点的当前投影。

临时同槽手动用物、原版临时选择和有明确来源的快捷用物让出当前输入、锁点及 use token，保留运行；原版操作与归还结束后续接。空档只约束挂机所属的下一轮，不阻止手动操作，不因借出、归还或移动重置截止时间。零空档的原版连续使用链也必须为真实工具／提炼候选和显式快捷用物让出使用机会，借用仍由原有 owner 选择、使用及归还。

主动数字键／滚轮改变当前选槽或热栏意图、记录物品移走／耗尽／变成另一类型、打开决明操作界面（含独立浮窗和位置编辑）、全屏地图、聊天／对话及角色确实不能用物，均清除运行并回待命；条件恢复仍须新点击。原版 override 的当前槽与 Hotbar 是两个事实：在 override 期间主动选择当前借用品所在热栏也可能改变 Hotbar，必须尊重该新意图。自动归还不是主动换槽。

关闭、会话退出和功能失败仅撤回自身输入及租约，不销毁已有射弹，不阻止别的 owner 归还物品。晶塔、NPC 等原版鼠标否决保留；被否决且尚未实际开始的启动不能在锁结束后偷偷开火。

## 实际完成后才有空档

正空档统一为：原版实际接受开始 → 完整操作与必要原生收尾 → 实际完成回执 → 等待空档 → 下次原版允许的使用。不从按键请求、动画开始、第一发、松手或开始回收计时。

- 普通挥击／枪弓法杖保留整次动画与冷却；同动画多发不被首发截断。普通独立子弹无需消失，召唤动作不等常驻召唤物死亡。
- 放手发射、Flint／Glacier 蓄力等保留实际原生释放阶段；Flint 等主控制体确实退休后收尾，Glacier 原生转入独立飞行后无需等待命中。
- 返回／主控制类只跟踪本次真实出生的完整对象身份；槽复用、历史同型弹体和普通派生弹不混入完成判断。
- 悠悠球投出至当前原版限距后的有效终点，真实到达后自然松手，等主操作真实回收及手部恢复后计时。实际自瞄的逻辑目标与中间导航点分开；卡墙且真实连续无运动／无进展时允许自然松手退场，不改 AI、不直接 Kill。副球与脱离球不造成永久等待。
- 没有有限终点的持续施法保持连续，实际结束后才有空档。棱镜不会为应用空档而周期断施法或重蓄能。

原版 AutoReuse 可能在同次 ItemCheck 中先提前重开动画、随后才扣完旧 itemTime。正空档在该提前入口抑制新操作，等待旧计时器真实完成；0 则保留原版可达的连续消费，不凭 `itemTime<=1` 伪造完成事件，也不插入统一空白帧。零空档下释放／返回类仍完成各自必要阶段。节奏以真实世界更新推进，毫秒向上折算为 60Hz 游戏步，粒度约 16.7ms，不以 Draw／重复回调计时。

原版可能在同槽手动使用时先开新动画、再扣完旧冷却；完成观察在原生扣时后、下一次手动发射消费前读取旧操作真实结束，不把借出或归还当完成，也不把手动动作混记为挂机动作。

## 输入、瞄准与存储职责

`HostAfkMode` 唯一拥有运行、世界点、当前操作及完成时刻。现有 ToolHooks 提供实际 Started／出生、AutoReuse、ItemCheck／AI 和选槽来源；窄的 `AfkNativeHooks` 只观察原生扣时后的事实。真实消费者使用短 scope 借用输入与游标，并保留原版 channel／release 结果。自瞄仍在其最终消费者覆盖挂机基础点，不新建预测或寻路系统。

只保存 `enabled` 和 `gapMs`，路径为 `JueMingRData/config/features/afk-mode.json`，格式 `JueMingR.AfkMode` version 1。PreferenceDocument 同步更新内存、后台合并写盘，损坏／未知文档保护不变；运行身份、物品、目标和计时均不落盘。

关闭时 Hook 只最小早退，不做挂机来源／弹体观察；运行只观察本地源与本次少量因果主控制体，不逐帧扫描整个射弹池，不额外调用整段预测，不在游戏线程写盘或 Sleep。工程计数不外推 FPS。

单人与原版普通好友联机的房主、客机沿项目支持范围，使用原版物品、消耗及同步，不增加房主限定或服务端协议。工程隔离执行不替代真实单人、好友主客机、物理输入／IME、FPS 和所有者体验。
