# Legacy 移动与增益

**Legacy 行为参考，尚不代表 JueMingR 已实现或已接受全部合同。** 来源：旧功能根 `移动页/` 四篇与 `增益页/` 五篇；[来源口径](功能索引.md#来源覆盖和限制)。

## 移动页

| 功能 | 操作/目的 | 限制 |
| --- | --- | --- |
| 连续冲刺 | 按住方向或双击并按住模式，减少反复双击 | 要有原版冲刺能力和就绪冷却；不改速度、不绕冷却；左右同时按或文本输入阻挡。主开关键只恢复已知非关闭模式，不猜模式 |
| 模拟连跳 | 真实长按跳跃，衔接原版可用地面跳、二段跳等机会 | 不创造跳跃次数或坐骑能力；“下+跳”穿平台让路，文本输入阻挡，背包/箱子/F5 本身不一概阻挡 |
| 智能防摔 | 危险坠落时按策略尝试已有能力、临时装备/雨伞、抓钩或传送杖 | 高优先级尚未 ready 时不让低级抢跑，落地恢复临时装备；原文致死兜底仍未实现，不能称绝对防摔/无敌 |
| 传送修正 | 真实使用混沌/和谐传送杖时把目标修到附近可靠空位 | 只修鼠标目标，原版执行传送；限 1326/5335，不直接 Teleport、不直接扣血或添加混乱 Buff |

## 增益页

| 功能 | 操作/目的 | 限制 |
| --- | --- | --- |
| 自动回血 | 默认关闭，Quick 选最高可用治疗量，Smart 按缺血选合适药；配置可排除药品 | 不直接改生命，不因开关亮就宣称多人同步已验证 |
| 自动回蓝 | 下一次真实耗蓝武器使用会因魔力不足失败且有缺蓝空间时用药，配置可排除品种 | 满蓝或最大魔力本就不足但无可恢复空间时不喝，不直接写魔力 |
| 自动增益 | 右侧白名单为维持列表，缺 Buff 且有药时补充 | 白名单空就空闲，不全量 QuickBuff 或无端消耗 |
| 自动家具增益 | 靠近水晶球、弹药箱、施法桌、磨刀站等且缺 Buff 时互动 | 原版家具动作，不直接 AddBuff；会打开制作面板的站点需恢复原有背包 UI 状态 |
| 护士自动治疗 | 缺血或可移除 Debuff、附近护士可交互时尝试对话治疗 | 会涉及原版费用/治疗；不直接写生命、钱币或 Buff。原文允许仅箱子打开的窄场景，聊天/NPC 对话等仍阻挡 |

这些配置是 Legacy 用户偏好，临时装备与恢复意图是会话状态，不应伪装成 R 已有的数据文件。是否导入和新版自然归属依[配置设计](../设计/配置持久化与用户数据布局.md)在对应任务决定。原文未提供的默认值不统一补成开启/关闭。

防摔现象需要原版对照，曾有卸翅膀后原版自身仍免摔的历史反馈；不能根据表象归因插件写状态。见[移动机制](../AI经验笔记/战斗移动与钓鱼机制.md#防摔根因要先区分原版能力与插件写入)。本轮没有重新测试任何策略、多人或性能。
