# Legacy 蓝图

**Legacy 行为参考，尚不代表 JueMingR 已实现或已接受全部合同。** 来源：旧功能根 `蓝图页/蓝图.md`（正文更新标记 26-08-22-1553）及 `蓝图综合实机测试场地方案.md`；[来源与覆盖](功能索引.md#来源覆盖和限制)。长文保留大量阶段流水，本页提炼用户能力和已暴露的差异，不声明完整蓝图已可用。

## 从采集到投影

F5 蓝图页可进入创建，左键拖动多选区域，保存时只读采集模板；退出创建保留内存选区但不保存，清除选区只清选区，不删模板或世界。没有 mask 时保存不可用；纯空气有选区但无内容，明确提示失败而不生成空模板。快捷入口默认关闭，开启后手持凝胶可见状态相关操作栏；旧 N/blueprint.main 直接打开入口已停用，创建/保存/蓝图库等动作键与主开关键分别配置。

蓝图库管理模板：命名、删除、导入/导出、材料清单、选择“放置”进入预览。预览确认只建立当前世界的蓝图实例数据，不等于已经造好建筑。已放置列表管理显示、隐藏、移除和层级；投影只观察完整/缺失/冲突/不可读，材料汇总帮助准备物品。区域修改写实例遮罩，清空放置移除投影；**都不是拆世界方块**。移动确认前原实例不变、取消回原位；已有完成/自动放置进度时不任意移动或镜像。

## 整件家具与自动放置

选区碰到可识别多格家具任一子格，应补齐整件；扩展格只补 object，不顺带采未选墙/线。半件或方向/frame 身份不可证明时精确标识，不以“含家具”全拒。缺失时显示整件半透明原贴图，同组有冲突应整体表达放不下，不能把剩余子格当独立可放。容错、材料与镜像机制见[经验主题](../AI经验笔记/蓝图多格物体与镜像.md)。

自动放置默认关闭，按真实工具、材料和距离通过原版使用路径施工，不移动玩家、不扩大距离、不用虚空袋材料施工（材料统计可只读袋中数量）。同类替换总开关及火把、平台、工作台、椅子、门、桌子、箱子、牌子八类默认都关；总开和对应类都开才认可替代。冲突格不自动拆除，红图不授权挖方块/墙/清线，液体、容器内容、牌子/墓碑文本、假人/展示架装备等外部 payload 不因此被恢复。

原文较晚边界描述支持普通 Tile/Wall/object、状态型默认本体、Cannon、Flexible Tile Wand、多色 wire/Grand Design，以及主体存在后的 paint/coating、普通 tile 锤击形状、inactive。OpenDoor 开启态、Timer 运行态、触发态开关、Monolith 效果、Cannon 角度等不恢复临时状态，只按同 item 默认本体处理。
