# 视距解锁行为合同

本合同来自所有者委托的 `JMR-VIEW-UNLOCK-20261018-v1` 及同任务续办 `JMR-VIEW-CACHE-RANGE-20261018-v1`。本批范围、三层条件缓存与统一原键缩放手感已获所有者实测正常反馈，网页性能与正确性复审无新增阻塞，随 [PR #125](https://github.com/Kuroneko2020/JueMingR/pull/125) 合并进入 `main` 生效；接受对象、具体场景及授权见 [#124](https://github.com/Kuroneko2020/JueMingR/issues/124)。旧交付、验证、包和安装保持原身份，不把任务合同或自动检查当作所有者体验接受。职责与原版接点见[实现设计](../设计/视距解锁实现设计.md)。

## 入口与操作

F5 地图页提供公开的“视距解锁”标准行，只有“开启”“关闭”两个按钮；名称悬停说明逐字为“可以调整到更大的视野范围”。首次没有设置时关闭，不要求隐藏资格或旅行菜单开启。

开启只放开调节范围，画面不会立即跳到预设倍率。随后使用原版世界缩放的放大、缩小按键，按住可连续调整；使用原版当前映射，重绑后仍有效。没有新的决明快捷键、绑键入口、倍率滑条、额外窗口或“打开”按钮。这是[默认绑键接入](本地短提示与快捷键反馈行为合同.md#后续功能的默认接入)的明确例外：本轮指定只沿原版缩放键，开关从 F5 操作。

基础目标范围为30%—1000%。按所有者2026-10-19关于统一缩放速度的补充，开启后每次原版Mapping按互逆比例调整（放大乘1.02、缩小除1.02），使相同倍率比例的变化需要近似相同Mapping次数，100%附近近于原速度；此补充取代本轮原固定2个百分点要求，不修改原授权资料。同轮重复消费无效，两键同时按净变化为零，不新增按键源、时钟或控件。实际相机仍使用原版float32／1/128／ToEven量化：例如目标30%在强制倍率1时实际为29.6875%。小步保存在唯一目标中，不把量化后的相机写回目标，故低端阶梯不会长期卡住；现有观察范围和原版强制倍率仍可能提高最低目标，不由缓存能否申请决定。

原版选项的世界缩放条仍只覆盖100%—200%。超范围时只夹取滑条显示，打开、绘制或悬停不会把显示值写回目标；实际拖动才按原版规则写回100%—200%。

原版聊天、文字编辑、录键、失焦及地图／拍照等非世界上下文不接受新的世界缩放动作；已被其它输入所有者消费的按键不会重新出现。UI 和全屏地图使用自己的缩放，世界视野改变不改变它们的大小。

## 关闭保留与生命周期

开关表示是否允许继续向普通范围之外扩大视野，与当前倍率、当前画面所需的外围绘制是三种不同事实。

| 当前条件与操作 | 结果 |
| --- | --- |
| 关闭后开启 | 保持当前倍率，允许之后用原键扩大视野 |
| 已调到超范围后关闭 | 目标倍率与完整画面保持，不自动弹回；标准行显示关闭 |
| 关闭且仍超范围，未按缩放键 | 保持当前选择及必要外围绘制 |
| 关闭且低于100%，按原版放大键 | 按比例逐步回100%，最后一步准确落边；向外缩小不动 |
| 关闭且高于200%，按原版缩小键 | 按互逆比例逐步回200%，最后一步准确落边；向外放大不动 |
| 关闭且超范围，向更外侧调整 | 不改变目标，重新开启后才可继续 |
| 已回普通范围且关闭 | 按原版2个百分点步长和普通上下限运行，额外外围工作按实际需要退出 |

开关 F5、暂时切入全屏地图、选项、拍照或失焦不重置已选倍率。特殊画面按自身坐标绘制；返回世界继续使用原版当前目标。倍率优先属于原版 `Main.GameZoomTarget`，本功能不新增跨启动倍率恢复服务，也不把倍率写入角色或世界存档。真正重新启动后的倍率沿原版自己的设置持久规则。

设备或资源故障与普通关闭分别处理。必要接点不符时不安装半套解锁；可选图格缓存失败保持合法倍率、光照和地图设置，使用正确直接绘制并记住失败资格，不逐帧申请；若已有部分画面提交则只放弃本帧，下一帧直接绘制，不向普通游戏入口泄露内部控制异常。只有必要宽视野绘制本身失败，才停止本次owner新的解锁、一次必要反馈并恢复普通安全状态。未知原版异常准确归还临时状态后继续传播。

## 可见内容与相邻能力

扩展后的画面应正确显示当前世界中客户端真实掌握的图格、墙、液体、光照、实体与必要世界效果。正常暗区仍然暗，不增加全亮、透视、全地图揭示，也不只缩小中央画面后遗漏外围。

玩家中心辅助瞄准的候选范围按当前真实相机扩展，保留既有距离排序与模式含义；光标中心的世界半径不因缩放自动变大。目标标记、预测、显名、工具选区与原版实际指点沿最终相机对齐。视野扩大不扩大攻击、挖掘、交互或服务端权限，不改变实体生成、AI 或退场规则，不恢复已撤红框和整组未来精算。

单人与普通客机按实际掌握的数据显示；客机未知区继续保持未知，不能当作空气供查询或操作使用。已收到区块不代表远处所有实体都已同步。具体取得的网络范围与限制由本任务实际原版请求链及联网证据说明。

普通客机需要当前视口的未知区块时，复用原版单区块请求，逐次更新最多新增一个请求、最多跟踪16个在途区块。同一区块收到前去重，只有原版实际解码完成才成为已知。视口移开时释放旧区块的本地跟踪，不声称撤回已发送的网络数据。当前仍需要的区块经过300次更新未收到，或请求发送发生异常时，停止额外请求并给出一次必要反馈；调回普通视野后可重试。关闭开关但仍保留宽视野时，当前实际视口仍承担这些必要责任。

## 配置与反馈

开关是当前游戏安装下跨角色、世界共享的普通偏好。唯一文档为 `JueMingRData/config/features/view-unlock.json`，UTF-8、`format="JueMingR.View"`、`version=1`、布尔 `enabled`；缺文件默认关闭且不预写默认 JSON，不含倍率、角色或世界身份字段。只存开关，不增加倍率历史或恢复服务。

复用 [PreferenceDocument 与原子文件合同](../设计/配置持久化与用户数据布局.md)。读取完成前拒绝修改；真实点击改变本次内存选择并按现有后台保存流程请求持久化。损坏、未来版本、未知字段、占用、外部变化及未确认提交保护原文件；保存失败不悄悄重置本次倍率或开关。安装、恢复与卸载保留该文件为用户数据。

普通 F5 成功点击、加载与保存保持静默，不产生开关短提示或新增状态行。真实读取／保存或能力失败使用现有必要错误通道和不可用悬停；普通名称提示保留既定原文。此功能不注册 R 开关快捷键，因此没有快捷键开关回执消费者。

## 当前路线与验证边界

本批采用最终倍率k=z的tile／tile2／wall三层缓存，在Color／White的实际宽视野条件下按当前设备和内存准入；不主动降低输出采样密度。稳定且采样相位可复用时减少重复绘制，连续变化或不合适时直接绘制；在直接绘制期间发生的原生内容刷新不会丢失，返回旧相位也必须先刷新失效的内容。背景、光照、动态实体、液体及场景filter继续原版对应路径，三层缓存水波保持direct坐标域；原生容量足够的Native路线继续使用原生液体层兼mask，切换时保持已有波纹的世界相位。Retro／Trippy、普通倍率或不符合三层缓存资格时不强行使用三层缓存。实际原生组覆盖足够时保留原缓存；相对普通视野扩展不等于必需Direct。确定回普通后，退出Native额外批次和设备订阅；关闭但仍Retained不提前清理。缓存世界批次在原版UI前归还，失败只退休自己，不清外来pending或依赖再次提交成功。

Reach按2048轴限制，HiDef三层路线保守按4096轴限制，原版8K资格不自动提高本缓存上限；超轴或可选资源失败使用正确direct。七层1:1矩形world缓存本轮没有实现。当前隔离完整Main的Reach1920×1080中，50%与30%的七层轴尺寸均不合格；这是该隔离设备/进程事实，不代表已观察所有者正常游戏profile，更不等于七层在所有设备均不可行。

当前隔离专项区分原版实际GPU绘制、CPU消费者、协议复用、成本和所有者体验。原版量化后的.296875和10倍、双端OFF、原映射键及原选项写回分别验证；世界目标512格、世界文字1024格及未知区合同不扩大。辅助瞄准保留玩家中心原有50格最小半径，在10倍时可含画外目标，不擅自收窄算法语义。

原3ea的完整专服／初始化客机TCP证据保留原身份：真实159请求、包10解码及已收到冷区Draw，不等于远程网络或完整客户端模拟。当前新范围的section验证只承担最终相机几何和既有预算的传播，不能冒称协议重新执行。已收到NPC与未收到item／projectile的原始分母继续保留。

本次原始Draw墙钟、分配、GC、内存、刷新、资源与画面证据由#124固定记录承担；不是GPU计时、完整Update帧时或所有者FPS。静止缓存收益与移动direct边界分别报告，不把30%比50%更慢归为优化失败或把少画内容当收益。旧3ea及e213的慢帧和成本不改签为新执行，完整项目仍INCOMPLETE、releaseEligible=false。

连续收窄、再扩展和相邻容量桶往返复用足够的wave pair，保留已有波纹。质量0且WaterDistortion完全淡出时，只省direct额外physical mask，恢复唯一原前景液体Draw；质量1和非零淡出尾仍消费mask。每次原PreDraw最多推进已有min(queued,2)步，不因缓存、mask或scene重复推进alpha／模拟。

新输入失灵事件的完整时序已按所有者要求记入#124及[输入经验I01续办记录](../AI经验笔记/输入捕获与坐标域.md)。目前未定位、未定责、未修复，重启后暂不复现，调查明确暂停。旧I01只症状相似；本轮缓存或范围验证不构成该事件原因或已修复的证据。
