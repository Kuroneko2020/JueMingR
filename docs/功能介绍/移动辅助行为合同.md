# 移动辅助行为合同

本合同承载已交付的三项移动辅助及本次智能防摔候选。原三项开发、输入生命周期与连跳完整惯性尾段依据 `JMR-MOVEMENT-INPUT-RELAY-FIX-20261021-v1`，接受状态见 [#126](https://github.com/Kuroneko2020/JueMingR/issues/126)；智能防摔原开发依据 `references/归档文件/JMR_SMART_FALL_PROTECTION_20261021_v1/`，同任务五项修复依据 `references/JMR_SMART_FALL_REPAIR_20261022_v1/`，任务与接受状态见 [#130](https://github.com/Kuroneko2020/JueMingR/issues/130)。旧移动开发原件保留在 `references/归档文件/JMR_MOVEMENT_ASSISTS_20261019_v1/`。研发候选不表示已经通过所有者体验或正式发行。技术职责见[移动辅助实现设计](../设计/移动辅助实现设计.md)。

## 连跳的持续接管与接力

持续按跳时，当前原版翼、靴、毯或条件悬停能主动接管的更新保持按住，不为剩余额外跳主动制造释放；已经真实重武装且当前可先消费的原版离散跳仍按原顺序发生。主动持续能力结束后，用当时真实余速保留惯性尾段，到不再逆重力上升时沿原版完整释放再按下接剩余extra。只有翼缓降不算主动推进，不能把额外跳永久锁住；不授予、冻结或恢复资源。

真实松键、Down、失焦、死亡、玩家/会话更换及更高输入owner及时取消本辅助交接。上述补充候选与本轮体验状态查 [#136](https://github.com/Kuroneko2020/JueMingR/issues/136)；旧用户接受不覆盖本轮新增行为。
## 入口与设置

F5 的移动页依次提供模拟连跳、连续冲刺、传送修正、智能防摔，首次均关闭。每行沿现有开启、关闭及行尾公共绑键入口；没有新增默认快捷键。绑键只切该项开关，实际生效后使用公共短提示，冲刺包含当前模式，如“连续冲刺（双击） 已开启”；关闭使用命令前的实际模式。普通点击静默。防摔许可配置入口暂隐藏；十二许可配置实现及既有保存保留，主开关与功能继续可用。配置恢复入口后仍只提供十二能力许可，不暴露算法参数。

连续冲刺从左到右为“按住／双击”模式、开启、关闭、公共绑键；开启/关闭列与其它主行对齐。模式默认双击，开关与模式独立保存，关闭时仍能查看、切换和保存模式；重开沿用当前模式。名称与按钮提示同步表达当前模式。切换模式撤销旧手势，不继承半个双击。

移动偏好属于这一份游戏安装，保存于 `JueMingRData/config/features/movement.json`，跨角色、世界与重启共享。保存四个主开关、严格两值的冲刺模式及十二防摔许可；十二许可首次均允许，主开关关闭仍保留选择。旧 version1 文件缺少防摔字段时保留原三项设置，补主 OFF、子项 true 的内存默认。不保存玩家、按键沿、Tick、坐标或恢复记录。缺文件使用默认且不主动创建JSON；损坏、未知字段、未知枚举与未来版本保留原件并保护写回，沿现有渠道报告保存／读取问题。不支持 Legacy 设置导入。

## 模拟连跳

按住当前映射的跳跃键，没有装备时落地连续起跳；有二段跳能力时沿原版合法顺序接力；翅膀、火箭靴、飞毯及相关持续能力按各自真实消费者资格接管。每个本功能登记且原版实际成功的普通／额外跳先完成全部受控持跳；完整自然惯性上升尾段只约束辅助追加下一次离散跳跃，仍逆重力上升时不提前制造下一离散跳跃边沿。原版翼、靴、毯及条件悬停有合法持续输入机会时按真实门限立即接管，不强制等顶点；最后 1→0 持跳更新对后续消费者仍保持同一按住输入。需要重武装时，先完成所有相关消费者均看到有效松开的完整更新，后续更新才按下；已重武装或原版本可长按执行时不额外等待。水中游泳等原生机会保持原规则。次数、燃料、飞行时间、冷却与落地恢复由原版处理，不写 releaseJump／rocketRelease／autoJump 伪造资格，不增加跳速、跳高、免摔或无限资源。本次澄清依据 `JMR_MOVEMENT_AIM_CONFIRMED_FIX_20261024_v1`，任务及体验接受状态见 [#136](https://github.com/Kuroneko2020/JueMingR/issues/136)。

松键立即停止后续辅助；Down+Jump 让路给下穿／下压。水中、反重力、滑墙与原生自动跳跃装备保持原版资格。不会自动召唤／切换坐骑，也不为飞行、悬停或条件飞行坐骑追加自动飞行；非飞行坐骑合法跳跃继续按原版处理。

防摔可在当前更新写入前取得 Jump 优先权，连跳让路。真实抓钩接管后，连跳撤销自己的合成松键贡献，不能间接收钩；真实玩家 Jump 仍按原版立即有效。

## 智能防摔

本节依据所有者委托 `JMR-SMART-FALL-PROTECTION-20261021-v1`、原版边界修复 `JMR_SMART_FALL_VANILLA_ACTION_FIX_20261022_v1` 及性能／恢复续修 `JMR_FALL_PERF_REFORGE_FIX_20261022_v1`，任务与验收状态见 [#130](https://github.com/Kuroneko2020/JueMingR/issues/130)。完整范围为二段跳、火箭靴、飞毯、翅膀、马掌、雨伞、抓钩、飞行坐骑、精灵腿、免摔坐骑、传送杖、重力球。遵循统一的[原版合法操作与 TAS 可达原则](../规范/Legacy平替与行为契约规则.md#原版合法操作与tas可达原则)，只使用真实合法物品和原版消费者，不补写 fallStart、免摔、速度或位置。理想精准的合法输入时序可自动化；临借不能产生新次数、燃料或飞毯起动资格。没有合法资源时允许无解。

先识别本版本真实摔伤风险和已有免摔事实，危险临近才有限探测近处接触；按真实可用性、完整发动阶段、落点／输入／装备干扰及代价联合选择，尽量晚地在触底前生效。高排位未就绪不阻挡及时后备，已确认主方案也不为慢后备不必要早动。临时装备须赶上真实装备与摔伤结算；不能将换装、发出输入、钩附着或提交使用单独认作获救。飞行坐骑及时收回，保住本来能落上的平台。

当前距离尚未越过摔伤门槛，但有限预计接触会跨阈并落地时，也须给及时的合法能力与其准备阶段机会；安全邻点不因此发动。飞行坐骑的斜平台收尾还须让原版自然清掉上次骑乘穿台状态，平平台不统一提前。自己的失败钩实际退场、相关轨迹或已观察锚点／射线改变时，允许同次下降有限重核；事实未变不盲发，不扫描全部弹幕。

选材沿真实来源资格和完整动作影响分，并非固定道具排名；同分再比较原生阶段长度。普通饰品优先有效功能装备，再背包0—49和合法社交10—19；只选择可消费的真实原版机会，耗尽或不匹配的首项不遮住后方具有真实余量的不同族。神灯腿仅走社交腿12→功能腿2。抓钩另在有限来源和抓点中比较。

二段跳仅消费当前实际生效族／坐骑原本 unused 机会，空中借普通社交／背包瓶不会获得新二跳；火箭只用真实 fuel 或当时原生合法恢复；飞毯使用原生 canCarpet 或仍有 carpetTime 的真实余量。组合、升级、换装、归还、开关和配装均不补资源。已经消费的资源不会因取消／归还恢复，尚未消费的资源也不会被辅助撤销。旧“每自然周期有限激活一次”及为此设置的账本、关闭态资源观察和对应救援期待已撤销，旧交付证据只保留历史身份。

需要重武装时，先让正常更新的 Jump／后续翼靴消费者完整看到有效松键，再在下一合法窗口 Press；已经重武装的能力不强加一帧等待。不写 releaseJump／rocketRelease／releaseUp，不截断正常起跳或上升尾段。重力球去回之间保留完整原生 Up 松键更新；手动 Up、强制重力或装备接管结束旧恢复意图，原版已经恢复时只观察结束。

马掌及组合、零翼时翅膀正常装备后覆盖真实落地；不额外给飞行时间。神灯腿等待原版慢落基线，重力球由真实原版 Up 阶段翻转和恢复，再精确还物。临时救援坐骑首次及时退骑若被原版拒绝，仍由本机拥有时按真实本机逻辑更新有限观察原版退骑资格；只改变空间或解除原版禁止退骑的控制状态也能继续收尾，关闭主开关保留这份归还责任。资格拒绝不重复退骑动作；玩家换骑、死亡或世代结束撤销旧意图。原坐骑物品归还与重新骑乘分别处理：恢复仅对仍是当前真实原物且许可有效时做一次完整原生 QuickMount；矿车沿其适用的原生 rail 分支。原坐骑恢复被拒或物品／选择被接管后结束旧意图，不凭类型强制 SetMount 或随空间变化复活重试。合法归还若被玩家对另一功能槽的新装备阻止，保留当前真实物品与合法新装备并交回控制，不强穿互斥原装。

抓钩计算实际来源、射速、子更新离散附着和玩家先于弹幕的原版顺序。及时获得实际原版保护后保持挂钩，交玩家手动解除，允许穿普通／斜平台。成功立即退出本轮救援；不等手动解钩持续规划，不自动 Jump、清钩或杀钩，也不为恢复平台碰撞补偿原版 GoingDown／stairFall。附加输入、真实物品和选槽尽早归还，归还不得使钩脱落。

交换真实 Item 引用，第一处写入前建立 owner，保护部分写入收尾、原物守恒、合法槽资格和原生同步。归还核准确 session／Player／物品引用与真实选择锚点，玩家新选择、同签名新物品、新坐骑或重力接管不被旧记录覆盖。关闭、失焦或输入接管禁止新动作，已发生借用仍按安全时机收尾；死亡、换角色／世界不串写。临时状态不持久化，不建立跨角色自动恢复作业。

只对真实本机玩家动作，普通好友本机房主和客机沿原版同步；连接方式不构成禁用条件。单人原生、编码、真实联网、图形／FPS及所有者体验分别记录。关闭／安全闲置不扫描背包或建计划；危险无候选和同目标失败不每 Tick 重扫、反射、重交换或发日志。仍拥有待解除救援坐骑时，仅作每真实本机逻辑更新至多一次的局部原版资格观察，成功或责任结束即停止；不据此重跑主预测或扫描背包。

## 连续冲刺

按住模式保持方向，在原版冲刺就绪后继续请求。双击模式在18个实际更新Tick内同方向按下、松开、再次按下并保持，第二次按下即武装，在原版合法时机发动并随自然冷却续冲；不要求第三下、第二次松开或额外长按。无方向最多容忍2 Tick，但无方向期间不补请求；超过后解除武装。按住模式反向直接按新方向请求；双击模式反向撤销旧武装，反方向作为新首击。双方向同时保持由最近按下者胜；同Tick按当前有效朝向，否则取右。

原生独立Dash键优先。辅助不修改速度、位置、冷却、资源或已发动冲刺的结束方式。资格直接使用原版本轮有效装备／套装结算的最终dashType，包含两种type1饰品、克苏鲁护盾、太阳套当前合法太阳盾与水晶刺客套，不在无盾时补授太阳冲刺。

坐骑62—65自带原生type6，首次进入即支持；56—61仅允许角色已有冲刺能力，没有装备／套装能力时不创造冲刺。其它不允许冲刺坐骑保持原版限制；普通高速移动和撞击不自动算本功能冲刺。

## 传送修正

只在玩家真实使用混沌传送杖或和谐传送杖时作用。原目标合法则保留；原目标不合格时，以原版限域后的目标为中心，在有限附近寻找最近合法角色空间，无候选保持原版失败。完整碰撞框、世界边界、墙体与进度、原版可达域和混沌杖代价保留。

合法空间可以在空中，不承诺脚下支撑、避液体／敌人或无伤传送；不选杖、不自动按使用键、不扩大射程。

## 输入、预测与证据

四项复用已映射且UI消费后的可信输入，尊重失焦／回焦隔离、真实文本、录键及模态owner。普通F5或背包可见本身不禁止移动；真正归属／消费的输入不会被重新读取补回。死亡、不可控、Session／玩家变化清短期意图，不恢复补发；已经发生的临时借用按上文安全收尾与准确身份处理。

远端玩家更新或相同编号的其它对象不会取消本机首击、双击武装或连跳阶段，也不取得本机输入许可。当前本机死亡、ghost、失焦及真实输入接管继续取消；更换本机对象或Session代次不继承旧手势。

外层更新没有原生输入映射时，只撤销本次动作许可，保留仍合法的已有手势和跳段；不合成松键、不推进双击窗口或中性宽容、不改变跳跃意图版本。同一新鲜映射只观察一次。真实取消重复到达保持幂等；冲刺开关／模式仅撤销冲刺，连跳开关仅撤销连跳。原生死亡发生在本次玩家更新结束之后，同对象复活也不得继承先前双击武装。

Jump持续意图及版本进入玩家运动预测前提；实际运动／传送改变后的旧前瞻须通过现有当前样本核验，不用全缓存清空或全局停线掩盖。复杂能力的预测质量与支持边界独立于真实连跳执行资格。

自动化只决定合法操作和已承诺的持续意图，原版决定物理、碰撞、装备顺序与资源，预测消费动作前封存的事实。一次冲刺或传送不默认增加持续意图字段；只有确实改变已知未来输入时才增加最小事实，语义未变不逐帧刷新版本。尚未决定的未来策略不当作已知计划。NPC追逐与未来发射原点共享同一玩家事实；仅接入同类合法输入且公共模型未变，不自动触发全模型回归，真实改变公共模型、快照、碰撞或失效语义时才沿实际消费者验证。

三项职责分别是：辅助决定何时请求合法原版动作；原版执行运动、碰撞、装备顺序、资源和代价；预测只消费已知持续意图及当前运动事实，不反向控制真实玩家。复杂装备未来动作尚未建模，不削减真实连跳能力，也不豁免新增退化。装备存在本身不应冻结已经支持的普通持跳近段：多段跳、尚未发动的飞毯、未点火的火箭靴及翼时耗尽而无翼靴燃料转换的状态，在当前仍为普通动作时继续沿已有运动模型推进。最后一更新、提前碰撞、已活动推力或将发生的未建模装备作用保留条件边界；这不表示翼靴、飞毯与坐骑已有完整未来物理支持。

CPU、原版隔离消费者、图形输入、配对性能、多人及所有者体验分别记录。候选包与安装身份及实际执行证据回到任务Issue；自动通过不等于普通包已由所有者启动、全部硬件零成本或多人已验收。
