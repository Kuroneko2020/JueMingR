# 移动辅助行为合同

本合同依据所有者委托的 `JMR-MOVEMENT-ASSISTS-20261019-v1`，原件位于本地 `references/JMR_MOVEMENT_ASSISTS_20261019_v1/`，用户结果以 `01_产品与界面.md` 为准。任务与接受状态见 [#126](https://github.com/Kuroneko2020/JueMingR/issues/126)；研发候选不表示已经通过所有者体验或正式发行。技术职责见[移动辅助实现设计](../设计/移动辅助实现设计.md)。

## 入口与设置

F5 的移动页依次提供模拟连跳、连续冲刺、传送修正，首次均关闭。每行沿现有开启、关闭及行尾公共绑键入口；没有新增默认快捷键。绑键只切该项开关，实际生效后使用公共短提示，冲刺包含当前模式，如“连续冲刺（双击） 已开启”；关闭使用命令前的实际模式。普通点击静默。

连续冲刺从左到右为“按住／双击”模式、开启、关闭、公共绑键；开启/关闭列与另外两行对齐。模式默认双击，开关与模式独立保存，关闭时仍能查看、切换和保存模式；重开沿用当前模式。名称与按钮提示同步表达当前模式。切换模式撤销旧手势，不继承半个双击。

三项偏好属于这一份游戏安装，保存于 `JueMingRData/config/features/movement.json`，跨角色、世界与重启共享。只保存三个布尔开关及严格两值的冲刺模式，不保存玩家、按键沿、Tick、坐标或恢复记录。缺文件使用默认且不主动创建JSON；损坏、未知字段、未知枚举与未来版本保留原件并保护写回，沿现有渠道报告保存／读取问题。本轮不支持 Legacy 设置导入。

## 模拟连跳

按住当前映射的跳跃键，没有装备时落地连续起跳；有二段跳能力时按原版顺序接力，随后由原版资格衔接翅膀、火箭靴、飞毯及相关能力。当前一次持跳段结束后才接下一段，不提前截断沙暴等长跳。次数、燃料、飞行时间、冷却与落地恢复由原版处理，不增加跳速、跳高、免摔或无限资源。

松键立即停止后续辅助；Down+Jump 让路给下穿／下压。水中、反重力、滑墙与原生自动跳跃装备保持原版资格。不会自动召唤／切换坐骑，也不为飞行、悬停或条件飞行坐骑追加自动飞行；非飞行坐骑合法跳跃继续按原版处理。

未来防摔可在当前更新写入前取得 Jump 优先权，连跳让路；本轮没有防摔功能或按钮。

## 连续冲刺

按住模式保持方向，在原版冲刺就绪后继续请求。双击模式在18个实际更新Tick内同方向双击，保持第二次按下后持续请求。无方向最多容忍2 Tick，但无方向期间不补请求；超过后解除武装。按住模式反向直接按新方向请求；双击模式反向撤销旧武装，反方向作为新首击。双方向同时保持由最近按下者胜；同Tick按当前有效朝向，否则取右。

原生独立Dash键优先。辅助不修改速度、位置、冷却、资源或已发动冲刺的结束方式。资格直接使用原版本轮有效装备／套装结算的最终dashType，包含两种type1饰品、克苏鲁护盾、太阳套当前合法太阳盾与水晶刺客套，不在无盾时补授太阳冲刺。

坐骑62—65自带原生type6，首次进入即支持；56—61仅允许角色已有冲刺能力，没有装备／套装能力时不创造冲刺。其它不允许冲刺坐骑保持原版限制；普通高速移动和撞击不自动算本功能冲刺。

## 传送修正

只在玩家真实使用混沌传送杖或和谐传送杖时作用。原目标合法则保留；原目标不合格时，以原版限域后的目标为中心，在有限附近寻找最近合法角色空间，无候选保持原版失败。完整碰撞框、世界边界、墙体与进度、原版可达域和混沌杖代价保留。

合法空间可以在空中，不承诺脚下支撑、避液体／敌人或无伤传送；不选杖、不自动按使用键、不扩大射程。

## 输入、预测与证据

三项复用已映射且UI消费后的可信输入，尊重失焦／回焦隔离、真实文本、录键及模态owner。普通F5或背包可见本身不禁止移动；真正归属／消费的输入不会被重新读取补回。死亡、不可控、Session／玩家变化清短期意图，不恢复补发。

Jump持续意图及版本进入玩家运动预测前提；实际运动／传送改变后的旧前瞻须通过现有当前样本核验，不用全缓存清空或全局停线掩盖。复杂能力的预测质量与支持边界独立于真实连跳执行资格。

CPU、原版隔离消费者、图形输入、配对性能、多人及所有者体验分别记录。候选包与安装身份及实际执行证据回到任务Issue；自动通过不等于普通包已由所有者启动、全部硬件零成本或多人已验收。
