# Legacy 战斗

**Legacy 行为参考，尚不代表 JueMingR 已实现或已接受全部合同。** 来源：旧功能根 `战斗页/` 十篇；[来源口径](功能索引.md#来源覆盖和限制)。入口为 F5 战斗页，分别帮助瞄准、朝向、使用节奏与信息提示。

| 功能 | 用户操作与效果 | 资格、默认或相邻边界 |
| --- | --- | --- |
| 辅助瞄准 | 使用合格武器时临时修正目标 | 不自动按攻击键，不改弹体/伤害；半径 0 的“已关闭自瞄”提示不替代完整运行判定，不宣称全武器兼容 |
| 自动转向 | 攻击时面向目标/鼠标方向 | 真实 A/D 优先；让路给专用使用节奏，不改变速度 |
| 自动连点 | 长按补足合格物品的点击节奏 | 排除鱼竿、原版左轮、镐斧锤工具、ShootsOnUseRelease；UI 实际捕获时让路，不能把单纯开背包一概当冲突 |
| 完美左轮 | 原版左轮 2269 长按时调 press/release 节奏 | 专用优先于省力魔法绳和通用连点，不扩到其它枪 |
| 省力魔法绳 | 有魔法绳效果且使用悠悠球时省力脉冲 | 优先于通用连点，不自行生成弹体 |
| 链球连击 | 默认关闭；合格链球长按右键发射/收回/再发射 | 真实右键交互、物品右键语义或 UI 占用优先；右键松开、换物、死亡或关闭退出，不改弹体运动状态 |
| 光剑快切 | 默认关闭；快捷栏至少两把合格光剑，当前持其中一把，右键按住且左键未按时循环 | 固定 18 类资格；间隔 0–30 tick，0 只去掉额外等候，不绕原版周期；松手后停在最后一槽，不恢复起始槽 |
| 哥布林必死 | 开启后玩家武器/弹幕可命中哥布林工匠 | 只针对 107，不包括被绑哥布林 105 或其它友方 NPC；不应从名称理解成自动击杀 |
| 装备提示 | Boss/特定事件中提示可能不适合战斗的装备 | 只提示，不自动换装或改伤害 |
| 自动汇报 | 新 Boss 战结束记录出现后，通过原版 `/bossdamage` 输出汇报 | 开启首轮把旧记录当基线，不立刻重发历史；无记录/命令不可用时不模拟键盘补救，属于聊天输出副作用 |

其它默认值与每种武器资格不从名称补猜。各开关/间隔/瞄准配置属 Legacy 设置，当前攻击周期、按下沿和目标缓存属会话状态；R 未建立战斗设置，数据设计与旧导入查[配置设计](../设计/配置持久化与用户数据布局.md)。

动作互斥和实际恢复比 UI 开关亮起更能说明功能能否用；反复写 fresh click 的外部 guard 也可能造成“自动连点”症状。机制与失败来源见[输入主题](../AI经验笔记/输入捕获与坐标域.md)及[战斗机制](../AI经验笔记/战斗移动与钓鱼机制.md)。本轮未进行武器矩阵、多人、性能或用户验收。
