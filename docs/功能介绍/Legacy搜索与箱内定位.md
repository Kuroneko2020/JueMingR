# Legacy 搜索与箱内定位

**Legacy 行为参考，尚不代表 JueMingR 已实现或已接受全部合同。** 来源：旧功能根 `搜索查询页/搜索查询.md`、`箱内物品定位.md`（均标记 26-08-28-0231）；[来源限制](功能索引.md#来源覆盖和限制)。入口在 Legacy F5 搜索查询页，两种功能各有目的。

## 查询物品资料

输入物品名、内部名、数字 ID 或 `#ID`，最多显示 40 个候选，过多则提示继续缩小范围。选中后查看基础信息、获取来源、合成来源/用途和直接微光关系；基础 value 是铜币单位换算，不是实时商店买卖价或折扣。

“选择物品”会暂时隐藏 F5，等打开选择按钮的左键释放，再接下一次真正点击。命中 UI 有物品才查该物品；UI 空槽不可穿透到世界。没有可见槽位时才使用新鲜 hover 证据，必要短等待后按点击瞬间冻结的世界坐标找掉落物/可反查方块/墙。完成后恢复 F5，不能让等待过程跟着后来鼠标改目标。

获取来源保留 NPC 掉落/出售/其它来源分类，含配方、掉落条件、整理的宝藏袋/开包/钓鱼/渔夫奖励/宝箱/世界生成/提炼/采集等线索。页面明确“仅供参考，不包准确全面”：随机商店线索不保证本次到货，开匣可得不等于匣子在哪里钓到，直接微光不覆盖所有分解，无法识别的条件保留未知。不为查询执行开包、奖励或商店动作。

## 定位附近箱内物品

上方“定位物品”输入支持相同查询方式，候选上限 24；输入变化只解析候选，不扫描箱子。点“定位容器”或候选才提交，匹配附近当前已同步箱子的 itemType 集合。命中后关 F5，世界中高亮容器；下次打开输入/候选清空，最近高亮快照仍可留到清空、打开箱子或自然过期。无有效目标/无命中时 F5 保留，提示“搜索范围内未找到物品”。不是全世界箱子搜索或背包操作。

多人客户端提交时原文有当前玩家 section 的受控原版同步请求，默认隐藏配置开启，同 world/section 300 tick 冷却；关闭该选项只查现有同步数据。请求已发送不等于结果已到，不请求周围九宫格或逐箱全图同步。未同步/远距查不到不能直接判 bug，也不能据此说多人效果已验收。

最近命中为会话快照，不持有可变 Item/Chest，不在 Draw 扫描/匹配名称，不取放物品。查询窗口与显示状态不是 R 已有持久文件；旧隐藏配置位置与导入在对应任务核对，新版布局查[配置设计](../设计/配置持久化与用户数据布局.md)。只读来源和 section 权威边界见[经验](../AI经验笔记/物品箱子与多人权威.md)。旧专属查询测量已退役，F5 不启动测量；本轮没有查询、多人或性能实测。
