# Legacy 杂项

**Legacy 行为参考，尚不代表 JueMingR 已实现或已接受全部合同。** 来源：旧功能根 `杂项页/` 八篇；[来源口径](功能索引.md#来源覆盖和限制)。以下入口均指 Legacy F5 杂项页。

| 能力 | 用途与实际操作 | 关键限制 |
| --- | --- | --- |
| 自动挖矿 | 热键模式手持镐子对准矿物标记；自动模式手动挖第一个后识别矿群。新矿群替换旧选区，以原版镐子长按采集 | 不是全图开采/直接删除 Tile；受真实工具距离、负 tileBoost、可达性和 UI 限制。宝石洞为特定混合组，泥沙/雪泥下落只有限追踪；手动切槽不强切回来 |
| 自动收税 | 靠近税收官且有税款时自动对话领取 | 使用原版领取，涉及钱币副作用，不直接改 taxMoney；聊天、箱子、NPC 对话、鼠标拿物等阻挡 |
| 快速重铸 | 在哥布林原版重铸界面，按住重铸键连续重铸，命中目标词缀停止本次长按 | 实际消耗钱币；名单空或界面不符不动作，不直接设词缀 |
| 旅行菜单 | 在非旅行人物/世界临时启用原版旅行菜单的单人实验入口 | 不声称多人支持；关闭、保存、离开世界需恢复。签名回归不证明 .7 save guard 已实机装好 |
| 游商测试 | 单人手动“开始”，白天、非日食、无入侵、无当前游商且有可用城镇住所时尝试原版到访 | 不直接刷脸、刷新商品或遣返；调用后观察区分成功/未验证/失败，不自动开启旅商方向，原文仍待实机验收 |
| 开发者菜单 | 两次点击确认后执行原版 `/hh` 帮助入口 | 首次红字提示坏档风险；不是无敌/传送等新按钮，也不是持久总开关 |
| 生成世界明细 | 对原版隐藏 WorldGen Debug/Viewer 入口的提示及启用 | 属诊断/实验，原版 enableDebugCommands 共享字段不能承诺完全隔离；不是普通信息窗 |
| 导出诊断 | 杂项页底部显式点“导出”，生成本地 ZIP 供调查 | F5 本身只显隐；导出不是启动任意测量，不上传。未曾记录的某帧细节不能事后补回 |

旧普通诊断包含快照、轻量缓冲、约 1Hz FPS/UPS 趋势及相关日志；0.1183 文档将 WP-TM-01/02/04 专属 owner/route/export 标为退役，旧特殊 entry 不应说成当前通用包必有。容量意义的“约十分钟”不是精确墙钟或单帧帧时证据；本地收口不证明 FPS 提升或用户接受。

旧导出位于 Legacy 用户配置根 `diagnostic-packages/`，开关/名单/热键属于 Legacy 配置；测试/实验按钮不因此变成长期偏好。R 未提供这些杂项业务或相同 ZIP 出口。当前诊断退出规则查[性能治理](../规范/性能治理规则.md#观察能力分类与安装退出)，用户数据与未来布局查[配置设计](../设计/配置持久化与用户数据布局.md)。本页提供历史用语，不执行其中实验操作，也不把旧调试入口作为新版建议。
