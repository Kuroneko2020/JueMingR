# 钓鱼与配装行为合同

状态：G10 所有者已授权的实施合同；实现、验证与体验接受状态以 [任务 #107](https://github.com/Kuroneko2020/JueMingR/issues/107) 为准。依据固定 Legacy 调查[钓鱼与配装 §0—15](全功能调查专题/钓鱼与配装.md)，本合同不把历史缺陷视为必须恢复的行为。

## 完整用户结果

信息页的完整鱼获与过滤鱼获是两个独立开关、颜色及字号，共用现有信息窗和位置。显示当前钓点可能出现的物品，不显示概率，不把可出现当作本次必得；无真实鱼竿/钓点不编造候选。过滤预览说明当前关闭、缺少声呐或候选不可读等实际条件。搜索目录、当前水域候选、过滤后候选和真实咬钩分别取证。默认字号 0.72，颜色分别为 `#87CEFA`、`#FFB366`，默认关闭。

钓鱼页依次为自动钓鱼、自动换装、自动配装、自动存放鱼、切杆跳过、快捷改名及过滤编辑区。五项自动能力默认关闭；存鱼为所有／任务鱼／关闭。换装与配装互斥，切换须先安全处理前一个策略已产生的借用。

过滤默认关闭、精确匹配；匣子和任务鱼默认为“要”，怪物默认为“不要”。模式循环为白名单／黑名单／关闭；特殊类别循环为跟随／要／不要。四份白/黑×精确/关键词名单独立保存。精确身份是 Item/NPC 类别加原版 ID，关键词只匹配当前语言显示名且忽略大小写，不把内部英文名当过滤关键字。

特殊类别按匣子、任务鱼、NPC 顺序求值。“要／不要”忽略黑白名单，只有“跟随”使用普通名单结果；开启白名单或黑名单但没有填写内容时，特殊规则仍生效。这是所有者体验反馈明确批准的改进，不照搬 Legacy 中名单覆盖特殊规则的顺序。实际咬钩仅把今日未完成的当前任务 ID 认作特殊任务鱼；搜索目录仍收录全部任务鱼。真实过滤要求声呐 Buff 122 的剩余时间大于零；关闭过滤、没有声呐或不能可靠识别时保留。

## 名单和预设的实际操作

鱼获列表采用当前原版的条件展示范围：满足条件时展开该规则的所有物品，并遵守展示停止规则；不求真实稀有度、概率或前项遮蔽后的精确结果集合。松露虫明确说明用于召唤，不加入普通物品或新的 Boss 搜索项。当前水域在有需求时至多每 30 个游戏更新重采样；点击“添加当前”当场刷新。超过有限水域读取预算返回不可读，不把截断水量当真实水量。

左侧精确名单/候选在空间足够时一行三项，较窄时减列；关键词最多两列。题头按“当前过滤模式：模式切换按钮、精确/关键词切换按钮”共排一行，关闭项写“关闭过滤”；工具栏均衡使用剩余宽度，右侧仅保留三个等宽特殊规则按钮，外框随内容收紧；工具栏与名单之间用细线和留白分隔；窄宽度可顺序堆叠。精确名单工具栏为“添加当前”“＋”“清空”“保存预设”“预设列表”。关闭过滤时名单操作灰显且不可执行，仍保留名单及模式/特殊规则设置。添加当前取当前水域；＋打开 Name／#ID 输入和浮层，空查询不扫描水域或展开全目录。两种候选均可多选后明确添加；96 是展示上限，截断可见，不是名单保存上限。条目可通过小叉号删除，各列独立命中并提示完整名称。

关键词拥有输入、确认、取消、逐项删除。清空只影响当前名单。二级窗口随实际内容收缩，达到视口上限才滚动；点击主 F5 窗口关闭二级窗口，整个点击不穿透执行底层按钮。切换白/黑、精确/关键词、切页、关闭或取消不会提交旧草稿；浮层互斥，按下和释放都归当前输入所有者。只有本次设置命令可靠保存完成且编辑作用域仍匹配时才清选择或关提交浮层；失败保留草稿与可回看的结果。短暂保存期间拒绝重复提交，但不把相邻控件一起变灰。

预设只保存当前作用域的名单，自动命名，不另加命名窗。预设列表按作用域筛选，窗口宽度随内容收缩；标题与过滤上下文同排分级，名称与内容紧凑同排，关闭与小叉删除为辅助操作，不再为每份预设和每个精确图标重复套框。精确内容显示逐个图标，关键词胶囊按完整文字加长，整项可换行；单个关键词超过可用宽度时在胶囊内换行，保留全部文本，不用省略号隐藏。可滚动、点击名称/内容应用及独立删除自建项；应用替换当前名单，不改任何其它规则或自动能力。保存预设、预设列表及其中内容不提供悬停提醒。内置“垃圾”仅出现在黑名单精确作用域，含 OldShoe、Seaweed、TinCan，不可删除；没有主动应用前不自动写入名单。重复内容沿稳定内容名替换同作用域自建预设。

## 自动钓鱼与相邻动作

玩家先手动抛竿，真实本机鱼漂入液才建立会话。记录玩家/世界/连接代次、原竿实物和槽位、完整 ProjectileKey（仅 -1 为无效）、原世界抛点。原版使用链承担收竿、鱼饵消耗、断线、随机堆叠、NPC、溢出和重抛；不直接造鱼、杀漂或改计时。收到请求、实际用竿、旧漂消失、产物入袋、新漂生成是不同事实，不以其中一个替代全部结果。

拒绝鱼获且不开切杆时等待原版自然逃脱，下一次咬钩重新判断，绝不因普通超时强收。切杆通过受控临时选择让原版结束旧漂，不使用临时槽物品；无安全槽或暂时不宜切换时等待。重抛沿保存世界抛点且至多一次，动作前复核没有玩家后来新抛的漂。未知结果不补发。

换离原竿、手动接管、生命下降、死亡及会话失效终止本次自动循环。受控切杆及原版尚未兑现的回竿缓冲属于当前钓鱼会话，不触发结束或重复换装。F5 暂停收抛竿等工具动作；普通 F5 浏览允许自动换装/配装，但须物理鼠标松开，且只承认壳层证明的自身鼠标界面占用。聊天、文本/IME、对话、箱子、鼠标拿物、失焦等安全门保留；回执与安全归还仍保留。普通背包沿当前原版动作的细分准入，不扩大为统一禁用。

会话开始/结束复现“开始钓鱼／停止钓鱼”；以松露虫开始的会话显示“开始鲨猪”，换离鱼竿或丢失鱼漂等自然结束显示“鲨猪啦！”，受伤、死亡、关闭仍显示“停止钓鱼”。这些沿现有玩家头顶短提示呈现，不发聊天，也不在自动重抛、切杆或借网时重复开始。特殊结束文字不是 Boss 生成成功凭证；松露虫召唤标记不作为普通物品 1 过滤，原版仍负责召唤、消耗及自动循环中的收抛。

G09 FishingBorrow 有效期间拥有该 token 的唯一必要重抛，G10 让位；借网不是手动换竿。G10 自动重抛后的原抛点继续传给下一次借网。捕捉的 Boss 暂停不扩张为全部钓鱼暂停；补给、快捷物品和加工继续得到合法机会。

## 专用存鱼

所有模式仅由自动收竿关联的原版真实物品产物取得资格，在该次完成边界捕获符合保护条件的同类型旧库存；直接入袋数量与溢出分别观察，不要求以背包新增量冒充整个产物，也不是整理全背包。产物全溢出时，可以处理当时已存在的合法同类型旧物；没有可移动旧物则本次资格立即结束，不等未来入袋补票。任务鱼模式在有效钓鱼会话内检查已有的当前任务鱼，并要求今日未完成、合格同类附近目标。手动收竿、负 NPC 不建立所有模式资格。落地再拾取仍是普通真实拾取，不追溯或重放钓获归属。

同一物品继续遵循卖出＞丢弃＞存放；专用存鱼优先决定其存放意图。共用附近同类型世界箱和原版权威存放，不新增银行目标。收藏、在用、手动取回、鱼竿/鱼饵、在途或未知操作保护均有效；所有模式不额外套普通堆叠的 maxStack>1 限制。无合法同类目标不发送存放；两种意图共用相同目标集合，不据此发第二次请求。

来源组、真实移动量/余量、提交及服务器返回分别记录；未知、超时、晚回包不重发、不解原版锁、不回填旧库存。关闭取消未开始资格，在途解释仍按原物品 owner 收尾。

## 临时装备

换装选择原版装备组，按专题 §7 的衣物5/目录饰品10启发式，同分取更高组号；配装按 §8 完整固定目录、效果分组、分数和来源顺序选择真实物品。旧分数不是实际最佳渔力：两套衣物每件实际均+5，鱼漂变体只生效一次。包括两袋、耳环、八鱼漂、线/箱/熔岩钩、钱币组及九种马蹄铁，不按名字猜效果。

当前/时装、背包0—49和当前可用的虚空袋是来源；不新增银行或世界箱。收藏可被临时装备，不意味着允许存卖扔。读取当前有效装备与其它组收藏共享语义，核槽位、难度、兼容及原版切组资格；当前组读取身上装备，不能把组存储当身上装备。

每次交换绑定真实对象、来源/目标和会话；只有实际应用项才产生归还责任。原物移动时不能拿同类另一件冒充，不能整包快照覆盖。手动换组/换受控格后的新意图优先；鼠标拿物、无安全空位、来源不可用时保留真实物品和必要结果，等相关条件变化再评估，不按重试次数丢责任。每次操作后物品仍留在真实容器中，不以内存库存保管物品。退出或身份改变不得对新角色执行旧归还；无法自动归还须说明实际结果。

入液后启用装备策略，使用松露虫时不自动换装/配装；正常收竿/重抛/受控切杆间保持借用。当前组已最优或没有适用候选不产生虚假借用，准备状态随会话退役。正常归还和玩家主动接管不作为橙色异常通知；真实未归还、未知结果等仍说明。稳定状态不逐帧全来源重算，有关物品、可用格或液体变化会更新。

可堆叠渔具拆出一件使用，需要同一来源背包或虚空袋中的安全空位；没有空位时提示等待，保持原堆不变。归还单件会留在该容器的预留格，不自动合并原堆。退出时尚未归还的物品保留原版实际布局；同一次工具进程重新进世界后显示一次“上一会话”结果，钓鱼页保留可回看说明，不把提示带成旧物品恢复操作。

## 快捷改名与公共入口

单人名字框双击编辑并确定；非编辑时按钮将末尾 ASCII 数字串进位，无数字追加1（`Test009→Test010`）。去 CR/LF、Tab 转空格并 Trim，结果为空或超过20个 .NET 字符拒绝，不截断、不用有限整数解析尾数。多人明确不可用，不仅改本地显示。

原版 Rename/SavePlayer 后分别确认运行时名字及保存读回，不能以无异常或 name 字段改变报保存成功。成功通过现有玩家头顶短提示显示，菜单不再重复显示成功或普通等待状态；异常/部分效果说明实际状态且不自动重试。今日资格按新名字在原版今日已完成名单中的精确匹配刷新，不清整个名单。角色文件路径/cloud及玩家对象不改，R 现有身份和记录归属保持。

自动钓鱼、换装、配装、存鱼、切杆及两个鱼获显示接公共绑键，默认空；热键在关闭和最后可靠保存的开启模式之间切换，UI循环另司其职。过滤模式按所有者追加要求仅通过页面按钮循环，不提供快捷键绑定。只有真实热键成功改变状态才发公共短提示；F5点击、加载和每条鱼不发开关浮字。复杂编辑/保存/装备结果保留必要可回看反馈。

## 证据和退出边界

纯规则/可靠存储、固定 .8 完整玩家执行链、实际 F5 输入绘制、工作量及全 diff 独立审查分别交付。只在隔离合成角色/世界/配置中自动验证，不启动 Terraria、不改真实资料或云账户。普通自动检查不代表真实 IME、多人、FPS 或所有者体验已验收。完整候选通过既有安装安全门后交付，Issue/Draft PR 保持开放等待所有者接受。
