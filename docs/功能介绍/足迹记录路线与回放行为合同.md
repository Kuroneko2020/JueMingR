# 足迹记录、路线与回放行为合同

本批目标由所有者完整开发指令授权，实施与验收状态查 [#87](https://github.com/Kuroneko2020/JueMingR/issues/87)。本合同不表示已经实现、实测接受或获准合并；技术落点见[实现设计](../设计/足迹记录路线与回放实现设计.md)。

## 入口与默认值

F5 地图页提供“足迹”的显示开启/关闭、配置与公共绑定图标。主行和快捷键仅控制显示，首次默认关闭、未绑定。配置中的“录制足迹”首次默认开启，已保存选择优先；正常进入可靠角色与世界后即可录制，不等打开地图。两项偏好沿当前安装共享的普通偏好保存。

显示关闭只撤销地图路线、时间轴与相关输入；录制关闭收好已接纳尾部，不再增长位置和时间，已有历史保留。重新录制另起连续段。回放暂停仅停止历史游标，不暂停游戏或录制。没有全局录制、回放、清除快捷键。

## 时间、位置与连续性

只记录可靠本地角色×当前世界；复用当前原版角色文件 local/cloud 路径与世界 GUID 的身份边界，不按名字合并，不把路径身份说成永久角色 UUID。SSC 或普通客机尚未可靠连接时不录制，不发送网络请求补轨迹。

录制时间是实际完成的原版世界模拟步，每 60 步为一秒；存完整 Int64 步数，不逐帧取整毫秒，不以 UTC、Draw 次数或昼夜变化补时。真正暂停、菜单、加载、离线不累计；背包、聊天、F5、箱子、大地图、失焦是否继续，由原版是否实际执行模拟决定。睡眠/日月晷/旅行昼夜快进或冻结不改变此换算。

每个合格模拟步观察玩家中心，以连续 tile 坐标保存（原版像素除以 16）。准确相同的位置合并停留时长；任何可表示的真实位置变化均保留，不将 2 格以内移动吞成挂机，不抽稀跨越转弯。记录只承诺每次观察的样本；相邻观察之间的展示插值不是对未观察路径的实测证明。

传送、出生/复活、离世重入、录制重开、身份变化、不可用位置及观测缺口断段。死亡/幽灵但仍可靠执行世界模拟时，以明确“无位置区间”保存时长，不制造 (0,0) 或出生点。不同段、无位置区间不连线或插值。正常高速运动不使用固定距离阈值判瞬移；已观察传送即使很短也断段。真正暂停不补时间；恢复位置可信且未发生跳变可保持地理连续，否则断开。物理存储分页不产生断段。

## 保存与可访问范围

不设置 200 小时、天数或总点数的自动淘汰；超过 24/200 小时按完整小时显示，不回绕。持续停留增长时长，不生成相同坐标的数百万点。

历史以封存块和有限活动尾部保存；新增事实只写有限增量，小根摘要可更新。全时间轴覆盖全部成功保存的历史。内存、待存批次、块缓存、查询准备和实际绘制各有边界，显示省略与缓存淘汰都不删除记录。大历史围绕当前游标优先取得真实连续片段，显示“部分路线，拖动查看其他时段”；不以固定最早或最近片段永久挤掉其它历史，不连接被省略的非相邻位置。

保存从第一项未提交事实起计算期限；新增点或断段不延后。暂停、关闭录制、离世和正常退出处理已接纳尾部。慢盘/失败达到有限接纳量后停止新增并提示，保护已有数据，恢复另起段；磁盘不足不删旧史腾空间。强退/断电前尚未可靠提交的尾部可能丢失，不承诺绝对无损。

可靠空、加载中、坏文件、未来格式、身份/尺寸不符、明确未提交、提交未确认分别处理。损坏或未知内容保留，默认录制不会用空数据覆盖；只展示已验证内容时必须说明不完整。未确认提交不盲重试。旧世界回执不改变新世界显示。

## 地图与回放

有效全屏地图展示打开时，默认全部历史范围、最新端、暂停、1x。绿色路线与地图地理坐标一致，屏幕线宽不随地图缩放变粗；只裁真实相邻边，用明确 1×1 纹理源。停留不制造零长射线，死亡点和标记继续各自工作。

底部紧凑控制条包含播放/暂停、时间轨道、倍率、“最新”和当前/总时长。倍率为 1x、10x、60x、300x、1800x；切倍率不自动播放，暂停不重置倍率。最新端点击播放从最早记录开始，中间位置继续播放，达到当时可用末端停止且不循环。“最新”跳到当前末端并暂停，保留倍率。

点击或拖动先暂停定位，历史暂停/拖动固定时间坐标和当时轨道范围，后台追加不挤走位置。播放由单调 UI 时间推进，保留小数；世界真暂停但界面可用时仍可播放。失焦或隐藏停止推进，重开不补隐藏时间并恢复默认状态。只在同段真实相邻样本间插值，完整停留照常播放；回放指示与真实玩家不同，不移动角色或自动改地图中心。

时间轴与 F5、Notes、绑定/样式/死亡/统计/标记窗口统一仲裁。条内开始的手势保有真实释放，条外开始不因移入抢占。失焦、布局/资源/会话/档案变化取消旧捕获；合成释放不确认。条外正常拖图、缩放、ping和原版玩家图标不被全屏透明层拦截。

## 三次点击清除

配置紧凑区域明确范围“当前角色在此世界的足迹”。总计三次明确激活，准确文字依次为：

1. `清除足迹` → 只显示 `确定？`，提供取消；
2. `确定？` → 只显示 `不可恢复，确定？`，提供取消；
3. `不可恢复，确定？` → 接纳一次固定档案清除命令，显示处理中或结果。

每阶段须先呈现，再接收新的按下和真实释放；长按、同帧重复、双击回调、旧释放或按住 Enter 不跳级。第三次前取消、Esc、关副窗/F5、失焦、换身份或档案代次撤销；普通录制尾部增长不撤销确认。第三次固定当前可靠身份、会话、旧档案代次和操作 ID，此后关窗/换世界只收尾原目标，不伪称取消，也不改删新世界。

清除先停止旧档案接纳/发布，沿同一后台写者顺序退役旧写入，再删除旧档案的所有正文块、活动尾部、索引及本模块可恢复的 bak/tmp。允许很小、不含轨迹正文的持久意图；不写空摘要代替删除，不创建撤销备份或回收站，不扫描外部备份或安全擦盘。

删除只限已验证的本模块专属旧代次路径，不删共享 pair 父目录、其它角色/世界、原版 .map/.plr/.wld、标记、死亡、天数、Notes、快捷键或任何其它内容。未知文件/异常链接/归属不明即明确阻塞，不扩大范围。

部分删除失败准确标未完成，已删除内容不反向恢复；固定命令可重试。持久清除意图在重启后只收尾该旧代次，阻止旧备份恢复。全部旧正文移除且旧写者不能提交后才成功。成功后保持录制偏好：原本开启从全新代次/新段重新录制，关闭保持关闭。随后出现的新足迹不属于旧史复活。安装、首次启动或测试不得自行发出真实用户档案清除命令。

## 验证与停止

清除自动检查只用隔离合成数据和其它功能/其它 pair 哨兵。实机卡仅要求自然短路线、停留、真暂停、开关、回放和重载；清除体验可用专门测试角色/世界的少量足迹。自动逻辑、真实文件、原版受控执行、图形设备检查、真实游戏/多人/FPS及所有者接受分别记录。交付后 #87 OPEN、PR Draft，等待实测和外部审查，不自动合并或发布。
