# 当前群系显示与 F5 配置

这是 **JueMingR** 的群系与 F5 用户说明。既有接受依据为 #34 / [PR #35](https://github.com/Kuroneko2020/JueMingR/pull/35)、[群系设计](../设计/代表性纵向切片一-群系显示.md)、[F5 设计](../设计/F5控制界面样板与UI基础.md)和[配置持久化设计 A 部分](../设计/配置持久化与用户数据布局.md)。当前目标为 Terraria **1.4.5.8**；既有 Windows Steam 单人实机证据保留原范围。[#71 已接受实现](世界感染幸运值渔夫任务与信息窗位置行为合同.md#12-r-已接受实现与验证边界)新增群系独立颜色/字号配置，首次默认从 0.72 增至 0.82，并接入共享信息窗位置；原开关/绑定保留，群系取数、页面控制、快捷键与呈现扩展至普通多人本地客户端。所有者简单实测未发现问题并正式接受本批及后续修订，随 PR #72 合并进入 main；不外推为真实多人、其它渠道、全部 Windows/IME、材质/字体/视口或 FPS 已验证。

## 查看群系与控制显示

进入单人世界或连接原版服务器的普通客机后，按原开关显示本地玩家群系；首次默认显示绿色 `群系: …`，随所处区域更新；离开世界回菜单不保留旧文字。F5 打开或隐藏控制界面，默认进入“信息”页。点击群系行的“关闭”隐藏群系文字，点击“开启”恢复；绿色/红色短下划线表达实际选择。实际故障显示“不可用”，不能靠重复点击或改配置解除故障。

F5 只控制界面显隐，不导出诊断。界面有两行分类：物品、杂项、地图、查询、笔记、关于，以及蓝图、钓鱼、战斗、信息、增益、移动。笔记、自动化、快捷键与其它信息显示见[功能索引](功能索引.md)。群系行“配置”打开独立颜色/字号副窗；感染、幸运、渔夫与位置入口也已接入。鱼获等无关样板仍不启用。

## 移动窗口与输入

拖住标题栏移动窗口，正文滚动时标题/导航固定。窗口位置可跨启动恢复；自动适应屏幕/UI scale 的边界夹紧不会覆盖用户原位置，用户再次主动拖动才形成新偏好。F5 是否打开、最后页签、滚动和正在拖动状态不跨启动保存。

信息文字位置使用信息页“调整信息窗位置 → 开始”，与拖 F5 标题栏分开。进入后松开进入键，再按住信息文字区域拖动；松开完成，Esc／右键／F5 取消。四项共用位置，各项仍各自调色/字号；全关时可拖临时目标，取消不开启任何功能。

失焦、进入全屏地图、原版设置/特殊 UI、拍照等不安全场景会关闭或取消当前交互。正常关闭或退出世界打断标题拖动时，提交最后一个有效且聚焦的位置，不把合成释放坐标当新位置；后续已接受的失焦合同则取消未完成拖动，恢复拖动前位置。直接关闭进程前尚未交给保存系统的拖动过程不保证保存；具体输入范围与极小视口行为查 F5 设计。共享 F5 壳层与群系读取/控制均允许单人及普通多人本地客户端，对方无需安装 R。服务器模式、菜单与无效本地玩家不显示；键鼠和有效焦点限制仍适用。真实多人体验仍未验证。

## 保存在哪里

同一游戏安装目录下：

| 文件 | 保存内容 | 缺文件默认 |
| --- | --- | --- |
| `JueMingRData/config/features/biome-display.json` | 群系显示的用户期望开关 | 开启 |
| `JueMingRData/config/ui.json` | F5 最终窗口位置 | 居中 |
| `JueMingRData/config/features/information-display.json` | 三摘要开关、群系及三摘要各自颜色/字号 | 三摘要关，四字号 0.82 |
| `JueMingRData/config/information-window.json` | 共享信息文字期望位置 | 左侧约 20、视口高 45%，按内容夹紧 |

偏好在同一安装内跨角色、世界与回菜单共享，不自动共享到其它游戏副本或电脑。首次缺文件不会立刻生成默认 JSON，真实修改后才保存；目录或锁文件存在不等于偏好已落盘。笔记、快捷键等已有各自存储，查配置设计的对应部分；本批不导入 Legacy 设置。新候选两份偏好的具体归属见[实现设计](../设计/信息摘要与共享信息窗实现设计.md#偏好样式与公共入口)，机械备份、锁和后台生命周期继续遵循既有配置设计。

## 正常静默，异常才提醒

合法读取、首次缺失、切换开关、拖动与正常自动保存都静默，不弹“保存中/保存成功”，也不改成成功日志。真正读取/保存失败、损坏、未知字段或版本、超时、占用或外部修改冲突才给必要中文提醒。同一份文档的同一持续异常不会因重复操作、开关 F5 或切世界刷屏；不同文档各自提醒。菜单或原版隐藏 UI 时暂不领取，显示成功才算提醒已交付。

异常时本次内存选择可能仍生效，但磁盘未可靠保存；保护原件，不自动降级、覆盖未知字段、恢复备份、换目录或提权，也不在本进程中自动重试/热重载。按提示退出游戏后处理具体文件原因再启动：格式损坏时先备份并仅移走提示的配置文件；冲突时保留该文件及 `.bak`；不要整体删除 `JueMingRData` 或盲删锁文件。各份配置独立，一份失败不等于另一份保存失败。
