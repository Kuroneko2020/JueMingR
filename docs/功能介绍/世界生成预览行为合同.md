# 世界生成预览行为合同

本合同对应 [#149](https://github.com/Kuroneko2020/JueMingR/issues/149) 的世界生成预览候选。候选、审查、包、实际安装与所有者体验分别回任务核对，收录合同不表示已经合并或实机接受。

## 用途与入口

创建新世界时，原版生成进度下方显示暗金提示“按 F5 查看世界生成预览”。按 F5 进入汉化后的原版世界生成预览，提示随原读条页退场。本功能自动提供入口，没有杂项行、独立开关或持久化偏好。

只有本次真实生成仍在进行、原版控制器和进度已发布、普通生成页位于前台且适配完整就绪，才显示可用提示。预备阶段不提前承诺入口。普通菜单、加载既有世界、游戏内、完成和中止后均不显示。适配失配只关闭本功能，原版正常建图继续。

## 原生功能与操作条件

原版继续拥有地图、阶段列表、暂停/继续、前进一步/后退一步、重置、生成快照、比较变化暂停、快速加载设置、地图与聊天显隐、搜索、帮助和取消。按钮是否可用、是否需要暂停、快照是否有效、动作结果及确认条件遵循原版。R 不修改步骤标识或世界生成算法，不创建第二套地图或快照。

“保存快速加载设置”保留原生效果：记录当前生成配置与阶段，保存原版需要的设置/世界及原生快速加载配置；这是玩家主动点击后执行的原有操作，打开预览本身不保存。独立开发者菜单、全局开发者命令启用和诊断导出不属于本功能。聊天入口保留，原版全局命令许可条件继续生效。

## 按键、取消与生命周期

F5 只承诺在普通生成页进入预览；不承诺再次 F5 返回。原版 Inventory/Cancel 路径是取消生成，界面相应文字使用“取消生成”，不将其描述为关闭窗口。原版空格键、方向键、R、M、C、H 与修饰键的准确操作以预览内汉化帮助和当前原版逻辑为准；原版文本输入让路与取消保护保留。

一次新按下只进入一次，长按跨页不重复打开。切窗后不把旧按键尾部变成新命令，可信松开后下一次合法 F5 恢复。生成结束后，游戏内 F5 仍走决明菜单原有许可和边沿；本功能不放宽世界内菜单的条件。

自然完成、取消和异常后，本次提示与自有状态退休；原版按自己的流程收尾。再次建图使用新的生成身份，不认领异常遗留的旧控制器或进度，也不复活上一轮显示状态。R 不删除原生生成快照、不撤销玩家主动保存的快速加载设置。

## 汉化与显示

锁定 Terraria 1.4.5.8 的阶段显示名、固定控件与 tooltip、帮助、动态阶段/状态及操作条件由显示生产点生成中文。步骤内部名称、排序、快照索引、命令、种子、数值、用户输入和路径保持原义；未知显示文本保留原文，不能用兜底掩盖已知漏译。

横幅借用当前原版字体与现有暗金色系，薄半透明深底、无点击/滚轮/焦点。位置围绕原生进度区域居中、跟随视口与 UI 缩放，避开阶段和进度。稳定布局复用度量与几何，不扫描世界或每帧遍历界面翻译。

## 支持与证据边界

本功能是当前锁定客户端的建图 UI 能力，不增加多人通信或服务端操作。客户端创建世界复用相同生成流程时使用相同入口，不表示联机中观看远程服务器建图。正常完整开发包保留其余功能，最终两文件发行另行处理。

实际入口/原版生成调用、输入与文本自动检查、真实图形专项及所有者本人实机各自承担证据；源码、CPU 断言或字典覆盖不能代证物理输入、全部视觉场景、多人或 FPS。实现机制及准确测试入口见[实现设计](../设计/世界生成预览实现设计.md)。
