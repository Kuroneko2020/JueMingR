## 来源、覆盖和限制

来源是 `JueMingZ/文档/功能介绍/`，2026-09-06 现场共 **79 文件**（上表 78 篇加根索引）。已查看真实索引与目录分布，对全部类别的候选阅读功能说明、玩家行为、配置或边界正文；长蓝图、查询和诊断文档采用针对机制/行为的段落阅读，未逐条阅读/验证其所有版本流水、内部字段、日志和关联测试。不能称全功能重验或全量源码审计。

旧文档根未被 Git 跟踪；现场源码 checkout `6ac6356c0c564f43284590c168855e96c50e13f7` 只标识来源工程，不能绑定文档字节。每篇注明原目录/文件，原件仍留 Legacy；在 R 不保存全文副本，不伪造可公开的 blob 链接。历史能力主要为原文描述，本轮没有据此认定实机、多人、性能或用户接受。

合并是按用户任务消除重复章节、旧类名与版本更新流水；不是裁剪产品目标。旧实现状态标签与描述冲突、右键提炼说法与原版调用不符等差异，在具体篇章保留并交对应功能任务核对。原文没明确的默认值、探测条件或存储文件名不补猜。

旧功能常规设置由 Legacy 自己的配置系统保存；本目录只保留已经明确的自然数据归属和必要文件线索，不能把 R 的 `JueMingRData` 当旧文件根。R 用户数据合同及未来建议查[配置设计](../设计/配置持久化与用户数据布局.md)，是否导入旧数据按功能另行评估。新用户行为在产生它的同一任务更新相关篇章；可复用机制进入[经验索引](../AI经验笔记/索引.md)，需要原件时读[本地资料说明](../设计/本地参考资料使用说明.md)。
