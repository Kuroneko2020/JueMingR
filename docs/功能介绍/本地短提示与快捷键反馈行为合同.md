# 本地短提示与快捷键反馈行为合同

本合同已获任务 [#101](https://github.com/Kuroneko2020/JueMingR/issues/101) 的开发授权，用于本分支实现与验证；产品体验、参数及合并仍待所有者接受。动态状态、候选和安装身份只记 Issue / PR。原有已接受合同继续有效。

## 来源与通道

开关状态短提示只由统一快捷键中合法派发并真实改变状态的键盘／鼠标开关产生。本批已接入群系、三项物品自动处理、三项实体显名、五种附近目标、三种世界文字、三项信息、三项指引、死亡点常驻、地图标记、足迹显示、快捷宣告开关、保持收藏、快捷物品开关、自动存钱、六项恢复／增益／服务和三项连续加工，共 37 项；这是本批覆盖清单，不是未来功能白名单或接入数量上限。

查询悬停物品、调整信息窗、发送快捷宣告和动态物品使用条目继续各自用途，不套开关回执。快捷宣告仍真实发送聊天；新开关短提示只在本地显示，不发网络。F5 点击、加载配置、启动、后台行为和业务执行不制造开关提示。

短提示承载一次操作的当前结果；持续故障仍由既有悬停／错误反馈承载；输入校验保留原行内提示；宣告保留原聊天通道。不吞、改写或提前消费现有错误。

## 后续功能的默认接入

以下是本批合同的一部分，随本批接受并合并后适用于后续任务；不构成未来具体功能的实施授权。新增或实质修改功能开关、模式、快捷键或操作反馈时，实施者和独立审查者必须核对本节，不依赖旧聊天或所有者再次提醒。

- 新增可由玩家切换的功能开关／主模式，默认同时交付功能行末尾的公共绑键入口、真实命令接线及快捷键生效短提示。沿用公共录入方式和默认未绑定，不擅自分配按键；特殊功能确不适用时，在该功能合同说明实际理由及采用的入口／反馈，不能只因忘记接入而省略。
- 新增适合即时、本地、短暂确认的操作结果，默认复用本地短提示入口；该显示能力不限定于快捷键，也不要求文案都是开关状态。调用方先确认真实结果，保留自身会话、有效性及业务／保存合同；技术接入和现有限制见[后续消费者接入](../设计/本地短提示与快捷键反馈实现设计.md#后续消费者接入)。
- 持续故障、需要回看的错误、界面内校验／原位确认和对外聊天继续使用合适的原通道；首次引导等具有专门计时／持久化语义的提示只复用适用机械层。不因“默认复用”把所有提示搬成浮字，也不为 F5 普通开关点击、加载或后台行为新增开关回执。
- 在新增功能自己的合同／设计和验证中说明来源、实际生效点、通道、过期／替代和例外即可，不另建全产品接入台账。独立审查核对新增功能是否漏绑键入口、漏结果反馈或重复造显示逻辑，以及例外是否有真实依据。存在不适用场景时按现行任务权限处理，不把每个普通内部接线变成新的审批步骤。

相关检查必须从实际注册／操作入口验证结果，不能只证明调用过显示方法；未来开关必须进入相应真实 Host 夹具，核对未生效／失败不假报成功、旧结果失效及相邻输入保护。当前 37 项通过不证明未来自动接入，具体覆盖维护见实现设计。

## 状态与文字

文字为“功能名 已开启／已关闭”，多模式为“功能名（模式） 已开启／已关闭”。开启使用已生效模式；关闭使用本次命令之前的实际模式。回血由关闭打开为快速；快速／智能关闭分别说明旧模式。NPC 名字／类型、宝箱始终／开过、牌子墓碑全部／前几行／前几字保持既有恢复模式。

运行时先行的设置在实际应用后确认，不等待文件保存；该提示不等于已保存。要求可靠提交的设置只在原设置所有者收到本次确切成功回执、发布对应有效状态后显示。Busy、拒绝、无变化、失败、结果未知或后来的同文件命令覆盖本次意图，均不报成功。原业务暂停、错误保护和保存语义不变。

## 显示与淘汰

工程候选参数：最多 4 个活动结果、无待显示历史队列；最多 12 个等待业务确认的请求，等待上限 5 秒。每条结果从发布起最多 1.8 秒，最后约 250 毫秒淡出；同一稳定功能身份替换旧结果，容量满只淘汰最旧的自有显示，不影响命令。参数是本批选择，不是先前所有者指定。

优先使用原版带描边浮字，在玩家屏幕头侧出现；开启为浅绿 `170,245,190`，关闭为浅灰 `225,225,225`。原版池满、槽被复用、清池、角色不可见、物品文字关闭或全屏地图时，使用屏幕上方居中的最多四行同语义描边文字。后备基准字号为原版 MouseText 字体的 `0.9 × UI scale`，窄视口整体缩小保留完整结果词。原版路径保留原版缩放／运动。

同一结果仅一个后端，不因切地图、缩放或丢槽重播。失焦、会话／角色变化、后续状态变化、过期即退休；不积压到下一场景。短提示不夺焦点、不消费输入、不增加 F5 内容高度，不新增设置页或通知历史。保持原版 `Main.showItemText` 值：该开关不关闭新快捷键确认。

隐藏全部 UI、缺失字体／图形设备或绘制故障时无法保证可见；显示失败只丢弃本次提示，不重试或回滚业务，不停用健康功能。此限制不能冒充已显示。普通用户未因此获得额外诊断或错误弹窗。

## 丢弃与首次引导的独立合同

自动丢弃继续在清空物品前取原本地化名称，在操作完成后使用实际数量；原开关、`showItemText` 和 60 帧原版运动保持。仅显示共用安全入池，主动开关结果活动期间丢弃显示退让；不延迟、重试或取消丢弃业务。原版外来文字不被抢占。丢弃提示关闭不影响快捷键回执。

首次引导共用安全入池／所有权／释放，角色身份、跨世界标记、真实 Draw 回执、三秒可读计时和暂停恢复继续由 Onboarding 独占；不改成入队即已看见，不套快捷键 1.8 秒期限或存储。普通开关不写标记、通知日志或历史。

实现与检查入口见[实现设计](../设计/本地短提示与快捷键反馈实现设计.md)。现有物品来源、收藏／使用／未知保护、卖＞扔＞存优先、足迹录制、地图记录、多人权威及 #48 限定延期均不在本批改变范围。
