# 工具与自动采集行为合同

状态：G09 实施合同，待所有者实测接受。授权与动态进度见 [#105](https://github.com/Kuroneko2020/JueMingR/issues/105)；调查来源为[完整专题](全功能调查专题/工具与自动采集.md)，实现方案见[设计](../设计/工具与自动采集实现设计.md)。本合同不表示实现、多人或实机已经通过。

## 范围与共同行为

本批交付自动捕捉、草药收获复种、自动挖矿的完整能力。三项独立设置，初始关闭，不导入旧配置。主开关键在关闭与上次可靠保存的非关闭模式间切换；捕捉首次恢复自动，挖矿首次恢复快捷键。所有绑定默认空，选脉有独立动作。F5 普通点击不显示开关浮字；快捷键经可靠保存完成后沿公共短提示显示真实状态；选脉结果单独反馈。

原版物品使用、选择状态、工具动画、声音、掉落、消耗与网络路径继续生效。自动操作按会话、真实物品对象、槽位和当前输入准入，不还原库存或世界快照。保存中、失败、未知、UI/文本/容器占用、失焦、死亡或会话变化阻止新动作；已开始动作只归还本次拥有的临时输入。较晚人工选择优先，不能被旧目标抢回。关闭不解除未知消耗保护。

各业务拥有自己的目标、等待与取消状态；共用的只是一次真实工具使用权。一次原版动画后归还选择并让出使用机会。快捷物品、药品恢复、加工及卖/扔/存按真实相交来源保护，不能因有一个工具在用而封锁所有背包行为。

## 自动捕捉

入口位于物品页，配置、自动、手持、关闭四按钮。自动提示“身上带着虫网就行”，手持提示“必须手持虫网”。自动只选主背包 0–49 的真实网；手持只使用当前合格网，不切换其它网。当前原版三网为普通虫网 1991、金虫网 3183、防熔岩虫网 4821；不按不存在的 catchTool 字段分级。先验证目标安全与真实挥网命中能力，再按原版使用周期、规模和稳定槽位选择；熔岩鱼饵不主动用普通网。

配置顺序为鱼饵、仙灵、金色、宝石、普通、松露虫、七彩草蛉、其他，默认全部开启；显示“X 个捕捉分类已关闭”。分类优先级为松露虫、草蛉、仙灵、金色、宝石、鱼饵、普通、其他。其他入口保留；当前正常可捕获观察没有独立剩余成员，不伪造 NPC。分类仅筛选主动目标，原版一次挥网可能顺带捕获关闭类别。仙灵状态不允许捕捉时不挥；神秘青蛙和雕像产物不作为能取得物品的主动目标，原版附带碰撞不改。

使用当前原版纹理帧与三阶段挥网几何，考虑方向、重力、坐骑和真实缩放；库存 24×28 不是捕捉范围。不用固定圆或额外扩大框触发空挥。目标由会话、NPC 对象、generation、槽和类型共同识别，每次动作复核。

两种模式遇到本客户端已加载的活动 Boss 暂停新切物与挥动，保留设置，玩家手动仍可使用。包括世界吞噬者等复合 Boss 实体，不依赖显示开关或固定距离，不把没有 Boss 的入侵一律算作 Boss。

只有自动模式可在普通钓鱼时借网。借用前记录同会话鱼竿对象/槽（允许 10–49）、有效本地鱼漂身份、原世界抛点及人工选择代次。原版归还鱼竿后，鱼漂仍在则不重抛；本次借网导致原漂消失且没有其它本机漂、意图仍有效时，至多一次正常鱼竿使用，使用借用前世界目标。提交前即消耗本次重抛资格；未知不重试。人工操作、换竿、死亡、会话改变、Boss、关闭或期限取消。公开窄借用状态给未来钓鱼协作者，当前真实消费者负责唯一重抛，不实现 G10 自动钓鱼。

## 草药收获与复种

物品页二态行，提示“携带再生法杖或再生之斧自动收获/种植”。只从主背包 0–49 选再生法杖 213、再生之斧 5295；当前合格工具优先，其次斧，再稳定低槽。

只主动处理花盆 78、种植盆 380 上七种草药 style 0–6，幼苗 82 不收；成熟 83、开花 84 按当前原版昼夜、天气、月相、深度和 remix 收获资格。底座 579、树木和普通地栽不进入主动范围。以真实工具矩形范围及 tileBoost + blockRange 判断；21×21 只是有界候选扫描。实际原版挥动、切割、动画和音效保留，不能承诺只有目标一格受影响。

正常收获沿再生工具 PlaceThing 链立即免费复种，不要求或消耗种子。只有真实收获作用域已确认原株消失、现为空位且底座仍合法时，才登记必要的种子后备。液体、底座暂态或多人非原子变化可能使即时复种失败，不能因为调用了 TryReplantingHerbs 就认定成功。

后备最多 48 条，原登记后 600 个游戏更新到期，不因瞄准刷新。缺种或暂不可达保留，有条件项轮转执行，新的收获不能无限饿死旧补种；同种幼苗或其它占用使该记录退休，不破坏现有植物。仅在实际需要时保护匹配种子来源，用正常种子使用和消耗，不直接改堆栈。未知消费停止重试并保留精确保护；关闭、死亡、换世界清理普通意图。

## 自动挖矿

杂项页为快捷键、自动、关闭；提示分别为“光标指到矿物上按快捷键选中挖矿区域”和“挖下第一个矿物开始接管”。专用动作只在新按下沿选择光标处支持矿脉，消费对应公共使用手势；有效重选替换，无效保留旧选区并说明。自动模式仅从玩家真实 PickTile 前后均可读且支持格实际消失/改变的首挖接管；本功能合成调用不递归，读失败不算挖掉，新的人工首挖立即重选。

始终使用当前真实 pick>0 工具，包括电钻与复合工具；不搜索最佳镐。槽、对象、类型改变取消，能力变化重新判定。保留 dx/dy 各不大于 3 的连接（含斜向和间隔），初始已空首格可从周边接入；离种子各轴最多 80 格、最多 512 成员，截断明确反馈。

材料为旧 33 项加当前四种静态尖刺，共 37：

`6,7,8,9,166,167,168,169,22,37,56,58,204,107,108,111,211,221,222,223,63,64,65,66,67,68,178,566,123,224,404,407,408,48,232,745,750`。

宝石 `63–68,178,566` 混组，普通承托石不加入；其它同类型连锁，四种尖刺各自同类。745 装饰尖刺也包含，不只按伤害集合筛选。

绿色表示本地只读判断当前工具在真实原版矩形范围内、能产生正进度且允许破坏；不要求一次破坏、不加额外圆，不等于服务器确认。红色表示当前不满足或未知。判定含 noBuilding、保护、镐力、魔矿/猩红矿深度等原版条件。覆盖颜色和执行共用含义，真正动手前重新读，不能通过试挖预测。Draw 只消费更新阶段准备的有限几何，按视口裁切并适配缩放/倒重力。

暂不可达保留等待；关闭、死亡、工具身份变化或离剩余选区包围盒各轴距离最大值超过 30 格取消。切换非关闭模式保留同一选区，没有两个并行矿脉。使用正常工具/PickTile 的累计进度、掉落、液体、重力与网络链，不整脉 KillTile。

泥沙 123、雪泥 224 消失后保留有界补位：135 游戏更新的有效观察期、原列及左右一列、向下 18 格、每轮最多 8 条。135 更新让最多 512 条证据至少轮转两次，避免大选区在首次落地前就耗尽复查机会；到期立即失去接纳资格，记录随有限轮转清退。真实首挖前保留原区观察，成功破坏后才接管；要求观测到消失/新落点变化，排除原先就存在且从未证实腾空的格。原选中格经可读观察确认腾空后可以重新接纳下落格；不宣称唯一原方块追踪。未知加载及活动泥土不当空气，有待补位时不抢先报完成。

## 验证与接受边界

本地验证使用隔离合成状态、当前原版程序集和正常 Host 入口，覆盖原版几何/工具、即时复种及后备、全部材料、因果首挖、红绿与输入/异常/多人消息路径；不能用自己实现的判定当唯一 oracle。工作量覆盖关闭、稳定、变化、满载及异常，实际入口自动选组。源码、独立审查、候选包、实际安装和所有者实测分别记录；不把本地通过等同真实多人、长期运行或 FPS 接受。
