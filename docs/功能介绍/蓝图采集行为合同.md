# 蓝图采集行为合同

## 适用范围与接受边界

本合同约束 [Issue #134](https://github.com/Kuroneko2020/JueMingR/issues/134)／[Draft PR #135](https://github.com/Kuroneko2020/JueMingR/pull/135) 的真实采集与蓝图库开发候选，原件为 `JMR_BLUEPRINT_CAPTURE_LIBRARY_20261023_v1`。第一步选区与凝胶条已由 #132／PR #133 接受合入 main；本批明确替代其保存／库禁用切片，不代表本批已获本人体验接受或合并。实际候选、验证、包、安装和限制回到任务记录，整体 #7 仍 INCOMPLETE／releaseEligible=false。

本批完成真实选区内容采集、固定草稿预览、确认保存及同安装蓝图库浏览／改名／两次删除／重启读取。同批世界图纸定位扩展见[投影合同](蓝图世界投影行为合同.md)；施工、旋转镜像替换、材料、instances、导入导出业务和 Z 旧数据迁移未授权。技术职责、格式与成本见[实现设计](../设计/蓝图采集实现设计.md)。

## F5 入口与准确文案

F5 → 蓝图复用标准功能行、提示、公共绑定编辑器与保存管道。表内文字按当前合同逐字呈现，不附加格数、状态行、未实现闪字或额外说明。

| 状态／行 | 标题 | 准确提示 | 主按钮与绑定 |
| --- | --- | --- | --- |
| 未采集 | 采集蓝图 | 点击开始键执行选区，反选取消选区。 | 开始；采集绑定入口 |
| 采集中 | 退出采集 | 退出选区，并清空已有选区 | 退出；同一个采集绑定入口 |
| 始终存在的下行 | 保存采集 | 点击保存键保存世界上已有的蓝图选区。 | 保存（有选区且可受理时可用）；独立保存绑定入口 |

开始不要求手持凝胶。成功进入采集后自动关闭 F5；按钮、采集快捷键和凝胶条都进入同一个开始／退出动作，标题变化不改变动作身份，也不新增单独退出键。

F5、保存绑定及凝胶条的保存统一进入“请求采集 → 固定草稿预览 → 确认保存”；重复请求不新建队列或重复资产。F5 的“蓝图库／打开”标准行提供独立公共绑定，默认未绑定；按钮、工具条和绑定的新按下共用打开出口，文本／IME／模态不触发。库可在未开启采集模式时打开，预览和库期间仍阻止世界攻击／挖放／交互，原版背包、F5 和文本输入保持正常。

主动采集／待存选区、草稿／保存及pending／Following／移动／移除／Committing期间禁手动开库，真实灰态原因由同一Host门给所有入口；拒绝不取消工作，Fixed被动投影允许开库。可靠保存后的内部转库仍可完成。F5保存是采集／重开草稿入口，禁用原因区分无选区、整理、保存、库不可用及保护；不能统一误报选区未完成。

## 凝胶快捷栏

标准开关名称为 **“手持凝胶显示快捷栏”**，没有 hint，默认关闭并沿现有偏好管道保存。该行提供独立的公共快捷键绑定入口，默认未绑定；按键与 F5 开关修改同一显示偏好，不改变采集模式、选区或世界动作门。开启且本机玩家实际手持凝胶时，在屏幕下方居中显示工具条；背包里存在凝胶、虚拟借入或自动切物均不构成手持条件。F5、聊天、地图或其他 UI 接管时隐藏工具条，保留已提交选区。

| 采集状态 | 仅显示的两个按钮 | 可用性与悬停提示 |
| --- | --- | --- |
| 未采集 | 采集蓝图／打开蓝图库 | 采集与打开库可用；采集提示为“点击开始键执行选区，反选取消选区。” |
| 采集中，集合空或非空 | 保存蓝图／退出采集 | 保存统一请求采集，无可用选区时不受理；提示“点击保存键保存世界上已有的蓝图选区。”；退出提示“退出选区，并清空已有选区” |

进入采集后前两个按钮被后两个替换，不同时摆放四个。悬停提醒使用暗金色 `#B8860B`、轻黑描边，仅绘制文字，没有独立矩形背景或边框；逐行以整条中心对齐，贴近条上沿，原版字体下可见描边间距约 2–4 UI 逻辑像素。复用现有字体度量、换行、裁切和 UIScale，不增加提示命中区域，也不改变公共 F5 提示。同批世界投影存在时，工具条追加移动／移除；移动／移除时各自原位取消，新取出另属取消摆放，详见[投影合同](蓝图世界投影行为合同.md)。

换成非凝胶或关闭显示开关只隐藏工具条，不退出模式、不清选区，世界动作门仍生效，原版与 R 的 UI 继续正常左右点击。F5 和采集绑定随时可请求明确退出。

## 世界格选择与呈现

在未被 UI 占用的可编辑世界区域新鲜按下左键，起点和终点采用世界格坐标，预览为包含两端的矩形。物理左键释放时只执行一次 XOR：矩形内原来已选的格取消，原来未选的格加入。单格按下释放有效，反方向拖动含义相同；拖动多帧只更新预览，取消草稿不改已有集合。右键只承担吞世界动作的义务，没有退出、清空、反选或菜单语义。

普通 Update／Draw 间隔和没有重新采样输入的外层 Update 不代表失焦或 UI 接管；已在拖动时继续保持草稿。每份 UI 判定仍绑定冻结的输入样本，未被原版 UI 认证的按下或释放不排队重放，释放最多提交一次。

矩形规范化后与当前世界有效范围相交。离屏、跨屏与相机移动不会截断已提交选区；完全位于世界外的矩形不产生边界格。世界有效范围是自然边界，没有 `16384` 或其他人为大小 cap。保存世界格坐标，不按屏幕像素保存端点，也不按选中格建立逐格对象。

当前鼠标格为蓝色；拖动预览和已提交选区也为蓝色，以不同 alpha 或描边区分。只枚举并绘制可见世界范围，稳态帧不扫描完整选区。世界坐标与 Game 渲染变换一致，支持跨屏移动、30%–1000% 视距及 UIScale、分辨率变化；UI 缩放不作为世界缩放使用。实际各视距／设备下的体验仍按任务证据和本人回报区分。

只读鼠标格显示沿用仍有效的焦点、会话和几何资格，不依赖本次外层 Update 是否重新获得动作采样许可。空 Update 或重复 Draw 不隐藏有效点，也不因此开始拖选、补出释放或再次提交 XOR；真实失焦、UI 接管及几何失效仍隐藏失效点。

## 世界动作与 UI 输入

采集是本机世界鼠标编辑状态。模式开启时，仅阻止新的工具使用、攻击、挖掘、放置、世界右键交互及向世界丢物等世界动作；原版背包、物品槽、菜单及 R 的 F5、凝胶条、绑定弹窗仍可正常左右点击。UI 的点击或拖物不启动世界拖拽、不提交矩形、不穿透使用物品。未知 UI 归属不能当成世界空白。

输入先冻结可信物理左右键、边沿和世界坐标，再在世界动作消费者前门控。不得删除全局 Mouse1／Mouse2、清空 UI 原始鼠标或禁用系统鼠标。Mouse1 改绑 Jump 仍可跳跃，WASD／Space 等非世界动作保持；独立键盘映射的 UseItem／UseTile 同样受世界动作语义门约束，普通药品 UI 和非手持快捷使用不被整方法误拦。模式只作用于本机玩家，远端 `Player.Update` 不重置也不驱动本机状态。

已经发生的动画和投射物不回滚；本步不引入攻击自动化，不改辅助瞄准。采集门与凝胶条是否显示无关，切换武器、隐藏条和关闭显示开关都不放行世界动作。

## 生命周期与独立释放

| 事件 | 模式及已提交集合 | 草稿及再次输入 |
| --- | --- | --- |
| 开始成功 | 开启模式，初始集合为空 | 启动点击不成为首拖；相关物理键先释放，再接纳新鲜按下 |
| 正常左键释放 | 保留模式，XOR 一次 | 本次拖拽结束，不重复提交 |
| 失焦、聊天、地图、UI 捕获、可信几何失效 | 保留同一世界模式与集合 | 只取消草稿；恢复后等待可信中性及新鲜按下，不续接按住状态 |
| 换成非凝胶、关闭显示偏好 | 保留模式和集合 | 只隐藏工具条；UI 接管才取消草稿 |
| 明确退出 | 退出模式，清空集合 | 清草稿；左右键各自等待真实物理释放才放行对应世界动作 |
| 本机死亡或 ghost | 保留同一世界模式与集合 | 取消草稿，复活后重新等待新鲜按下 |
| 离开当前世界／角色、断线或正式会话重置 | 清模式、集合和草稿 | 仅保留仍按住的世界动作释放屏障，防下一会话误触 |

左、右释放屏障独立：左键释放不放行仍按住的右键，反之亦然。失焦产生的伪 Released 不证明物理松手；恢复聚焦后的可信释放才可解除相应屏障。释放帧仍归旧动作，之后的新按下才恢复普通世界行为。屏障期间 UI 继续正常左右点击；释放观察不依赖本身的可编辑门，避免自锁。退出时仍按住的键盘 use 请求也要等真实中性，不随后重放开火。

会话清理依赖真实世界、角色、连接身份和 Runtime 生命周期，不因远端更新、短时没有有效 local player、UI 隐藏或死亡擅自清集合。模式、集合、拖拽及释放屏障均不持久化。

## 真实采集、空气与对象

已提交 XOR 集合冻结为一次采集，不把未选 holes 变成外接实心矩形。先证明格可读，再判空气；好友客机未收到 section 时明确提示局部尚未收到，保留选区，不当作空格、不请求全图。

前景、墙、四线、致动器和 amount>0 的液体都是内容。active 且 inActive 的块仍保留本体；无本体的残留 paint／frame／liquid-kind 不造内容。半砖、斜坡、漆、隐形／全亮涂层及适用方向／样式保留。纯空气不生成内容／擦除标记；全部为空时提示“选区内没有可保存的内容”，不建资产并保留选区。最终边界裁外围纯空，内部孔洞和分离内容的相对距离保留；这项边界默认值与空气 no-op 是不同决定。

选到可可靠确认的固定多格对象任一子格时，自动补整件 tile 外观，不扩大原选区、不补支撑物、不带框外墙／线／液体／致动器。原版子格合法随机帧、PaddingFix和实际形态按各自机制解释，保留每格原始外观。自然内容及无固定矩形元数据的可读内容按已选逐格快照保存，不无界遍历整树，也不把未来放置资格作为采集门。真正未收到、残缺或采集中变化的固定组逐组显示稳定身份、坐标及准确原因，可逐组排除或明确排除全部；排除只去该组 tile 层，保同格已确认其它层，不默存半件。用户列举的门／家具／植物是发现入口，不是产品类型支持名单；正常内容不能靠要求排除交付。

箱子／梳妆台、牌子／墓碑、展示物可保存可靠建筑外观；箱内物品、文字、箱名、展示物品／生物及运行实体负载不在本次范围。按世界投影任务原件的所有者语义裁决，新采集不生成这些范围外 Missing，旧合法 v1 资产与草稿也不显示历史 Missing，无需重采、迁移或重写。旧字段仍严格解码并核 root／metadata 一致性；未收到 section、固定组残缺、内容变化和真实坏文件仍准确提示。不读存档补负载，也不以“未支持”或黄色替代提示继续打扰正常建筑。

## 固定草稿与可靠保存

分批读取在游戏线程按数量和时间预算推进；UI 打开或 CanEdit=false 不饿死已受理采集。草稿引用固定独立内容，源世界改变、相机移动和确认保存都不重新读世界。记录起止 tick，不声称全区域同一瞬间事务快照；对象组封闭前重核，变化组转未确认。

草稿在独立“保存采集”页展示名称、真实尺寸／内容摘要、有限像素色块预览和顶栏保存／返回。名字默认“新蓝图”，允许在专页单击改名或保存后在图库双击改名。命名统一最多 48 个 Unicode 文字元素，拒空白名、首尾空白、换行／控制符、非法 surrogate，超过长度明确失败，不截断；既有文字元素资源边界同用于 UI、领域与编码。允许同名，由稳定 ID 区分，名称不成为路径。

保存按钮与名称Enter共用当前确认资格：合法且IME稳定的名称、DraftReady且非busy／protected、当前草稿／排除组合／尺寸／设备身份的图和同key非空过滤摘要、过滤摘要中剩余未排除不可靠对象数为零缺一不可。尺寸／filter／device变更后的旧结果不解禁。失焦释放预览与分页资源、回焦重建同组合后，逐项排除事实仍有效，不要求重新翻页。显示资格不随输入采样阶段闪变，开始动作仍核本轮输入许可；Enter仍先提交名字再保存一次，失败保原草稿和编辑buffer；最终文件创建仍权威拒绝不可靠对象或过滤后空内容，不能将入口分叉描述为已保存坏内容。保存页只保留返回，不显示取消按钮，不撤销已受理Create。

取消或关闭未确认草稿不写资产、不清选区；保存中不得把关闭 UI／换世界宣称成肯定取消。只有正文与 metadata 可靠提交确认后才显示成功、入库并定位新项。成功且仍是原 session／mode／selection revision 时清原选区、继续留采集模式；迟到成功只更新真实库，不清新会话／新选区。可继续的明确失败保留草稿和选区；旧操作已经安全退休时准确结束旧草稿、保留选区，故障解除后允许显式重新采集。提交未知继续保护原同 ID 和文件、禁止盲重试，不假成功；材料保护不长期占住活动采集槽，新的明确采集拥有独立操作身份。

## Z 式蓝图库

图库在 F5 蓝图内容区内呈现二级菜单，沿 R 外壳和 UIScale。页头为“蓝图库／共保存 N 个蓝图”，导入／上一页／下一页／返回依 Z 相同位置；每页 6 项、2 列先左后右、最多 3 行，卡片高 166、预览高 68。真实层色块预览让全部内容参与有限像素汇聚，属于摘要，不是原版贴图／灯光／动画渲染。

卡片单击选择、名称双击原位编辑；“保存”可靠提交后才改正式名称，失败保留原编辑 buffer／焦点。改名只修改该 ID metadata，不重写正文。删除第一击只变“确认”，同 ID 第二击才提交；可靠逻辑删除前不移卡，失败／未知保护。已确认逻辑删除后即使正文清理未完也不复活，重启不复现；清理未完成单独提示。返回、翻页、切项和失焦清危险确认，不能让第二击落到另一资产。

放置在同批扩展中启用为纯世界投影；导入、导出、材料仍保留 Z 同位置但明确 disabled，无假对话框／成功提示。图库加载、空库、读取错误和单项坏项隔离分别显示；未知未来版本、恢复材料和外部变更原字节保护，健康项可继续。库关闭且无在途时不扫目录；稳态绘制不读正文、不重建缩略图。

资产位于已验证游戏根 `JueMingRData/blueprints/templates/`，同安装跨角色／世界共享，名字不是路径。安装／更新／恢复默认保留全部蓝图及未知项，不用 DLL 回退覆盖用户内容，不创建 instances 或自动导入 Z 数据。

## 验证口径

原版普通好友房主／客机属于支持目标；静态与隔离检查只证明其实际覆盖的 section／会话／无网络写入／数据和输入接缝，不冒充真实联机。普通完整包、实际换装、本人正常启动、图形与 IME、物理输入、FPS／长期及体验接受分别记录。当前批次事实回 [#134](https://github.com/Kuroneko2020/JueMingR/issues/134) 与[交付记录](../计划/蓝图真实采集与蓝图库交付记录.md)，本人最短操作见[体验卡](../../scripts/phase0s/Blueprint-Owner-Test-Card.zh-CN.md)。
本批集中返修补充：自动默认名由后台全库metadata选择“新蓝图／新蓝图 2…”（跨页、重启有效），手动同名仍允许；保存时不静默改掉已显示的草稿名。失焦不等于取消受理采集；明确返回／取消才丢未提交草稿。排除组合的图片、尺寸、数量和缺失提示始终对应同一固定内容及排除key；全部排除成空明确提示并禁保存，恢复组合可复用配对缓存。

本轮保存前页改为独立“保存采集”工作区：默认名称可直接保存，单击右侧名称框可中文编辑，大预览保持等比和实际固定摘要，顶栏左标题与右保存／返回同排垂直居中，下方名称标签与右输入框共享底框；低高度沿原滚动访问全部排除组和错误。普通图库仍六卡／双击改名。保存页按Draft用途申请有限物理像素；文本、caret、滚动不重读正文。Saving只冻结当前呈现，不因关闭页面撤销受理写；可靠失败保草稿，未知提交保护并停重试。实例、多层永久消除及先选目标的移动／移除见[投影合同](蓝图世界投影行为合同.md)。
