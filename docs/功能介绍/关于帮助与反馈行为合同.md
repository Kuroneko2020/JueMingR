# 关于、帮助与反馈行为合同

本合同对应 [#95](https://github.com/Kuroneko2020/JueMingR/issues/95) 的获授权开发范围；实现、验证、安装和所有者接受分别由该任务记录。它不表示本批已获实机接受，也不授权下一功能。

## 使用与内容

F5 → 关于按所有者最新明确决定复刻 Z 关于页的整体双栏构图：顶部像素标题、左侧广告占位、右侧介绍／QQ反馈／赞助原图、底部致谢，以及原版色板、角饰、星点、虚线与小图标。不采用“快速上手”卡片。默认大小与默认缩放完整展示；窗口实际缩小时允许主滚动，不整体缩字。保留 R 外壳、字体、输入和资源所有权。左侧“使用帮助 / 版本信息”打开页内帮助，展示并可复制当前加载的完整构建和 Terraria 版本，再返回关于；不重置其它页面草稿。十二个分类不是所有功能均已交付的承诺。

复制群号只复制群号；复制版本只复制页面明确展示的运行版本文本，不包含角色、世界、路径、账号或日志。一次明确点击进行一次有限剪贴板写入，成功才显示“已复制”；失败原因可回看、可再点击，结果保留在原按钮及现有提示区域，不增普通状态行或改变几何。不自动打开 QQ、网站、支付软件、加入群、上传或提交问题。

帮助按实际装配能力说明导航、键位录入、物品整理/查询/定位/宣告/收藏/快捷物品/存钱、信息地图与记录、笔记与数据保留。正文及[玩家指南](玩家使用指南.md)对照现行功能合同；不提前承诺钓鱼、蓝图、补药等未交付能力。

## 首次提醒与保存

起步方案采用本机可靠角色跨世界一次。首次具备呈现条件时非模态提示“按 F5 打开决明R；使用帮助在‘关于’页”，约3秒可见阅读期再短暂淡出。它不打开窗口、抢输入、暂停世界或发送服务器聊天；失焦、加载和遮挡不消耗阅读期，退出世界取消临时显示。未实际呈现不登记已看；实际呈现、内存抑制和可靠保存分别判定。

复用当前 R 经校验的角色文件路径及本地/云域，独立于世界 GUID。路径不是永久角色 UUID：移位按新归属处理，同路径替换角色无法区分；不按显示名或运行 token 保存，不读取角色存档全文。SSC/身份未知仅提供会话级一次提示，不写匿名文件，不承诺跨启动记忆。可靠身份后来就绪时，只有同一角色连续性成立才合并本次呈现事实，不再次闪提示。

标记独立保存于当前 Terraria 安装的 `JueMingRData/behavior/onboarding/<角色摘要>.json`；不修改原版角色/世界文件，不导入 Legacy 标记。仅实际呈现回执触发后台可靠保存。缺失可创建；损坏、未知格式/版本、恢复材料或冲突保护原件。保存失败在当前会话仍抑制重复并给出一次必要错误，帮助始终可用；本进程不对失败角色自动重试，下一次正常启动再读取。缓存和退休 worker 有明确上限，不无限积累。

## 适用、来源与限制

关于、帮助、复制和提示为本地客户端能力，单人、主机本地玩家和普通多人客户端可使用，对方服务器无需安装 R。身份未知不禁用页面；专服无图形对象。本地隔离验证不代表所有玩法已联机实测。

所有者明确确认既有反馈联系方式有效并授权两张本地赞助原图迁入；原字节和源提交见[实现设计](../设计/关于帮助与反馈实现设计.md)。角色跨世界一次、页内再次帮助和反馈最小范围是本次 Prompt 的起步方案，不倒写成所有者此前逐项原话。不迁入 Legacy UI/记录/诊断框架。

安装和恢复保留全部用户数据、配置与恢复材料；安装器不生成“已看”标记，不要求删除真实标记测试。未实测的首次情形以隔离证据说明，已有标记时可直接查看再次帮助。真正图形/输入失败必须修复，环境未执行项及真实多人、物理设备、全部资源包和 FPS 的未知单列。
