## 首次提醒与保存

本机可靠角色跨世界一次。首次具备呈现条件时，从玩家头顶弹出黄色“按 F5 打开决明R”，复用原版重铸／拾取的 PopupText 队列和绘制，保留原版描边、上浮和缩放动画，没有底板或独立窗口。文案使用原版 Advanced 入口，不伪造物品或附带数量。头侧入队后按原版世界浮字移动与镜头投影，倒重力时从对应头侧弹出。

约3秒有效可见阅读后由原版淡出，收尾有界。失焦、地图、加载和已知遮挡时暂停，原版浮字关闭或队列满时等待；不挤走其它提示。屏外或已知 HUD／笔记遮挡不记已看。资格在 Update 检查，原版绘制后的 F5 图层再次核对回执；本帧后续 UI 新产生的遮挡可能覆盖已经提交的原版浮字，该帧不计有效阅读，不承诺事后撤销原版绘制。

提示不打开 F5、抢输入、暂停世界或发送服务器聊天，退出世界取消临时显示。未实际呈现不登记已看；实际呈现、内存抑制和可靠保存分别判定。

复用当前 R 经校验的角色文件路径及本地/云域，独立于世界 GUID。路径不是永久角色 UUID：移位按新归属处理，同路径替换角色无法区分；不按显示名或运行 token 保存，不读取角色存档全文。SSC/身份未知仅提供会话级一次提示，不写匿名文件，不承诺跨启动记忆。可靠身份后来就绪时，只有同一角色连续性成立才合并本次呈现事实，不再次闪提示。

标记独立保存于当前 Terraria 安装的 `JueMingRData/behavior/onboarding/<角色摘要>.json`；不修改原版角色/世界文件，不导入 Legacy 标记。仅实际呈现回执触发后台可靠保存。缺失可创建；损坏、未知格式/版本、恢复材料或冲突保护原件。保存失败在当前会话仍抑制重复并给出一次必要错误，不影响 F5 正常使用；本进程不对失败角色自动重试，下一次正常启动再读取。缓存和退休 worker 有明确上限，不无限积累。

## 适用、来源与限制

关于、复制和提示为本地客户端能力，单人、主机本地玩家和普通多人客户端可使用，对方服务器无需安装 R。身份未知不禁用页面；专服无图形对象。本地隔离验证不代表所有玩法已联机实测。

所有者明确确认既有反馈联系方式有效并授权两张本地赞助原图迁入；原字节和源提交见[实现设计](../设计/关于帮助与反馈实现设计.md)。角色跨世界一次来自本次 Prompt 的起步方案；删除帮助、QQ临时反馈和二维码边框是后续明确修订。不迁入 Legacy UI/记录/诊断框架。

安装和恢复保留全部用户数据、配置与恢复材料；安装器不生成“已看”标记，不要求删除真实标记测试。已有标记的角色不因样式修订再次提醒，未实测的首次情形以隔离证据说明。真正图形/输入失败必须修复，环境未执行项及真实多人、物理设备、全部资源包和 FPS 的未知单列。
