## 笔记与悬挂便签

详细静态查证及已接受的新版目标见[笔记功能行为合同](笔记功能行为合同.md)：需求已确认、功能尚未实现，首轮排除旧数据导入，后续另行决定。以下仍是 Legacy 静态摘要，不因新版目标获接受而变成 R 行为或旧版实机证明；冲突处按主合同的已确认决定与现行安全要求处理。以下纠正以该文的源码、实际测试断言及原件身份为依据，不将旧摘要重复记载当独立验证。全局快捷键不属于本轮笔记需求范围。

用于同一本地用户配置根的全局记事，不按角色/世界隔离。F5“笔记”页点击 `+` 新建，标题默认“新笔记”，不自动进入编辑；双击标题单行编辑，Enter 保存、Esc 取消；双击正文多行编辑，Enter 换行、Esc 取消。内容区空白命中、切页或主动关闭 F5 会尝试保存 dirty 草稿，普通保存失败留稿并阻止本次后续动作；任意窗口外点击不具备同一保证，强制隐藏也未处理保存失败返回值。删除在 F5 内二段确认，确认可能跨切页/关闭保留。

“悬挂”让便签在 F5 关闭后仍显示正文，不显示标题，不提供编辑/删除或用户调整大小。工具栏 hover 显示，拖动 handle 移动，箭头调背景透明程度，叉号只取消悬挂；再次悬挂会重建默认位置、尺寸和透明程度。旧说明的“透明度 100”对应存储“不透明度 0”，默认背景全透明，正文和工具文字仍可见；toolbar 未见实时数字读数。正文可滚动；命中便签时隔离游戏点击/热栏滚轮，便签范围外不全屏阻断，F5 编辑捕获另有边界。已检查的笔记入口/模型/路由未发现 Markdown、富文本编辑器、图片、附件、搜索、云同步或多人共享；原生文本剪贴板有版本相关证据，聊天标签绘制仍需区分纯文本存储与字面显示。

旧数据位于 Legacy 用户配置根的 `notes/`：`index.json` 存顺序、内部 noteId、标题、悬挂与位置等，`<noteId>.txt` 存 UTF-8 纯文本。标题不是唯一 key/文件名。正文读取错误会降为空内容、跨文件回滚仅尽力而为、缓存忽略刷新失败，不能概括为绝不假成功或丢失。原文同时保留 catalog `Implemented=false` 和已接入 UI 的描述；不能只看标志断言完全缺失或完全可用。本次专项只读查证，没有复测保存、迁移笔记或将其文件放入 R 数据根。

## 功能主开关热键

完整入口、源码反例与新版候选见[统一快捷键功能行为合同](统一快捷键功能行为合同.md)，本节只保留主开关摘要。该专项固定 Legacy 源码 `6ac6356c0c564f43284590c168855e96c50e13f7`；原功能文档与截图另有身份，不能由源码 SHA 代替。

F5 eligible 行最右双击 keyboard 打开小窗，单击开始录入；新主键形成组合后立即尝试保存，小窗保留结果。主开关首次默认未绑定；生产保存策略只允许键盘单主键或一个明确左右的修饰键加主键，不能用通用 `Ctrl` 代替 `LCtrl/RCtrl`。不带修饰的 Esc 取消、Backspace 清除；带修饰时会成为保留键拒绝。此限制不能套给快捷物品、采集、三格宣告或通用解析器。

该键只切主开关/主模式，不使用物品、不创建蓝图、不挖矿、不宣告。多模式要求合法的上次非关闭模式，否则拒绝；自动回血/回蓝有目录类型与应用不一致、可绑定却拒绝切换的静态反例。登记了 63 个目标不证明 63 项均可用。

保存只查内部完整同组合，不提供强制覆盖；不检测子集重叠或玩家当前原版键位。运行按组合满足沿、每 binding ID 各自记录，额外修饰键不排除匹配；不能概括为跨消费者一次手势只执行一次。文本、聊天、modal、录入、F5 可见等有 gate，但物理读键与早退使失焦恢复边界不能保证无补触发。关闭/切页也没有统一结束全部录入；保存失败可能已改内存，具体入口反馈不一致。

绑定存于 `unified-hotkeys.json`，旧 `hotkeys.json` 仍承载条目与模式历史；测试兼容桥不是生产自动导入。R 当前有[输入基础](../AI经验笔记/输入捕获与坐标域.md)和真实功能，但统一快捷键仍未实现；候选未获接受，不恢复已退休键位。后续数据设计查[配置设计](../设计/配置持久化与用户数据布局.md)。
