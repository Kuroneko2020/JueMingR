# Legacy 笔记与快捷键

**Legacy 行为参考，尚不代表 JueMingR 已实现或已接受全部合同。** 来源：旧功能根 `F5通用/笔记页.md`、`功能主开关快捷键.md`；[来源与覆盖限制](功能索引.md#来源覆盖和限制)。

## 笔记与悬挂便签

用于全局记事，不按玩家/世界隔离。F5“笔记”页点击 `+` 新建，标题默认“新笔记”；双击标题单行编辑，Enter 保存、Esc 取消；双击正文多行编辑，Enter 换行、Esc 取消。点击卡片外、切页或关闭 F5 先保存 dirty 草稿，保存失败保留编辑态且不继续后续按钮动作。删除在 F5 内二段确认，不是假删。

“悬挂”让便签在 F5 关闭后仍显示正文，悬挂窗口不提供编辑/删除。工具栏 hover 显示，拖动 handle 移动，箭头调背景透明度，叉号只取消悬挂。旧界面“透明度 100”对应存储“不透明度 0”，两种口径方向相反，不应误写成文字一起消失。正文可滚动；命中便签时隔离游戏点击/热栏滚轮，范围外不全屏阻断。没有 Markdown、富文本、图片、附件、搜索、云同步或多人共享。

旧数据位于 Legacy 用户配置根的 `notes/`：`index.json` 存顺序、内部 noteId、标题、悬挂与位置等，`<noteId>.txt` 存 UTF-8 纯文本。标题不是唯一 key/文件名。原文同时保留 catalog `Implemented=false` 和已接入 UI 的描述；不能只看标志断言完全缺失或完全可用。本轮不复测保存、不迁移笔记，也不将其文件放入 R 数据根。

## 功能主开关热键

F5 eligible 行最右双击 keyboard 图标打开配置；默认都未绑定。只支持单主键或一个修饰键加一个主键；Esc 取消、Backspace 在录入态清空，鼠标键、多修饰键不属于此入口。保存前检查冲突，不提供强制覆盖。按住一次只触发一次，松开才能再触发；文本输入、聊天、modal、录入或失焦时阻挡。

该键只切主开关/主模式，不使用物品、不创建蓝图、不挖矿、不宣告。多模式功能回到上次非关闭模式；没有已记录模式时不猜默认。快捷物品、蓝图动作、挖矿采集键与三格宣告有各自入口和允许按键，不能相互套用。旧绑定保存在 `unified-hotkeys.json`，不把旧 `hotkeys.json` 兼容桥或字段名升级成 R schema。
