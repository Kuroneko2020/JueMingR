# Legacy 更多信息

**Legacy 行为参考，尚不代表 JueMingR 已实现或已接受全部合同。** 来源：旧功能根 `更多信息页/` 的 19 篇同名功能说明；[来源口径](功能索引.md#来源覆盖和限制)。入口为 Legacy F5“更多信息”，用于只读显示，不能把显示开关当动作开关。本批三摘要、共享位置及新增群系样式的[新版首轮目标](世界感染幸运值渔夫任务与信息窗位置行为合同.md#10-新版首轮已确认目标)已获所有者确认，旧表的字号、资格及缺陷不因此改写为新版要求或已实现事实。

文字、信息窗与调整框下沉至原版主要 UI 之前是旧 .6 层级目标；当前实际锚点及fallback不证明 .8 全组合已验证，视觉在下也不保证调整时输入在下。样式可调不授权绕过输入隔离或每帧扫描。默认值和精确探测条件依对应完整提取，不为其余项编造统一“全开/全关”。开过容器记录是候选，不证明当前位置仍有箱子。

三项显名的本轮源码核对补充：标签本身不注册交互、不改NPC，但仅开任一显名也会进入共享Draw里的旧箱子键导入/开箱坐标记录与保存；本页“只读显示”不能推广成整条调用链无写操作。旧`.6`层级记录与当前fallback的限制、保存失败后新内存值仍生效等，见[完整合同的绘制与副作用](敌怪动物与NPC显名功能行为合同.md#5-世界绘制生命周期多人和成本)。R不因此获得箱子迁移授权。

本批高亮也经过上述共享 Draw 副作用，甚至尚无探测能力时也可能进入箱子记录；目标扫描本身不改 tile、照明、地图或实体。旧说明的“身上有金属探测器”须按真实原版探测状态理解，可含合成饰品/符合条件的队友共享；“目标消失不残留”只证明旧矩形内完全没有同类型active格时不画，不能保证残片/粘连多格对象正确。详见[查询与失效](附近目标探测与高亮功能行为合同.md#4-查询范围完整对象与失效)及[多人和副作用边界](附近目标探测与高亮功能行为合同.md#5-多人只读与性能边界)，静态调查不代表 R 已实现。

证据差异：旧 `Terraria原版参考笔记/Chest_Container_notes.md` 的普通宝箱能力分类比后来宝箱显名覆盖更窄；[完整调查](宝箱牌子与墓碑显示功能行为合同.md)已对照真实代码，确认梳妆台/fake显名与世界Chest、银行、展示类分别处理。旧共享Draw在分派前导入/登记箱子，“本项标签不写世界”不等于全链无文件副作用；静态成本与FPS归因分开。新版首轮选择见[已确认合同](宝箱牌子与墓碑显示功能行为合同.md#7-已确认的新版首轮合同)，不回改本表旧事实或声称已实现。

本批三项与位置的旧配置在Documents下JueMing-Z全局appsettings中；显示状态窗不经过世界标签的箱子导入/记录路径。树妖实际依赖当前活动NPC，巫师/渔夫优先读各自原版saved标记，普通客机历史可读性有限；详见[资格表](世界感染幸运值渔夫任务与信息窗位置行为合同.md#3-三个-npc-前提原版标记与当前存在不同)。首次提示另属玩家登记。R现有配置与笔记、绑定等存储查[配置设计](../设计/配置持久化与用户数据布局.md)，本批未实现，不创建旧数据副本或导入。
