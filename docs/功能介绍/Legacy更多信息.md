# Legacy 更多信息

**Legacy 行为参考，尚不代表 JueMingR 已实现或已接受全部合同。** 来源：旧功能根 `更多信息页/` 的 19 篇同名功能说明；[来源口径](功能索引.md#来源覆盖和限制)。入口为 Legacy F5“更多信息”，用于只读显示，不能把显示开关当动作开关。

| 能力 | 用途、操作与重要边界 |
| --- | --- |
| 群系显示 | 信息窗显示当前玩家群系，移动后更新；R 的实际版本另见[当前说明](当前群系显示与F5配置.md) |
| 世界感染、幸运值、渔夫任务 | 显示可读上下文摘要；条件不足时不可用或空闲。感染不全世界扫 tile，幸运值不自称完整官方计算器，渔夫显示不改任务或改名 |
| 完整鱼获、过滤鱼获 | 抛竿后显示当前环境可能鱼获及过滤后保留候选；环境/钓具变化刷新。两者都不收杆、切杆或重抛，真实过滤另属[钓鱼](Legacy钓鱼.md) |
| NPC 显名 | “名字／类型／关闭”；实际候选为城镇标记或骷髅商人，不是所有友好引擎NPC。名字可取个人名，类型走类型名；旧UI与旧快捷键的再次开启记忆存在分叉，详见[完整提取](敌怪动物与NPC显名功能行为合同.md#2-三条真实调用链与用户操作) |
| 动物显名 | 依据Critter/可捕捉等实际条件，只显示名称，不自动捕捉或对话；金色动物固定金色，字号仍属本项；与NPC候选可能重叠，按实际分支顺序只取一份，见[分类](敌怪动物与NPC显名功能行为合同.md#3-对象文字与生命值) |
| 敌怪显名 | 名称与当前/最大血量两行，随同一开关，没有独立血量开关；按分组/角色选代表与生命来源，不加总全体段，不保证任意Boss都只在头部显示。当前源码默认名称0.70、血量0.57，旧说明0.80/0.67是不同口径，见[样式与操作](敌怪动物与NPC显名功能行为合同.md#4-样式配置面板与保存) |
| 宝箱显名 | 始终、开过、关闭等模式，自定义名优先；较晚文档明确普通/第二套及 fake chest 的默认名，梳妆台另用 dresser 名称。被挖掉或不再是容器 origin 不显示旧缓存名 |
| 牌子显示、墓碑显示 | 附近文字直接显示，行数/样式按配置，墓碑另有全部、前几行、前若干字等模式；不打开编辑、改字或删除，物体移除/类别改变不显示旧字 |
| 显示生命水晶、显示生命果 | 原版探测能力有效时，为屏幕附近 active/type 匹配的世界方块画矩形/角标；默认关闭，粉色/黄绿色。完整移除后复核隐藏；旧版没有本批调色窗，残片/相邻件与完整物体不同，见[完整提取](附近目标探测与高亮功能行为合同.md) |
| 显示魔力水晶、显示碎岩龟 | 同一 tile 路径分别识别639及睡眠形态751；不查掉落 Item 或召出的碎岩龟 projectile，浅蓝/固定橙黄色。实际身份及同批候选见[五项身份](附近目标探测与高亮功能行为合同.md#2-五项身份与来源) |
| 显示龙蛋 | 旧入口存在，但消费者只查不存在于当前 .8 的 TileID.DragonEgg；有开关不等于可显示。新版已由所有者明确选择 PalworldChilletEgg=752 巨型龙蛋，这是补齐旧失效映射；五项三箭头/独立调色的新合同见[第7节](附近目标探测与高亮功能行为合同.md#7-已接受的五项新版合同)，不倒改本表旧行为 |
| 调整信息窗位置 | 进入调整状态拖动并保存信息窗布局，只改 UI；不等于 R 已支持信息窗拖动 |
| 首次进入世界提示 | 按持久玩家身份一次登记，同一玩家跨世界不重复；暂时解析失败不误记成功。旧 service seam 不证明被 store 吞掉的真实磁盘失败可观察 |

文字、信息窗与调整框位于原版主要 UI 下，重叠时物品栏、容器、装备、小地图、生命/魔力等优先。样式可调不授权绕过输入隔离或每帧扫描。默认值和精确探测条件只保留原文已明确部分，不为其余项编造统一“全开/全关”。开过容器记录是候选，不证明当前位置仍有箱子。

三项显名的本轮源码核对补充：标签本身不注册交互、不改NPC，但仅开任一显名也会进入共享Draw里的旧箱子键导入/开箱坐标记录与保存；本页“只读显示”不能推广成整条调用链无写操作。旧`.6`层级记录与当前fallback的限制、保存失败后新内存值仍生效等，见[完整合同的绘制与副作用](敌怪动物与NPC显名功能行为合同.md#5-世界绘制生命周期多人和成本)。R不因此获得箱子迁移授权。

本批高亮也经过上述共享 Draw 副作用，甚至尚无探测能力时也可能进入箱子记录；目标扫描本身不改 tile、照明、地图或实体。旧说明的“身上有金属探测器”须按真实原版探测状态理解，可含合成饰品/符合条件的队友共享；“目标消失不残留”只证明旧矩形内完全没有同类型active格时不画，不能保证残片/粘连多格对象正确。详见[查询与失效](附近目标探测与高亮功能行为合同.md#4-查询范围完整对象与失效)及[多人和副作用边界](附近目标探测与高亮功能行为合同.md#5-多人只读与性能边界)，静态调查不代表 R 已实现。

证据差异：旧 `Terraria原版参考笔记/Chest_Container_notes.md` 的普通宝箱能力分类比后来宝箱显名覆盖更窄；显示梳妆台/fake chest 与世界 Chest、银行、展示类的语义要分别核对，不能据旧笔记一刀切新版范围。详见[箱子机制](../AI经验笔记/物品箱子与多人权威.md)。

开关/样式/位置属 Legacy 配置，首次提示属玩家登记；确切文件与旧导入需在对应功能任务核对。当前 R 只实施两份配置，查[配置设计](../设计/配置持久化与用户数据布局.md)，不创建更多信息旧数据副本。
