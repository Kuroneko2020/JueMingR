# Legacy 更多信息

**Legacy 行为参考，尚不代表 JueMingR 已实现或已接受全部合同。** 来源：旧功能根 `更多信息页/` 的 19 篇同名功能说明；[来源口径](功能索引.md#来源覆盖和限制)。入口为 Legacy F5“更多信息”，用于只读显示，不能把显示开关当动作开关。

| 能力 | 用途、操作与重要边界 |
| --- | --- |
| 群系显示 | 信息窗显示当前玩家群系，移动后更新；R 的实际版本另见[当前说明](当前群系显示与F5配置.md) |
| 世界感染、幸运值、渔夫任务 | 显示可读上下文摘要；条件不足时不可用或空闲。感染不全世界扫 tile，幸运值不自称完整官方计算器，渔夫显示不改任务或改名 |
| 完整鱼获、过滤鱼获 | 抛竿后显示当前环境可能鱼获及过滤后保留候选；环境/钓具变化刷新。两者都不收杆、切杆或重抛，真实过滤另属[钓鱼](Legacy钓鱼.md) |
| NPC 显名、动物显名 | 前者含城镇 NPC 与骷髅商人；后者只是动物名称，不自动捕捉，也不打开 NPC 对话 |
| 敌怪显名 | 名称与当前/最大血量两行，血量随该开关，没有独立血量开关；多段 Boss 不将全部段血量相加，不承诺所有 modded NPC |
| 宝箱显名 | 始终、开过、关闭等模式，自定义名优先；较晚文档明确普通/第二套及 fake chest 的默认名，梳妆台另用 dresser 名称。被挖掉或不再是容器 origin 不显示旧缓存名 |
| 牌子显示、墓碑显示 | 附近文字直接显示，行数/样式按配置，墓碑另有全部、前几行、前若干字等模式；不打开编辑、改字或删除，物体移除/类别改变不显示旧字 |
| 显示生命水晶、生命果、魔力水晶、碎岩龟、龙蛋 | 满足各自探测条件时高亮目标；不是拾取、破坏或自动采集，目标消失后不留旧高亮。原文条件不足的部分须在对应任务查证，不能假设无条件透视 |
| 调整信息窗位置 | 进入调整状态拖动并保存信息窗布局，只改 UI；不等于 R 已支持信息窗拖动 |
| 首次进入世界提示 | 按持久玩家身份一次登记，同一玩家跨世界不重复；暂时解析失败不误记成功。旧 service seam 不证明被 store 吞掉的真实磁盘失败可观察 |

文字、信息窗与调整框位于原版主要 UI 下，重叠时物品栏、容器、装备、小地图、生命/魔力等优先。样式可调不授权绕过输入隔离或每帧扫描。默认值和精确探测条件只保留原文已明确部分，不为其余项编造统一“全开/全关”。开过容器记录是候选，不证明当前位置仍有箱子。

证据差异：旧 `Terraria原版参考笔记/Chest_Container_notes.md` 的普通宝箱能力分类比后来宝箱显名覆盖更窄；显示梳妆台/fake chest 与世界 Chest、银行、展示类的语义要分别核对，不能据旧笔记一刀切新版范围。详见[箱子机制](../AI经验笔记/物品箱子与多人权威.md)。

开关/样式/位置属 Legacy 配置，首次提示属玩家登记；确切文件与旧导入需在对应功能任务核对。当前 R 只实施两份配置，查[配置设计](../设计/配置持久化与用户数据布局.md)，不创建更多信息旧数据副本。
