# 信息摘要与共享信息窗实现设计

本设计对应 [实施 #71](https://github.com/Kuroneko2020/JueMingR/issues/71) / [PR #72](https://github.com/Kuroneko2020/JueMingR/pull/72)。行为依据是已接受的[主合同第十节](../功能介绍/世界感染幸运值渔夫任务与信息窗位置行为合同.md#10-新版首轮已确认目标)，实现与简单实测接受边界见[第十二节](../功能介绍/世界感染幸运值渔夫任务与信息窗位置行为合同.md#12-r-已接受实现与验证边界)。这是本批有限实施设计，执行和验证结果查 Issue/PR；不把设计或旧 V0 静态证据写成运行通过。

## 所有权与接入

现有六项目依赖不变，不增加第三方依赖。Platform 的 Information 类型只表示四项身份、资格和一次已完成更新的标量事实，不引用游戏。Features 分别拥有感染、幸运、渔夫的内容解释和版本；共享的只有简短文本发布机械能力。Host 在原版完成更新后读取一次需求限定的事实，分别交给三个内容 owner。群系继续使用原 BiomeDisplayFeature/Runtime 已发布模型，不重读 Zone；所有者体验后明确将其范围扩展到单人和普通多人本地客户端（netMode 0/1），服务器模式、菜单与无效本地玩家仍拒绝。

`HostInformation` 只组合三个内容 owner、两个偏好文档与生命周期；原生就绪、原生取数、HUD、调整和 F5 控制各有窄文件。组合根只安装和分派，不承载业务。原群系固定绘制消费者退休，同一 Map / Minimap 前 UI 图层只绘制准备好的四块，顺序为群系、感染、幸运、渔夫。某一项失败只发布本项不可用，不禁用其它功能。

## 资格与原版就绪

资格与数据就绪是两个输入。感染需要活动 Dryad 20；幸运为可靠 savedWizard true 或活动 Wizard 108；任务为可靠 savedAngler true 或活动 Angler 369。每次有需求时只遍历一次所需 NPC 表，按已满足条件提前结束，不依赖显名开关。单人可靠 false 且未见活动 NPC 可判条件不足；普通客机 saved false 只能判历史未知。所有来源都只读，不持久化世界事实。

`InformationReadiness` 的原生代次早于显示 Session 建立。原版 clearWorld 开始与客户端 Connection 对象变化使上一代就绪失效；事件开始捕获代次/连接，成功结束时仍匹配才公布，避免旧回调串世界。显示关闭时保留当前代次和极少就绪布尔，首次显示 Session 不再清除同一代已收到的正常数据。

感染仅由本代成功消息 57 或原版 CountTiles(0) 的正常统计公布标记就绪；加载本身只累积计数，不是公布。有效三项全零合法，不读 total*2 替代，不触发 CountTiles/全图扫描。消息 74 正常应用才证明客机任务下标/今日状态已同步；方法被调用、消息编号匹配或未执行原方法均不足。Hook 必须验证实际成功分支，安装失败保守保持未知并限于摘要故障。

固定 T8 的消息观察位于最后一个相关字段成功写入后，同时核对声明长度、接收缓冲身份、连接和开始代次；其它 prefix 跳过、提前返回、读取抛错均不认证就绪。CountTiles(0)、LoadWorldFlags 和 AnglerQuestSwap 观察只接受原方法正常执行；本地任务加载限定 netMode 0、格式版本至少 101，并核对恢复世界与实际进入世界身份。NPC 表缺失或不完整不能证明 NPC 不存在，已有可靠正面事实仍可独立满足资格。

本地任务加载记录有效 LoadWorldFlags 的任务字段恢复，再与正常活动世界入口合并；旧格式、失败加载保留未知。原版 AnglerQuestSwap 的权威成功周期可恢复就绪，同鱼再次出现也更新今日状态。角色累计次数独立读取。原版正常消息/加载已写入的字段是唯一来源，不发请求、不读玩家文件、不记录姓名历史。

幸运在完成原版更新的同一游戏线程边界读取 localPlayer.luck 和十一来源；拒绝 NaN/Infinity。纯解释按固定 T8 公式处理有效性、未舍入总和及可见舍入，最后才省略低于 0.0005 的项。使用 0.0005 显示量级并容纳 float 累计误差的明确容差，不制造第十二个差额来源。瓢虫以游戏时钟标注剩余，火把/钱币原值和药水/风筝等级变化独立参与可见内容键。不得调用幸运更新/随机/环境重扫函数。

任务名称/地点依赖合法 item type、当前 Language.ActiveCulture 和已完成的资源重载代次。使用 `ItemName.<内部名>` 与 `AnglerQuestText.Quest_<内部名>` 的 UnformattedValue；只接受末行完整位置标注，允许有界空白、成对半角/全角括号与冒号，以及精确当前鱼名加逗号后的“捕获位置”。不抓故事括号或其它鱼名。名称与地点组成第一逻辑行，累计和今日状态为第二行；正常 0.82 同排，空间不足沿现有度量折行。

读取 `LocalizedText.UnformattedValue`，避免故事变量展开额外查 NPC 名字。当前版本全部 41 种任务按独立原版资源期待逐项核对英文和简中地点。实际启用汉化的天使鱼末行是 `(天使鱼，捕获位置：太空，纯净地形)`，旧两个固定前缀不能解析；原版同键为天湖/Sky Lakes。当前磁盘反例已确认，未取得截图当刻内存文本，不能断言它是唯一运行期原因。任意语言或替换格式仍无保证。

T8 的 LanguageManager.OnLanguageChanged 在 ReloadLanguage 完成原生、资源包与复制文本后发出；同语言 UseSources/HotReload 也经过它。reader 在 Host 构造完成时订阅、OnExit 解绑，回调只推进代次；下一次真实需求才取当前两条原文。同代次稳定时不取文，重载后原文和名字未变不解析。缺键、未就绪、未知格式、读取异常与成功使用不同内部状态；一次异常仅有一次后续需求重试，持续失败等待真实资源或任务/语言变化，无定时器或逐帧失败重试。累计/今日变化不重新取地点，资源回调不清 HUD 或读故事。

## 偏好、样式与公共入口

`config/features/information-display.json` 保存三项新增开关和四项各自 RGB/字号，不复制 biome-display.json 的群系开关。`config/information-window.json` 通过现有 UiPreferenceCodec/WindowPosition 表达独立 HUD 期望位置；它与 F5 的 ui.json 完全分离。两份各自使用 PreferenceDocument 和 AtomicFileDocument，未改变偏好不创建文件；未知字段/版本、读失败、外部冲突按现有保护机制拒绝覆盖。

四字号首次均为整数百分之一 82，合法范围 50–180；步进加减 10 后夹边，82 本身合法。默认颜色依次 90EE90、DDA0DD、FAFAD2、E0FFFF。恢复只改当前项颜色/字号，不改开关/位置/绑定。公共 StyleTarget 增加四项身份；Same 必须纳入此身份。继续使用 StyleEditor 的 HSL 预览、真实释放/完整 HEX 提交、退休及同值短路。

F5 信息页只接已有目标行；群系补配置按钮，三摘要接配置/开启/关闭/键，位置接开始/键。感染正文仅写“世界感染”，原帮助说明“显示原版最近公布的统计，感染变化后不会立即刷新。”群系 adapter、页面命令与绘制可用性、原稳定快捷键统一允许有效本地客户端 0/1；热键使用公共 Gameplay。共享 Session 沿本地玩家、世界、mode、连接 socket 变化先清旧模型后立即观察，不增第二条采集或服务器组件。鱼获样板不激活。统一热键冻结前登记三开关和位置一次动作，保留原群系 ID 和所有原动作。热键只调用业务命令，原有可靠保存后绑定生效合同不变。

## HUD 准备、投影与调整

HUD 为四个独立布局缓存，键为块内容版本、该块字号、实际字体身份和有效最大宽度。内容用实际字形度量折行，正常视口保留说明；极端视口/字号有有限行数和省略保护，优先主信息。颜色只改 Draw 颜色；锚点只改变投影。宽度/字体变重排必要块，单块变高仅改变后续块偏移，不重测它们。

字形准备与 Draw 都在块级隔离失败；同一失败字体不因计时或文字变化反复尝试，真实字体替换后可重新准备。Host 准备入口另有信息呈现模块边界，意外资源/几何异常只停本会话信息呈现并取消调整，不得外逸到共享 Runtime 的自动化等故障门；新 Session 可重新准备。临时空目标失败也不冒充群系业务失败。对应 `NativeInformationFailureChecks` 注入实际度量与准备入口，检查相邻功能状态保留和有限尝试。

原始默认期望为 UI 坐标左侧约 20、视口高度 45%。期望锚点与按当前内容/视口夹紧的有效锚点分开；临时小窗口不写回位置。Draw/可见区域/命中使用同一冻结 UI 矩阵的坐标，不减相机、不受重力/游戏缩放影响、不再除 F5 自身缩放。正常展示无捕获，不逐行新建纹理或 Begin/End。

调整有 Waiting、Dragging 与 Idle 状态，保存进入前期望、独立草稿和最后有效前台样本。开始需偏好就绪、上下文许可及现有 F5/Notes 安全离开实际成功；失败保留原 UI。重复开始幂等。只有真正安全离开完成的回执允许进入，不以隐藏布尔猜成功。记录原 F5 是否可见，保留其页签/滚动；正常完成或显式取消按许可返回。

等待进入物理输入全部释放后，下一次真正左键命中 HUD 才抓取；普通等待不全屏阻断。原生 UI/Notes/已有捕获优先使用现有实际 owner 事实，不猜遮挡矩形；拖动持有已取得的归属并消费尾缘。全关时只准备临时可拖目标，不采业务或开功能。

`InformationPointerObservation` 配对观察实际原版 UI pass 开始/完成；新抓取要求前一已完成 pass 的位置、几何、玩家/世界和更新代次与当前样本匹配，缺回执时保守不抓、不补放点击。原版真实占用可取消手势。释放前先核对字体/视口/UI 矩阵，不能等下一次 Prepare 才发现旧几何。Notes 安全离开只接受对应导航成功回执，另一次操作通过既有导航 epoch 取消待离开；已提交保存仍可完成。进入事件已经真实释放时直接记中立，不再额外丢掉下一次按下。

有效真实释放且确有位移才提交；同值/原地释放不把临时夹紧位置写回期望。Esc、右键、F5、失焦、许可丢失、地图/特殊 UI、几何改变取消草稿。失焦期间不重开 F5，不把合成释放当完成。世界正常退出/正常宿主关闭只消费已缓存的有效前台且确有位移草稿；显式取消/失焦使其不可提交，Dispose 不重读鼠标。提交后立即更新内存，后台 bounded 保存；失败保留新意图并准确提示，旧 revision 回执不覆盖新意图。

## 工作量与失效责任

| 工作 | 频率 / 输入规模 | 失效与关闭行为 |
| --- | --- | --- |
| 原生就绪 | 正常加载、统计、消息事件；几个标记 | 关显示仍接收；连接/clearWorld 作废，无扫描/文本 |
| NPC 资格 | 启用摘要的完成更新；最多一次原 NPC 表 | 只查询所需种类，已满足即停；三项全关零查询 |
| 标量采样 | 启用且资格允许的完成更新；固定字段数 | 每次取得新鲜事实，关闭不读本项业务 |
| 幸运解释 | 当前可见表示依赖的量化键改变 | 原始小变化尚不影响表示复用；来源/说明变化不可漏 |
| 任务本地化 | 合法任务类型/语言/资源完成代次改变；异常至多一次后续需求重试 | 同内容不解析；今日与累计不取文；关闭零读取 |
| 文本发布 | 各块可见数据或状态改变 | 不在缓存命中前重建长字符串签名 |
| 字形度量/布局 | 该块内容/字号/字体/宽度改变 | 颜色/位置不重测，四块全关且未调整零布局 |
| 投影/绘制 | 可见 HUD 帧，至多四块及有限行 | 使用准备模型，无世界读取、输入更新、保存 |
| 提交 | 用户有效改变偏好 | 同值零 revision，拖动无逐帧快照，异步有界合并 |

必要计数只在真实昂贵点，Debug 编译隔离；不增加性能 manifest、常驻探针或逐帧日志。自动检查沿 core/shared-host/style-host/storage-host 和正规 build/开发包，新增路径路由不能落未知或跳过。计数是实际工作量证据，不等于 FPS。

## 施工与验证

1. 先写会失败的真实默认/样式消费者与纯解释反例，再实现类型/偏好及四块 HUD，接群系配置和退休旧 Draw。
2. 逐项接原生读取/就绪与 Features 发布；真实 T8 Host 验证消息成功/早返/跳过/异常、事件先于 Session、关显示到达及换代；隔离数据，不运行游戏循环或触发网络/世界重算。
3. 接位置状态、Notes 安全离开回执、公共一次动作和尾缘；测试等待/原地/位移/取消/失焦/几何/退出与实际配置命令。
4. 真实 Host 连续更新/呈现验证关闭、稳定复用、局部说明变化、同鱼周期、颜色/位置/字体失效；隔离真实文件验证默认、重启、延迟/失败/未知格式及最新意图。有限错误注入的断言必须能抓到无条件重建。
5. 正规 Debug/Release/架构/工作量和相关现有输入/样式/存储回归；环境可用时用实际 XNB 查看少量默认 0.82/全信息/长说明/配置/空调整/小视口/材质代表预览。设备创建前环境不可用单独记录，实际错误不延期。
6. 一次独立完整增量审查，明确问题窄修窄复核。固定干净被审提交沿既有新 InformationSummary 完整 profile 顺序构建 A/B、核对声明产物与包，复用原安装/恢复工具安全换装。包保留全部原功能，无用户数据/原版引用/Debug 观测。

实际维护入口为 `InformationTests`、`InformationFixtureTests`、`NativeInformationChecks`、`NativeInformationLocalizationChecks`、`NativeInformationBiomeChecks`、`NativeInformationConfigurationChecks`、`NativeInformationInputChecks`，以及原有公共样式、偏好并发和安装恢复检查。`scripts/build.ps1` / 开发包自动执行相应工作量组；`scripts/test-phase0s.ps1` 执行完整行为/安装恢复组。图形设备创建前无可用适配器时，只延期明确图形项，非图形结果不能写成完整图形 suite PASS。当前执行、审查、包和安装身份统一记录于 #71/#72。

## 恢复与交付边界

原生 Hook 安装验证失败只让摘要保守不可用，不影响原加载功能。偏好失败保护旧文件，已提交的新内存意图不被旧完成倒写。安装先验证锁定 EXE、现有八载荷/回执及精确恢复归属、游戏/服务器退出，再通过旧包恢复和新包安装；不直接覆盖未知安装，不改 EXE/JueMingRData。旧包、回执、分支、证据都保留。

本批实现及后续定向修订已获所有者简单实测后的正式接受；保留已测试安装，纯文档收口不重建、打包、重装或启动游戏，安装来源与主线合并身份分别记录。自动 Host、模拟事件与普通客机真实游戏内验收分开；群系与三摘要均面向有效本地客户端 0/1，简单实测不证明全部多人拓扑、Windows/IME、材质/字体/视口或 FPS 已验证。实际合并与任务收口查 #71/#72，不构成发布或下一功能授权。
