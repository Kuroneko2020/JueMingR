## 本批能力与职责

- 敌怪名称与当前/最大生命两行共用开关；动物仅名称且金色例外；NPC 为名字、类型、关闭。首次三项关闭，NPC 最后非关闭模式默认名字。明确选名字/类型更新记忆，关闭不覆盖记忆；公共快捷键调用同一 Toggle 命令。
- Features 持有不可变 `EntityLabelSettings`、三项资格/输出规则及有界敌怪归组；Platform 只提供本批的只读事实与观察端口。Host 读 Terraria，组合唯一 Runtime、文件存储和 UI，不把业务放进 Runtime 或通用 Manager。
- 三项样式独立：敌怪 `CD5C5C`、动物 `5DADEC`（金色 `FFD700`）、NPC `90EE90`。字号以百分之一整数存储，默认 90，范围 50–180，按钮增减 10；显示时除以 100。血量字号为 `max(50, nameSize-13)`，默认 77，实际最大 167。恢复默认仅替换目标样式；已有保存值按原值读取，不随默认调整迁移。
- 本批不导入 Legacy；旧四个功能及其快捷键、列表、Notes 和世界/角色资料不参与新文档读写。

## 原版证据与观察

当前 .8 参考及安装 EXE SHA-256 同为 `960A03BFF6050CF7BE16DFC1A7B19E10FC2C4F8F835A6A3B135A50DD9E6BA2F3`，参考身份以 `eng/TerrariaReferences.baseline.json` 为准。本批定向反编译及哈希在本地 `.local/研究/entity-labels-implementation/source-identity.json`，不作为产品资产或编译引用。

Host 在游戏线程、Runtime 的一次 Update 中读取 `Main.npc`。没有开启项时不扫描、不构建标签，清空本批暂存；仅动物/NPC时不执行敌怪归组。只读快照保留当前必要位置、生命、关系及显示信息，后台只接设置值。资格优先 NPC 范围、动物范围、敌怪，确定单一分类；不凭字符串、旧 lifeMax 阈值或数组先后分类。

原版 `TypeName` 使用 `Lang.GetNPCNameValue(netID)`；`GivenOrTypeName` 为个人名优先。敌怪/动物使用类型显示，NPC 名字使用个人名优先的原版值。金色读取 `NPCID.Sets.IsGoldCritter`。当前 generation 随 NewNPCInstanceInSlot 更新；Host 用会话、引用、槽、generation、type/netID 使短寿命缓存失效，并每次刷新位置/生命，不能持有旧生命对象作为未来数据源。

敌怪归组只使用当前有效关系。共享生命的 `realLife` 必须指向有效生命主体，不求和；独立生命的部分不因 Boss 标志折叠。普通对象使用自身生命。归组采用数组索引表及线性有界阶段，不为每个对象扫描全表；屏外生命源先保留，最终绘制才筛屏幕范围。特殊多段的代表体与分裂行为须在定向 .8 证据/测试中明确；无法证明的异常关系跳过并计入本批有限原因，不能输出 0/0。

当前 Host 有限映射覆盖已核验的蠕虫共享家族与血肉墙主体/眼；EoW 13–15 的原版 `realLife=-1` 和分裂变形保持独立生命。蠕虫关系要求同家族、有效 root 与前后相邻互证，链不完整仍允许可靠头部自身生命，但不猜远处身体代表；已观察到同槽 root 被替换的旧成员，在其自身更新身份前拒绝重新关联。月亮领主按当前 core/head/左右手完整关系与阶段确认独立生命，不合并 `ai[3]`；破坏眼睛为动画恢复的生命不显示为满血目标。未知 `hide` 不强行显示。候选区余量和共享代表体可见范围分开，屏外头部不压过屏内身体。

名字字符串比较可每次观察，文字度量只在实际文字、字号或字体身份变化时更新；缓存以当前实体槽和有限标签数为界，消失/换世界清除。无按前 N 个槽截断、远处占满名额或任意 Tick TTL。当前语言变化经原版显示字符串变化自然更新。

## 生命周期与操作边界

继续复用唯一 `SingleFeatureRuntime`，不另建 Session。世界观察有效与允许执行物品动作分别表达：世界、玩家、连接身份有效且玩家 active 时死亡不结束观察会话；物品动作继续要求未死亡。待提交采集在死亡边界取消，已提交操作的保护/回执仍由既有同会话所有权处理；复活不重放旧采集。换世界、玩家、连接仍结束旧 Session；针对无新动作、在途保护、真实回执及旧采集不重放分别验证。

单对象读取失败只影响该对象；共享观察/字体/绘制不可用只停止本批输出，保留用户设置和有限可定位原因，不拖垮 F5/Notes/物品处理。不能用临时不可用倒写关闭偏好。

## 世界绘制

仅一个 `InterfaceScaleType.Game` 层，放在 `Vanilla: Ingame Options` 前、Capture gate 后，位于主要原版 UI 与 F5/Notes 之下，不破坏现有四个 F5 层的相邻锚点。当前原版 Game 层使用 `GameViewMatrix.ZoomMatrix`；输入位置为世界锚点减 `Main.screenPosition`，不再次套 UI 或世界变换。

位置包含原版当前 `netOffset/gfxOffY`。倒重力时按屏幕上缘选择对象下方世界边界，再镜像锚点；文字保持正立向上排，不把文字本身翻转。字体 identity 改变清度量缓存，内容/字号变化只重算对应项，消失对象的缓存随当前绘制集合退休；没有资源所有权转移。

菜单、专服、无客户端世界、全屏地图、隐藏 UI、FancyUI、相机捕获等状态不绘制；不以 `drawToScreen` 排除正常离屏渲染模式。观察位置与缩放变化及时可见；按实际字体可视 bounds 居中，两行紧凑排列。借用 MouseText 字体，不创建逐标签纹理，不在回调中 Begin/End，不注册命中。回调自己隔离失败且始终返回 true，避免原版层在异常时截断后续 UI。

## 信息页与编辑器

在现有前三行接入稳定的 typed 命令、选中/可用态、配置目标和公共动作 ID；其它样板行仍无命令。主窗口、导航、滚动和布局尺寸不改。配置入口与快捷键入口用滚动后的同一绝对矩形。群系原分派须收紧到群系命令，不能把新命令误判成关闭群系。

一份 `StylePopup` 服务三个目标，一份编辑草稿。布局使用 R 字体、面板和公共按钮；显示目标标题与 X、色块和六位 HEX、H/S/L 标签/数值/滑条、字号 +/-/数值/恢复默认，动物增加短说明。只为当前错误留高度，按实际文字度量与视口约束布局。绘制/命中共享同一布局；字体、材质、视口、缩放、主窗移动导致几何变化时取消捕获。

HSL 拖动只改草稿；有效前台真实释放提交一次，拖出可夹边；失焦、关窗、换页/目标或几何失效取消并吞完整尾缘。RGB 转 HSL 不回写原色；显示整数不量化草稿；灰色临时保留 hue，偏好仍只保存 RGB。

HEX 与 HSL 同草稿，开始编辑载入当前值并选中替换。使用原版字符队列及现有 Host 输入采样/所有权模型，六位有效时自动提交，Enter 验证提交，不足/无效不提交。Esc 先取消字段未提交草稿，下一次才关副窗，同一 Esc 不泄漏到 F5/游戏。完整提交后 Esc 不回滚。若支持粘贴，整段验证后一次提交，不截前六位；开发测试仅注入假剪贴板。

副窗与快捷键副窗互斥；切换释放旧目标的捕获与文本租约，保留快捷键双击入口语义。副窗覆盖区遮断底层点击/悬停/滚轮，拖动/编辑捕获阻止主窗拖动和游戏动作，关闭保留尾缘抑制。Notes/聊天/原版文本所有者优先，不以另一套键鼠轮询绕过公共输入层。

## 偏好与快捷键

唯一新文档 `JueMingRData/config/features/entity-labels.json`，严格版本 1，存三项开关/模式及最后 NPC 模式、各 RGB/字号。复用 `PreferenceDocument` 与 `AtomicFileDocument` 的串行后台合并保存；Draw/Input 不执行 I/O。缺失用默认，格式/未来字段/冲突保留原件；不可可靠保存时允许明确的本次内存选择并给出直接短反馈。

补齐 PreferenceSnapshot 对底层提交不确定、保护状态与有限错误类别的传递，旧完成不能将新 revision 标为保存。副窗取消只丢未提交草稿，不取消已提交写入。关闭后保存故障由 Host 保留有限反馈，不能假称原件一定未变或新值一定保存。

在现有 HostHotkeys 构造、Bindings 冻结前注册恰好三个新动作；默认未绑定。复用现有冲突、录入、精确修饰键、新主键边缘和文本/失焦让步，不另存 NPC 模式，也不改变旧四项动作 ID。重叠许可只影响保存，不升级成持续冲突监视。

完整包包含现有 Host。安全安装前核对旧回执、受管 payload、目标 EXE 与 Terraria/TerrariaServer 均停止；保留全部 JueMingRData，不启动游戏。本次接受后的文档收口保留已安装的c1候选及恢复材料，不为主线SHA变化重新构建、安装或重测。既有图形环境限制、未查看预览及未覆盖场景仍保留；静态/fixture不称多人实测，所有者体验接受不替代逐项验证或正式发布。
