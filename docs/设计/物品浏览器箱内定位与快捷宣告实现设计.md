# 物品浏览器、箱内定位与快捷宣告实现设计

状态：#89 授权实施的开发候选设计。产品合同见[行为合同](../功能介绍/物品查询箱内定位与快捷宣告行为合同.md)。候选审查、包与安装身份查任务 Issue；本文件不表示实机接受。

## 职责与生命周期

`Platform/ItemCatalog` 存不可变目录/关系值；`Features/ItemBrowser` 管纯匹配、索引与 64 条浏览历史；Host 仅在游戏主线程分批冻结资料和准备可见纹理。语言事件（含同 Culture 重载）更换目录/布局代次；世界条件使动态来源失效，设备资源不进入纯值索引。

`Features/ChestLocator` 管每槽覆盖证据，Host 管查询上限、结果寿命、原版 tile/Chest 身份、155/32 接收观察与世界绘制；连接来源不明即撤销库存知识，不阻断原版包。容量包不证明有任何内容，重复槽不能补齐缺失槽，结果不是服务器事务快照。正常 section 同步提供普通客机核心路径；本轮不主动发159，仍未知的数据如实保留未知，不能用159伪装刷新。

`Features/Announcements` 管安全文本与独立时钟限频；Host 管冻结目标与唯一普通聊天出口。公共点选有单独输入 owner：原版 MouseInput 阶段取得 Mouse1..5 手势，ItemSlot hover 仅记录新鲜值；消费失败不能降级为成功。不覆盖现有地图的 pointer claim。

查询页独立 Presentation/Layout/Renderer，复用 F5 外壳、UiSurface、字体、TextEditInput/SingleLineEditView。查询与定位两个 TextEditBuffer，只有一个当前文字租约。两栏常态、短视口切换，稳定可见图标与关系页缓存，禁止 Draw 枚举原版资料或 LoadItem。物品说明、搜索草稿、定位状态和换行候选必须走 `F5Layout.DynamicTextSize`，度量结果由当前页面持有；不能写入外壳固定文案的 1024 项生命周期缓存。浏览分页与定位输入间的细线复用单 texel 绘制，过矮布局撤销旧几何。

## 原始证据与覆盖责任

目标 Terraria 1.4.5.8，EXE SHA-256 `960A03BFF6050CF7BE16DFC1A7B19E10FC2C4F8F835A6A3B135A50DD9E6BA2F3`。原版 Recipe.requiredItemQuickLookup 在完成 SetupRecipes 后应用替代组并保留 stack；GetIngredientsForOneCraft 会用 RNG，禁止用于资料。ItemID.Count=6196，目录初始化不等于配方就绪。

ItemDropDatabase.GetRulesForNPCID 的声明报告可读，global 独立一次；Player.OpenBossBag/OpenFishingCrate、FishDropRuleList.GetDisplayableDrops 含 RNG，不执行填表。商店 SetupShop 的受控临时快照只按显式刷新分批，不按每帧或遗漏条件的缓存键声称实时。微光采用原版等价物/转换表及版本化前置条件，解构的条件、选中配方、组 DecraftItemId 单独处理。

NetMessage.SendSection 对服务端已知 TileSections 跳过；32 无事务 ID/坐标/箱代次，155 仅 Resize；RemoteServer 旧回调可进入全局缓冲，需保守来源失效。ChatHelper 的底层 SendData 吞网络发送异常，调用成功不构成送达回执。

交互参考仅作组织依据：[RecipeBrowser](https://github.com/JavidPack/RecipeBrowser/tree/f23758a6397898701149d42c51de64314cb4447a)、[QuiteEnoughRecipes](https://github.com/harperstoeckle/QuiteEnoughRecipes/tree/64276ca3e04c23ec428d50eca43f45cbe449d92d)。不复制资源或 tModLoader API。

## 工作量预算与验证顺序

| 状态 | 允许工作 | 禁止工作 |

| 定位提交 | 先类型上限，再有界空间枚举和 64 内容候选 | 假刷新、自动开箱、无限等待 |
| 高亮 | ≤24 身份/版本检查与绘制 | 物品数组、网络、重新排序 |
| 宣告新沿 | 一次冻结点解析、有限条目拼接 | 每帧目标遍历、失败重试发言 |

实施顺序：目录/匹配 → 配方/来源与历史 → 显式定位/接收/高亮 → 宣告/点选 → 原版与相邻回归/工作量 → 独立审查 → 同工作区干净重复构建、完整包、安全安装。先失败用例后实现；自动门按实际新增路径选组，不能静态字符串断言冒充边界执行。

实际执行结果、独立审查、负对照和候选/包/回执身份集中记于 [#89](https://github.com/Kuroneko2020/JueMingR/issues/89)。交付后 Issue OPEN、PR Draft，等待所有者实测和外部代码审查；不声称实际 FPS 改善或多人送达，不合并、不发布。

目录每步最多64物品或32配方，掉落每步一个NPC身份，微光每步32type；来源族局部失败独立显示，不清除其它来源。全部游戏对象主线程读取。稳定页面保留搜索结果、排版、可见ID集合与借用纹理身份；字体/皮肤或设备资源改变重新准备。64条历史包含关系/分类/替代页和正文滚动，定位草稿独立。

箱定位每步最多512枚举格，完整对象只读有限邻格；64个内容候选按真实容量读取，24个命中冻结数量/槽数与接收年龄。接收队列最多4096条，每更新处理256条；积压期间不以旧覆盖发起查询，溢出撤销知识。槽版本、连接/世界、箱对象/完整帧改变撤回结果，本机选择性存入与原版制作亦然。标签、脉冲填充和边框均≤24，按世界缩放裁切，不重读物品或请求网络。

宣告仅保存独立默认关闭偏好 `config/features/announcements.json`；动作 `announcement.send`、`announcement.toggle` 和 `item-browser.query` 复用原有公共绑定文件，默认未绑定，不覆盖未知绑定。已有 send ID 保持发送语义，toggle 资格只依赖设置已加载，不依赖当前开启。左侧 Field 的 HotkeyTarget 路由到 send，右侧图标路由到 toggle，均通过既有双击 Popup 与同一冲突表；可见绑定仅在值/字体改变时重测，长组合省略显示、悬浮提供全文。设置按值相等自校验，重复选择不写盘；失败/受保护状态通过开关提示显示，本次选择仍可用而不覆盖原文件。每条消息500ms，空气另加2000ms；会话更换清限频，时钟回退重新武装。冷却浮字走原版 `CombatText.NewText`，本地独立500ms提示门，资源失败局部隔离，不逃逸到公共输入/Runtime。UI/目标解析、安全文字和原版聊天出口分开；正常发送只有原消息，不额外刷成功提示，也不声称送达。正常正文共用「这里有 」和中文逗号；空气/不可见等完整通知不重复加前缀。正文按完整条目收束，超过预算或条目上限时在最终字节预算内加省略提示。

Legacy 文案依据冻结 `6ac6356c0c564f43284590c168855e96c50e13f7` 的 `MapQuickAnnouncementTextBuilder`、`MapQuickAnnouncementDeliveryService` 与 `TerrariaChatAnnouncementCompat`：不可见「这里看不见东西」，空气19条，冷却「宣告冷却ing」为本地玩家浮字。R 的空气选词用坐标/更新计数，不耗共享 RNG；原版浮字自身的随机偏移另属原生显示成本，不能宣称整个提示链零 RNG。

目标 .8 `Lang.BuildMapAtlas` 的82/83/84三阶段草药按frameX/18识别七种植物；395展示框按36帧周期归一2×2左上角，只读 `TileEntity.TryGetAt<TEItemFrame>` 与已收到的非空item。两者即时冻结，不等待放置目录重采实体。普通未知对应可读原版MapHelper/Lang地图名称；80/529/530/461的选项涉及邻格或SceneMetrics，保守使用option0，数组/option/legend缺失或越界保留未知。地图名不能生成ItemType；实际 .8 祭坛已有物品对应，不能凭旧版本印象判为不可放置。

首次世界点选/宣告无需预先打开查询页：先冻结可见对象和新鲜UI边界，再只按每更新64项准备原版放置元数据，不准备目录描述、配方或其它来源。最多180更新，指针/会话/界面变化、Esc或目标方块变化取消；取消与完成后停止读取，不延迟重采目标。映射仍含家具style与唯一对应检查。回声前景、墙自身回声与原版光照例外分别判定；未知对应不回退成错误的默认家具样式。

关系中的产物、材料/替代组及工作台按完整文本换行，保留数量并可滚动恢复；不会只把关键数量藏在省略号后。对应检查覆盖实际长物品名、替代组、工作台、297与580逻辑高度。

## 验证和完整交付入口

正规 `scripts/build.ps1 -Configuration Debug|Release -WorkloadBaseline <本轮基点>` 自动执行 `browser-host`（含公共Host/输入/存储修改的消费传播）：纯目录/关系/64历史/槽覆盖/安全文字/限频，以及 NativeWorldTextProbe 的 `BrowserCpu` 真实1.4.5.8目录、配方、掉落、商店、微光、ItemSlot出口、155/32接收、空间扫描和完整Host装配。导出类型白名单只增加本轮实际跨项目值与领域类，原依赖禁令保留。

图形入口 `NativeWorldTextProbe <仓库根> <Content> <隔离输出> BrowserVisual` 使用原版XNB与生产页面，生成两栏、紧凑、1280×720/150%目录/详情/替代页、过矮、加载/无匹配/末页、长关系、返回/取消，以及实际定位器产生的未知/成功详情与正常/倒重力绿色叠加图；检查控件边界、文本宽度，120次稳定准备不重建布局/搜索/可见集合/纹理。`NativeBrowserLifecycleChecks` 连接真实完整Host、按下/释放定位按钮、成功自动关闭、F5重开和清除，核验高亮像素撤销及窗口仍可用。CPU另用同一布局连续浏览160种真实说明再重开，防止固定缓存增长；宣告覆盖真实21种草药阶段/样式、展示框有/空/缺失/隐藏和原生浮字池。CPU UI seam、最终聊天出口拦截及隔离原版执行分别标记，均不等于真实游戏循环、Windows IME或联网送达；各入口是否已执行及环境限制仍以#89记录为准。`scripts/test-phase0s.ps1` 保留完整加载/输入/图形/安装恢复，将item-browser纳入用户数据保留检查。

打包沿 `scripts/build-phase0s-validation-package.ps1 -Profile ItemBrowser -OutputDirectory <全新目录> -WorkloadBaseline <本轮基点>`，包ID为 `item-browser-<FULL_SHA>`，完整继承足迹及此前功能，仍为8项载荷。同一干净候选在当前单一工作区顺序构建两次，比对全部声明产物与包字节，不称独立环境复现。安全安装沿既有恢复/安装脚本和已核归属的旧回执，保留全部用户数据与旧包/恢复材料。
