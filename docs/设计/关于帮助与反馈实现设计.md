## 页面、版本和输入

Host `About` 独立拥有当前关于/帮助视图、操作结果和页面元素；F5Layout 仅接页内容与真实高度，F5Renderer 复用既有批次和裁切，Shell 只转交原公共输入产生的命令。所有者在开发中明确要求一比一复刻 Z 外观、去掉“快速上手”，并澄清默认大小完整展示、小窗口允许滚动；该新决定替代原 Prompt 对占位/装饰的较早取舍。R 522×581默认内容区采用原版78高页头、双栏与14间隔、8外间隔、54高页脚；较短窗口保留内容高度后滚动，不按屏幕比例整体缩字。版本详情和再次帮助合并为左下入口，完整版本及复制按钮位于帮助正文顶部，首页保留原版紧凑构图。

视觉来源是同一只读冻结 Legacy 的 `LegacyMainWindow.About.cs`、`LegacyUiSkinPalette.cs`、`VanillaUiSkinCompat.cs`；仅适配绘制事实，不迁 UI 框架。AboutPainter 以借用的 MagicPixel 绘制三层8/6/4圆角底色、角饰、静态星点/虚线、消息/说明/爱心小图标与二维码角框；不调用旧项目。色板按原版中央纹理采样公式从现有借用皮肤准备，严格限一代资源一次，失败保留fallback，不逐帧读回。采样上限1048576像素；稳定绘制只有固定数量原语，不反射、分配数组或制造动画。完整原始正方形二维码以6单位白色外边距包含显示，既不裁切也不重编码。

文字布局按视图、运行事实及字体/宽度失效，稳定鼠标移动与滚动只投影；试探换行使用已有动态度量，不能污染1024项固定文字缓存。复制成功/失败文本预先度量并固定按钮几何；实际新点击才清/替换对应结果，离页退出操作结果。F5 继续独占按下沿、同代次同目标释放、失焦及真实释放尾部；从笔记/查询/模态离开先通过已有 BeforeLeave，不取消在途玩法动作。

版本取已加载 Host 程序集的 `AssemblyInformationalVersion`（当前正式产品版本尚未分配，显示开发构建）及实际加载 Terraria 程序集/运行版本；与固定加载能力范围1.4.5.8分开。首次进入页面时构造，稳定帧不反射、读Git/回执或哈希文件。完整复制文本同时在页面展示；没有私人路径、角色或世界资料。

剪贴板复用 `NotesClipboard.TryCopy` 的 Unicode机械出口，通过窄函数注入页面；不调用 NoteWorkspace/TryPaste，不复制Win32声明。一次调用返回false或异常均为失败，不循环抢占；页面提示仅可声称无法写入剪贴板，不猜占用或权限的具体原因。

## 首次提示、角色与文件

Features `Onboarding` 独占呈现状态和标记语义；Host `Onboarding` 适配已存在 Runtime Session、角色文件身份与绘制。身份准入沿 ActivePlayerFileData 对应 LocalPlayer、非SSC、有效路径/local-cloud与客机完成连接；角色摘要使用独立版本域，绝不取世界 GUID、数组槽或显示名。运行对象只用于取消迟到/错误角色回执，不作为永久key。保留既有路径身份限制，不建立身份数据库或读其它历史。

状态区分等待读取、可呈现、实际显示/内存抑制、保存中、已保存、失败保护；未知身份只会话抑制。可见计时使用单调时间与有效连续Draw回执，失焦/遮挡打断计时链，退出清提示。Draw不提交worker；Update核同一Session/角色后接收有效回执并发一次保存。未知身份后来可靠，仅在相同角色引用/同Session连续性成立时合并，晚到文件结果不影响新角色。

文件为小型严格 UTF-8 JSON `format=JueMingR.Onboarding`、`version=1`、`character=<摘要>`、`seen=true`。只有可靠缺失使用未看默认；未知字段/未来版本/错误身份/坏值整份保护。复用 `DocumentWorker` 和 `AtomicFileDocument(protectRecovery:true)`，游戏线程无文件读盘/文件哈希/JSON；角色文件路径及local/cloud摘要仅在身份准入变化时计算一次，后台无live对象；只有 Saved 才持久成功。失败本进程不自动重试，缓存保留失败角色抑制；下一启动新owner重新读取。最多64个纯摘要条目、4个在途/待收尾worker。成功且worker已收尾的非当前条目按最近使用淘汰，失败条目本进程保留保护；全为失败或在途时新角色会话兜底、不新开文件，不驱逐未完成worker。未呈现就离开会退役读取owner并移除未看条目；同key旧worker尚在退役时等其完成再单次准入，不重复抢锁。可靠身份暂失先脱离旧文件，已确认看过的抑制仍属于当前角色准入，不因文件观察暂失而清除；恢复到同一文件与角色连续性才可合并；恢复到另一文件重开角色准入，旧回执不串标记。

未来版本、未知字段、损坏/错误身份、过大、占用、权限、恢复材料、读失败、写失败和提交结果未知分别投影；提交结果未知不承诺原文件未变，未来格式不暗示同版重启可修。必要错误由现有本地反馈一次发出，关于页可回看，不增加普通功能状态行；静默正常读取/保存。每次独立失败产生一次本地反馈，关于页保留最近错误。进程退出对已接受工作使用750ms有界总等待，未完成的原生I/O继续拥有资源，不强制终止或删根。安装不预建标记，不访问真实角色数据。

## 实施与验证顺序

1. 真实关于/帮助入口RED：现有空关于页不能提供按钮、版本和长文。独立页面内容/布局、同源复制、原字节资源嵌入与F5薄接线后，验证主输入、稳定按钮反馈、长页高度和重复进入。
2. 首次状态及文件RED：未Draw不能保存、同角色跨世界不重复、未知→可靠不二次呈现、损坏/未来/失败不能覆写或自旋。实现领域owner与Host薄接线，验证隔离真实文件、Session与显示回执。
3. 正规完整profile、资源及工作量：新增AboutHelpFeedback完整profile继承G01–G06；本批CPU与图形检查纳入既有入口及diff选组。图形使用固定原版XNB、正常/矮窗口/150%与替换字体，不启动游戏；剪贴板测试注入受控端口，不接触Windows当前内容。
4. 完整Debug/适用Phase0S与图形、完整diff独立只读审查；固定clean实现，顺序两次Release完整包比较全部声明文件及ZIP。原版、用户数据及旧安装精确保护，按既有安全门安装并回读；停止待实测和外审，不合并。

每一步保留关键失败反例和实际执行身份，自动/图形夹具/真实输入/联网/所有者接受分别陈述。不用源码字符串检查代替真实按钮、实际呈现、文件结果和产品载荷。
