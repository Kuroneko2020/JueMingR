## 页面与输入

Host `About` 独立拥有关于页、群号复制结果和页面元素；F5Layout 仅接内容与真实高度，F5Renderer 复用既有批次和裁切，Shell 只转交原公共输入命令。所有者要求复刻 Z 整体外观、默认完整展示、小窗口可滚动，并在实测后明确删除帮助／版本页面、入口和正文；较早 Prompt 的帮助与运行版本复制方案已被替代，相关代码和命令一并移除。R 522×581默认内容区采用78高页头、双栏与14间隔、8外间隔、54高页脚；较短窗口保留内容高度后滚动，不整体缩字，没有“快速上手”卡片。

视觉来源是同一只读冻结 Legacy 的 `LegacyMainWindow.About.cs`、`LegacyUiSkinPalette.cs`、`VanillaUiSkinCompat.cs`；仅适配绘制事实，不迁 UI 框架。AboutPainter 以借用的 MagicPixel 绘制三层8/6/4圆角底色、角饰、静态星点/虚线与小图标。按最新决定，二维码不带平台名称和旧角框，微信使用1 logical绿色边框、支付宝使用1 logical蓝色边框。色板中央采样严格限一代资源一次，失败保留fallback，采样上限1048576像素；稳定绘制不反射、读回或分配数组。原始正方形二维码保留6单位白色外边距，既不裁切也不重编码。

文字布局按内容及字体/宽度失效，稳定鼠标移动与滚动只投影，不污染1024项固定文字缓存。群号、复制成功、复制失败三个标签预先度量并固定几何；只有待消退结果才读取单调时钟，3秒后恢复群号，离页直接清除。计时变化不重建布局、不更换命中代次、不访问剪贴板。QQ悬停仅“点击复制”。F5继续独占按下沿、同代次同目标释放、失焦及释放尾部；从笔记/查询/模态离开仍通过已有 BeforeLeave，不取消在途玩法动作。

剪贴板复用 `NotesClipboard.TryCopy` 的 Unicode机械出口，通过窄函数注入页面，仅复制群号；不调用 NoteWorkspace/TryPaste，不复制Win32声明。一次调用返回false或异常均显示“复制失败”，不循环抢占或猜失败原因。

## 首次提示、角色与文件

Features `Onboarding` 独占呈现状态和标记语义；Host `Onboarding` 适配已存在 Runtime Session、角色文件身份与绘制。身份准入沿 ActivePlayerFileData 对应 LocalPlayer、非SSC、有效路径/local-cloud与客机完成连接；角色摘要使用独立版本域，绝不取世界 GUID、数组槽或显示名。运行对象只用于取消迟到/错误角色回执，不作为永久key。保留既有路径身份限制，不建立身份数据库或读其它历史。

状态区分等待读取、可呈现、实际显示/内存抑制、保存中、已保存、失败保护；未知身份只会话抑制。可见计时使用单调时间与有效连续Draw回执，失焦/遮挡打断计时链，退出清提示。Draw不提交worker；Update核同一Session/角色后接收有效回执并发一次保存。未知身份后来可靠，仅在相同角色引用/同Session连续性成立时合并，晚到文件结果不影响新角色。

旧调查[§2.1](../功能介绍/全功能调查专题/剩余入口与产品收尾.md#21-触发状态和用户所见)已正确提取头顶黄字、阴影和上浮，冻结 Z 的 `UI/FirstWorldLoadPromptOverlay.cs` 可核对。前一 R 候选误做为居中带底板提示；这是实现偏差，不能归因于提取。所有者随后明确优先复用原版重铸浮字队列，因此本次移除自绘提示，使用锁定1.4.5.8的 `PopupText.NewText(AdvancedPopupRequest, position)`，与现有自动丢弃反馈共用原版20槽池与绘制。Advanced允许准确文案，未调用物品重铸操作；没有新增Hook或独立批次。

Update以当前Player头侧入队，倒重力取Bottom并补偿原版文字中心镜像；已入队项的位置、速度、描边、缩放、原版碰撞和淡出交给原版。原版满池会顶替已有项，因此入队前同步检查空槽，满池等待。Host只保留自己槽位与对象，修改前还核对active、Advanced、freeAdvanced和准确文案；原版复用对象或ClearAll后不得清理别人的继任项。无显示资格时只释放自己项并断开可见时钟，恢复后重新准入以完成剩余阅读；不保存或恢复整个池。

只有提示尚未完成才核对呈现资格、缓存字体尺寸和投影自身边界；关闭完成路径不扫描池、不测量字体、不取时钟。原版仍承担其自身浮字工作量，不凭复用推断FPS更好。前3秒有效阅读仅保活自己的lifeTime，之后令其进入原版淡出；为防原版碰撞延寿，收尾最多40次有效更新后只释放本项。领域收口与原版自然消失解耦，避免不足旧0.6秒阈值而重复入队。

锁定原版Main.Draw在DrawInterface前调用DrawItemTextPopups并完成SpriteBatch.End；现有F5 layer仅确认此前已绘制的自有项，非零且可读缩放、当前资格、屏内及已知遮挡均检查后交回执。NewText只在Update调用，初始scale=0不记已看；F5回执不绘字、不操作批次、不做I/O。全屏地图、hideUI或失焦即使跳过F5 layer，也由Update主动暂停计时并释放本项。本帧后续UI新出现的遮挡无法撤销已提交的原版浮字，该帧不计回执；不声称Update能够预测所有当帧绘制占用。

文件为小型严格 UTF-8 JSON `format=JueMingR.Onboarding`、`version=1`、`character=<摘要>`、`seen=true`。只有可靠缺失使用未看默认；未知字段/未来版本/错误身份/坏值整份保护。复用 `DocumentWorker` 和 `AtomicFileDocument(protectRecovery:true)`，游戏线程无文件读盘/文件哈希/JSON；角色文件路径及local/cloud摘要仅在身份准入变化时计算一次，后台无live对象；只有 Saved 才持久成功。失败本进程不自动重试，缓存保留失败角色抑制；下一启动新owner重新读取。最多64个纯摘要条目、4个在途/待收尾worker。成功且worker已收尾的非当前条目按最近使用淘汰，失败条目本进程保留保护；全为失败或在途时新角色会话兜底、不新开文件，不驱逐未完成worker。未呈现就离开会退役读取owner并移除未看条目；同key旧worker尚在退役时等其完成再单次准入，不重复抢锁。可靠身份暂失先脱离旧文件，已确认看过的抑制仍属于当前角色准入，不因文件观察暂失而清除；恢复到同一文件与角色连续性才可合并；恢复到另一文件重开角色准入，旧回执不串标记。

未来版本、未知字段、损坏/错误身份、过大、占用、权限、恢复材料、读失败、写失败和提交结果未知分别投影；提交结果未知不承诺原文件未变，未来格式不暗示同版重启可修。必要错误由现有本地反馈一次发出，去掉对已删除帮助页的引导，不增加普通状态行；静默正常读取/保存。进程退出对已接受工作使用750ms有界总等待，未完成的原生I/O继续拥有资源，不强制终止或删根。安装不预建或清除标记，不访问真实角色存档。
