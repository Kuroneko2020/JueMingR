# 工具与自动采集实现设计

状态：G09 三项能力、各轮有效修复及性能检查补强的实现设计已获所有者接受，随 [PR #106](https://github.com/Kuroneko2020/JueMingR/pull/106) 合并进入 `main` 生效。范围以[行为合同](../功能介绍/工具与自动采集行为合同.md)及 [#105](https://github.com/Kuroneko2020/JueMingR/issues/105) 为准，不实施 G10。人工接受的保留安装与后续工程验证分别记录，不要求追加人工复测，详见[接受边界](../功能介绍/工具与自动采集行为合同.md#验证与接受边界)。当前原版为锁定的 1.4.5.8，EXE SHA-256 `960A03BFF6050CF7BE16DFC1A7B19E10FC2C4F8F835A6A3B135A50DD9E6BA2F3`；Legacy 只读调查基线 `6ac6356c0c564f43284590c168855e96c50e13f7`。

## 决策与职责

- `Features/Tools` 保存不可变三域选项、可靠文件发布、材料分类、有限矿脉连接与后备队列；不引用 Terraria。
- `TerrariaHost/Tools/HostTools` 只做生命周期、准入、设置/快捷键装配。`AutoCapture`、`HerbHarvest`、`AutoMining` 各自唯一拥有业务状态；不扩展巨型 Runtime。
- `ToolUse` 持有持续意图的真实工具对象、唯一租约、选择与暂时鼠标瞄准。业务 `Refresh` 维护目标，`Used` 观察真实开用，`Yielded` 区分自动公平交接。通过 PickItemSelectionOverride、TrySyncingInput、ItemCheck 及 Finalizer 使用原版；不直接回写 selectedItem、库存或世界。目标完成不等同使用权结束，较晚人工 buffer 优先。
- `ItemOperationOwnership` 增共享单调 use lease 分配，既有 QuickItems/Extraction 同用，迟到清理不能因各自从 1 编号而释放其它 owner。新增精确工具调用委托不覆盖 QuickItems 的消费许可。待补种只保护真实当前候选种子，未知保留受影响来源。
- `HotkeyUseGesture` 聚合 QuickItems 和 Tools 的真实观察需求，维持没有消费者/尾段时零来源检查；专用选脉按公共认领消费，不增加系统输入采样。
- 原版 NPC 事实按现有缓存共享；捕捉使用独立 Boss 谓词，不能沿显示端 boss 单字段漏掉 EoW，也不直接沿 AnyDanger 把纯事件当 Boss。

## 原版依据与安全出口

网的真实帧来自 `Item.GetDrawHitbox`，三网库存尺寸不能替代。隔离、复用的几何 Player 只运行三网限定 useStyle1 的原版 ApplyUseStyle/GetMeleeHitbox，不临时改真实玩家。几何上下文按真实方向、重力、坐骑及缩放刷新；纹理帧缓存。逐 NPC 只测有限预备矩形，真实目标身份和命中在使用前复核。

当前三种网只需预备三阶段原版矩形。缓存键覆盖真实纹理值／动画帧、有效尺度／手套、原版使用时长、尺寸、位置、方向、重力和坐骑中心偏移，更新号不是失效条件；绝对坐标保留原版整数截断，移动时重建三个阶段。未就绪资产不永久缓存失败，按原版请求加载。启动以玩家先于 NPC 更新的实际顺序，按相对速度检查未来阶段；阶段扫掠框先粗筛，只有可能相交时逐合法阶段帧核验。既有挥动不因一次外推失败中途重借，实际消费者持续接收当前目标中心。

`CaptureOpportunity` 只记有限 NPC 槽的对象／generation／类型与已尝试机会。一次借用最多两个原版开用，记最后一次真实挥网开始时的相对运动，避免归还期间停步丢失新窗口；机会耗尽或自动让位保留 miss，人工和危险取消不冒充 miss。已经观测到的离开事实跨归还保留；出入、相对运动方向或静止状态变化、真实形状／工具／方向变化可重新准入。先选定最合适的真实可捕网，再判断机会，避免仅轮询另一个背包网就洗掉 miss。Boss 聚合按 `NativeNpcObservation.Epoch` 共享；玩家选物阶段和原版 NPC 更新后分别失效，同代次重复请求不再遍历全表。

原版 `SelectedItemState.Update` 先恢复原选择再请求 override；活动意图在源身份、当前准入与目标刷新都有效时继续同一 override，避免选择变化制造额外计时重置。原版自然推进 useTime/useAnimation/toolTime，持续控制每更新在拥有的原版入口提交，鼠标瞄准仍在每次 finally 归还。公平性按实际就绪需求周期核验，在安全归还后交接；提炼 Ready 可观察“归还工具后可解除的原物保护”，真正 Pick 仍复核全部保护。只有真正人工 Select 才将其缓冲消费识别为人工手势，不能把提炼归还当人工取消。Ready 查询不推进补种轮转或创建动作。

外层 `Main.Update` 与真实输入／玩家更新不是一一对应：固定 .8 的 `DoUpdate` 在部分帧跳设置下会在采样前返回，R 的外层前后缀仍会执行。`HostInputState.CanRetainAutomaticIntent` 表示当前原版运行条件及前台重激活隔离允许保留既有自动意图，后台不额外要求焦点；`HostTools.CanRetainUse` 再核对原有界面、危险、物品和会话边界。`ToolUse.Update` 使用此保留条件，不能因本轮没有输入样本就取消持续租约。选择、Sync、ItemCheck、投射物与实际消费仍使用要求新鲜样本的 `Admit`；空外层更新不借输入、不调用消费者、不推进或重置工具计时。后台真实模拟可继续捕捉、采草/补种、已有矿区和借网补抛；区域选择、人工首挖仍须有效前台输入。人工接管、界面、关闭、死亡和会话变化仍可取消。

自动首挖已经建立选区后，玩家松开物理左键时，仍手持同一工具的动画可以继续。仅在不可立即换槽、没有 override／人工 buffer／本帧手选、身份与准入均有效时，现有 Sync 接缝取得同一 `ToolUse.Acquire` 租约；不改选择，不等下一整段动画，不重置 HitTile 或工具计时。持续按住和新的人工按下仍优先。该获取与普通选槽获取共用唯一使用链和共享物品所有权。

`HerbField` 用固定 441 位保存当前可收候选；幼苗和暂不满足原版条件的植物不在每次 Choose/Ready 中全量重查。稳定更新分批读 24 格，未知外部成长、底座等变化在 19 更新内复查，首次准入仍受既有四更新探索节奏约束。移动、范围、工具能力、noBuilding、世界身份及原版昼夜／雨云／血月／月相／40500 时间阈值／深度与 remix 谓词变化立即重查，原始 time 不作每更新失效键。候选执行前读当前成熟度、天气与底座；活动目标成功后无探索冷却。精确工具对象保留，新主包来源有界发现，手持来源立即优先；没有合法目标不创建意图或闭包，无工具清观察。

`MiningOverlay` 共享候选资格与颜色数据，但缓存不能授权执行：范围／能力及世界身份变化立即失效；近处成员以格、上下支撑／帧／墙和原版锚点见证变化，额外每更新最多 24 成员深查，512 格的未挂钩变化最多 22 更新复查。候选资格独立于当前借槽持有状态，避免交接 Ready 被显示红色压掉；无可执行候选时不建意图或全区深查。删除成员补偿轮转游标，保留剩余成员的复查界限。Draw 只画缓存并叠加实际持有条件；真正挖掘逐次读原版完整资格。空区且无 falls 时 `RetireRegion` 清工具、覆盖与重力观察，保留模式和物理按住代次。未知消费保护不随普通缓存退休清除。

矿业 UI 的选脉 Field 紧邻“快捷键”模式，行尾 Hotkey 为主开关；第二行“选择挖矿区域”及其同动作键盘入口保留，共三个控件、两项绑定。两个 target 在逻辑元素上显式保存，不靠投影顺序推断。动态绑定按全文、实际字体身份、框宽单独拟合缓存，滚动只更新坐标，不占固定文案缓存。所有录入、可靠保存及双击资格复用公共热键窗。

普通浮标 AI 在 owner 选物不再是鱼竿时 Kill，故回竿本身不能保漂。`FishingBorrow` 持有同会话竿对象、有效漂身份、原世界目标、人工选择代次及有限租约。它是真实捕捉使用的协调出口；一次重抛提交前锁定归属，任一当前本机漂存在即不抛，未知终止。合成未来参与者只能观察此归属并让位，不能第二次抛竿。收获与补种避让当前真实鱼竿及本机漂，不获得借竿许可。

暂时换工具期间，`ToolUse` 对原选择的精确 Item 保留自动物品处理保护；钓竿从借出至单次重抛决定结束由 `FishingBorrow` 继续保护。这些仅进入自动业务观察，不能阻止用户人工拿走。真实新按键到达时即归还共享使用权，原动画清理仍按原版寿命完成，不能让旧租约吞掉新的手工首挖。

草药资格调用原版只读 `IsHarvestableHerbWithSeed`；执行沿真实再生工具 `PlaceThing`。在真实 PlaceThing_Tiles 作用域前后观察目标，优先识别原版免费同 style82；只有已收获空位进入后备。`PlaceAlch` 对液体/坡度/虚化底座的额外限制证明后备有必要。后备种子走原版使用，重新核对原株、底座、工具与物料。

有限等待使用 Tools 局部累计时钟。锁定 .8 的 `GameUpdateCount` 在 `DoUpdateInWorld_Inner` 入口、玩家和弹幕更新前增加；外层 `Update`、甚至 `HandleInput` 到场仍可能跳过世界阶段。`HostTools.Tick` 累计该 uint 计数差，原版自然回绕保持小步，回退形成大年龄使旧等待失效；新会话清普通状态后重设基线。共享 Runtime tick、Input.Frame、原版计时和动作节奏不改。600／135／300 保持原值，借竿回执和真正重抛前也检查期限；计数只证明模拟机会，不证明成功或服务器确认。稳定 `HerbField` 的 24 格探索以此去重，环境／位置／能力变化仍立即检查；其它有活性职责的观察不一律禁止空回调读世界。

`HerbHarvest` 用七个 ulong 位图记录每种种子的所有候选槽位。首次必要发现读取 0–49 槽，同 `Input.Frame` 与同库存数组可供 Ready／Choose 共用；本地玩家每次 `ItemCheck` 前后及异常、Host 更新观察和 Reset 仅标记失效，不主动扫描。拾取、外来网络等在动作外发生的新槽事实到下一观察机会再发现，不承诺任意同帧变化立即可见。位图不缓存保护或位置权限：候选逐次读取真实类型／数量、现有物品保护和 CanPlant，取得租约后的消费仍由 ToolUse 核对精确来源。未知位置／来源保护不随位图失效或开关清除。DEBUG 计量包括发现、候选读取与创建种子意图时的读取；有种时的必要复核不承诺总数恒等于 50。

范围调用原版 `IsInTileInteractionRange`，挖矿 tileBoost 与种植 tileBoost+blockRange 分别处理。`PickTile_DetermineDamage` 和 `HasEnoughPickPowerToHurtTile` 写 hitTile，禁止用于预览；`GetPickaxeDamage` 对本批严格 37 类型的可达分支只读，必须由动态独立 oracle 验证，不能放开支持集合。`CanKillTile` 还需配合 `CheckTileBreakability`，避免展示架等受保护支撑误判为可挖；先确认 3×3 可读，再查询其严格材料分支，避免原版查询补建缺失 Tile。实际执行仍再次检查。正伤害目标持续处理至消失或失去资格，不能逐击轮换大选区而被原版有限 HitTile 缓存不断淘汰累计进度。

`PickTile` 前后记录仅在物理玩家调用、同会话、支持原格且两次均可读时产生首挖。合成 owner 标记贯穿原版调用与异常清理。选区上限 512，扫描最多种子 ±80，更新准备可执行性和覆盖；Draw 不扫描世界或复制列表，颜色按 AlphaBlend 预乘。重力首挖在原版递归生成下落弹幕前捕捉候选及占据位，证实真实破坏后才接管。仅已确认腾空的原选中格能清除既存占据位；未知不清除，明显无关旧格不接纳。最多 512 条、每更新 8 条、寿命 135 游戏更新，使大选区有至少两轮复查机会；不声称唯一方块身份。

首挖还须匹配 `ItemCheck_UseMiningTools_ActuallyUseMiningTool` 的玩家、Item 和坐标作用域，排除宠物等其它 PickTile 调用者；同一物理按住只接管一次，新的按下允许重选。钻头仍走该原版镐击链；只给本次 ItemCheck 经 TryUpdateChannel 发布的精确钻头弹幕，在原版 AI 期间借用同一提交瞄准，正常/异常退出即时归还。未拥有的同类型弹幕不受影响。

钓竿恢复许可在获得使用权后建立；主动收回状态不建立许可。即使网动画尚未开始，已选网也可能产生断漂责任。终态保留 token、Session、Rod、RecastAttempted/Started/Observed，迟到回调按 token 与当前 phase 拒绝。未来协作者在 Borrowed/Returning/RecastOwned 保留其会话并让位，任何终态都不是重试同一 token 的授权；未知新漂状态仍不补第二次。已有相同实际世界/玩家连接的暂停不清除未知来源与目标保护。

## 原实施、验证与交付流程（历史）

以下保留原开发流程及各检查的职责，不是本次收口的新执行要求。原流程由一个写入者沿普通分支实施，证据代理与最终审查只读；临时测试日志/任务材料在已登记 `.local/g09`，未生成额外 worktree 或工程副本。本次只做文档最终化与窄复核，保留已接受安装，不重新构建、运行产品测试、打包或安装。

1. **策略与持久化**：先写材料37/宝石连接/截断/距离、补种48/600/轮转、三设置默认与模式保存、唯一租约迟到释放的失败测试；实现独立类并跑 ArchitectureTests 目标组。失败、Busy、未知不能发布新权限。
2. **原版使用控制与捕捉**：先加真实 Host 反例（人工 buffer、同号旧租约、异常借鼠标、三网真实帧、EoW与纯事件、普通网熔岩）；实现有限 ToolUse、捕捉与 FishingBorrow。验证每网/方向/重力/坐骑原版 ItemCheck，漂存活零重抛、消失一次、多漂、10–49槽、换竿/人工意图/迟到确认以及合成协作者。
3. **草药与挖矿**：原版初始化真实 tileAlch/tileCut、TileObjectData；两工具×七style×两底座无种子免费复种、天气边界/有限补种/晚种子/异物；全部材料对原版伤害和保护 oracle、矩形角、首挖不可读/递归/重选、重力新旧格、累计进度。实现后沿正常入口核对动画/掉落/消费与原版消息，不用直接 helper 代替整个链。
4. **实际装配和 UI**：完整 ContinuousProcessing profile 包含 G09。捕捉/收获物品页、挖矿杂项页、公共配置弹层/绑键/短提示；三开关+一次动作注册冻结前接入。真实 UI/Hotkey/短提示消费者与相邻 QuickItems/Recovery/Processing/卖扔存保护回归。
5. **自动工作量和独立审查**：维护脚本真实选组与反向依赖，关闭无在途零业务读，满载有界、Draw只读预备项。正规 Debug 构建自动运行相关组；实际 XNB 图形入口验证布局、字体、裁切、缩放和最终提示。全 diff 的独立新上下文审查后按具体问题窄修复核。
6. **原完整交付**：固定 clean commit，同一工作区两次顺序干净完整构建/包比对；完整载荷及ZIP一致才候选交付。核实际回执、旧载荷、EXE、游戏退出和冲突安全门，通过才原入口安全安装，保留用户文件/旧包/备份。当时保持 Issue OPEN、Draft PR 并等待实测；该等待状态已由 #105 的接受与收口授权替代，后续等待/种子发现修复未制作新包或换装。

每步只记录实际运行结果；动态状态和具体SHA见Issue，未跑项不得标为PASS。独立审查重点是原版入口因果、受控写入/异常所有权、人工意图、多人未知停止、全部材料和副作用，而不仅是策略测试数量。
