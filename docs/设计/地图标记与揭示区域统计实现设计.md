# 地图标记与揭示区域统计实现设计

## 原版证据与坐标

锁定 Terraria 1.4.5.8，MVID `2c29f6c3-4bd9-4add-9c58-da159804e083`，SHA-256 `960A03BFF6050CF7BE16DFC1A7B19E10FC2C4F8F835A6A3B135A50DD9E6BA2F3`。定向反编译当前二进制，不以旧版参考替代。

`MapOverlayDrawContext` 的正向关系为 `(q-mapPosition)*mapScale+mapOffset`；`Main.DrawMap` 原版 ping 是独立逆向依据。全屏 `MapIcons.Draw` 已含 `-10*mapScale` 偏移，不能重复补偿；死亡专用 Y 修正只属于死亡点。图标源中心与 drawScale 不改变保存坐标。

键盘/滚轮可在 Update 改变视图，鼠标拖图和最终夹紧却发生于 DrawMap。因此只在成功完整 Draw 后发布实际可见几何；新右键输入立即以该几何和同次原版 `PlayerInput.MouseX/Y` 热点冻结 q。后续绘制只投影固定 q，不在未来帧重采样。无 Draw 的多个 Update 不使仍在屏幕的几何任意过期；会话、视口、设备、地图关闭与异常使其失效。

## 职责与存储

`Features/MapMarkers` 独占不可变资产、严格编解码、命令确认和编辑状态；复用 `DocumentWorker` 逐命令提交及 `AtomicFileDocument` 的身份/恢复保护。可靠角色×世界身份复用现有死亡记录的路径 local/cloud＋世界 GUID 摘要边界，不改变旧档案键。没有可靠身份不创建公共 unknown 文件。

`Features/Exploration` 独占完整扫描/动态块计数、状态发布及摘要。标记文档、探索摘要、共享安装偏好分别落入 `map-markers` 用户资产、`records/exploration` 摘要和 `config/features` 偏好路径；精确 schema 与最终路径随实现补齐。后台只处理冻结文档，不访问活动 `Main.Map`。

宿主只提供当前地图、揭示读取、真实写入通知、生命周期与受控视角操作。地图绘制协调器共享几何和最高可见悬停结果；死亡和标记保持独立 owner。UI 不拥有保存事实，输入复用 HostInputState 的唯一真实采样、焦点与尾缘；文本使用现有完整文本元素规则与 IME lease。

## 揭示变化与并发

当前 `WorldMap.IsRevealed` 是 `Light>0`，没有可复用聚合计数。`LightingEngine.ExportToMiniMap` 在 `FastParallel.For` worker 中写图；调用方等待所有 worker 完成。`Netplay.InnerClientLoop` 可在另一线程 Load，因此不能直接把所有写入当成游戏线程事件。

观察实际 store：Update/SetTile 的数组 Set，UpdateLighting 的成功 Set，私有 UpdateType 的 stobj。UpdateLighting 用现成新旧 Light 过滤 true→true；UpdateType 旧 Light 已大于零，只有新值为零影响揭示。Load/Clear/ClearEdges 以外层批次 epoch 失效，禁止逐格放大。`clearMap/refreshMap/loadMapLock` 都不是可靠数据写锁。

有限块数组保存版本、计数和脏状态；worker 仅原子标记，游戏线程按预算读取。读取块前后版本/批次 epoch 不一致则不接纳，后到通知再次使块待处理。完整扫描与动态维护替换同一块贡献，不采用扫描游标+delta。扫描结束后只处理实际脏块；关闭动态先断观察门，不进行附加 map cell 读取。

## 实施与验证顺序

1. 资产严格 codec/命令确认、完整文本边界与探索块算法，先建立独立期待和失败反例。
2. 原版变化 Hook、可见地图几何与共享悬停、会话/身份/退出接线；独立原版坐标锚点和真实写入入口验证。
3. F5 行、管理/详情窗、创建选择器、改名/删除/定位及输入尾缘；保留相邻 Notes、死亡、快捷键消费者。
4. 正规工作量分组、完整 Profile、隔离持久化/安装恢复、全量 Debug/Release 与必要图形检查；记录 2000 次实际观察成本和有限负对照。
5. 独立审查、修复、固定 clean 候选、重复构建/完整包、安全安装。交付后停止，不合并。

正确性和额外成本分别报告。默认动态关闭不替代正确性。地图像素、真实 IME/焦点和多人体验不得由纯数学/合成输入证据冒称验收。所有测试只使用隔离数据。
