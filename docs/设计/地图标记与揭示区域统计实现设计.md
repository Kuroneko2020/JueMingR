# 地图标记与揭示区域统计实现设计

- 状态：#85 实现候选的设计与本地证据，未代表所有者接受完成。
- 上位：[行为合同](../功能介绍/地图标记与揭示区域统计行为合同.md)。单一实施者在普通分支开发，只读代理核对证据与独立审查。

## 原版证据与坐标

锁定 Terraria 1.4.5.8，MVID `2c29f6c3-4bd9-4add-9c58-da159804e083`，SHA-256 `960A03BFF6050CF7BE16DFC1A7B19E10FC2C4F8F835A6A3B135A50DD9E6BA2F3`。定向反编译当前二进制，不以旧版参考替代。

`MapOverlayDrawContext` 的正向关系为 `(q-mapPosition)*mapScale+mapOffset`；`Main.DrawMap` 原版 ping 是独立逆向依据。全屏 `MapIcons.Draw` 已含 `-10*mapScale` 偏移，不能重复补偿；死亡专用 Y 修正只属于死亡点。图标源中心与 drawScale 不改变保存坐标。

键盘/滚轮可在 Update 改变视图，鼠标拖图和最终夹紧却发生于 DrawMap。因此只在成功完整 Draw 后发布实际可见几何；新右键输入立即以该几何和同次原版 `PlayerInput.MouseX/Y` 热点冻结 q。后续绘制只投影固定 q，不在未来帧重采样。无 Draw 的多个 Update 不使仍在屏幕的几何任意过期；会话、视口、设备、地图关闭与异常使其失效。

## 职责与存储

`Features/MapMarkers` 独占不可变资产、严格编解码、命令确认和编辑状态；复用 `DocumentWorker` 逐命令提交及 `AtomicFileDocument` 的身份/恢复保护。可靠角色×世界身份复用现有死亡记录的路径 local/cloud＋世界 GUID 摘要边界，不改变旧档案键。没有可靠身份不创建公共 unknown 文件。

`Features/Exploration` 独占完整扫描/动态块计数、状态发布及摘要。后台只处理冻结文档，不访问活动 `Main.Map`。相对于安装目录的最终路径为：

- `JueMingRData/map-markers/<pair>.json`：`JueMingR.MapMarkers` version 1，pair、width、height、revision 和 records（稳定 32 位小写十六进制 ID、round-trip 连续 x/y、icon、name）。严格 4 MiB、4096 条资源护栏；正常新建 120 条，合法超量只读。未知字段、重复 ID、非有限/界外坐标和不匹配身份均保护原件。
- `JueMingRData/records/exploration/<pair>.json`：`JueMingR.Exploration` version 1 / algorithm 1，逻辑尺寸、完成计数和 UTC ticks；旧摘要只是历史完整覆盖结果，不能证明当前动态连续性。
- `JueMingRData/config/features/map-markers.json`、`exploration-dynamic.json`：分别使用自己的 bool codec/version 1，首次默认均为 false；不与资产或摘要合并。

原子文件保护复用正式、`.bak`、恢复材料和已读身份的现有规则。标记只有成功回执更新 Saved；操作期间的新草稿或 IME 仍由原编辑器保有，翻页/定位/关闭在必要保存成功后执行。未知提交停写，离会话失败单独保留并发出一次性中文提醒，不污染新世界文件状态。资产最多 8 个退休 worker、32 个失败身份；摘要退休 lease 总量 32、并发 worker 8，同 pair 串行。退出给全部地图存储共用 750 ms 等待预算。

宿主只提供当前地图、揭示读取、真实写入通知、生命周期与受控视角操作。地图绘制协调器共享几何和最高可见悬停结果；死亡和标记保持独立 owner。UI 不拥有保存事实，输入复用 HostInputState 的唯一真实采样、焦点与尾缘；文本使用现有完整文本元素规则与 IME lease。

## 揭示变化与并发

当前 `WorldMap.IsRevealed` 是 `Light>0`，没有可复用聚合计数。`LightingEngine.ExportToMiniMap` 在 `FastParallel.For` worker 中写图；调用方等待所有 worker 完成。`Netplay.InnerClientLoop` 可在另一线程 Load，因此不能直接把所有写入当成游戏线程事件。

观察实际 store：Update/SetTile 的数组 Set，UpdateLighting 的成功 Set，私有 UpdateType 的 stobj。UpdateLighting 用现成新旧 Light 过滤 true→true；UpdateType 旧 Light 已大于零，只有新值为零影响揭示。Load/Clear/ClearEdges 以外层批次 epoch 失效，禁止逐格放大。`clearMap/refreshMap/loadMapLock` 都不是可靠数据写锁。

有限块数组保存版本、计数和脏状态；worker 仅原子标记，游戏线程按预算读取。读取块前后版本/批次 epoch 不一致则不接纳，后到通知再次使块待处理。完整扫描与动态维护替换同一块贡献，不采用扫描游标+delta。扫描结束后只处理实际脏块；关闭动态先断观察门，不进行附加 map cell 读取。

`Load` 必须按当前绑定地图失效：原版 Load 的接收对象可以是旧 A，但 MapHelper 的版本读取器写的是当前 `Main.Map` B。Clear/ClearEdges 则要求接收对象匹配。手动校准只在可靠动态底数及同 epoch 时保留旧块贡献；原版批次落在此决策边界时仍使连续性失效。暂停校准不暂停已有可靠动态，校准每批给脏块保留份额，避免持续探索被全图游标饿死。

## 预算与呈现

块为 64×64，边缘按逻辑尺寸裁切。性能模式完整扫描每 4 次更新最多 4096 格，快速每次最多 32768 格；无完整快速扫描时动态维护每次最多 4096 格，元数据访问最多 64 块。快速校准与动态共用 32768 格总上界，扫描末批剩余预算可用于多个脏块，不能各自叠加。按 60 updates/s，无暂停/冲突的 4200×1200 地图 1254 块、8400×2400 地图 5016 块，性能约 83.6/334.4 秒，快速约 2.6/10.5 秒；边缘填充导致实际格读取小于块容量。遇并发失效需重读，实际耗时不能按这一估算保证。

三个块数组有效负载分别为 20064/80256 字节，另有数组/owner 头；不复制整张地图，不建立逐格影子数组。动态关闭保留有限底数供历史展示，换会话解绑并释放地图和计数 owner。UI 最快 333 ms 发布，只在两位比例或状态变化时格式化；详情扫描文字按需格式化，隐藏时不准备；标量改变只改两段文字，不重建按钮和完整布局。首次未建立底数时不显示 0%。

摘要从首次未提交脏结果起 10 秒到期，连续变化不滑动延后；失败 1 秒间隔、最多 3 次，冲突/未确认立即停写，退出尝试提交末次可靠内容。摘要反映一次完整覆盖后已处理的贡献，并非跨线程瞬时全图快照。

地图页将统计值放在功能名右侧的固定槽内，动态文本不进入永久文字缓存；详情使用放大结果与同行扫描进度，下方一个框内等距排列扫描地图、扫描速度、动态更新三行，标签与控件列对齐；单个操作铺满控件列，成对操作等宽。管理窗最大逻辑宽 480、统计窗 320；关闭位于右上角，组内控件保留至少 6 像素内边距，正常逻辑高度约 268。统计页用“性能优先/快速完成”直述速度取舍，“动态更新”的用途说明只在悬停开关时通过既有 F5HintLayout 显示，稳定悬停不重复排版。管理窗 10 行一页，容量/每页数量在标题右侧，页码与翻页按钮位于固定底栏，空/单行收缩高度；短视口正文滚动。正文高度计入页脚间距后推导可见槽，正常高度不丢掉第十条或最后说明。两段统计标量更新保持原槽与字号，不重建按钮。旧“完整扫描已结束”及平铺动态开/关控件已退出。

名称使用 20 单位预算：恰为单个 ASCII 字符的完整文本元素占 1，其余完整元素占 2；不按 UTF-16 长度或字体像素测量。`MarkerName` 是编辑和 codec 的同一校验 owner，`TextEditBuffer` 仅提供可选候选校验，在原子提交草稿前调用；已有调用者保持原五参数及默认行为。旧合法 10 元素名称仍全部合法，不迁移 schema、不截断原件。边界、混排、组合字符与真实编辑/保存事务由地图资产及 Popup 检查覆盖。

八种 Item ID 为 8/48/50/224/171/393/966/29，原版资源只缓存八项，按资源/设备代次恢复；失败同代不反复加载，占位十字不改写样式。稳定绘制 O(M) 投影和命中、O(V) draw；悬停尺寸按名称与字体缓存。共享 `FullscreenMapDrawing` 每次原版图标阶段仍有一个小型 MapView 分配（含全关时），它提供死亡/标记的共同可见几何，不能把整体地图关闭开销表述为零。

## 验证入口与边界

`scripts/build.ps1` 及完整开发包选择 `map-host`，执行 `ArchitectureTests --map-markers-exploration`、实际 .8 `ExplorationCpu` 和 fixture `map-popup`；共享修改还带 Notes、死亡、输入、文件等现有组。`NativeMapDrawOracle` 用原版 Main.DrawMap 的 ping/MapIcons 参数流作独立锚点，显式拒绝旧鼠标缓存、floor+.5 等错误。`NativeExplorationBoundaries` 走真实 Load/Clear/UpdateType 及 LightingEngine 的 FastParallel worker，独立枚举当前地图对照。

`NativeExplorationCosts` 在小/大地图、未安装观察/动态关/动态开、详情关/开和六种实际原版更新模式中各走 2000 次 Host 更新。Debug 输出 Hook store、附加读取、块、UI/布局和提交数量；Release 走同一功能路径计时与当前线程分配，Debug 计数器编译移除。输出保留忽略目录，不进入产品。CPU 链计时不包含 GPU、Windows IME 或真实游玩；图形 `MapVisual` 使用实际 XNB/设备检查图标、管理窗、编辑、短窗口、占位和夹边选择器，图形结果也不等于所有者实机验收。

普通探针包含既有 Debug 专用消费者，因此探针本身保持 Debug 编译。Release 测量将该探针 EXE/config/PDB 复制到新建隔离输出目录，只放入同次 Release 的 Features/Platform/Infrastructure DLL，再以 `ExplorationRelease` 启动；它从 Release 正式输出加载 Host，断言 Features 中调试计数不存在。不能直接把整个历史探针按 Release 编译，也不能把 Debug DLL 带入这个测量目录。该范围只运行地图链，其余 Debug 专用测试方法不执行。所有时间测量均是普通 Release 生产 owner/Hook/Host 的同一链；探针只控制有限场景和外部时间，不安装到游戏。

## 有限成本记录（2026-09-17）

环境为 Windows / .NET Framework x86 / i7-11800H，16 逻辑线程，固定 Terraria 1.4.5.8。两次 Release 测量使用普通 Release 生产程序集，以下范围取两轮 8400×2400、详情关闭、各 2000 updates 的结果；每项包含实际原版方法、Hook、统计、Host/F5 prepare 及后台提交，未包含 GPU/文件 worker 的线程时间和分配。墙钟含正常系统波动，不能把某行较快解释为改善。

Debug 工作量另算：同 2000 个已揭示 Light store，Hook 薄门调用 2000；关闭后附加字段处理/脏通知/格读取均 0，开启后检查旧新 Light 但脏通知/格读取 0。同值 SetTile 与新揭示各 2000 store 通知，合并成 69 块重数、282624 格读取，元数据访问 124168（逐步最多 64）。普通变化全图重启 0；稳定形态比例/详情格式化及保存提交均 0。新揭示比例格式化 2 次、提交 2 次，其中测量窗口内收到确认 1 次，尾部另等最终确认并独立全量枚举。无证据时不把缺计数写成零，Release 表中工作量列为 NA。

当前线程分配：三组稳定场景各 360000 B/2000 步，这是完整旧功能 Host 共同基线；同值 SetTile 开启 360056 B，新揭示开启 362320 B。不包含后台线程分配。一次全图 Clear 原版本身约 17.5–29 ms，因此总量中的批次峰值不能全归因新增算法。完整性能扫描实际小/大图 5015/20063 次更新，单步 P95 25.9/25.6 微秒；快速 157/627 次更新，P95 434.8/235.7 微秒（包括 Host，其余变化关闭）。这些是有限设备测量，不是统一预算或实机 FPS 承诺。首次默认关闭沿授权的保守选择保留；当前未发现必须禁用动态的已证实正确性缺口。

本地原始记录留在 `.local/map-markers-exploration/native-cost-debug-06`、`native-cost-release-02/03`，真实资源预览在 `visual-04`；它们不纳入发布资产。正式回归也会在 build 的 checks 输出同类表。文件 worker 的持久化正确性、有限重试和退出保护另由门控存储/实际原子文件测试验证，不能由这一计时表代替。

## 实施与验证顺序

1. 资产严格 codec/命令确认、完整文本边界与探索块算法，先建立独立期待和失败反例。
2. 原版变化 Hook、可见地图几何与共享悬停、会话/身份/退出接线；独立原版坐标锚点和真实写入入口验证。
3. F5 行、管理/详情窗、创建选择器、改名/删除/定位及输入尾缘；保留相邻 Notes、死亡、快捷键消费者。
4. 正规工作量分组、完整 Profile、隔离持久化/安装恢复、全量 Debug/Release 与必要图形检查；记录 2000 次实际观察成本和有限负对照。
5. 独立审查、修复、固定 clean 候选、重复构建/完整包、安全安装。交付后停止，不合并。

正确性和额外成本分别报告。默认动态关闭不替代正确性。地图像素、真实 IME/焦点和多人体验不得由纯数学/合成输入证据冒称验收。所有测试只使用隔离数据。
