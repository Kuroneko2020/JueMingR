# 蓝图采集实现设计

## 范围与状态

本设计对应[行为合同](../功能介绍/蓝图采集行为合同.md)、[#134](https://github.com/Kuroneko2020/JueMingR/issues/134)／[Draft PR135](https://github.com/Kuroneko2020/JueMingR/pull/135)。第一步选区已接受进入 main，本批候选继续真实采集、固定预览和蓝图库；验收、包及安装身份以任务回执为准，不从设计推导实机通过或已合并。整体资格仍由 #7 承担。

Features 拥有坐标／采集纯语义、库领域格式和唯一后台 worker；Platform 仅机械文件端口，Infrastructure 实现局部 I/O，TerrariaHost 唯一读活世界及图形／输入适配。没有 Features→Infrastructure／Terraria 或 Infrastructure→Features 依赖，没有第二 Runtime。放置 plan／施工、材料、导入导出、instances 与未来框架不在本批。

## 坐标集合的纯边界

`JueMingR.Features/Blueprint/BlueprintSelection.cs` 不引用 Terraria、XNA 或其他 Feature，只处理坐标。它既不拥有采集模式，也不推进拖拽、输入和会话。Host 决定何时提交和清理，绘制只消费可见横段。

| 类型／入口 | 语义 |
| --- | --- |
| `BlueprintRectangle.FromEndpoints(startX,startY,endX,endY,worldWidth,worldHeight)` | 包含两端的格坐标先规范化，再与世界范围相交，结果为半开矩形；用 `long` 中间值避免 `Int32.MaxValue + 1` 溢出 |
| `BlueprintSelection.ToggleRectangle(...)` | 对规范化、裁剪后的矩形执行一次坐标 XOR，不查询世界内容 |
| `HasSelection`／`Clear()` | 常数时间判空；退出时清理当前集合，不为 UI 逐帧计数 |
| `EnumerateVisible(left,top,rightExclusive,bottomExclusive)` | 只返回视窗内 `BlueprintSpan(Y,Left,RightExclusive)`，不扩展为逐格数据 |

内部为 `Dictionary<int,List<BlueprintSpan>>`：Y 直接索引，行内横段有序、非空、不相交且不相邻；相邻片段合并，空行删除。完整实心矩形每行一个 span，存储随高度增长而不随面积建对象。没有人为格数 cap；当前世界有效范围仍是自然边界。无格数 UI，也不维护可能溢出的 Int32 面积。

一次提交只访问矩形覆盖的行。行内二分定位首个相交或相邻横段，重组该局部片段，再替换受影响范围；未受影响的行和列表不变。`List` 插入／删除可能移动该行后缀，成本随该行片段数而非矩形宽度增长；这不是对碎片数量或后续全部资产操作“无限成本”的承诺。

可见枚举直接逐视窗 Y 查字典，再二分第一个 `RightExclusive > viewLeft` 的片段，只返回 `Left < viewRight` 的横段并裁剪。稳态工作量为可见行查询、各命中行的二分和可见 span 输出；不遍历离屏全部选区，不按 span 宽度逐格铺块。枚举器是一次呈现的短期对象；同一游戏线程中查询期间不修改集合。

`DEBUG` 中仅保留有限工作量计数：提交行数、可见查询行数、命中 span 数和二分比较数；每次对应操作重新计数。正常 Release 不含这些属性，不新增日志、后台 worker 或永久观察系统。

| 成本责任 | 本步边界与证据 |
| --- | --- |
| 触发与规模 | XOR 仅在一次可信释放提交；完整矩形受当前世界高度约束，碎片受实际选区形状约束，无人为 cap。拖动稳态只更新两个端点及预览矩形。 |
| 突发工作 | 大矩形提交会访问覆盖的全部 Y，碎片行重组和列表移动有一次性成本；不以“每帧不可全扫”偷换成取消大范围选择。 |
| 稳态呈现 | 每次有效 Draw 只查询当前视窗 Y 和可见横段，横段按一块填充；无 Tile 内容读取、全世界快照或逐格对象。 |
| 生命周期 | 选区只驻当前会话内存，明确退出／会话离开清理；草稿取消不重建集合。关闭采集后不查询或绘制选区，必要的输入释放屏障独立收尾。 |
| 失败与并发 | 同一游戏线程推进集合，可信几何或 UI 归属不足取消草稿；不把失效证书重试成提交，不为选区创建并发 worker。 |
| 结论限制 | 纯 CPU 工作量断言与局部静态形态支持上述窄成本事实；没有 FPS、慢帧、全部世界碎片规模或真实多人性能合格结论。 |

## Host、输入与呈现责任

`HostBlueprint` 持有当前本机会话唯一的 `BlueprintCaptureState`。后者拥有 mode、draft、selection 和独立释放 tail 的纯状态推进；Host 负责真实会话、物理输入、原版消费者、UI 及偏好的适配。F5、快捷键与凝胶条读取投影并提交同一个动作，UI 不另存 mode／selection／drag。工具条只以当前可见矩形接入既有 UI 指针过滤及世界 hover 租约，不把采集 mode 接到 Shell 的整体指针归属；库与草稿的额外世界交互门仍由同一状态尾部机制承担。

| 当前职责 | 实际落点 |
| --- | --- |
| 会话与共享动作 | `Blueprint/HostBlueprint` 实现 `IRuntimeFeature`，在 Session 开始／结束收尾并核对 Runtime generation、本机 Player、世界及连接身份；`Toggle` 是 F5／绑定／条共用入口，`Save` 统一受理采集／固定草稿请求。 |
| 纯编辑状态 | `Features/Blueprint/BlueprintCaptureState` 独占进入／退出、草稿、中性等待和分键 tail；`Pointer` 只接受 Host 认证的样本，释放一次调用纯选区 XOR。 |
| 当前 UI 归属 | `Blueprint/BlueprintPointerProof` 绑定 mapping 与几何，观察 `DrawInterface`、MouseOver 边界、资源条和物品槽／热栏；只发布有界证据，下一次输入推进时消费一次。 |
| 精确世界门 | `Blueprint/BlueprintHooks` 在控制复制、tile 交互和 held ItemCheck 消费者门控；原版 UI raw input 不被全局清除，临时鼠标租约由 postfix／finalizer 幂等归还。 |
| 世界绘制 | `Blueprint/BlueprintWorldLayer` 复用现有世界几何 `TryView`，只消费可见 span 和裁剪后的草稿，不调用 Tile 内容读取。 |
| F5 投影 | `F5/BlueprintControls` 提供准确静态文案、行尾同一采集绑定和独立保存绑定；命令交给共享 Host，绑定和 F5／条保存共用同一请求。 |
| 凝胶条 | `Blueprint/BlueprintToolbar` 只持有两个按钮的布局、UI 手势及自身绘制资源；同文件 `BlueprintToolbarLayout` 提供真实布局和命中，不拥有编辑集合。 |
| 组合与公共接线 | `Phase0SLoadChainHost` 装配 Host 并接入现有最终输入、世界层及 F5 层；`F5Shell.AttachBlueprint` 接 owner，`F5Layout` 将 attached／active 纳入蓝图页失效键，`F5Renderer` 投影可用性及准确提示。 |

`BlueprintHooks` 的精确世界接缝包括 `TriggersSet.CopyInto/CopyIntoDuringChat`、`LookForTileInteractions`、`TileInteractionsUse`、`ItemCheck_ManageRightClickFeatures`、held scope 内的 `ItemCheck_TryStartUse`，以及直接读右键的 `dropItemCheck`、NPC hover、Void Lens、Money Trough 与 projectile despawn 分支。`Tools/ToolHooks.Before` 在已有组合入口防止新工具／Combat lease 注入，再在 held ItemCheck scope 保底。QuickHeal／QuickMana 共享 TryStartUse 的非 held 路径不被整方法禁止；这些有限接缝不代表全物品审计已做。

世界指针由最终输入阶段的物理点、相机、RenderZoom、重力及 viewport 冻结，再反解世界像素并 `floor(/16)` 得到 tile。输入不在 Draw、ItemCheck 或临时改写准星的 combat scope 中重新读取 `Main.MouseWorld`，不依赖 Combat 业务对象。几何、视距或有限性失效取消草稿，保留已提交集合。起点一直是世界 tile；相机正常移动可更新当前端点。

世界呈现复用 Game 层与世界矩阵，蓝色鼠标格、草稿矩形及选中 span 分别使用可辨识 alpha／描边；工具条使用 Terraria UI logical 域，raw 指针通过 UI 逆矩阵转入该域。世界与 UI 两种变换不得混用。绘制隐藏只改变呈现和草稿许可，不能销毁同世界 mode／selection。

鼠标格的只读绘制使用 `CanRetainEdit && HasPoint`，动作推进仍使用 `CanEdit`。原版允许没有 `DoUpdate_HandleInput` 的外层 Update 后继续 Draw；`BeginUpdate` 清掉的是本次动作许可，不是有效持续点。受控原版专项以没有草稿／已提交集合的生产世界层实际像素分别读取正常输入、空 Update 和连续 Draw，防止别的蓝色矩形遮住指针消失；同时断言 Mapping／中性屏障／草稿／集合没有被 Draw 推进。该显示修复不证明普通启动中左键拖选的首次拒绝原因。

raw 左右键及 UI 输入保持完整。世界动作语义门在原版消费者前作用于本机玩家的 useItem／useTile 请求及必要直读旁路；按键映射 Jump 等其他语义不受影响。临时鼠标值仅在精确世界消费者 scope 内借用并幂等归还，不包整个 Draw／UI，也不跳整个 ItemCheck。门控不恢复 `releaseUseItem`、channel、动画、计时或已发生投射物。

采集许可与 UI 当前归属分别判定。新按下／释放绑定同一映射几何与会话，UI 点击和 UI 拖物不能被世界选择重释；未知归属不默认空白。Draw 只发布当前 UI 占用证据，Update 一次推进与提交；重复 Draw、空 Update、远端玩家更新不提交 XOR 或证明物理释放。

冻结时要求 `CanStartActions`，Draw 认证时要求同一 mapping、raw 坐标、屏幕／缩放／矩阵／重力及 `CanRetainEdit`。后者核持续焦点与同一编辑条件，不再要求外层 Update 已清掉的新执行许可。旧实现将没有新 mapping 的空 Update 误判为失效：`CanStartActions=false → Matches=false → Consume.Pointer(false) → NeedsNeutral`，导致持续按住无法出现预览。实际原版对照中 1:1 输入／Draw 和资源回调原本可达；该对照不保证所有 JIT 状态下的小 wrapper 均可达。只有真实 Draw 完成的证书在紧邻下一 mapping 消费；无 Draw 的持续按住可保留已有草稿，遗漏按下不能由后续 hold 补成新按，未认证释放取消草稿，不迟到提交。失焦、显式 UI、几何不匹配或已到场但未完成的 UI pass 仍取消草稿。

凝胶条提示仅用 `F5HintLayout` 的换行／度量缓存，舍弃其面板绘制与 padding；按最后一行底部确定内容高度，逐行居中并扣回真实字形偏移。实际原版字体内部透明行已留可见描边间距，不再叠加旧面板高度、6 像素间距和 8 像素文字内边距。文字为 `#B8860B`，条本体和按钮保留，提示不参与命中。输入／UI 回归由显式 `BlueprintOriginal` 专项复用静音、独立 SavePath 的原版 Main 初始化夹具承担；它使用 `SkipAssemblyLoad`、简化 Update、受控窗口／焦点和输入提供者，并手动初始化 Runtime，保留原版输入映射／UI／Draw。不直接调用指针证书回调或强设成功位，不能代证普通加载、预 JIT 时序、OS 物理输入或本人体验。

普通故障有限轨迹已证明可信输入、可编辑门和几何匹配到达，但资源 wrapper 回调不达，松开无法解除中性屏障。单靠 MouseOver 边界返回不能排除原版 `ignoreErrors` 吞异常。定向反例先编译真实 `DrawMouseOver`，再正常安装 Host；真实资源原体成功返回、无异常，wrapper 仍零回调并重现中性屏障失败，支持调用方预先编译后绕过小 wrapper 的因果链。该 wrapper 从首个实现 `39322bd` 引入，前两次调度修复没有改它；旧原版专项跳过全程序集预热，并在 Host 安装后才首次准备此调用方，因而漏掉该顺序。

资源证明改在三个原版具体显示实现 `ClassicPlayerResourcesDisplaySet`、`FancyClassicPlayerResourcesDisplaySet`、`HorizontalBarsPlayerResourcesDisplaySet.TryToHover` 的正常返回处取得；六种原版样式由这三类承担。原版 interface dispatch 进入实际实现，回调仍要求当前 UI pass、边界、原体确实执行及冻结 raw／mapping／几何匹配。原体跳过或抛异常不供应证书。只在资源 UI 结束后读取其 UI 归属，后续掉落物／NPC 的世界悬停可以设置 `mouseText`，不能在整个 MouseOver 结束时把该值追认为 UI；不改 caller、JIT／优化、公共输入或唯一状态所有者。

一次性 v5 诊断已按本次用户运行导出停止，原源码／载荷／有限结果独立保全。本候选删除 recorder、字段／事件调用、额外边界返回 Hook 和编译选择器；普通产品不再包含本轮诊断入口。源码退出不表示机器已退出诊断安装：实际受控恢复、普通包身份和未验收项分别由同任务交付记录及 Issue 承担。

进入先建立模式与世界门，再让成功的 F5 开始动作关窗，启动手势先等可信释放；退出清集合并留下独立左右释放屏障。死亡、失焦、聊天、地图和 UI 接管只取消草稿；真实会话离开清 mode、selection 和 draft，仍按住的键只保留世界动作 tail。可信释放观察不依赖可编辑门，不能把门控后的 false 当成物理松开。细节和禁止结果以[生命周期合同](../功能介绍/蓝图采集行为合同.md#生命周期与独立释放)为准。

## 绑定、偏好与统一保存入口

`blueprint.capture` 是开始／退出的同一个稳定动作，`blueprint.save` 是独立保存请求动作；`blueprint.toolbar` 是凝胶条显示开关，`blueprint.library` 是打开图库的稳定动作。四个动作默认未绑定，注册在 `HotkeyBindings` Freeze 前，绑定编辑、冲突和可靠提交复用现有 `config/hotkeys.json`、`DocumentWorker` 与 `AtomicFileDocument`。F5、热键与凝胶条统一调用 HostBlueprint.Save；CanSave 复核已提交选区及当前在途状态，三入口均先采集、预览，再确认保存。图库三个入口共用 `HostBlueprint.OpenLibrary`，公共输入租约／新沿／模态门不绕过。凝胶条绑定与 F5 行都调用 `HostBlueprint.SetToolbar`，唯一偏好 owner 不变，不触及 `BlueprintCaptureState` 或世界动作门；按键状态反馈复用现有标准开关通道。

“手持凝胶显示快捷栏”默认 false，存于已验证游戏数据根下 `JueMingRData/config/features/blueprint.json`，格式为 `format: JueMingR.Blueprint`、`version: 1`、布尔 `gelToolbar`。`BlueprintPreferenceCodec` 只拥有该偏好语义，`HostBlueprint` 装配现有 `PreferenceDocument<bool>` 与 `AtomicFileDocument`，上限 65536 bytes；游戏回调只提交命令／轮询完成，编码和机械 I/O 交给已有文档 worker。

缺文件采用默认值，损坏、未知字段、未知版本、I/O 与冲突继续遵守[配置持久化设计](配置持久化与用户数据布局.md)的保护，不自动覆盖原件或切换数据根。安装不创建默认配置。mode、selection、draft 不进入偏好配置；资产格式与目录由下节独立合同承担，没有旧 Z 数据迁移。

工具条只有当前状态对应的两个按钮。`BlueprintToolbarLayout` 按字体实际度量计算底部居中面板，缓存由尺寸、UIScale、字体和 mode 变化失效；XOR 内容变化不要求重建 F5 布局。可见几何变更取消旧 armed 手势，真实左右尾部独立消费至可信释放。实际手持凝胶才显示，F5／聊天／地图接管时隐藏；隐藏条不改变采集门。保存／打开库接真实命令；不可执行时仍占有 UI 命中，保存保留准确悬停提示。

条复用 `UiSurface`、`F5ControlRenderer`、`UiTextMetrics` 与公共 `F5HintLayout` 的有界文字排版，再由 `CenterHint` 明确放到整条上方居中，以金色绘字；不直接沿用 F5 面板左锚位置。条自有 scissor rasterizer 并在退出释放，字体、InventoryBack 与 MagicPixel 纹理由 Terraria 拥有，条不释放借用资源；Draw 的 scissor／图形状态在 finally 中归还，不依赖已关闭 F5 后释放的 renderer 租约。

## 定向验证与证据边界

纯 CPU 入口 `BlueprintSelectionChecks.Check(IList<string>)` 使用两种独立判据：手算的分裂／合并／边界横段，以及有限小世界中每格被奇数个历史矩形包含的数学定义。后者不调用生产裁剪助手、不复制行 XOR 算法。覆盖单格、反方向、含端点、部分重叠、内含、相邻、重复两次、删空行、世界外和 Int32 极端端点。

规模检查用完整 8400×2400 范围及一行 Int32 最大宽度证明表示不受旧 16384 cap 限制；只通过 span 长度计算面积，不展开大集合。Debug 工作量断言分别核对完整矩形按高度提交、单格只改一行、窄视窗只查可见行，以及 4096 碎片行用二分跳过离屏前缀。Release 检查确认有限探针不存在。这些结论不等于游戏 Draw、帧时间或 FPS 测量。

Host 的释放、取消、UI 归属、原版消费者前后顺序、绑定和配置需由对应实际接线的窄检查承担；旧 `PageCompositionCpu`／`F5AutomationCpu` 不因名称相似自动覆盖本步。游戏画面、真实设备、30%／1000% 体验、真实好友联机与本人接受按实际执行记录，未执行不写 PASS。验证、独审、包和安装的动态回执留 [#132](https://github.com/Kuroneko2020/JueMingR/issues/132) 及对应 PR，本页不复制多轮流水。

`BlueprintOriginal` 现先显式准备真实 `DrawMouseOver`，随后才装配正常 Host。测试观察者只计真实资源返回／异常，不直接调用证明回调或赋成功位；覆盖六资源样式的世界拖放／XOR、实际资源 tooltip 与按住跨回世界、原体 skip／异常仍拒绝、实际掉落物世界 tooltip 仍可选，以及既有混合 Update／Draw、像素、原版 UI 和世界动作门。最终本轮绿色实际加载普通 Release 四模块，worker 同批复制但未启动；夹具仍使用 SkipAssemblyLoad、简化 Update、手动 Runtime 和受控焦点／窗口／输入，只覆盖明确 caller-first 顺序，不能代证完整普通预热／启动、OS 输入或用户接受。

## 固定采集、对象与流式暂存

BlueprintSelection.Freeze 复制已提交有序 spans 及单调 Revision，Contains 以二分查询，不展开世界 bbox。BlueprintCaptureState.ModeGeneration 每次 Enter／Exit 增长，避免退出重进相同几何与旧 token 碰撞。CaptureToken 为 operation/session/mode/selection revision，Host 同时绑定 runtime、player/world/connection、Main.tile 和 sectionManager 实例。

BlueprintCaptureSource.Read 在游戏线程先核 session、世界边界、数组及客户端 section.TileLoaded、原始 Tile 非 null，再复制 active/inActive、type/frame、半砖/斜坡、漆/隐形/全亮、wall、四色线、actuator、liquid amount/kind。无宿主残留属性不形成内容；不用 Framing.GetTileSafely（它会掩盖 unknown 且可能写 tile）。后台只接纯值，不持 Tile／Main／Player／TileObjectData／纹理或世界引用。

frame-important是绘制标志，不等于固定矩形对象。无TileObjectData的可读内容以原始CaptureCell／ObjectId=0保存已选快照；null Describe只表示无固定对象组，不表示无帧或可施工。固定对象沿锁定1.4.5.8元数据的尺寸、CoordinateWidth/Padding/Heights、FullWidth/Height、PaddingFix、StyleHorizontal/WrapLimit/Multiplier/LineSkip、SubTiles/Alternates解释；完整样式跨度包含PaddingFix，成员起始偏移不包含。闭门按PlaceDoor/CloseDoor逐行独立随机X槽归属同建筑style，原始X/Y保留，随机槽不充当alternate／方向；开门仍按自身宽度／方向网格证明。

Read完成section／Tile资格后，对同一个实际Tile调用原版GetTileData(Tile)，立即投影纯值；Describe只消费最近成功Read的投影，不新增隐藏活读。注册基准不能用GetTileData(type,0)替代：它可能直接选中改变尺寸的SubTiles[0]；按锁定原版整数重载的越表回注册基准语义取得根网格，再解实际style与形态，不提交放置请求。Alternates仍按固定ABI私有属性准确核验。原版GetStyle_Detritus／SmallPiles／Stalactite选择的是形态／附着Y区域，以对应原版生成规则解码区域起点而非全局取模（例如Y=90），不按类型名称列支持名单；未知selector保持准确未确认。未来放置不在本批，不能以其支撑／材料资格拒绝可靠的世界外观快照。

CaptureJob 对整件 footprint 每格过可靠读取门，按独立行高／列步进及同对象含义确认，再短重核 tile 语义；不要求子格 raw frame 相同。单对象证明临时数组最多 2047 格，超出或畸形元数据明确转未确认，不构成用户选区大小上限。没有全世界 mutation revision，不增加世界 hooks；固定起止 tick 表示各自读取时刻的快照，不声称跨帧事务原子。残缺／重核变化组可逐组排除，仅去其 tile 层，保同格已确认其它层。

对象首次完整封闭后输出整组（原选成员全层，框外只有 Tile），后续原选成员跳过，不生成同格分层重复记录。活动 footprint 去重索引随扫描行回收；回收与对象读取／构建都在 Advance 的时间预算内推进。库 Seal 对任何重复／冲突坐标直接拒绝，不用保首条／末条吞掉不一致。未知不能与空白混同。

游戏线程每次 Advance 起点预算 1024 次实际 tile read＋约 1ms，同时覆盖对象证明、去重／退役和 chunk 构建；时间是本地工作预算，不是 FPS 承诺。单块 cell＋对象记录至多2048，接收后数组封闭；单槽忙时不继续读。Host 最多一构建块＋一提交块，另有有界单对象证明临时值；不按 bbox dense 分配、不建全量 List<Cell>/byte[]，无16384选区cap。

BeginStage→AppendChunk→SealDraft 为一领域 worker，私有 stage 以 operation handle 持固定数据。每块排序，最多16路外部归并为规范 Y/X cell／对象ID流；每路驻一块，不以全量 HashSet 验证。规范正文跨块保持严格顺序与对象引用闭合，不把坏数据 sort-dedupe 成合法。Preview／Create 流式消费固定句柄；Create 按用户明确排除集过滤到新私有正文并重算 bounds/count，缺任何未排除未知组则拒绝；不重新读世界。正文保捕获 world 坐标，以 summary.Left/Top 作为相对原点，省去全内容改写。

CaptureFlow 由 Host 唯一拥有。Update 在 CanEdit=false／F5打开时仍推进已受理读取；世界／mode失效停止活读并精确丢弃可证明自有未发布 stage。Library Pump 在菜单期也收取独立回执；保存一旦受理，关闭 UI／换世界不假称撤回。Saved receipt 必须关联原始四字段 token；仅同 session/mode/selection revision 才清原选区，旧成功资产仍入库。OperationRetired与提交确定性独立：Append／Seal普通故障和Promote后明确metadata前提交失败终止旧operation、保护原材料并释放槽，Host去掉旧handle/summary重试资格、保选区。CommitUnconfirmed保护同ID，不能盲重试；槽退休后只允许用户显式新采集。迟到回执或旧handle不能取得新stage的token，也不能退休新Flow。

## 蓝图库格式、机械保护与生命周期

数据根由 composition 从已验证游戏根传入 `JueMingRData/blueprints/templates/`，FileBlueprintLibrary 构造不触盘；首个明确库命令取得 `.library.lock` 排他 lease。Features LibraryState/LibraryWorker 单命令／单结果槽；无命令等待，不轮询。每资产 ID 目录，名称不参与路径；metadata 唯一发布点，不重写全库。

| 文件 | 本批格式及边界 |
| --- | --- |
| metadata.json | 严格UTF8 JSON，format `JueMingR.BlueprintAsset`/v1；assetId/name/contentRevision/contentHash/width/height/contentCount/blockCount/missingSummary/createdTicks/updatedTicks/deleted；64KiB |
| content/root.bin | JMRB magic 0x42524D4A/v1；revision、blockCount、index SHA256、bounds／long count／未知组count／起止ticks／TargetVersion／有限缺失类别 |
| content/index.bin | 每块32字节SHA256顺序表，流式读取与验核 |
| content/chunks/D20.bin | JMBC magic 0x43424D4A/v1，至多2048条cell＋对象／1MiB；全层纯值、对象身份与具体原因，不存原版packed headers |

编码／解码严格核长度、count／bounds溢出、已知枚举、唯一记录／ID、路径和对象引用／可靠footprint，未来版本／未知字段／截断／外改及恢复材料保护原字节；单项坏项隔离，目录读取错误不同于空库。名称同 LibraryName：48个既有TextElements文字元素，拒首尾/空白/control/非法surrogate；沿既有每元素1024 UTF16上限和总UTF8≤32768资源边界，UI／领域／编码一致，无截断。允许同名但稳定ID不同。

正文先完整封闭／校验／Flush，再通过 AtomicFileDocument 原子提交小metadata并核验；仅此后 Saved。小metadata复用有界byte[]机械类型，大正文按块读写，不借其clone机制扩大为整量内存。改名只动单资产metadata，保持正文revision/hash和预览cache。未知提交保持同operationId和保护，不盲新建资产、回滚或自动恢复bak。

删除首先可靠提交 metadata.deleted=true，逻辑发布撤销确认后才移卡；随后每批最多32个精确拥有且hash匹配文件清理，不递归未知目录／链接／未来文件。清理失败或未知材料继续保护并明确 CleanupPending，已确认删除重启不复现。取消未保存draft仅后台释放当前operation可证明私有且未发布清单；提交中／未知／恢复材料不删除。安装更新恢复全部保留用户blueprints，不创建instances，不迁移Z。

## 图库呈现、文本与派生预览

BlueprintLibraryPresentation/Layout/Renderer/PreviewCache 在 F5 page6 普通图库保留42页头＋6gap、每页6项/2列/3行、166高卡、68高预览、8gap及同位置操作；保存采集是独立全宽工作区，不复用BuildCard，不改R外壳。页面只持页码／selected ID／编辑buffer／确认ID和GPUcache，不另持业务mode/selection/save。逐组未确认原因按需6组页流式提供，逐组排除/恢复和全排除都交Host；全排除时可恢复全部，不构造全量ID集合。

BlueprintPreviewBuilder 以全部固定内容投影到有限像素，普通图库最多512×128；Draft按已验证Stage用途最多1024×768且RGBA不超3MiB，四参普通builder不借Draft预算扩大；worker只生成uint像素值，图形线程上传Texture。请求尺寸来自最终实际图区的物理像素预算（逻辑231×58，150%时346×87），避免生成256宽再点采样缩小丢掉细线／远端单格。键为content hash/revision、排除集、renderer version、最终输出尺寸和device generation；改名／相机／稳定hover不扫正文或重建。12项且8MiB retained预算的LRU同时保存纹理与对应summary并同逐出，设备变化／UI退出释放自有纹理，原版共享资源只借用。失败key缓存同样有界；派生图失败不撤销可靠Saved。

图库文字以LinearClamp采样，按当前文字scale计算小字描边外扩；几何度量与实际外扩一致。摘要图单独PointClamp pass按最终像素呈现，不把文字和像素摘要混用同一采样策略；SpriteBatch／设备状态在finally归还。布局只在提交最终有效高度后ClampScroll并重新投影；加载临时空页保留上次有效高度，删除缩行／视口变大再夹紧，不让旧armed几何继续消费。

F5Shell 统一接 BeforeInput/ProcessInput/Prepare/Draw/Suspend/text-token；子菜单显示时静态三行控件退出绘制和命中，真实高度／scissor共用于绘制和命中，旧geometry取消armed。普通图库名称双击原位编辑，保存采集右侧名称框单击编辑，Enter不抢IME composition，首Esc取消编辑，后续Esc/返回离开；失败保同buffer和焦点，未知提交禁对应ID重试。库mode=false打开也经现有BlueprintCaptureState交互请求门拦世界动作，退出/失焦不伪造physical release；左右/key use tail继续由唯一状态观察中性退休，原版UI保持可用。

退休后名称框已隐藏且不租文本时，原本保留的受保护编辑buffer仍可由首个新Esc明确取消，释放尾缘被完整消费，后续独立Esc才返回；不借用他人的文本租约，不重试旧操作，不改变确定性反馈、选区或恢复材料。

名称输入的字符提交／原版租约由TextEditInput负责，组合串及caret由SingleLineEditView投影；图库renderer在当帧最终clip内依据冻结UI矩阵和当前UIScale提交可见caret的原版IME anchor（对应原版内部Y偏移），候选仍由Main.DrawIMEPanel绘制，不自绘候选或重复调用。自动模拟只证明组合刷新和anchor资格／几何，不代证真实Windows IME。

隐藏名称编辑仍在实际输入 postfix 向 TextEditInput.AfterSample 提交一次真实键盘样本。BeforeSample 已释放自有租约，但旧按住动作的 keyboardTail 只在聚焦的物理中性样本后退休；失焦、隐藏和切页不伪造释放，不清他人 WritingText／blockInput。原版 KeyboardInput 先按 WritingText 决定映射、UpdateInput 再清瞬时标志，故隐藏分支不能跳过该收尾。

本次世界投影任务替代旧范围外 Missing 提示合同：CaptureSource 不按类型生成负载缺失；Presentation 的卡片、选中底部、草稿与列表均不消费历史 Missing 文案。存储 v1 字段、Measure、metadata/root 一致性与坏文件保护原样保留；显示范围不改变旧资产完整性验证。

### 集中独审返修边界（#134）

对象 Direction 按锁定原版 `TileObjectDirection` 保存 0=None、1=PlaceLeft、2=PlaceRight；不使用玩家方向的 -1/1 口径。非法枚举拒绝；原版左右变体走完整采集→stage→Saved 检查。

原采集 Summary 保持固定，过滤后尺寸／数量／缺失只属于同排除key的派生预览。纹理和该Summary同存同逐出；无图像的空结果／失败摘要也按同key有界保存，零内容明确显示且禁保存。A→B→A缓存回访与旧A迟到不能改变当前B或固定草稿。UI统一单调read generation并只取消当前受理List／Objects／Preview；worker同样显式只认只读Kind，Create／Rename／Delete不受同数值代次影响。返回／翻页／改组合释放旧读，稳定Draw不重读。

## 专用保存采集页（本轮多实例修复）
