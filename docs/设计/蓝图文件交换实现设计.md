# 蓝图文件交换实现设计

对应[任务 #147](https://github.com/Kuroneko2020/JueMingR/issues/147)，用户结果归[蓝图采集行为合同](../功能介绍/蓝图采集行为合同.md)。本设计规定本任务接受的交换机制；源码、运行、候选及安装状态以任务与 PR 的实际证据为准，不由本文预签。

## 交换对象与身份

交换单位为单个 `.jmbp` 蓝图库原模板，携带原游戏内名称、root、index 与全部 chunk 原字节。实例镜像、trim、原点、世界进度、材料、配置和临时 UI 状态不属于文件。root 仍可能包含采集 bounds 与 ticks，不承诺移除全部坐标和时间。导入分配新本地 AssetId，保留 ContentRevision 与正文；不伪造 CaptureToken，不自动放置。

## v1 精确容器

整数均为小端，无对齐、无压缩；名称为严格无 BOM UTF-8，不能使用 BinaryWriter 的字符串前缀。字段顺序不可重排。

| 顺序 | 类型 | 字段与约束 |
| --- | --- | --- |
| 1 | 8 bytes | magic：`4A 4D 52 4A 4D 42 50 00`，即 ASCII JMRJMBP 后接零 |
| 2 | Int32 | ExchangeVersion，精确 1 |
| 3 | UInt32 | 名称字节数，1..32768 |
| 4 | bytes | 名称，通过当前 LibraryName 校验 |
| 5 | UInt32 | root 字节数，1..65536 |
| 6 | bytes | 原 root，现有 LibraryCodec 严格解码 |
| 7 | Int64 | index 字节数，精确 checked(root.BlockCount * 32L) |
| 8 | bytes | 原 index，SHA-256 等于 root.IndexHash，流式核验 |
| 9 | 重复 BlockCount 次 | UInt32 块长度（16..1048576）及该块原字节，块号由顺序确定 |
| 10 | 32 bytes | SHA-256，覆盖字段1—9的全部原字节及所有长度前缀 |
| 11 | EOF | footer 后必须立即结束，拒绝尾随与拼接 |

位置与剩余长度使用 checked Int64，先证明长度和每块最小剩余空间再分配；index 不按总长一次分配。现有 root/index/chunk hash、跨块顺序、引用、对象完整 footprint、bounds 与总数仍须全部成立，不能 Normalize 坏文件。目标版本精确匹配受支持 Terraria 身份。合法但仅可展示、尚不能自动施工的内容原样携带。

ContentHash 为 Base64(SHA256(root原字节))，与包含显示名的容器 FileDigest 不同；两者不是来源签名。仅在 incoming 完整健康后，用小 metadata 筛 hash 候选，再完整证明已有候选健康。坏项不能冒充重复；同名异正文共存。健康重复只定位已有项，不改其本地名称；允许校验 incoming 时短暂写自有私有 stage，但不产生第二个成品资产。

## 唯一 owner 与调度

Host 拥有 request/session/UI 资格；专用 STA 拥有原生 COM 窗口；按需唯一外部 I/O 执行者持选中的外部流；原 LibraryWorker 继续唯一写内部 stage 和 metadata。固定小容量 mailbox 和至多两个 64KiB 交接缓冲限制外部在途数据。LibraryWorker 等待外部 ack 时返回仲裁，投影、材料与已有施工 lane 必须继续获得机会，不在游戏线程或库线程 Wait/Join 外部调用。

交换受理槽与普通库命令槽分开。交换期间拒绝新采集 stage 和模板 Create/Rename/Delete；只读 List/Preview、已放置实例材料与移除继续。modal 只覆盖原生窗口与可信输入交接，不延长到整次慢 I/O。所有语义校验和健康候选复核沿可让步验证器推进；metadata lease 仅在最终小提交片内持有。

## 发布、导出与命名

导入从独立随机 stage 和新 AssetId 开始，完整原字节与语义验核后封闭正文，PromoteStage 只移动正文；可靠 metadata 提交是唯一可见发布点。Promote/metadata 未确认时保留稳定候选身份和恢复材料，不另建资产重试或盲清。完成或健康重复命中后，仅仍有效的请求/session/UI 意图在真实输入中性尾结束后自动打开图库并选中结果；后来的显式关闭、卡片/名称选择、翻页及新 session 撤销该待显示意图。失败和取消不自动打开，也不创建世界实例。

导出冻结 TemplateKey 与名称，核源身份及完整正文；目标同目录不可预测 CreateNew 候选完整写出、Flush 和流式 readback 后才发布。不存在目标用不覆盖 Move；覆盖必须来自本次原生明确确认且绑定目标对象 identity，复核后同卷 Replace 并保留本次唯一 backup。替换后核真实 backup 与正式目标；未知提交保护材料，禁止删除正式文件、猜失败重试或回滚。

默认名 `JM`＋本机本地 `MMdd`＋至少三位正日序号＋`.jmbp`，999 后自然增位。内部以完整年月日持久计数，跨目录共用；准备票据冻结日期与候选号，跨午夜不变更已显示建议。自动建议在实际目录避让同名文件和目录；观察到手改后本次保持手改模式，已有目标走 Windows 覆盖询问。取消与目标未成功不耗号。

小文档 `blueprints/exchange-state.json`（数据根相对路径）格式为 `{"format":"JueMingR.BlueprintExchangeState","version":1,"localDate":"yyyy-MM-dd","lastSequence":0}`。严格字段、有效日期及非负 Int64；缺失是首次，未来版本、损坏、外改与 Unknown 保护原件，不归零覆盖。文件可靠成功后才以原计数 identity 提交计数，两者不是跨目录原子事务。文件成功而计数失败必须报告文件已导出、编号未保存；进程内高水位不倒退，后续计数不能可靠读写时拒绝继续自动编号。

## 生命周期与证据边界

请求身份不借采集 token。窗口取消不写文件/计数；读写和验证在下一合作片取消；不可撤销提交开始后等待实际成功/失败/Unknown。UI关闭只退休展示资格；session变化取消未提交工作，不能将已发布事实说成撤销。退出不无限等待整张蓝图，超时不跨线程 Dispose 在途流或释放其数据根。来源原件和未知恢复材料保护，正常成功仅清本次可证明拥有的候选/backup。

格式向量、隔离文件、坏数据、去重、提交故障、阻塞外部流的 lane 公平性和生命周期分别验证。fake/CPU/受控 Host 证据不代签真实 COM、OS 回焦、普通完整加载、多人、FPS 或所有者体验。
