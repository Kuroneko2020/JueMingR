## 时序与有界成本

完成原版Main.Update后先开始当前NPC读取代次，再推进现有唯一Runtime/Session。需求先判：三项全关无本批取数；无accCritterGuide或hideInfo[11]隐藏不做稀有发现；无危险跳过装备分类。已选槽每Update O(1)复核引用/generation/type/netID和位置；发现单趟O(N)，首轮以15次更新为上限节奏，资格/会话/传送或目标失效及时触发重新发现。发现与跟踪不建立多份NPC堆快照，后来更优者正常替换。

| 规模/阶段 | 取数/缓存与失效 | 稳定与退出 |
| --- | --- | --- |
| N：本机NPC槽（最多Main.maxNPCs/实际数组） | 基础active/type/引用按槽当前Update复用；rarity/boss/住房各有需要才读；名字只为已选稀有对象读取 | 显名/摘要不依赖本批开关，也不让本批依赖它们；关闭仍保留其它消费者的必要工作 |
| P：当前晶塔 | 有旅商才进行有界元数据复核；直接比较必要类型/坐标，不每次重建集合；匹配晶塔即跳居民 | 相机/玩家移动不失效地点解释；目标位置跨阈值、列表/住房变化或迟到数据可刷新，未知不能称无 |
| E：最多10功能槽+5misc | 仅有危险时读一次有限有效槽，GetEffectiveArmor返回引用只读；已核无副作用，收藏共享有固定小范围冲突检查 | 按当前固定ID建立小问题集合，顺序/换槽无关；不构造全背包或多语言名字签名 |
| T：原版短命文字固定池 | 仅装备提醒可见期间，在Update准备阶段读附近活动PopupText/CombatText；优先用原版已存尺寸/有限缓存 | 只移动装备文字到稳定相邻垂直带，不改池或其它TTL；无提醒零占用扫描，极密场景不保证完全无重叠 |
| V：最多三项准备提示 | 内容/字号/字体/实际宽度变化才度量；整数距离不变不格式化，位置/Alpha只投影 | 三者局部故障隔离；Draw无NPC/住房/装备/I/O/时钟或召唤，不额外Begin/End |
| 单次召唤 | pending为空立即返回；正式按下/释放命令绑定Session与输入有效期，下一完成更新消费 | 最多一次原版调用；结果立即正常观察，不确认/异常不重试，不向方向注入坐标 |

装备危险用当前Boss类型集合和指定事件位表示，数组/多段顺序不构成变化；不增加距离/参战门。问题集合按type去重，真实新增/移除/替换重新提醒，全部清除立即撤销。176个ID依据锁定.8资源ItemName键与ItemID常量：75基础项＋102音乐盒族−重复576；Radio为5113的历史别名，2799机械标尺不能误用486，27个OW音乐盒不依赖显示名前缀。完整映射由固定表和原版消费双向验证，不从生产规则生成测试期待。

## 绘制、时钟与局部共存

以当前Game矩阵把玩家和目标变到物理视口，倒重力镜像锚点/指向而保持字形正立。圆周半径46物理像素，使用单一长度和单位方向；逆变换回借用Game层输入，禁止分别夹X/Y。近目标同时缩短半径与箭头图形，连尖端也不越过目标，零向量不画。屏外名字/距离在有限字框内省略/夹边，底边空间不足改放箭头上方；箭头不移到屏框边缘。旅商单独保留椭圆屏边三行，距离始终取玩家到当前目标。

装备采用Stopwatch单调秒数：从风险被观察到的时刻起3秒不透明、后0.25秒淡出。隐藏UI/地图/暂停不会冻结其现实单调寿命；暂停后首个有效Update即按时间更新，Draw不推进业务。关闭/纠正/危险消失/死亡/会话退出立即清本来源，暂停中不能凭没有新事实制造风险；其它通知不改变此时钟。

共存优先使用头顶上方稳定分层，必要时只把装备标签移到相邻空带；同一提醒保留已选带，确实冲突才迁移，避免每帧往返。读取原版池只提供几何，不取消/排队/重置任何来源；几何按原版未缩放半尺寸绘制原点，再处理旋转/缩放，不能直接把position当中心。正常默认字体/典型连续丢弃、重铸和战斗文字由真实Host/原资源代表检查；无限密集池容量及逐字符动态特效不承诺全部消除重叠。字体/语言/宽度变化使布局失效，失败测量不提交成功缓存键；显式重新开启可独立恢复，新会话重置失败反馈去重。

## 单次世界操作

请求仅来自杂项“召唤”正常按钮释放，不提供默认热键/开关。常显真实世界风险；页面状态使用廉价世界/玩家/时间信息，住房/NPC最终检查只在请求时进行。typed边界在执行前重查游戏线程、本地有效未死玩家、当前Session、输入未取消/失焦、netMode0、白天/非日食、准确入侵 `type>0 && delay==0 && size>0` 和无活动368（含hide）；NPC表不可读拒绝。

只调用一次已核public static void SpawnTravelNPC；它可能先改商品/随机状态再因无住所返回，因此结果分未调用拒绝、调用后已观察到、调用后未确认、异常及取消，不能回滚部分世界副作用或自动重试。方向从正式NPC观察发现结果。R不复制住房搜索，不强加自然到访上午/两居民/随机门，也不阻止晚间离开。Agent隔离测试不调用真实世界操作。

最终输入许可独立使用Shell当前的文本、地图/相机、模态与可见状态，不能只复用采样时的焦点布尔值：按钮释放后原版同帧仍可打开聊天。该门保留F5自身mouseInterface租约，避免合法点击被误拒；不收紧三个显示的0/1观察边界。取消请求被消费并退出，恢复输入不迟到执行。
