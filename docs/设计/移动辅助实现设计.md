# 移动辅助实现设计

行为依据见[移动辅助合同](../功能介绍/移动辅助行为合同.md)和 [#126](https://github.com/Kuroneko2020/JueMingR/issues/126)。采用既有 Features／Platform／TerrariaHost／Infrastructure 边界，不增加生产项目、外部依赖或通用调度平台。

## 唯一职责与生命周期

Features/Movement 提供不可变 MovementOptions、严格JSON codec、有限冲刺手势、Jump当前更新owner协议及有界传送候选排序。MovementSession唯一拥有进程级PreferenceDocument和真实玩家输入作用域；机械落盘沿既有AtomicFileDocument，后台不持Terraria对象。

MovementHooks独立Harmony owner在准确原版Main.DoUpdateInWorld_Inner范围内，仅允许真实本机Player.Update建立scope；孤立JumpMovement、远端玩家和预测克隆没有此资格。原版文本／地图／观战／其它实体接管之后、双方向归零之前唯一IL边界采集有限输入事实。保留原版双键归零，不改变普通水平移动。Frame／Mapping／Session与游戏线程标识用于freshness，持续意图版本仅随语义变化，不随普通新映射失效。

每次动作消费重新核HostInputState和F5真正文本／录键／模态／指针owner。F5可见不是movement barrier，背包可见不复用自动工具的粗禁令。Update finalizer关闭自己的scope并保留原异常；禁用、模式变化、失焦、死亡或Session退出撤销短期手势，已经消费的原版输入不回滚。

## Jump与预测

MovementJumpHost只在共享真实scope和当前许可下执行。JumpMovement前按当前一次持跳段与原版剩余能力补releaseJump；合法地面合成起跳仅临时借autoJump穿过原版justJumped资源刷新，不能补满资源。JumpMovement后才为后续原版火箭消费者提供rocketRelease，不在早于canRocket结算时错误拒绝。原版对false的消费保留，归还仅撤自身未消费贡献。

当前更新MovementJumpOwnership支持写入前更高防摔owner取得控制；本批没有防摔策略。飞行／悬停／条件飞行坐骑按准确原版能力族排除，不能把这一Jump边界提升为Dash禁令。

PredictionPlayerMotion携带AssistedJump及版本，SameSample统一对比；普通无装备持续连跳共享运动事实，预测以原版普通谓词独立推进并与真实轨迹比较，复杂装备保留其条件质量边界。输入阶段先撤销已失效意图，不能在真正Player.Update之前继续消费旧前提。NativePlayerMotion跨进程格式随实际字段升级协议，不兼容旧端明确拒绝。worker恢复的Profile在本次Predict有限线程scope绑定准确Player引用；后续Alignment再次Write、Conditional/TargetRectangle/ImpactState均从该次快照取得AssistedJump与默认重力，不重新读取接收端不存在的live Jump owner。Complex仍按本帧Mechanism与恢复的意图重新计算，不能冻结初始dashDelay派生结果。正常、异常、不同receiver嵌套退出归还先前scope；仍被外层占用的同receiver重入在清理前拒绝，外部live采样保持原出口。原有消费／续用资格继续复核当前运动状态，避免全局清缓存。

## Dash与局部输入归还

ContinuousDashGesture只保留左右沿、首击／最近按下、武装与短暂中性状态，同一Mapping只推进一次。18 Tick双击及2 Tick无方向宽容以实际Update计，禁用／切模式清手势。

ContinuousDashHost在DashMovement前只查看本轮最终dashType／冷却及原版坐骑许可；62—65的type6在原方法开头才赋值，前置可推算即将可用但不自行写能力。原生有效Dash输入先行，其消费不在后置回滚。真正借用时有玩家与调用owner，DoCommonDashHandle最小范围借左右位让选定方向到达实际读取，再立即归还；不把原版合法转向扳回，不跨后续普通移动。正常和异常finalizer均收回自己的贡献。

## Teleport

TeleportHooks验证唯一LimitPointToPlayerReachableArea后Vector2局部位置，在ApplyItemTime已发生的真实两杖分支直接修正目标；不借全局鼠标，不因itemTime已设置而错误拒绝。TeleportTargetSearch常驻有限只读偏移表，按距离／确定等距顺序遍历，合法原目标零候选，首个合法早停。完整框、可达域与350／87真实墙体语义由准确原版证据核定。helper异常保原局部目标，停止自身辅助且报告一次，原版使用和代价继续。

## 呈现、成本与验证路由

MovementControls投影唯一偏好owner，三标准行复用F5RowLayout／字体度量／裁切／Hint，模式变化使相关布局重建，Draw不拼提示。三个主开关使用现有公共绑键和真实生效短反馈，不增加常驻状态行。普通完整ContinuousProcessing组合创建偏好、业务与独立Hook owner，Session结束清瞬时状态，进程结束有限排空保存。

关闭／无需求只保留必要身份／许可分支，无装备／背包扫描、逐Tick反射发现、I/O、日志或请求队列。传送仅真实无效目标触发有界搜索；状态和资源无持续增长。工作量责任进入movement-host、CheckCatalog、原版scope与共享输入／存储传播，图形完整Main验证保持独立身份。配对测量同时比较关闭／开启闲置与等价原版人工动作，绑定实际动作分母、耗时分布和分配／GC，不能仅比较不动与持续动作或仅给平均FPS。

原始证据留本地，短证据入口位于review-materials/movement-assists-20261019/evidence.md；Issue记录实际候选／包／安装与未决项。普通包不夹带临时观察；包、同一目标安全换装、所有者普通启动与体验分层。
