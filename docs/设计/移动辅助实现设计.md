# 移动辅助实现设计

行为依据见[移动辅助合同](../功能介绍/移动辅助行为合同.md)，原三项接受状态见 [#126](https://github.com/Kuroneko2020/JueMingR/issues/126)，智能防摔候选见 [#130](https://github.com/Kuroneko2020/JueMingR/issues/130)。采用既有 Features／Platform／TerrariaHost／Infrastructure 边界，不增加生产项目、外部依赖或通用调度平台。

## 唯一职责与生命周期

Features/Movement 提供不可变 MovementOptions、严格JSON codec、有限冲刺手势、Jump当前更新owner协议及有界传送候选排序。MovementSession唯一拥有进程级PreferenceDocument和真实玩家输入作用域；机械落盘沿既有AtomicFileDocument，后台不持Terraria对象。

MovementHooks独立Harmony owner在准确原版Main.DoUpdateInWorld_Inner范围内，仅允许真实本机Player.Update建立scope；孤立JumpMovement、远端玩家和预测克隆没有此资格。原版文本／地图／观战／其它实体接管之后、双方向归零之前唯一IL边界采集有限输入事实。保留原版双键归零，不改变普通水平移动。Frame／Mapping／Session与游戏线程标识用于freshness，持续意图版本仅随语义变化，不随普通新映射失效。

每次动作消费重新核HostInputState和F5真正文本／录键／模态／指针owner。F5可见不是movement barrier，背包可见不复用自动工具的粗禁令。Update finalizer将原生异常事实沿唯一 Session 传给防摔收尾：异常的 Release 不算已完成等待，须撤旧输入／动作并请求精确还物，真实资源不回滚；最终器关闭自己的scope并保留原异常；禁用、模式变化、失焦、死亡或Session退出撤销短期手势，已经消费的原版输入不回滚。

MovementSession把上下文保留、新鲜映射观察与动作执行分开：唯一上下文谓词合并原版本地alive/non-ghost、Runtime会话、实体控制和现有输入owner，使用CanRetainIntent而不要求本epoch已映射；Observe只对CanStartActions成立且尚未观察的Mapping读取Jump/Down。空outer Update只做上下文核对，不采Triggers、不推进真实Player Tick或手势。Capture和所有原生动作仍严格匹配Frame/Mapping/Generation与CanStartActions；没有Capture只归还本次借用，真实上下文失效才撤销历史。意图绑定现有Runtime generation和准确Player引用，不改全局ItemSessionProbe、不新建会话探测器。

BeginUpdate先以有效Main.myPlayer、可用玩家数组槽位及精确Player引用识别当前本机，再进入既有scope重入和上下文核验。远端、同whoAmI异对象、空槽位或无效索引的调用无副作用退出；非本机调用不是本机上下文失效，不能清本机首击／武装、Jump意图／Held／Coast或推进版本。当前本机仍按原上下文谓词取消；对象与Runtime generation换代仍清历史。新增回归由真实输入采样、Dash／Jump原生消费者产生状态，直接调用生产BeginUpdate，比较该远端调用紧邻前后，不代签真实多人联网。

死亡可在Player.EndUpdate之后发生，下一次Player.Update又会经UpdateDead早退，故BeginUpdate拒绝失效本地玩家前必须局部取消，不能依赖Capture或全局Session退出。CancelJumpIntent只在JumpHost实际改变已发布意图／阶段时推进输入版本；重复取消幂等，冲刺开关／模式不改变Jump版本。JumpHost仍唯一发布Jump事实和阶段。

## Jump与预测

MovementJumpHost只在共享真实scope和当前许可下执行，唯一拥有None/Held/Coast阶段。Before登记合法起跳候选，紧邻After确认原版从jump<=0进入jump>0且逆重力运动才成为Held；不把外部上升或中途启用已有跳段登记为本功能动作。Coast登记尚未追加下一离散边沿；BeforeJump选择本更新唯一有效Jump，AfterJump仅观察阶段，不在同更新把按住改为松开。最后1→0持跳更新对Carpet／wing／boot／两处后置hover保持同一按住输入。已重武装额外跳仍遵守原版消费者优先，不以持续飞行为由提前制造离散边沿。

Coast在原版持续消费者有实际机会时保持真实长按。判断只读有限当前Player字段：翼时和实际wing/jump/velocity条件、毯的额外跳／资源／坐骑资格，以及靴的rocketRelease／fuel／delay／CanUseBootFlyingAbilities和稍后真实canRocket速度门。反重力持翼保留原版绝对velocity.Y>0和三分之一重力分支，不把“有翼”概括为可飞。实际WingMovement完成立即退休旧阶段；毯或靴实际接管在scope收尾退休，退休不在同更新改mask。没有合法持续接管的Coast继续有效松开，直到沿重力速度非负再允许下一离散边沿。撤销观察仅核现有主线程、真实scope和Player实例，不用CanAct新动作门阻拦已发生事实；同一Harmony owner承担安装与整体回滚。

有效Jump只过滤固定原生读取，不写controlJump、不恢复输入快照。安装时严格核JumpMovement一处、CarpetMovement两处、Player.Update的JumpMovement之后至GrabItems之前八处读取（含后段hover）；读值过滤保留原分支、算术、标签与异常块，不匹配即撤回本功能整套补丁。scope外、克隆、远端、无当前可信许可及原本false输入均不被赋予动作。原版翼靴燃料换算继续执行，不能为尾段冻结资源。

尚未重武装的离散或靴请求先完成整更新释放，之后才press；已有release或原生autoJump资格不强塞等待。连跳不临借releaseJump／rocketRelease／autoJump，没有恢复这些字段的账本；原版false输入产生的release与自然资源恢复保留，scope末尾只归还mask，不恢复原版字段。共享普通scalar与冻结Native Step同样模拟“未重武装先完整释放，后续合法按下”；其已支持普通子集中的Coast仍表示整更新释放，复杂持续接管保持原有条件边界，不扩建翼靴毯预测。空翼反重力的绝对正Y三分之一重力不是普通held前缀，AssistedOrdinarySpan明确拒绝该前缀；现有阶段／意图／版本和wire身份保持。

当前更新MovementJumpOwnership支持写入前更高防摔owner取得控制；G13 SmartFallHost在同一真实scope于连跳写入前预约。飞行／悬停／条件飞行坐骑按准确原版能力族排除，不能把这一Jump边界提升为Dash禁令。

防摔的Jump接点是同一真实Update内、BeforeJump写入前的ReserveFallProtection；TryAcquire在Written后拒绝换owner。Cancel仅撤回模拟连跳贡献，不能撤销高优先权预约；原版资源仍归原版消费者。真实抓钩接管后撤销连跳贡献，保留真实controlJump供原版手动解钩。

G13独立拥有危险判断、策略、获救结果与恢复，按真实需要作有限落点判断，并复用现有事实、几何和窄输入／装备所有权；辅助瞄准的完整长时域预测不是前置。G14模板编辑／投影与G15材料／世界施工分别验收；防摔、钓鱼、工具仅在真实资源争用处共享有限所有权，不预建总线、总队列、第二套原版物理或全装备组合矩阵。

## 智能防摔阶段与借用接缝

G13原开发原件为 `references/归档文件/JMR_SMART_FALL_PROTECTION_20261021_v1/`，五项修复原件为 `references/JMR_SMART_FALL_REPAIR_20261022_v1/`；进展和权限回到 [#130](https://github.com/Kuroneko2020/JueMingR/issues/130)。MovementOptions增加SmartFallProtectionOptions，沿原version1严格JSON增加可缺省的smartFallProtection对象；旧文件主OFF、十二许可true。临时动作和恢复不进入配置。

MovementSession仍唯一掌握真实本机Player、Runtime generation、线程、映射scope与偏好。SmartFallHost独立拥有风险、联合时机、动作及能力特定成功／收尾，只有它消费SmartFallBorrowOwner。仅防摔开启也建立Jump预约scope；关闭／失焦但有借用时允许同一准确对象最小收尾，不赋予新动作许可。远端／克隆先拒绝，不得清本机借用；生命周期结束撤销旧对象写资格。

固定原生接点由MovementHooks同一Harmony owner安装并有限ABI核对：原版输入完成后Capture；UpdateEquips后观察真实装备结算；JumpMovement前先防摔预约、后连跳；Jump／Wing后观察真实作用；唯一WOFTongue之后、整个controlHook/releaseHook分支之前发动所选钩；GrappleMovement之后确认真实保护；ItemCheck的operation／entered和异常finalizer归还选槽／输入；PickItemSelectionOverride、TrySyncingInput及真实SelectedItemState.Select维护实际选择锚点。ItemCheckWrapped仍在真实Player.Update内部、碰撞之后，杖和持伞须赶上前一有效更新。TeleportHooks仅在准确原生两杖局部Vector2优先应用本次防摔目标，不借全局鼠标，不要求传送修正开关开启。

时机按原生前置与首次接触决定，不能拿较晚Hurt检查当作触底后仍可救援的许可。火箭首次点火尚未通用重置fallStart，精灵腿的慢落也需下一早段天然重置；飞行坐骑新frame尚未进入空中，须等PlayerFrame后真实Hover再在平台标志计算前收骑。免摔坐骑的CanMount会检查加上velocity后的合法空间，必须保住这个更早的前置窗口；关闭／失焦不得拿自己骑乘带来的免摔当作可以提前卸骑的证据。二段跳以静态族映射匹配仍生效的原版 unused；临借只改变真实装备，不产生资格。

### 原版资源与合法输入阶段

移动自动操作统一遵循[原版合法操作与 TAS 可达原则](../规范/Legacy平替与行为契约规则.md#原版合法操作与tas可达原则)。同版本、模式、初态和既有资源下须存在合法输入／交互序列；可用理想精准时序，不能伪造原版 release、授予资源或跳过必要阶段。调用原版方法仍须核对应消费者与前置条件。

本节依据所有者 `JMR_SMART_FALL_VANILLA_ACTION_FIX_20261022_v1`，明确撤销旧社交包的受控授予解释。删除 SmartFallResourceCycle、RefreshDoubleJumps 专属 observer、OFF 消费观察、AllowsActivation／OriginalResources 及资源写入／撤回。原生消费者独自管理 unused jump、rocketTime、canCarpet／carpetTime，取消和精确还物不恢复或清除这些历史事实。

来源缓存只保留匹配真实 unused 的二跳端点、有真实燃料／原生 empressBrooch 恢复的火箭端点，及 canCarpet 或残余 carpetTime 的飞毯端点。固定 NativeMask 另携带火箭／飞毯 readiness 布尔变化，即使来源暂未功能装备也能使稳定无解缓存重核一次；燃料每步倒计时、release 字段与动作阶段不使库存缓存逐帧失效。无资源普通瓶不会临借；马掌组合仍可由被动族取得，零翼时仍保留 hasWings 的原生免摔。

防摔 BeforeJump 在真实下降且无活动 jump tail 时预留共享 owner。需要重武装时 ReserveFallInput 标记有效 Release，JumpMovement／CarpetMovement 及 Update 后置翼靴的既有十一处读取持续过滤到本更新结束；不在 AfterJump 还原 held=true，不写任何 release 字段。原版松开分支自行 rearm，下一次正常许可的 BeforeJump 再 Press。动作计入必要的一更新准备延迟，已 rearm 直接 Press；pending 只推进已选动作，不重新扫描来源或地形。关闭／权限取消在尚未消费时结束准备、归还物品和自己的输入；真实已用资源不回滚。

Up 首次 Press 后至少一次完整正常更新不借 Up，由原版 UpdateControlHolds 重武装 releaseUp，随后合法 Press 返回。真实手动 Up 在首次 Press 准备期及翻转后均结束旧动作，不能把玩家的原生翻转认作辅助成功并安排返回；强制重力、装备／配装及输入权限变化使旧恢复意图退出；已回到原重力只结束，不追加翻转。未采用可选的归还球自然恢复优化。

原坐骑在借入前记录真实原物与选择锚点；精确还物完成后，重新核准确当前 Player／epoch 的 CanAct、CCed／tongued／dead／noItems／重力、当前真实原物及选择，再调用一次 QuickMount。原生 ItemCheck_TryStartUse、CanMount 及其它使用拒绝继续有效，实际 mount 结果才是恢复；拒绝不以位置／revision 无界重试。默认／实际矿车只沿原物身份仍在、普通 QuickMount 来源为空时的原生 QuickMinecart rail fallback，不直接制造类型。手动选择、原物变化或新坐骑退休旧意图，之后下马也不复活。

救援临时 ownedMount 的解除与上述原坐骑重新启动分别拥有状态。首次退骑仍在当前及时接点直接 TryDismount；真实失败后才保留 pending，并以 MovementSession 从真实本机 Player.Update 传入的 tick 去重，同更新的 Capture／BeforeGrapple／Protected 收尾入口合计至多一次额外 CanDismount 观察。空间变化和 CCed 不由位置／库存 Revision 代表；仅原版 DontDismountWhenCCed 集合内且实际 CCed 时可直接等待，其余按原版20×42变形空间资格。观察拒绝不做 TryDismount、不扫背包、不重跑 Contact，资格通过才再做一次真实动作。关闭主开关保留这份收尾责任；成功、手动换骑、死亡、世代结束及新救援清 pending 和 tick。原坐骑的一次性恢复拒绝仍永久退休，不被此观察唤醒。

额外原版资格调用会经过 Collision.SlopeCollision／TileCollision。局部保存 stair、stairFall、sloping、up、down 并在 finally 归还五个 scratch；真正 TryDismount 的全部原生副作用保留。原生可能为 null 邻格创建 Tile，不回删、不复制空间算法或建立 tile 缓存；正常已实例化局部格的工作量与无待收尾路径分别验证，不声称绝对零分配。

真实 Item 借入／逆还与正反向 CanSwap 及 native-use guard lease 保持；逆还互斥冲突保原物、favorite 和玩家新装备，按 TakenOver 结束。合法社交翼、马掌组合、重力球与神灯腿12→2继续分别经过原版消费者。

物品hint来自既有ItemHostObservation真实变更／Invalidate和原生物品获取、已有槽修改事件，读取Revision不扫描。GetItem仅以调用前数量和原版返回的未接收余量确认真实取得；满包或uniqueStack拒收而原量返回不推进hint，不为这项通知另扫背包。防摔不为OFF或安全闲置请求库存采样。ItemOperationOwnership只窄加防摔真实inventory／armor／misc端点，钓鱼已占端点依原journal窄协调，不复制钓鱼平台。借用记录在第一写前建立，恢复以准确引用和当前owner为准；用户接管不被旧快照覆盖。无进展恢复只在实际机会变化时做有限重试。

手动槽事件仅在真实鼠标／手柄命令edge观察该槽和cursor两个对象，前后实际引用／type／stack／prefix／favorite变化才推进hint，hover不采样；真实配装切换另以准确本机成功事件通知。能力缓存同时核十二许可、原生资源及只读准备事实。GetPreparation与实际TryBorrow共享准确身份、已装／需借区分、原生忙碌／选择／锁及真实端点门，不取得token或写Item；noItems的物品使用限制不提升为已装合法Jump的统一禁令。候选干扰消费实际借还写入、当前热栏源、替换／钓鱼端点、选择、输入、原生资源、短期轨迹及混沌代价，不以每族固定排序代替完整可用方案。钩来源在真实物品变化后有限缓存，分别用原版射速、子更新、射程与离散附着阶段判断及时性，不用名义shootSpeed预先剔除其它来源。同一次候选搜索内，shoot与shootSpeed完全相同的原生飞行参数共享成功／失败几何结果，不跨更新缓存世界几何；各真实端点仍独立核准备与干扰，最后计划重绑选中Item引用，不能把代表物品借给另一端点。

接触缓存保留本次有限脚部／迎面走廊实际读过的格，包括原来为空的格；后续只重读尚未越过的该带碰撞事实，不只核旧命中格，变化当次有限重探。无关世界格不属于缓存输入，不依赖全局地形扫描或全世界变更总线。无进展拒绝位不因自身逆还推进Revision重开；只读阻塞stamp按真实busy／buffer等布尔门变化而非倒计时每步推进，机会解除才重核准备。原生QuickGrapple自身容量循环中记录的有限旧钩key用于观察其自然退休／状态变化，不额外逐帧扫描弹幕池。稳定不变时不重复来源扫描、规划或动作；不通过陈旧来源或永久锁死后续合法机会换低成本。

Contact 末尾可选 horizon 默认仍48，主预测及接触带沿原视野；OppositeClear 只消费前两 tick 是否接触，显式取2，继续复用完整宽度、方向、斜坡、半砖与子步算法，恰好 Ticks==2 仍拒绝。Debug OppositeTileReads 单列反向访问，性能分母来自危险 Capture、有球但尚未 Due 的真实重复候选路径；Plans 仅计主 Contact，不能代替反向查询成本，也不能据局部访问量宣称整体倍速或 FPS。

BorrowOwner只在当前inventory0–49、当前社交装备10–19取得来源，功能装备沿原版有效投影读能力，不从银行或非当前配装取物。有限inventory／armor／misc端点owner先于写入；原版IOLock只TryEnter，不阻塞保存线程。两端交换实际Item引用，沿既有原版槽资格检查，收藏在装备语境按共享标志处理，逆还恢复原物意图。若钓鱼实际同格，保留A→F journal，先S→F，再由钓鱼当前意图决定F→A。
