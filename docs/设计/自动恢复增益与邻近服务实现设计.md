## 所有者与职责

`Features/Recovery` 拥有纯选药、互斥/需求、有限失败准入及不可变设置；`TerrariaHost/Recovery` 分恢复品、手动跟随、家具、NPC服务和呈现适配，不把业务扩回 Runtime。现有 `Phase0SLoadChainHost` 只装配，在同一个 Runtime/Session 和合法游戏线程更新；公共输入与公共快捷键继续唯一所有。

恢复使用不选槽、不搬药、不清输入；保留真实 Item 数组/引用/槽与会话世代。`ItemOperationOwnership` 窄扩账户与槽域，消费和护士按真实写集认领；最终原版入口仍核验，不用一个 AutomaticOperation 布尔绕开所有保护。异常不回填数量或 Item 快照。自动使用与手动学习作用域明确区分。

药品、增益设置和 NPC/家具开关按自然域保存，沿用 `DocumentWorker` / `AtomicFileDocument`。新许可只在可靠提交后生效；关闭/移除在待保存期间先阻止旧资格。每域一个在途请求，有界排队/重试，不保存原版对象到 worker，不新建数据库或执行框架。

护士报价只临时替换本次购物条件，后来的手动对话优先；真正 BuyItem 前再次核对目标、许可与实际账户。CoinsCombineStacks 有付款能力上限，扣款确认使用五账户未截断总额，避免巨额合法金币被误判为未确认。未知扣款保护当次钱币及可写空槽；银行的移动、拾取、排序与合并也按真实写集让路，不全局禁用无关银行。

药品由 `PotionConfigurationPopup` 独占浮层几何和物理点击尾部，F5 提前声明指针所有权，主页面不插入网格；标题与许可说明按字体度量同排、大叉号关闭；缩放/字体/许可变化撤销旧捕获，失焦/离页关闭。增益名单默认在主视口左右两栏显示，隐藏展开/收起按钮但保留其 handler；刷新在左栏标题，跟随加/删在右栏清空左侧。只有独立药品副窗沿用文字租约，内联名单不取得键盘权限。可见页按有界 30 Update 库存观察刷新两栏和勾叉，离页或界面关闭不扫描；功能关闭但名单可见时仍显示真实库存。`RecoveryCatalog.StockReads` 只在 DEBUG 统计实际槽读取，稳定绘制零读取、300 Update 至多十次 98 槽、关闭界面零读取进入正常回归。库存变化只更新投影，不写持久名单。关闭与缺货叉号复用 `ItemsRenderer.Cross` 纯线条符号，无黑底，不依赖字体叉号字形。

自动增益有专属后台准入：共享原有游戏/UI 安全门，仅在后台跳过焦点、手势资格及陈旧 mouseInterface；前台仍走原准入。`HostRecovery.Update` 和 `BuffRecovery.Use` 共同使用此出口，后台只执行增益叶子。不修改 `HostInputState`、其它自动功能和 Runtime 会话身份，不产生后台线程/输入/合成 Tick。原版继续实际更新才有增益；未知槽位、手持钓竿/材料占用、真实冷却/消费及结果不明不重放继续成立。

税收结果未确认属于玩家同一税款周期，不属于某个 NPC。增长、换目标和开关不解除；观察到原版税额归零才结束该周期，包括原版已归零但后续 UI 抛异常的当场观察。没有自造逐次服务器 ACK。

## 生命周期与性能卡

| 域 | 触发及规模 | 稳定/关闭成本和退休 |
| --- | --- | --- |
| 恢复 | 合法本地玩家每更新先检查缺口/费用/原版冷却，再有限主包58+虚空40候选 | OFF 无扫描；同次真实喝药防重复；未知来源保护至明确身份变化，不靠开关洗白。 |
| 目录 | 主动打开/重试时按 ItemID.Count 完整定义一次，actual type 去重 | Draw 不 SetDefaults；失败不缓存为空，不后台每帧重试。 |
| 增益 | 非空名单且有效开关时先查现有 Buff 后来源；稳定/无库存每30 Tick复查，许可变化立即失效 | 单项失败记录有界，以真实物品/效果/配置变化恢复；已知暂时 potionDelay/沉默在调用前拒绝，不污染失败缓存。空名单/OFF不扫库存。 |
| 跟随 | 真实手动使用/取消入口且对应跟随开启 | 早退不扫描；局部前后态只覆盖一次动作，不追踪自然消失。 |
| 家具 | 缺七种效果时每30 Tick扫描有限交互区域，缓存最近候选；移动立即重扫 | 已有全部效果不查 Tile；同位置完整循环后间隔复查，移动/修改候选重验。会话退役清候选。 |
| NPC | 有治疗需求/正税款才有限发现；已知目标直接复核 | 无钱观察支付能力而不点击；失败/未知不循环；真实身份变化退休，临时 unavailable 不等于新会话。 |

动作前重读与持续施法及时性不能用极长轮询换取计数低。工作量计数仅 DEBUG 检查；无生产常驻探针、签名字串或普通状态日志。共享冲突按合同优先，独立分支继续。

## 实施与验证入口

纯策略与存储检查由 `tests/Recovery/` 及架构检查入口承担；`tests/NativeWorldTextProbe/NativeRecovery*Checks.cs` 覆盖真实恢复与持续施法、跟随事件、家具作用域、护士/税收、来源占用、输入/UI、后台增益及有界工作量，相邻输入/物品/存钱沿正规路由回归。开发交付的独立审查、固定 clean head 双轮完整包与安全安装记录保留原身份，接受收口复用范围匹配的有效证据，不重新构建、打包或改写安装回执。

纯策略验证全部合同表，不用 fake 效果冒充原版消费。受控原版测试在独立临时目录与合成玩家/世界数组中执行，禁止读写真实存档或消费真实物品；保留原施法/鼠标状态测试。界面检查真实字体与主窗布局，普通状态不变高。实际网络只在已授权拓扑验证，源码同步路径与隔离 netMode1 不等于联机通过。

正常 build/workload 入口已接入 recovery 局部组；共享输入/F5/文件/物品占用改动扩选真实消费者，保留 About 局部组。验证实际执行组而非只登记名字。安装、包、源、验证身份分别记在 Issue/PR，技术文档只保留可维护事实，不写会话流水。
