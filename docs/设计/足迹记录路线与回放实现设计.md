# 足迹记录、路线与回放实现设计

本设计服务 [#87](https://github.com/Kuroneko2020/JueMingR/issues/87) 的[行为合同](../功能介绍/足迹记录路线与回放行为合同.md)。采用现有六项目、net472/x86/C#7.3、固定原版 1.4.5.8 与现有 Harmony/文件/UI 能力；不引入依赖、通用数据库或第二套 Runtime。以下是本次授权内的实施设计，不代表测试或验收已完成。

## 方案与职责

选择“顺序编号不可变块＋有限尾部＋小根提交”，而不是每次保存整史 JSON，也不为单项能力引入数据库。每块固定最多 256 条，封存后不改；块数与时间摘要放小根，不在内存维护全史索引。通过块编号直接寻址、按块首尾时间二分查询，驻留成本不随磁盘总点数增长。块内部保存完整样本和停留时间，不做几何抽稀。

| 位置 | 职责 |
| --- | --- |
| `Platform/Footprints` | 无宿主的样本、有限批次/查询结果与窄机械文件端口 |
| `Features/Footprints/FootprintRecorder` | 游戏线程有限活动批次、Int64 时间、连续段与增量版本 |
| `Features/Footprints/FootprintArchive`、Codec | 单写者使用的领域格式、块/尾部提交、时间定位与合法性 |
| `Features/Footprints/FootprintStore` | 有界批次 FIFO、最新查询、清除命令与后台结果，不持锁做 I/O |
| `Features/Footprints/FootprintPlayback`、ClearConfirmation | 纯时间轴与三阶段明确激活语义 |
| `Infrastructure/Footprints/FileFootprintArchive` | 限定根/代次路径、原子根/目录指针、有限页 I/O、专属文件逐批删除 |
| `TerrariaHost/Footprints` | 原版模拟/传送/出生观察、可靠身份、Host 生命周期、地图投影/输入/绘制 |
| 现有 F5/Hotkeys/Composition | 行、紧凑配置、互斥与最终完整 profile 装配 |

## 时间与原版依据

锁定原版 MVID `2c29f6c3-4bd9-4add-9c58-da159804e083`、EXE SHA-256 `960A03BFF6050CF7BE16DFC1A7B19E10FC2C4F8F835A6A3B135A50DD9E6BA2F3`。本地 `.8` `Main` 提取的 Update/DoUpdate 外层会因限帧、焦点暂停、菜单、CanUpdateGameplay/CanPauseGame 退出；`DoUpdateInWorld_Inner()` 才进入世界步并递增游戏计数、更新玩家。入口/异常必须区别，不把未完成步骤当成功样本。

每完成一个内层世界步骤接纳一步。Main 的目标间隔 `0.01666666753590107` 与玩家逐步 velocity/倒计时 `/60` 支持 60 步/秒的模拟时间单位；`gameTimeCache` 在准入前保存外层时间，不能用它补真实暂停。GameUpdateCount 能被重置和快照恢复，不能作永续时长差值；自有 Int64 累加保留全部步数，格式化时商/余数分开。无 UTC 补时，UI Stopwatch 与录制时间分离。

本地中心每模拟步读取一次；有效坐标完全相等才合并，变化保留 native float 可表达精度。相邻样本用 Start/End 模拟步、连续段 ID 和位置有效原因表示，固定页边界不改变段。原版 Teleport/Spawn 窄观察提供短距离断段；未知位置/死亡/幽灵形成有原因的无位置时段。准入、可靠身份与操作物品输入许可独立。

## 存储、身份和失败

偏好：`JueMingRData/config/features/footprints.json`，独立 format/version，录制 true、显示 false；复用 PreferenceDocument/AtomicFileDocument。历史：`JueMingRData/footprints/<pair>/catalog.json` 与 `<archive-id>/root.bin`、`blocks/<sequence>.bin`。pair 复用 LocalWorldIdentity；archive-id 是本档案代次，不是会话 token。目录指针同时可表达已持久接纳的旧代次清除意图，内容只有身份/尺寸/代次/操作 ID，不含轨迹正文。

catalog 的排他文档租约覆盖整个 pair；每个代次根复用现有原子文档。封存块先 CreateNew 写完整校验内容并 Flush，再根提交引用；已有同序号块只能在完整字节相同时幂等复用，绝不覆盖冲突。根内尾部有界，不反复重写历史索引。根是唯一已提交事实，部分文件/孤页不能假装可靠空。格式、身份、尺寸、顺序、时间与哈希严格校验，未来结构拒写；不自动恢复备份或以默认值洗坏档。

游戏线程活动批次至多 256 条，FIFO 至多 8 批；慢/失败满载停止新接纳、明确提示，恢复先断段。只有相同逻辑尾点的延长可覆盖更早尾值，已封存移动点不能被后批吞掉。保存从首次未提交起 10 秒到期，停录/暂停/离世收好尾部；明确未提交有限退避，未知提交终止自动重放。旧会话保存可完成原档案，但不向当前会话发布；同 pair 退休顺序及有限退出沿现有 Host 方式。

后台读取每次最多有限块，查询槽只保留最新目标；过时结果不发布。已加载 immutable 块缓存有限，尾部时间与几何版本分别变化。历史暂停的查询范围固定，录制追加不使旧片段重建；隐藏时取消查询并退役路线数组。默认全时间范围，大规模只返回围绕游标的有限真实片段并提示部分显示；任一保存时间可通过二分定位，不永久限制最近 N 条。

## 清除顺序与文件边界

第三次真实按下/释放在已呈现阶段后接纳，捕获 pair、会话、archive-id 与 operation-id；正常尾部修订不改清除目标。前两次不更改历史或文件。取消和布局/焦点变化复位；最终接受后只显示在途结果，关窗不撤回已发命令。

清除与保存由同一个 worker 串行：停接纳并丢弃本命令授权的旧未存尾部 → 已入 I/O 写者结束 → 原子提交 catalog 的删除意图 → 关闭旧根租约 → 有界检查/删除该固定代次自有块、root、bak/tmp/lock → 核对已无旧正文 → catalog 切换新 GUID → 发布成功。失败保持原命令和停止状态，不创建新代次路径；重启只在合法持久意图存在时收尾，不猜测删除。旧重试携带旧代次且不能越过新 catalog；读缓存与查询发布也检查代次。

路径由验证的根、摘要 pair、GUID、固定序号产生，不接受 UI 名称/任意相对路径。检查祖先及每个条目的 reparse/类型；只遍历目标代次固定层级且单批删除，未知名字阻塞。禁止对数据根/pair父目录递归通配删除，禁止跟随链接；不碰任何其它域及外部备份。删除工作不持前台交接锁，不一次复制 F 个文件名，不每帧重试失败文件。

## 地图、布局与输入

路线接现有 FullscreenMapDrawing/MapView.Project，使用连续 tile，绝不套死亡点 Y 偏移或重复 mapOffset。借原版 MagicPixel 的 `(0,0,1,1)` 源区，绿色屏幕 1 像素，裁切真实相邻边；不逐线 Begin/End，不释放原版资源。几何按片段身份/视图失效，时间游标只选择到该时刻的邻边或停留位置。

地图底部最大宽 900 的两行条：第一行播放/暂停、可伸缩轨道、倍率、最新；第二行当前/总时长与必要加载/部分/失败反馈。小视口保留原字号、按钮最小命中，缩短轨道；无历史禁用播放。配置最大宽 340：标题和关闭，录制开关一行，默认行为/状态一行，清除范围一行，下方同区域切三阶段按钮与取消；正常/无历史/加载/保存失败/清除处理中均保留清楚文字，不叠多个模态。

复用 HostInputState 唯一样本与物理沿，Shell 先仲裁，时间轴只处理可见且未被高层占用的区域。AfterMapping 阶段提前声明鼠标/滚轮占用，键盘刷新后处理相同样本，原版映射不得复活已消费手势；条外按下不抢，条内拖动保有直到真实释放。窗口/字体/资源/会话变化、失焦和清除取消捕获，旧释放不确认。

## 同任务实施与验证落点

按所有者指定顺序串行执行，不使用工作树或并行写者：

1. `tests/Footprints` 先建立录制、时间、停留/小运动/转弯/断段独立期待，执行预期失败，再实现纯领域与严格格式。长停留通过等价步推进验证超过 200h，不实际等待。
2. 真实隔离文件验证分页/尾部/重复批次/全时间定位、坏/未来/尺寸、慢写与未知提交；接 Host 实际模拟与偏好。测试期待依据上文时间/邻接不变量，不复制实现输出。
3. 原版几何参照、跨页相邻边、裁切、局部几何失效、不可见零路线工作；时间轴从头/续播/末端/最新、固定历史时间域与 UI 单调余数。
4. 三阶段输入真实按下释放与取消；其它 pair/功能哨兵，受控保存交接点、部分删除/重启/旧命令不删新档案。清除从不读取或删除真实用户数据。
5. 正规 `build.ps1`/工作量选组带真实 Host、文件与受影响地图/F5/输入消费者；有限负对照验证计数和关键失败门。图形可用时原 XNB 预览，不启动游戏。
6. 未参与实现的只读上下文审完整增量，明确问题窄修复核；固定 clean 候选，完整 profile 顺序 A/B 包、隔离安装恢复、核对已确认目标后安全换装。最终记录实际 SHA/包/回执，等待实测与外部审查，不合并。

原始证据留 `.local/footprints` 或正规 artifacts 输出；设计只维护现行技术合同，阶段状态留 #87。性能证据分别量 N（历史）、S（块）、A（尾部）、Q（查询）、V（可见边）、F（删除文件）；有限 CPU/分配不推导游戏 FPS 或多人体验。
