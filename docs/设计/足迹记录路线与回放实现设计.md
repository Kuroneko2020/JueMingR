# 足迹记录、路线与回放实现设计

本批按 [#118](https://github.com/Kuroneko2020/JueMingR/issues/118) 的明确授权扩展已接受的 #87 基础；对应[行为合同](../功能介绍/足迹记录路线与回放行为合同.md)。足迹主体已有独立工程审查及所有者功能/外观体验接受，性能暂接受但未量化 FPS；本次20项注释与战斗文字收尾另作有限验证和一次集中独审，随 PR #119 合并进入 `main` 生效，不重开足迹算法。历史 #87 接受不代证新格式/200小时总览。保留六项目、net472/x86/C#7.3和锁定原版1.4.5.8，不引入依赖或第二套Runtime。

## 职责与接口

Platform足迹DTO定义显式时间区间和窄文件端口；Recorder是游戏线程唯一活动轨迹所有者；Archive/Codec是worker内格式、根提交和正文校验所有者；OverviewIndex拥有可重建空间/LOD摘要；Store串行保存FIFO、独立精细/总览请求和清除。Infrastructure只操作固定根/代次/块/缓存路径。Host观察真实完成世界更新并接专用现实钟，MapLayer只消费冻结快照、投影、绘制和输入。

时间全部是累计合格游玩时长的Int64 TimeSpan ticks（10,000,000/s）。FootprintSample是[Start,End]区间，FromX/FromY与X/Y为真实起终点；同位置为Stay，无位置区间保留Dead/Ghost/Unavailable原因，坐标归零。Sequence按源区间递增，Segment仅表示地理连续；同段相邻必须时间相接、下一From等于前一终点。存储分页不是断段，简化显示边保留源序号范围，不套Sequence+1规则。

## 现实钟与在线压缩

足迹专用FootprintPlayingClock用Stopwatch单调源，保留固定单位换算余数；锚点跨越正常帧间等待，重复/同刻回调不加时。Before/After原版DoUpdateInWorld_Inner确认真实完成才接纳位置；外层Update的原版菜单、gamePaused、CanUpdateGameplay与ShouldUpdateEntities门关闭锚。F5/地图/失焦本身不等于暂停；依原版实际是否继续世界更新判断。异常、换档、停录/重开与已知Teleport/Spawn断开连续性；不改全局Runtime或其它功能时钟。

Recorder每观察只做有限算术，以锚点后的分轴可行速度交集约束同步位置误差。二维误差0.125 tile，每轴epsilon/sqrt(2)；新真实端点的速度必须落在此前全部约束交集中，之后才加入自身约束，不能只检查交集非空。失败即冻结前一合格端点并从那里续段。使用double计算差值与速度，持久时间不使用float累计。

到达/离开停留明确封存，停留不摊成慢走；折返和缓弯受同一SED约束，慢漂移不按单步距离永久吞掉。活动数组256区间，首脏10秒期限不因新样本后移；保存冻结整个接纳批次，检查点后另建同段区间，已提交运动段不回头改写。背压拒绝新事实时不增加End，保留已接纳尾部，恢复断段。

## 新格式、保存与恢复

偏好继续使用config/features/footprints.json（录制true/显示false），不改偏好schema。新正文根是JueMingRData/footprints-v2/<pair>/catalog.json及<generation>/root.bin、blocks/<D20>.bin；旧footprints根未接入，安装与新清除均不读取、迁移或删除它。

catalog使用独立JueMingR.FootprintCatalog2身份；二进制根/块魔数与version=2，头写明固定时间单位、pair、generation、世界尺寸、块号和区间数。每区间49字节，256区间正文加头/校验仍在16KiB有限读写上限内。根只含有限尾部和已提交块数；SHA256覆盖正文，不把空间索引塞入不断增大的根。

pair排他catalog租约覆盖代次切换。先CreateNew并Flush不可变块，再原子提交引用它的根；只在根确认后发布已保存。相同编号仅允许完全相同字节幂等重试；冲突、未知提交、坏/未来/身份尺寸不符保护原件，不以空档覆盖。普通明确I/O失败有限重试并保留pending/FIFO；InvalidDataException显式进入保护读取路径。

重入分批核固定目录/块名，校验提交根、末块与前块/尾部接缝即可恢复录制；较早正文按查询/总览增量读取时校验。Loaded仅表示根与恢复边界成立，不冒称全部历史已校验。每个实际读入块验证身份/序号/校验和及其前块边界，时间定位仍二分有限块；正文缓存最多64块，精细查询默认8192、上限16384，仅供游标细节。

## 全历史总览与缓存

worker用独立总览槽接收generation、Serial、视口、zoom与截止时间，保存FIFO优先。精细/总览请求互不覆盖；晚到结果必须同时匹配代次及请求版本。每轮最多8块准备/查询，部分覆盖明确Complete=false和CoveredEnd；不会把有限输出当成已完整准备。

OverviewIndex按128 tile空间格登记实际原线和可选简化弦经过的格子，线段穿格成本不枚举包围矩形面积。每不可变256区间块生成可遍历DP层级，跨不同连续段或不邻接端点绝不拼接。显示几何误差0.375屏幕像素，另有0.25像素量化重复覆盖合并；按zoom折算世界误差。时间边界下钻原时间区间，回放位置由精细轨迹求出，不能沿只保证几何误差的大弦匀速定位。

派生缓存位于同代次overview/<D20>.bin，独立版本、源样本SHA256、generation/块号与内容校验，单文件64KiB。每个新worker首次准备该源块会核正文并比较来源指纹，不能用已有缓存掩盖坏正文；之后缩放/重开可重读已验证派生页而不重新压缩。坏缓存可重建，源损坏停止保护。

几何LRU与视口选边缓存分别8MiB，空间元数据预算16MiB；超过元数据预算退回按编号流式查询派生页，保完整覆盖，不删史或停录。连续回放同一视图向前时保留在途请求至完整，新的partial不替换安全旧完整历史；完整后原子换，回退或换视图立即换代次，避免准备成本超过节流周期时饥饿/历史闪失。历史静态块复用；当前root尾与有限录制/在途/最近提交批次依SourceSequence拼接，索引追上后撤临时覆盖。地图关闭取消可选查询并释放几何/视口缓存，有限空间索引保留供同worker重开。

## 绘制、回放与交互

MapLayer订阅现有FullscreenMapDrawing Routes/Overlay/Completed/Begin；MapView复用原版投影，路线在标记/死亡点前绘制。Draw不读文件、不建索引、不压缩；只提交视口请求、复用投影并画冻结LOD边/有限尾部。保持LimeGreen及地图Alpha，MagicPixel明确1×1源，投影后居中描边2屏幕像素；地图缩小不把线宽缩薄，边缘裁切计半线宽，不改其它图标。

打开地图默认最新、暂停、1×；倍率1/10/60/300/1800×、最新播放从头、历史继续、到末端停止、不循环。显示总时长由真实已知End决定，拖动固定当时范围，后台追加不挤游标；隐藏/失焦停止推进不补隐藏时间。条内按下拥有真实释放，条外不抢，字体/屏幕/档案变化取消旧捕获；F5/Notes等高层UI继续优先。

## 清除与验证

三次分别呈现后的明确激活绑定当前新版pair/generation/operation；同worker先停止接纳旧代次、收尾在途写者并持久清除意图，再逐批精确删blocks、overview和root/bak/tmp/lock，换新GUID。未知目录项、链接或归属不明即阻塞；不删pair父目录或旧格式根，不递归通配删除。

现有ArchitectureTests足迹组覆盖新区间/压缩/停留/回放、真实隔离文件/恢复/损坏/清除和worker背压；OverviewChecks覆盖早中晚空间、LOD/穿屏、时间截断、缓存坏/源坏及稳态复用。显式--footprints-200h入口流式执行43,200,000观察和独立重放误差核对，完整档案交给真实Store/Host/MapLayer与原版XNB绘制专项。NativeFootprintTimingChecks检查30/60/120Hz、同刻/暂停/重入和原版门；输入/标记/死亡点及路径同开按实际影响验证。

这些是工程证据入口，不代证所有者日常游戏加载、体验、多人或FPS。固定候选、实际执行/复用、参数/规模/耗时、失败处置、审查及包/安装身份集中查#118；按07完整准入后才按08一次正式完整候选轻量换装。
