# 世界生成预览实现设计

用户结果见[行为合同](../功能介绍/世界生成预览行为合同.md)，实际候选与验证回 [#149](https://github.com/Kuroneko2020/JueMingR/issues/149)。本设计描述本任务候选机制，不将未完成的工程、安装或本人体验写成通过。

## 职责与来源

实现位于 `TerrariaHost/WorldGenPreview/`：`HostWorldGenPreview` 拥有本次调用身份与入口许可；`WorldGenPreviewHooks` 拥有局部 Harmony 安装和失败撤回；`WorldGenPreviewBanner` 拥有一个原版生成页的非交互提示；`WorldGenPreviewLocalization`/`WorldGenPreviewText` 拥有有限显示转换。原版独占控制器、进度、世界、快照、原生控件与操作结果。没有新的项目、依赖、Runtime 或 worker。

锁定 `external/TerrariaRefs/Terraria.exe` 为 1.4.5.8，SHA-256 `960A03BFF6050CF7BE16DFC1A7B19E10FC2C4F8F835A6A3B135A50DD9E6BA2F3`、MVID `2c29f6c3-4bd9-4add-9c58-da159804e083`。资料身份与只读使用见[资料入口](本地参考资料使用说明.md)，原版源码和资源不进入产品。

`Phase0SHarmonyWorker.Install` 在已验证程序集与共享输入 Hook 后一次安装可选 owner `JueMingR.WorldGenPreview`，早于首个世界 Session。程序集可绑定、UI可用、生成已发布和字体/设备可绘制是四种不同就绪，不能互相替代。

## 局部入口与调用身份

原版 `WorldGenerator` 构造函数始终创建控制器；`bool WorldGenerator.GenerateWorld()` 先 `Controller.SetGenerator`（加载原生快照），再发布 `CurrentController`、`CurrentGenerationProgress`。这些初始化不依赖 `DebugOptions.enableDebugCommands`，因此使用局部路线 A，不改共享字段，也不注册全套 Toolkit。

精确 prefix 为本次 `GenerateWorld` 建立小 token；`CurrentGenerationProgress` 的两个原生写入中，仅 `_progress` 来源的发布写入之后（清 null 写入不发布），IL 接缝记录相同控制器和进度。正常/异常 finalizer 只退休相同 token、原样返回原版异常。入口同时要求 token 已发布、两个原版生成 flag、控制器/进度对象身份、菜单拓扑和当前普通 `UIWorldLoad`；不能凭 UI 类型或静态非空认领生成。异常可能留下原版静态字段，下一次 CreateNewWorld 也可能先显示读条再启动生成；已退休 token 排除了这段旧对象窗口，不改原版字段来掩盖问题。

`void UIWorldLoad.Update(GameTime)` 的唯一 debug 条件替换为本功能许可，保留原生 F5 读取及唯一 `UIWorldGenDebug.Open()` 动作；薄包装隔离自有入口构造/激活失败。Inventory 的原生排队取消及其余 Update/布局逻辑继续执行。原版 `UIWorldGenDebug.Close()` 返回普通页，但本功能不新增关闭动作或 F5 开关。

显示和操作归属在准确的原生 `UIWorldGenDebug.Open()` 边界认领，因此也覆盖原生 QuickLoad 配置恢复后由生成器自动打开的路径。prefix 仅允许同次已发布且仍活动的菜单生成 token，构造期只开放显示投影；finalizer 以同 token、无异常且原生菜单预览激活成功才开放操作门。构造或激活异常会清理进入中/已进入状态，并原样返回异常；非目标、未发布或已退休的静态残留不能取得归属。F5 包装仍只负责该入口的有限失败隔离，不成为原生自动打开的前置条件。

## 完整原生控制与有限例外

原生预览 `OnActivate` 把 SnapshotFrequency.None 改为 Automatic；控制器在预览活动时计算 hash，原生快照/步进继续由原版承担。R 不复制地图、快照或阶段结果。

两个直接消费者需要窄转交：

- 原生快速加载按钮的唯一编译生成 action 调用 `DebugUtils.QuickSPMessage(string)`。只在本次已进入的活动菜单预览、同控制器且 netMode=0、命令精确为 `/quickload-regen` 时转交原生 `ToolkitDebugCommands.QuickLoadRegenCommand(DebugMessage)`；保留原 SinglePlayer 条件和玩家主动触发的原有效果。其余仍执行原调用，不构造全局命令处理器、不开启其他命令。
- `Controller.ReportException(string,Exception,bool)` 的 debug 读取局部允许本次已进入且仍活动的同控制器；原有暂停参数、展开预览、聊天消息与 Trace 保留。未进入预览的普通建图不因此自动暂停/开窗，其他 debug 消费者不放行。

## 输入与线程

真实顺序是 `Main.DoUpdate_HandleInput` → R InputPostfix/`AfterKeyboardRefresh` → 原版聊天/调试/菜单 → `MenuUI.Update` → `UIWorldLoad.Update`。入口使用现有 `HostInputState.CanStartActions` 与 `HotkeyInput.IsNew(F5)`，消费该冻结边沿；不读取第二套 OS 键盘、不用玩法 Session 或 CanRunAutomaticActions 准入。文本输入与 Main.blockInput 继续让路。现有 F5Shell 在相同采样处理，世界内 CanPresent 不变。

生成线程只发布和退休有限 token；UI、节点、字体度量及图形均由原版 UI 线程消费。没有图块锁、全图复制、后台 UI 更新或无界队列。

## 本地化、布局与成本

安装时定向解析锁定预览、其编译生成委托、Controller 及必要快照/快速加载显示接缝；以精确指令形态与命中数预检。固定字面量只在本次 owner scope 中选择中文；阶段在 `GenPassElement` 构造/标题的 Name 读取后生成显示名，不修改 `GenPass.Name`。动态进度在 UI 的 Message 消费点处理，容量一缓存原文与中文，原生 OnDeactivate 清理。反馈只处理准确 NewText 显示调用，Trace、命令和用户参数不改。非本任务上下文与未知模板保留原文。

横幅是普通页的无命中 UIElement 子节点，使用原 `_progressBar.GetDimensions()` 的逻辑坐标锚点；借用 MouseText/MagicPixel，不重开 SpriteBatch、不拥有游戏资源释放权。字体身份变更重测；进度几何、视口或缩放变化重排；稳定帧复用。UIGenProgressBar 的逻辑高70不包含下垂装饰：安装期精确解析四个原生借用纹理字段，节点首次绑定其 Asset，准备时以三种 outer 的完整尺寸及 lower 的原版 `(36,60)` 相对位置求联合足迹；字体/布局与纹理身份分别失效。横幅位于真实足迹下方，不把显示矩形夹回装饰上，也不读取纹理像素或消耗原版随机选择。ConditionalWeakTable 只关联当前原版页与其节点，节点随原版页生命周期退休，不持有历史页列表。

非生成上下文只有有限 gate 早退；安装发现是一次性，新增每帧工作与世界大小无关。原版预览本身的地图扫描/hash/快照成本仍存在，CPU 工作量不能证明 FPS 或所有机器无卡顿。

## 失败与验证

必需接缝全部成功才发布 Ready；任何版本/签名/IL失配或局部错误只撤回本 owner 的 patch、禁用提示并通过既有限错误记录报告，不拆核心输入/加载链、不重复安装。生成异常原样传播，R 清理可重复执行，不删除世界/快照或撤销玩家保存。

`scripts/test-world-object-text.ps1 -Scope WorldGenPreviewCpu` 与 `worldgen-preview` workload 组负责锁定程序集真实 Hook、原版 GenerateWorld 发布/完成/取消/异常、真实读条 Update/F5 消费、输入焦点边沿、文本保真与不可用资源早退。`WorldGenPreviewVisual` 在真实原版资源上核原生构造/控件/普通页Draw、自动 Open 的中文/操作归属与构造失败清理、100稳定帧一次度量与布局、视口/缩放刷新以及横幅与实际三种outer/lower足迹不相交。图形文件单独变化也选中已登记的 `worldgen-preview` CPU 责任，图形专项仍显式执行。CPU scope 用终端 Open 观察器隔离资源构造，不能代证完整预览构造/绘制或物理键盘；图形与本人实机分别记录。正式路由按完整 BASE 计算，不以 Feedback/PrepareOnly 冒称交付资格。
