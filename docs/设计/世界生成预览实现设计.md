# 世界生成预览实现设计

用户结果见[行为合同](../功能介绍/世界生成预览行为合同.md)，实际候选与验证回 [#149](https://github.com/Kuroneko2020/JueMingR/issues/149)。本设计描述本任务候选机制，不将未完成的工程、安装或本人体验写成通过。

## 职责与来源

实现位于 `TerrariaHost/WorldGenPreview/`：`HostWorldGenPreview` 拥有本次调用身份与入口许可；`WorldGenPreviewHooks` 拥有局部 Harmony 安装和失败撤回；`WorldGenPreviewBanner` 拥有一个原版生成页的非交互提示；`WorldGenPreviewLocalization`/`WorldGenPreviewText` 拥有有限显示转换。原版独占控制器、进度、世界、快照、原生控件与操作结果。没有新的项目、依赖、Runtime 或 worker。

锁定 `external/TerrariaRefs/Terraria.exe` 为 1.4.5.8，SHA-256 `960A03BFF6050CF7BE16DFC1A7B19E10FC2C4F8F835A6A3B135A50DD9E6BA2F3`、MVID `2c29f6c3-4bd9-4add-9c58-da159804e083`。资料身份与只读使用见[资料入口](本地参考资料使用说明.md)，原版源码和资源不进入产品。

`Phase0SHarmonyWorker.Install` 在已验证程序集与共享输入 Hook 后一次安装可选 owner `JueMingR.WorldGenPreview`，早于首个世界 Session。程序集可绑定、UI可用、生成已发布和字体/设备可绘制是四种不同就绪，不能互相替代。

## 局部入口与调用身份

原版 `WorldGenerator` 构造函数始终创建控制器；`bool WorldGenerator.GenerateWorld()` 先 `Controller.SetGenerator`（加载原生快照），再发布 `CurrentController`、`CurrentGenerationProgress`。这些初始化不依赖 `DebugOptions.enableDebugCommands`，因此使用局部路线 A，不改共享字段，也不注册全套 Toolkit。

精确 prefix 为本次 `GenerateWorld` 建立小 token；`CurrentGenerationProgress` 的两个原生写入中，仅 `_progress` 来源的发布写入之后（清 null 写入不发布），IL 接缝记录相同控制器和进度。生成线程调用栈保存准确本次 token（支持有限嵌套，互不串线程）；正常尾部 SetDebugWorldGenUIVisibility(false) prefix 在原版可见性检查之前先标记该调用 token 不可再准入，但保留早期入口归属，随后原版按既有主线程关闭/等待再清静态。正常/异常 GenerateWorld finalizer 才以同 token Finish/CAS 释放归属，原样返回异常；不长期保有已结束 Controller。入口同时要求 token 已发布、两个原版生成 flag、控制器/进度对象身份、菜单拓扑和当前普通 `UIWorldLoad`；不能凭 UI 类型或静态非空认领生成。异常可能留下原版静态字段，下一次 CreateNewWorld 也可能先显示读条再启动生成；已退休 token 排除了这段旧对象窗口，不改原版字段来掩盖问题。

`void UIWorldLoad.Update(GameTime)` 的唯一 debug 条件在本功能认领生成时让路；未认领时仍服从原版 debug 许可。早期页面不消费共享 F5，postfix 保留横幅准备。生产 `InputPostfix` 在 `AfterKeyboardRefresh` 和既有 F5Shell 消费之后薄转交模块，模块以同 token 的输入许可和新边沿唯一分派 `UIWorldGenDebug.Open()`；薄包装隔离自有入口构造/激活失败。Inventory 的原生排队取消及其余 Update/布局逻辑继续执行。原版 `UIWorldGenDebug.Close()` 返回普通页，但本功能不新增关闭动作或 F5 开关。

显示和操作归属在准确的原生 `UIWorldGenDebug.Open()` 边界认领，因此也覆盖原生 QuickLoad 配置恢复后由生成器自动打开的路径。prefix 仅允许同次已发布且仍活动的菜单生成 token，构造期只开放显示投影；finalizer 以同 token、无异常且原生菜单预览激活成功才开放操作门。统一的私有 Controller getter prefix 严格使用本线程 activeEntry 进入作用域：域外执行原 getter，域内每次读取复核同 token 并返回捕获对象，退休则抛出携带同 token 的专属信号，由 Open finalizer 清理后正常退让。安装时核锁定模块、准确签名及原 getter 的字段读取体，先装 getter 再编译/patch 构造调用者；不递归调用原 getter，不保留顶层重复读取规则。顶层构造与 OnActivate 的命中计数不能证明同步子链全覆盖：GenPassElement 构造立即经 Index 读 Passes，颜色初始化立即经 CurrentTargetPass 读控制器；这些不是以后才执行的委托。该检查不是生成锁，返回后退休也只会使用捕获的旧对象，不再解引用被清空的静态。其它无异常完成但身份已退休时也恢复本次准确激活页；不拉回用户后来切换的页或新生成页面。提前退休使已完成激活的页由原版关闭交接覆盖，尚未激活的页由 scoped getter/finalizer退让覆盖。真实构造/资源/激活异常仍原样传播，自有 F5 入口按原局部失败边界停用；非目标、未发布或已退休的静态残留不能取得归属。F5 包装仍只负责该入口的有限失败隔离，不成为原生自动打开的前置条件。

## 完整原生控制与有限例外

原生预览 `OnActivate` 把 SnapshotFrequency.None 改为 Automatic；控制器在预览活动时计算 hash，原生快照/步进继续由原版承担。R 不复制地图、快照或阶段结果。

两个直接消费者需要窄转交：

- 原生快速加载按钮的唯一编译生成 action 调用 `DebugUtils.QuickSPMessage(string)`。只在本次已进入的活动菜单预览、同控制器且 netMode=0、命令精确为 `/quickload-regen` 时转交原生 `ToolkitDebugCommands.QuickLoadRegenCommand(DebugMessage)`；保留原 SinglePlayer 条件和玩家主动触发的原有效果。其余仍执行原调用，不构造全局命令处理器、不开启其他命令。
- `Controller.ReportException(string,Exception,bool)` 的 debug 读取局部允许本次已进入且仍活动的同控制器；原有暂停参数、展开预览、聊天消息与 Trace 保留。未进入预览的普通建图不因此自动暂停/开窗，其他 debug 消费者不放行。

## 输入与线程

锁定客户端的真实正常采样路径是 `Main.Update` prefix/`BeginUpdate` 撤销旧许可 → `DoUpdate → UpdateUIStates → MenuUI.Update → UIWorldLoad.Update` → `DoUpdate_HandleInput` → R InputPostfix/`AfterKeyboardRefresh` → 后续 `Main.UpdateMenu`。`MenuUI.Update` 与 `UpdateMenu` 是不同调用；失焦早退分支还可能执行 UpdateMenu 后返回而跳过本帧采样。旧设计把早期 UI 更新排到了输入后，已由锁定客户端原始 IL 和菜单帧旧红反例推翻。入口使用现有 `HostInputState.CanStartActions` 与 `HotkeyInput.IsNew(F5)`，消费该冻结边沿；不读取第二套 OS 键盘、不用玩法 Session 或 CanRunAutomaticActions 准入。文本输入与 Main.blockInput 继续让路。现有 F5Shell 在相同采样处理，世界内 CanPresent 不变。

所有共用准入从同一 token 捕获 readonly Controller 与已发布 Progress，核静态身份及当前 token 后只解引用捕获对象；正常清空导致拒绝本次机会，不调用 Fail。准入退休标记与调用归属释放分开，finalizer 采用 compare-exchange，迟到旧尾部不能清掉新 token。早期 debug gate 捕获原生 Controller、核无本功能调用归属并末尾复核相同静态身份，覆盖原生外层已读旧对象而收尾随后清空的窗口；从未认领且稳定的原生 debug 上下文仍保留。原版 CreateNewWorld 的后台 Task 在 GenerateWorld 普通页尾部先请求隐藏、再清 Progress/Controller；未显示时隐藏直接返回，不保证主线程等待。生成线程只发布和退休有限 token；UI、节点、字体度量及图形均由原版 UI 线程消费。没有图块锁、全图复制、后台 UI 更新或无界队列。

## 本地化、布局与成本

安装时定向解析锁定预览、其编译生成委托、Controller 及必要快照/快速加载显示接缝；以精确指令形态与命中数预检。固定字面量只在本次 owner scope 中选择中文；阶段在 `GenPassElement` 构造/标题的 Name 读取后生成显示名，不修改 `GenPass.Name`。动态进度在 UI 的 Message 消费点处理，容量一缓存原文与中文，原生 OnDeactivate 清理。反馈只处理准确 NewText 显示调用，Trace、命令和用户参数不改。非本任务上下文与未知模板保留原文。

横幅是普通页的无命中 UIElement 子节点，使用原 `_progressBar.GetDimensions()` 的逻辑坐标锚点；借用 MouseText/MagicPixel，不重开 SpriteBatch、不拥有游戏资源释放权。字体身份变更重测；进度几何、视口或缩放变化重排；稳定帧复用。UIGenProgressBar 的逻辑高70不包含下垂装饰：安装期精确解析四个原生借用纹理字段，节点首次绑定其 Asset，准备时以三种 outer 的完整尺寸及 lower 的原版 `(36,60)` 相对位置求联合足迹；字体/布局与纹理身份分别失效。横幅位于真实足迹下方，不把显示矩形夹回装饰上，也不读取纹理像素或消耗原版随机选择。ConditionalWeakTable 只关联当前原版页与其节点，节点随原版页生命周期退休，不持有历史页列表。

非生成上下文只有有限 gate 早退；安装发现是一次性，新增每帧工作与世界大小无关。原版预览本身的地图扫描/hash/快照成本仍存在，CPU 工作量不能证明 FPS 或所有机器无卡顿。

## 失败与验证

同步子构造回归通过生产 F5 和真实原生构造分别隔离两个窗口：A 在子元素首次 Index 前，B 在 Index 已实际返回、颜色 helper 已进入后的准确 CurrentTargetPass 前，一次性执行生产 Closing 接缝，再按 Progress→Controller 清空。旧 af08 在两处均产生普通空引用并误停功能；新期待是同 token 专属退休信号原样到达 Open finalizer、仅放弃本次页面、Ready/Failure/Hook 保留，并由真正新的 GenerateWorld/Controller 再经生产 F5 恢复。另核作用域结束后原 getter 行为及真实构造故障仍 Fail。首次无 XNA adapter 的准备失败不算旧红；环境恢复后的实际资源执行与其原件分别记录，旧顶层退休证据不代证新增子链。

必需接缝全部成功才发布 Ready；任何版本/签名/IL失配或局部错误只撤回本 owner 的 patch、禁用提示并通过既有限错误记录报告，不拆核心输入/加载链、不重复安装。生成异常原样传播，R 清理可重复执行，不删除世界/快照或撤销玩家保存。

`scripts/test-world-object-text.ps1 -Scope WorldGenPreviewCpu` 与 `worldgen-preview` workload 组负责锁定程序集真实 Hook、原版 GenerateWorld 发布/完成/取消/异常、真实生产外层 prefix→早期读条 Update→原生输入及生产 postfix→唯一 F5 分派、焦点/释放/skip/modal/block/chat/debug=true 活动与 Closing 后持键反例、原生外层条件后清空/Finish、未认领稳定原生 debug、确定身份检查后清空与下一轮新 token、文本保真与不可用资源早退。旧 `Sample→page.Update` 只证明局部预置输入后的行为，不能证明生产菜单时序；旧候选 open=0、新路径 open=1 的原始对照回 #149。`WorldGenPreviewVisual` 在真实原版资源上核原生构造/控件/普通页Draw、自动 Open 的中文/操作归属、准确原生构造退休正常退让及真实构造失败隔离、100稳定帧一次度量与布局、视口/缩放刷新以及横幅与实际三种outer/lower足迹不相交。图形文件单独变化也选中已登记的 `worldgen-preview` CPU 责任，图形专项仍显式执行。CPU scope 隔离 Main 重主体但按独立锁定 IL 保留菜单/输入相对顺序，通过实际生产 Hook 驱动；用终端 Open 观察器隔离资源构造，不能代证完整预览构造/绘制或物理键盘；图形与本人实机分别记录。正式路由按完整 BASE 计算，不以 Feedback/PrepareOnly 冒称交付资格。
