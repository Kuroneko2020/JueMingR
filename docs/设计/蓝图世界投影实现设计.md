## Host scene 与编辑事务

HostBlueprintProjection 是唯一 scene owner：每份独立 identity(instanceId)、origin、commitOrder、immutable sparse source mask、水平姿态；world session 与 sceneRevision 属 Host，只有一个 pending Open／候选／选择／移动／镜像／修剪／Committing 事务。TemplateKey(assetId,revision,hash)不含 origin/session/instance。CurrentProjection 只是候选或最新 Fixed 的兼容只读投影，不是 scene 权威。

取消来源由明确的 BlueprintProjectionEditKind（Place／Move／Remove／Mirror／Trim）拥有，pending、Committing 和取消均保同一类型；restore 只承担原场景快照，不拿 null 猜操作种类。CanInvoke对应入口为可开始或可取消自身，Host命令先自身取消再开始，注册predicate同门。F5将来源与修剪 preview revision 传入Prepare→Layout.Matches/Ensure/built缓存，各行原位更换名称与按钮但HotkeyTarget不变；Toolbar按同一 mode／revision 撤旧armed，物理release尾仍由原owner消费。SelectingRemove的RemoveAll明确发布业务空 scene，再调用ClearProjection收pointer／toolbar与全部运行资源，不删除资产；session退出的资源清理不发布空 scene，晚回执不得复活。正常commit受理不写反馈，真实错误通道保留。

移动候选复制原点和旧 mask，旧位置只为取消保留；绘制排除原 Moving source，避免两份预览。启动、选目标、确认各走 BlueprintPointerProof 与既有 HostInputState 的新手势、世界门及独立释放尾缘。Pointer 保冻结 world matrix，并保 tile 内部位置供半砖坡命中；不 raw polling／全局清键。失焦只打断基准，可信 neutral 重建增量，明确 Back／Esc 才取消 Open。Fixed 不占动作门，F5 关闭不清场景。

Moving隐藏source仅退休派生命令，原immutable DTO／mask／origin／order仍由restore持有；共享DTO按引用只计一次，不能让隐藏旧命令占满64MiB后误拒自己的候选。取消先丢candidate命令，再从原DTO以restore有限优先恢复全部core，不重新读盘／解码；Moving期间晚Open只更新source验证资格，不重建隐藏命令。整renderer重建资格在遍历cores前固定，避免首core发布后误跳其余同mask快照。point16从选中进入Moving后归rollback保留，取消保exact旧快照；成功提交转给copy，完整128core包含point后合并，不让Fixed旧point长期抢占后续candidate。

确认按轻量 bbox 筛 scene 对手、排除 Moving 自身，给原唯一 worker 一份(session,transaction,sceneRevision,candidate,previous)纯值请求。后台查整个真实重叠和完整对象成员，返回完整新 masks／空实例 IDs。Host 核三身份仍匹配后一次应用 masks／origin／最新顺序和退休；预览／失败／取消不留部分提交。Mask 只增、永不露底复活，按局部格位／对象集合需量增长；Tile、Wall、Liquid、Actuator各位及四色Wire独立，对象ID只在该instance内有效。

Committing 期间固定实例因读取或图形解释失败退休，Host 先取消整笔编辑、恢复移动原位置，再释放故障引用；worker 在途计算和已发布旧回执都不能提交。当前事务回执若遇 sceneRevision 失配也显式结束事务，不留 Committing 占用动作门。成功原子应用内部的空实例退休不触发这条取消路径。

固定 scene 的语义 owner 仍是 HostBlueprintProjection。结构性提交、确认移动／镜像／修剪、可靠删除／移除、完成退休和永久 mask 变更只置 dirty，同一安全更新／离场出口合并为一份不可变 BlueprintSceneDocument；Moving 保存仍在 scene 内的原 restore，Following 不加入。BlueprintSceneHistory 只拥有 scope、已接受快照及单 DocumentWorker 的读写／退出责任，复用 AtomicFileDocument，不访问 Terraria live object。scene.bin 写 v2、读 v1/v2；保存可靠 scope、世界尺寸、revision、精确 TemplateKey、原点、严格提交顺序、严格 0/1 水平姿态及原始逐层／整对象 source mask，不保存 Match、UI、预览、来源、ToolUse token、原生代际或 packet34。v1 record 最小104B、v2为105B，先核版本和精确长度；v1默认为普通姿态，不迁移 mask。仅完整 decode 成功才由 AtomicFileDocument.RetainLoadedSource 留住精确旧字节，首次真实 v2 保存前写固定 scene.bin.schema1-original；单纯打开不改文件，档案冲突沿原保护，不能重新 Encode 一份旧档冒充原件。

可靠 LocalWorldIdentity 可迟到绑定。初读完成后每 Pump 至多受理4个原 Library Open 复验请求，仍用原32条背压；全部引用 settled 后将合法子集按保存顺序一次发布，建立新session／projection generation并重建资格／世界匹配。RequestProjectionRestore 在同一原模板读取过程中分批验证mask层位、对象和计数，不另造正文缓存或worker。某条模板丢失／损坏不阻独立合法实例恢复，但整档保持保护，不把删失引用静默filtered回写。未来格式、scope／尺寸不符、损坏、I/O失败、外部冲突或提交未知同样保原件；无变化不保存，资源清理不写空。ProcessExit只排空已接受不可变请求，不读取当前游戏状态。

## 镜像 view、修剪与完整消费者（#144 候选）

`BlueprintProjectionView` 是不可变的有效解释入口：包含原有效 W/H、Summary.Left/Top、姿态、source mask 与纯值镜像 profile。raw 文件和查询目录保保存坐标；读取窗口时减一次 Summary.Left/Top 才成为 source 局部格，永久 mask、source range 的局部几何和窗口 core 使用该 source 域。display 局部格由姿态解释，world 格再加实例原点。文件 ordinal、物理块号与成员块号是原运输身份，不是坐标，姿态不能重排或重算它们。不复制反向模板、不重排原文件、不让 display 坐标进入永久 mask。目标矩形反查 source 的半开区间用同一 view，含端点拖动先以 long 计算、裁到 W/H，再转半开区间。

普通／完整对象有效源在 worker 运输时通过同一 view 解释。对象按真实成员块一次取得完整 row-major 成员，profile 只在元数据与完整 raw 布局唯一证明同一原版本体／样式时归一旧 alias；无注册自然逐格与显式未知不同，非法／冲突不能降级自然。镜像结果为 display row-major；原 SourceWindow 与 CellsInSourceOrder 显式保留物理 ordinal。Host 逐格消费者先按原 ordinal 取得源记录，再取该记录对应的有效目标，不二分镜像后的行序或用反射 X 再套 source mask。

原版 TileObjectData 的私有布局只在游戏线程编成 immutable `BlueprintHorizontalMirrorResolver` 快照；Features／worker 不拿原生对象。采集与 WorldObjectSemantics 共用准确登记布局解码和有限 operating frame 归一，canonical 再核完整成员。profile 的 Revision／Ready 和 view 引用进入资格与 source 请求／回执身份；按模板缓存普通／镜像两份资格几何并计 SourceIndexBytes，mask 计数仍沿原有界源扫描，不建立每实例全正文或新 worker。世界比较、材料（含剥漆耦合）、逐格／整件／门施工、near／frontier／连续游标与门9格上下文都使用同一有效源。门上下文保明确空格，未入主分母；普通源被剥离的对象 Tile 仍经完整对象解释，不能由局部 context 重新猜方向。

显示保原 source 像素命令与 source parity；最终 Draw 在实际纹理尺寸、Centered、DrawOffset／FrameOffset 结算后，以实例完整 W×16 的轴反射整个 sprite 矩形并切换 FlipHorizontally。晶塔动态静态本体外延也走该出口。语义合法帧与源外观是两路数据，不能用改 FrameX 取代像素反射。世界 Match 的可视位置与原生 watch bounds 经过同一 source/display 变换，真实变化反查 source 后仅撤相关证明。外框始终使用原 W/H；Draw 不推进比较或重新解释原版元数据。

Mirror／Trim 共享 `HostBlueprintProjectionEdit` 的冻结单次点选事实（session、transaction、sceneRevision、反向提交序列、world tile／subtile）。唯一明确点击的16格 point core 到货后继续原请求，较新的编辑、场景变化或取消先退休旧资格；不让 hover 抢占，也不要求第二次点击。Mirror 在旧原点完整 Match 资格明确为无后，将反射副本送原 Commit lane 核全部真实源和对手；旧场景保持到当前回执原子发布，成功保实例身份、取最新顺序，自身从对手中排除。匹配晚变和场景换代仍在发布前拒绝。

Trim 选择成功后打断指针并要求独立 neutral／drag。`HostBlueprintTrimSession` 固定最初 `editorMask` 引用、目标/原点/姿态、scene与transaction；Host拥有已封口 `trimManualGeometry`、独立 `trimPendingGeometry`、一个精确 `trimFlight`、活动拖动、sealed/verified版本及确认责任。新拖动只改变活动框和UI代次，不清已完成并集、不取消旧flight。release把用户矩形减去原manual union，只有新增全层几何增加sealed版本；成功受理后转移pending容器只读所有权，再换新容器，busy保原后缀而不复制或排FIFO。合法回执必须等于当前flight、操作和固定基线，按其through版本前进；新preview revision或TrimDragging不使旧前缀过期。没有拖动/pending/flight且verified==sealed、累计非空时才可确认全部。

全层用户区域与仅Tile对象扩展使用两个 `BlueprintTrimGeometry`。第二笔差集只减manual，不减家具bbox。worker的 `ProjectionTrimOperation` 仅保存相对baseline的新增cell层bits、ObjectIds、累计计数及verified版本；新增范围按真实目录块去重查询，先扣baseline及overlay，再增加尚有效的独立层位和每色wire。首次触及正对象有效Tile，经完整可靠成员核实才整件增加Tile删除和source footprint；后续只重复触及Tile不收正文，后来明确选中的框外墙线仍可增加。任何中途失败作废整个操作，不发布半步摘要。`BlueprintProjectionTrimPlan` 的Accumulate回执只有独立累计计数、本步扩展及最初OriginalMask，Mask为空；预览不写scene/材料/施工分母或保存。

一次确认在输入末尾接受后固定verified==sealed版本与累计数，进入本trim的finalizing并禁止新拖动。原唯一commit lane的Freeze在worker按合作切片把baseline与overlay组合一次，返回独占的不可变Mask；不每笔CopyCells/CopyObjects，也不把可继续写的字典包成快照。Freeze回执在Poll/Update只暂存 `trimFrozenPlan`。Host输入末尾先裁决取消，再以接受后的确认身份及当前输入许可核实最终版本/基线/计数，才原子发布一次、保持order/origin/pose，全部展示层归空才退休。按钮的新确认资格与已有确认的发布资格分别判断，finalizing禁用按钮不取消已接受命令。任何主动编辑仍通过原ProjectionEditing门暂停新施工，已在途原生、归还和网络责任不回滚。

`BlueprintPointerProof` 的held保留条件使用真实capture/trim拖动事实。Shell仍先于Host做一轮公共Dispatch；键盘/Mouse3–5只登记当mapping的Ready意图，Mouse1经原native Draw和紧邻mapping证书仅升级Ready，真实F5/凝胶release按各自控制权登记来源，不借世界拖选force。Host的Esc、Toolbar处理与Pointer可信世界右键先于 `ArbitrateCurrentTrim`，同操作取消mapping栅栏防取消后重入。未受理Ready只活当轮，缺Draw/失权不重放。接受后的Freeze可跨普通F5/临时失焦等待，发布仍要求CanStartActions、CanRetainWorldInput及世界或普通F5窄许可，文本/模态/原版忙态继续阻挡。失去可信拖动仅清活动框，不合成Released，不清完成并集或合法flight。Notes安全离页保持原身份检查。细节见[F5设计](F5控制界面样板与UI基础.md)与[统一快捷键设计](统一快捷键实现设计.md)。

镜像等待只读取 `ProjectionMoveEligibility` 并保priority；该入口仍Ensure首次资格与Match，Current+Unknown不再因每Update调用旧CheckProjectionMove重复Demand。section到达、原版写入、catalog/view/mask真实失效沿原路由撤Current并重新取源；未知仍不允许镜像，最终发布前Match复核不变。旧Move明确点击的CheckProjectionMove语义不改，不加定时重试或第二份Unknown状态。

`LibraryWorkerProjectionMembers`按本调用的已接纳distinct IDs和原字节责任计划有限prefix，成员块并集每batch一次分派，完整raw所有层先规范化/排序、核数量和重复坐标，再由source/door/qualification/mirror/trim消费。ordinary、object和门context可共享同ID本批语义；source ordinal、display row-major及9格已知空上下文各自保留。跨batch允许受有界内存约束的复读，不保存模板正文索引；资格只缓存原小结论及两姿态数字几何。DEBUG统计涵盖新发现扫描、完整成员访问和解释，不以cache命中或旧collector计数代替完整工作量。

红预览主区域以最大合并行span存储，Tile扩展独立union填充并索引每个真实对象四边，同侧重叠边去重。receipt按冻结pose把source footprint转display一次；WorldLayer只查相对origin的可见行/二分区间及真实边，活动框独立，不遍历历史矩形/ObjectBounds，不把viewport裁剪边当对象边。数值几何和overlay随唯一选区/对象增长；显式取消、引用/资产退休、scene/session失效、库关闭/失败/stop均撤lease并唤醒唯一worker安全释放。idle overlay不进入有工作谓词，cleanup只撤私有引用，绝不清改已交给scene的最终mask容器。

## 唯一 worker、模板共享与公平

LibraryState 提供 RequestProjectionOpen/Window/Source(s)、ClearProjectionWindow/Source、ReleaseProjection、CloseProjection、Request/CancelProjectionCommit 与相应 Take 回执。每模板唯一 Index／ProjectionDirectory；多实例只持引用，最后引用退休才释放 reader 与该模板 raw blocks。无每实例线程／8MiB缓存。普通 List／Create／Delete 优先取得服务，Open／Window／Overlap／Source四路轮转并有批次让步；Save 已受理边界不被取消读触及。

未完成 Open 最多32条背压，存量 refs 不限数量；window active+pending最多32、每identity latest、FIFO。Opened／window／source回执分身份，总32条及32MiB正文加384B单项source封装／summary引用槽的共享DTO背压，单window原32MiB能力不缩，Take唤醒；无新需求不忙轮询。全模板 decoded raw 共8MiB／至多64块，保守计费128+cells×64+objects×128，Open对象引用校验也借全局cache，避免32个iterator各乘一份8块cache。旧普通保存validator仍保原私有cache。

last-ref退役标志独立参与worker工作谓词；释放一批reader期间到达的新退役不能随普通wake被消费后遗留，且不依赖新操作／Take回执才释放。删除失败恢复先保留原窗口供绘制，未Opened时移动资格仍为Checking；旧窗口不代证当前世界。Open及原位置观察就绪后要求新点击才进入Moving。取消与晚回执按原identity恢复Fixed命令，不依赖相机／coverage变化。

窗口先消费当前需求已有cache hits，再读miss，65块／63驻留反例无需涨8MiB常数；无用旧请求可退休，已读immutable blocks保留。Host每instance单pending core，不因精确view每格变化替换仍有用结果；回执只要该core仍在当前coverage就按当前mask应用，world/session退出或明确取消则退休。

完整Open继续核root/meta/index/hash、旧v1顺序／引用／对象footprint；目录构建O(N+B)不代表全部旧完整验证总成本。ProjectionDirectory仅每块first/last(Y,X)及object Id范围，O(B)，不保存整正文或对象metadata字典；匹配供源另保每对象的纯整数成员数量和实际成员块号，计入模板共享SourceIndexBytes。按X/Y二分命中块，整重叠查询跳过块前空行并复核跨块末行，不因百万行稀疏bbox逐空行扫描。实际窗口读块hash，不每次重验全index；object元数据按块首末Id二分及块内二分。

## 有界 source cores 与命令增量

Host默认128×128局部source core，加真实视觉／邻接halo，core／segment以source坐标稳定对齐；同模板远距窗口分别请求，不粗并巨大bbox。每帧最多4个新window admission、场景轮转且候选优先；每instance只一笔在途。超worker DTO预算按FailureCode缩core128→64→32→16并保模板引用，极小范围仍过密时停止原样重试，移动coverage后可重新退让，不退休实例或变模板尺寸cap。

Host scene retained effective windows总32MiB、derived commands按每条80B计总64MiB。回执核身份后对含halo的完整window按当前永久mask产生不可变effective DTO，保bounds／完成事实、未mask层及有效Tile引用的整件metadata，再按构造器重算bytes。commit新mask时替换受影响快照，Moving copy／restore不原地改旧window；shared8MiB保原始模板块。Renderer先stage replacement命令及净增bytes，两预算均容纳才一并发布；拒绝释放局部stage，不覆盖现有有效core。完成空、预算拒绝和未读分开，只有完成空允许向下命中。

普通缺core采用先到驻留，不驱逐仍在coverage的resident；容量不足记录该实例／core／mask／demand的denied，稳定同需求不重读／rebuild。candidate及一个用户明确点击的16格point core可有限抢占普通core，普通不能反逐；hover不提升优先。旧 Move／Remove 的点读到货仍要求新点击；#144 Mirror／Trim 冻结的一次认证点击则在同请求到货后继续，不能混成 hover 自动选择。DTO与commands同步RemoveCore，完整core包含point时合并ownership。coverage／mask／候选或point需求变化及实际Trim／remove／cancel／retire／compact释放才重试，Pump／Draw／completion本身不推进capacity epoch。预算不足仅提示部分可见内容暂未加载，不宣称全显，不用涨常数或永久冻空替代收敛。

离屏清窗口／段并撤在途需求，保轻量实例／模板引用。上述分别是DTO payload估算与retained commands，不是进程内存峰或整个scene heap；窗口／List／Array复制、segment邻接样本、hash、Open每iterator当前≤2048记录及32KiB缓冲、查询目录O(B)、下述共享位置／层位索引、mask需量与GPU借用分别计。无实例／候选／在途时不周期扫库或读盘，允许必要O(instanceCount) bbox粗筛。

BlueprintProjectionRenderer按16×16 source段保存完成窗口的纯值命令，比较真实局部cells／objects和一格邻接，仅重建进入／变化段；mask改变同样按段比较，origin不入key。每窗不Clear整个命令cache，离屏trim历史段。全局Wall→Liquid→Tile→特殊本体→Wire/Actuator pass保持，避免分段家具外延被后画墙遮住；晶塔本体去重。缺少的邻接是unknown，不当空气永久定边；raw窗口带完整halo后发布，masked邻接从有效内容重新派生。

优先新 core 真实超预算时，先对已有不可变窗口／Segment 引用作局部 victim 规划，普通可容纳窗口仍走原快路径，ordinary receipt 不取得驱逐权。raw 严格按现窗口共享身份去重，commands 复用 Extra 位置去重且只更新受影响 owner；incoming stage 也剔除同 owner victim。只有两个预算都可满足才实际移除并发布最终 stage，再以最终容量 revision 记 victim denial。不可满足时只拒绝 incoming 并保留相对真实未变状态的原净成本，不改旧 resident、renderer commands、命中与容量 revision；不靠实际驱逐后重读恢复，也不每帧清 denial 或扩预算。

## 资源与失败

WorldLayer组合所有已就绪Fixed与唯一候选，沿既有GameViewMatrix／ReverseGravitySupport；轮廓裁view后转像素，不扫全bbox。命中反向提交顺序，在完成core中二分cell再应用mask；空气／masked层不抢目标，NotLoaded不选穿。半砖／坡看tile内坐标。Hover与点击共享同一目标。

纹理只在graphics线程按distinct key借原版资源；paint请求ready后不固化fallback。设备身份变化不使用旧device纹理，不Dispose原版借用资源，不因此重读正文。不调用有world／生态／实体副作用的DrawSingleTile/GetTileDrawData/TileObject.DrawPreview作产品API，不替换Main.tile或Player，不烘巨大RT。

库删除在唯一worker先停asset新读／释放Index再走原可靠墓碑流程。Host退休所有引用并保存仅用于确定precommit失败的旧scene快照；仅 DeleteProvenUncommitted 恢复，Unknown／Protected不盲复活。恢复先保全旧 identity／origin／order／mask／窗口，Host 每次 Pump 最多四笔 Open admission；背压 false 保留在轻量待受理队列，未完成 Open 仍最多32，不能变成实例恢复上限。重新验证前不确认与该实例重叠的编辑，明确移除／session退出会退休相应资格。可靠失败重Open后复用验证未变的窗口。单instance移除不影响同模板其它引用，rename仅meta。错误回执按session／identity退休；图形解释错误停止故障instance并按上述规则终结受影响确认，正常资源等待不假坏资产。实际证据及未测边界回交付记录。

### 单格种植盆与平台分别解释

锁定 1.4.5.8 的八款种植盆物品 3215–3222 实际输出 Tile380、style 0–7。该类型 frame-important，但没有 TileObjectData 登记：WorldGen.PlaceTile 写 FrameY=18×style，独立连接 framer 只写 FrameX=0／18／36／54，掉落再由 FrameY 还原物品；CanPoundTile 明确排除它。NativeMaterialPlacement 因此编译明确的 PlanterBox legacy 单格规则，RequiresObject=false、Platform=false，分类版本为 3；不能继续把无 metadata 当成该生产者未支持，也不能伪造 TileObjectData 或世界 Metadata 对象。

原版采样对可靠单格种植盆发布 PlanterBox18 profile、semantic X=0、semantic Y=raw Y。纯值消费者只在四种合法 X、完整 Y/style、无半砖／坡形及同次样本字段一致时折叠连接帧；错误值保持 Unknown／未解释。执行转换只建立候选自己的 Cell 和 FrameY，Object=null，沿原 legacy 消费者检查与放置。种植盆不进入平台 Smart 或锤形路径，不与平台、粘土盆共享替换组。平台仍按已有可靠 18 像素／27 槽 profile 与真实正 ObjectId 路线解释。

### 候选、原版消费与共享供给

原要求的额外候选按产物和 UseItemType 建冻结索引。Host 先有料且可用的原物，再当前真实来源和其余有限有货候选；每次原版预检扣原共享预算，预算暂停保 range／ordinal／cursor 及依赖身份，确定拒绝只淘汰该候选／位置。早期原物缺料门与 Material 等待唤醒同用有效候选关系；补入一种允许替代可恢复相关范围，补无关物品不重扫全图。无 scene、无需求或有效策略关闭时不新增替换发现工作。

TryCreateExecution 从候选自己的冻结 rule 网格和已解码 prototype 建立私有 Cell／Object，再由 TryDescribeTarget 重新解实际 Body。原 Requirement 和 raw 模板不改，不复制原 Body 后仅换 style。普通替代继续走原 ToolUse 与材料准备 owner；PreflightBuildObject、ExactObjectBuildChoice、NativeBuildChoice 和晚期消费者用严格 SamePlacement 核本次具体执行，再由原要求核该产物仍允许。Containers／Containers2 的网络 action、style、top-left 与回执随具体执行，不能沿原要求发另一类容器请求。

火把 helper 推导的有效产物与真实来源分开：TryEffectiveTile 可取获准输出的网格，保这次 SourcePlacement 的确切 Use／Consume 身份。NativeBuildGeometry、legacy writer 和读回核这一份具体输出；后续世界正常变成另一允许火把只影响世界认可，不能代签早先未知消费。替换关闭时不借该组放宽旧精确路线。

Smart 平台中心取实际执行 type／style。每个可能被原版改形的邻格先证明它满足自己的原要求及当前策略，再严格绑定现场 Tile 引用、type、FrameY 与前后 shape；允许同类不授权改邻格材质、未选成员或范围外内容。原 Smart 输入、有限 write set、真实中性释放和有界回退继续有效，不能把全部替代平台退回先放平再锤来代替已有直接斜放。

世界材料先按本次 view／mask／世界本体收集所选范围的完整原需求，随后以一次 BlueprintMaterialInventory 构造 BlueprintMaterialAllocation。同一共享供给图的精确边费用为零、替代边为一；增广先原物，必要时经反向边重分配相交候选池，容量按整份数量推进，不逐堆叠单位循环。Held 保实际精确原物库存，AllocatedExact 与 SubstitutionAvailable 是该行已分配的供给，Missing 由后二者扣除。publisher 只在完整 bill、库存或策略真变时重建一次共享账，再沿原行预算发布；不逐行复制同类库存，也不取得原生物品锁。模板静态清单仍是名义原图，Pending／Unresolved 与库存暂存保护不变。

### 有效策略失效与恢复

RefreshSubstitutionPolicy 是唯一发布口；总开关关闭时改单类只保存偏好，不撤确实仍为精确关系的证明。有效总开关、已启用类别或当前目录关系改变时递增有效 revision，停止新增旧规则动作、撤旧 Match／材料与本体 proof、候选及等待，原更新预算重建存活实例。最终退休、prepared／continuation 与异步晚结果必须属于当前策略及当前 owner／range；旧完整 Match 不能与新 partial 拼成完工。

已进入消费者、归还、未知扣料和网络回执仍按原准确 token／receipt 收尾，关开不恢复消费、不解锁 Unknown，不复活已退休实例。模板、raw frame、确定不依赖策略的源缓存、镜像 view 和永久 mask 继续归原 owner；scene 不保存具体选材、候选或 Match，重进按当前全局偏好重新建立世界证明。关闭／无实例／稳定输入不新增全图、全物品、I/O 或日志循环；Draw 只消费已发布状态。

## 世界匹配与当前完成证明

[#138](https://github.com/Kuroneko2020/JueMingR/issues/138) 按所有者明确委托实现[匹配行为](../功能介绍/蓝图世界投影行为合同.md#世界匹配移动资格与完成退休)，不迁移 v1 格式。Features 的 WorldMatchModel／Comparer 只比较纯值；Host 的 WorldMatchSource复用采集门与对象 decoder，一次 TryRead 只复制一格，TryDescribeTarget只解释保存值，不暗读完整对象。结构等价、组内同件证明、目标完整成员 raw 布局各有责任，捕获用 raw 稳定性不能替代跨建筑等价。

Open 在既有完整校验中为每个有格内容的物理块建立 SourceRange：原始层数、依赖外框和同模板共享的不可变位置／层位索引。外框仅作粗筛；精确索引不包含任何 CaptureCell 正文、观察到的 Tile 或世界值。普通稀疏位置按排序坐标保存，每点8B；不同层位时另2B，确有对象ID时另4B。相邻同层行段可压成矩形，几何树按节点32B另计，固定对象／数组开销保守计128B。对象Tile位置与整个footprint／扩展依赖合为每ObjectId唯一矩形叶，其它层仍独立；不能同时保点路由与重叠extent而把同一store送两次，也不能按整root去重掉后续真实store。可靠原版开门用已存Direction和OriginX的一致性取得hinge，左右两种源的合法union恒为hinge±1三列；两列源不能再左右各扩一列，无关第四列只在粗bbox内。异常metadata保守fallback并由语义门拒绝未知。DEBUG的SourceIndexBytes与O(blocks)查询目录、8MiB解码缓存分别计费；它是模板共享的静态索引，不乘实例数，也不宣称整个进程只占8MiB。

Source 通路与 viewport 的 Latest 槽分离，同一 reader／8MiB raw cache 和总请求／回执配额共享。一个identity仍最多一笔source运输请求；每请求最多64个有限逻辑需求，常规批目标256KiB，返回装下的合法前缀。首件超过批目标时单独服务并保原单window32MiB能力，未回子项不算完成；批满不退休合法模板。每子项保逻辑range、实际ObjectId、原请求ObjectId、offset／next／complete及独立window；旧单项API沿同一通路，旧回执属性只指首项。普通项交付当前物理块剩余源记录，不以过滤后格数代替原始offset；逻辑对象请求只带整件Tile，显式正ObjectId入口仍保旧完整全层语义。

worker先用已验证metadata与实际成员计数决定前缀，再将本批所需的真实物理块取union，一块只扫描一次并按ObjectId分发。普通同格其它层用WithoutTile独立留下；跨块对象成员从实际块号合并，不按巨大bbox扫无关块。共享window引用只计一次，回执目录／描述符、metadata字符串、summary两个克隆引用数组（每槽保守8B）、构造list容量与ToArray重叠都分别计费；summary字符串仍共享模板，不重复复制。加载根最多16个MissingPayload类别、UnreliableReasons不落v1根，因此完整最坏运输为32MiB+256B封装+128B引用槽，Host reservation用同一公开常量。构造按有限记录／计划／块yield，保List、Save、Delete及其它投影lane服务。取消serial在发布锁内再核，旧运输不能清掉同identity新请求。

Host全场景最多4个在途／就绪／部分采样工作槽；每在途请求按完整最大回执33,554,816B预留，就绪后按唯一window、Host目录与描述符实际估算收缩，源与预留总门为两份最大回执加16KiB槽开销。运输和世界采样分开选择：一个批可供多个对象在同一Update连续完成，大项保各自部分进度，至多4份采样list、metadata对象／私有数组、结果dictionary及witness另按实际容量计量；这些组件估算和共享cache／索引／已发布观察证明分别报告，不称整个进程内存峰。每次逻辑选择只检查这4槽及每槽至多64子项，已退休引用从临时选择数组立即清掉；不为每件小对象重新扫描全部待源实例。无实例时全清，晚回执丢弃；普通块仍保持按物理块顺序局部性，稀疏空洞不扫描。

已保存v1根要求UnreliableObjectCount为零，可靠整件成员少于2048；当前合法普通块与单对象源在256KiB批目标内。大于软目标首件的单独服务仍保留为旧32MiB协议能力的静态边界，不把无法打开的uncertain根当作已实测大对象，不改变该安全门或格式。

Failed回执的IdentityRetired表达worker实际已经撤销引用的事实，与FailureCode和viewport generation分开。viewport窗口预算退让仍保identity并按既有缩窗重试；source／模板广播失败即使恰好同名window-budget、generation为0，也必须按致命身份清理。Moving的candidate与scene restore共identity，Host先按identity释放活动source槽和优先引用，结束该编辑且不重建失效restore，再沿正常退休链释放其watch／显示／命中／窗口。普通Cancel仍重建原restore；同模板其它实例逐一消费对应失败，不Clear不同模板，晚source／commit不能恢复失效身份。

## 材料与实际施工接缝（#140 候选）

2026-10-28 的精确目标资格有限替代本节旧“非液体全为施工”口径。NativeItemCatalog 的既有 64 项 pass 同时保存原始直接／tileWand／Flexible 输出声明、编译状态及锁定版本的覆盖证据。BlueprintPlacementCatalog 分开回答 Construction／DisplayOnly／Unresolved、材料 Exact／Ambiguous／Unsupported 和当前 executor 能力；没有 descriptor 本身不是天然物否定证明。已证展示 Tile 只在派生施工副本 WithoutTile，原捕获与永久覆盖仍保全。

显示 Open 不等待目录。即使材料与自动施工关闭，Fixed 实例仍 demand 同一有界目录编译。唯一 worker 的 RequestProjectionQualification 以 template／catalog／classifier／raw mask 建立共享施工 geometry 和有效 required／unknown 分母，回执核原 identity、catalog 实例及 revision、mask 原引用。Host 只有资格 Current 才建 Match；原始 SourceRanges 与显示窗口继续共享原内容。mask 或资格改变撤旧 Match、贡献与候选，原始 mask 的旧 RemovedConstruction 只是历史派生值，不能再减作最终分母。外版本 root 的全部 required 保 Unknown，不能在 Host 单格查询时恢复为已知，也不产自动候选。

原四份／既定字节上限内的 build source 不再因未走完而永久 pin。每 range 的 forward ordinal 仍唯一拥有顺序发现进度；每 retained part 仅附有界的附近／最近真实放置邻接游标，直接二分原排序 cells，不复制目标表或世界完成状态。库存类型先负筛，范围 broad phase 复用原版 TileReachCheckSettings，再由准确物品范围与完整原版几何最终准入。真实变化撤旧候选证明、刷新当前范围，并合并一次附近重访；同源进行中的有限遍历保留序号，到尾后下一次服务才按最新范围重开，静止无变化的结束pass休眠。每个源的local／forward按有限slice交替先后，命中提前返回也先推进轮转；slice用尽只暂停，不误记源耗尽。四源继续共享原64 source-step预算，不为每个源另发预算。远处或暂不可运行的源可让出缓存，恢复后forward原位续行。
