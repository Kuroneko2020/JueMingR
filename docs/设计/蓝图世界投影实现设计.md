# 蓝图世界投影实现设计

适用行为见[合同](../功能介绍/蓝图世界投影行为合同.md)，存储 v1 机械规则沿[采集实现](蓝图采集实现设计.md)。本设计不更改旧正文布局、全库迁移或安装数据归属。

## 唯一协调与输入

HostBlueprintProjection 拥有 None／Following／Fixed／Moving、当前身份和原点、替换／移动的恢复事务以及请求代次。F5、库卡、凝胶条和公共绑定调用 Place／MoveProjection／CancelProjection／RemoveProjection；renderer 不反写 mode，worker 不替用户确认。独立 capture Flow、selection 和 accepted write 槽不被投影复用。资格依据实际选区、草稿、在途／未退休 operation，不依据 UI Visible 猜测。

沿原 BlueprintPointerProof 冻结鼠标与世界矩阵，仍由匹配 DrawInterface 的原版 UI 完整返回证明世界归属。输入先在原映射接缝观察物理键与语义 use，再由认证样本消费；Following／Moving 通过既有世界动作门，Fixed 不占门。启动与接管后必须可信全松，失焦不退休尾部；Moving 首个合格中性世界格仅建立增量基准。Esc 经公共 HotkeyInput 新动作及抑制尾部，不另写全局 WritingText、blockInput 或 raw mouse。

WorldLayer 分开投影与采集资格，不再因 State.Active=false 跳过 Fixed。复用 WorldTileObservation 的视口和原 GameViewMatrix／ReverseGravitySupport；UI matrix 仅服务 UI。轮廓四边先与世界可见范围相交再作像素转换，不逐格遍历完整 bounds。

## 单 worker 与回执

LibraryState 提供 RequestProjectionOpen、RequestProjectionWindow、CloseProjection、TryTakeProjectionReceipt。独立 mailbox 只有一个 latest 窗口与一个结果，不占普通 library accepted command／receipt 槽。Open 分阶段、按批让步，普通 List／Create／Delete 能取得服务；不新增读线程争 files owner。Opened 消费前有界背压，不能被提前 Window 覆盖。

Identity 为assetId／contentRevision／contentHash／sessionGeneration／projectionGeneration；窗口另有windowGeneration。Host 只消费当前资格，Close／移除／换 session／删除先退休资格，worker 于下个边界释放 index／iterator／cache。旧错误同样按 serial 退休，不终止新窗口。改名不进入 immutable key；取消替换保存旧身份和原点，以新投影 generation 重开旧资产，读新图失败不丢旧 Fixed。

Delete 在唯一 worker 内先关闭关联 index，再走既有墓碑／受保护文件流程；无永久 Pin 或无限清理重试。已确认 Deleted、确定未提交失败与 CommitUnconfirmed 分开。未知受影响 ID 本进程禁重读，Host 不凭缓存继续展示合法图。

## 空间目录、窗口与成本

Open 先核 root／metadata／index，沿旧完整顺序、对象引用和 footprint 校验，流读建立 cell 块first／last(Y,X)与对象块 ID 范围。只目录为O(B)，不保存全量 cell／object，也不增加全对象 ID 字典。一次目录构建O(N+B)；完整旧引用核验可能更贵，不能把整个Open冒称O(N)。index信任句柄由worker保留，窗口逐实际块核hash，不每窗口重验全index。

每个可见y按[xL,xR)二分块范围，去重后只解码命中块，避免超宽行退化整行。主体查询O(H log B + 2048 Bv)，另有Ov次对象ID范围二分及必要对象块。有界对象查找复用既有范围目录。局部格减保存Summary.Left/Top；Summary保源原点供自然内容sourceX奇偶，raw frame不改。

已解码块LRU保守计费≤8MiB且最多64块；目录O(B)，发布窗口及临时集合按真正可见交集面积A为O(A)，不设模板大小cap。Window.EstimatedBytes只估发布DTO，不代替临时List／HashSet与最终复制峰值；目录、cache、窗口和绘制命令分别计量。无投影无在途时不周期扫描／读盘。

上述8MiB仅是投影owner持久decoded缓存；完整旧v1验证阶段仍有原ObjectLookup临时8块缓存、单当前chunk及hash缓冲，Open结束释放，不把持久cache计数冒称整个Open或进程内存峰值。

视口逆变换到局部范围并扩真实视觉／邻接halo；静态metadata外延下限5格，晶塔按当前资源真实分格尺寸增大RequiredHalo。完整窗口到齐再发布：已证无记录才是空气，NotLoaded／失败不进入永久派生结果。窗口失败不发布半结果，明确错误停止本次读取并保库资产。原点变化不克隆／重parse资产；相机或移动改变可见窗口时只请求latest，静止同屏0新文件读，不遍历N。

## 纯值绘制与图形资源

BlueprintProjectionRendererCommands 只解释有界local cells／objects与纯值summary，生成纹理key、source rect、局部像素、flip与颜色命令。SetWindow仅完成Window引用改变时重建，Draw只加origin／camera与原版world变换。纹理按distinct可见key在graphics线程借用原资源，pending继续绘制后续帧；paint沿原版纯资源路径请求，不把RGB乘色当精确paint。借用资源不Dispose，设备身份变化后不使用旧device纹理；无自有大型RenderTarget或全图烘焙。

半砖保1:1源裁剪，坡面沿原版2px条带，平台独立分支；邻接仅用已完成halo。可靠家具保raw member frame，元数据解释绘制尺寸／行高／偏移，不统一frame/18；逐格恰好一次，屏外origin不丢可见片段。晶塔用独立纯静态纹理帧，不调用实体创建、运行态或真实Player绘制。墙邻接推导frame，液体静态按kind/amount，四线／致动器独立像素符号；不调用会读写Main.tile的DrawSingleTile／GetTileDrawData等入口。

资源／解释的明确错误只停止该投影并一次反馈；未知tile／wall不能数组越界拖垮Runtime或静默丢层，库原文件保持。缺纹理未ready是等待，不能误报永久坏资产。原始字段、蓝图邻接推导、缺美术上下文的静态代表三者分开，不声称源景逐像素复制。真实原版参照和实际WorldLayer的图形证据分别登记，CPU命令正确不代证最终像素。
