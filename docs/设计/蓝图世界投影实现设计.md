# 蓝图世界投影实现设计

2026-10-26 [#140](https://github.com/Kuroneko2020/JueMingR/issues/140)／[Draft PR #141](https://github.com/Kuroneko2020/JueMingR/pull/141) 的材料与实际施工接缝见文末；既有匹配、永久 mask 和稳定退休仍为最终事实出口。

行为权威见[投影合同](../功能介绍/蓝图世界投影行为合同.md)，v1机械格式与持久化仍见[采集设计](蓝图采集实现设计.md)。不迁移／重写旧库，不持久化 world 实例。

## Host scene 与编辑事务

HostBlueprintProjection 是唯一 scene owner：每份独立 identity(instanceId)、origin、commitOrder、immutable sparse mask；world session 与 sceneRevision 属 Host，只有一个 pending Open／候选／SelectingMove／SelectingRemove／Moving／Committing 事务。TemplateKey(assetId,revision,hash)不含 origin/session/instance。CurrentProjection 只是候选或最新 Fixed 的兼容只读投影，不是 scene 权威。

OwnMove/Remove/PlaceCancellation由真实mode、pending与restore引用派生，Committing仍保来源；CanInvoke对应入口为可开始或可取消自身，Host命令先自身取消再开始，注册predicate同门。F5将来源传入Prepare→Layout.Matches/Ensure/built缓存，移动／移除行原位更换名称与按钮但HotkeyTarget不变；Toolbar区分None/Fixed/Place/Move/Remove且重测同源按钮和可选第五槽，generation改变取消旧armed，物理release尾仍由原owner消费。SelectingRemove的RemoveAll只调用ClearProjection并收pointer／toolbar，退休worker／window／commit与全部scene资源，不删除资产；晚回执不得复活。正常commit受理不写反馈，真实错误通道保留。

移动候选复制原点和旧 mask，旧位置只为取消保留；绘制排除原 Moving source，避免两份预览。启动、选目标、确认各走 BlueprintPointerProof 与既有 HostInputState 的新手势、世界门及独立释放尾缘。Pointer 保冻结 world matrix，并保 tile 内部位置供半砖坡命中；不 raw polling／全局清键。失焦只打断基准，可信 neutral 重建增量，明确 Back／Esc 才取消 Open。Fixed 不占动作门，F5 关闭不清场景。

Moving隐藏source仅退休派生命令，原immutable DTO／mask／origin／order仍由restore持有；共享DTO按引用只计一次，不能让隐藏旧命令占满64MiB后误拒自己的候选。取消先丢candidate命令，再从原DTO以restore有限优先恢复全部core，不重新读盘／解码；Moving期间晚Open只更新source验证资格，不重建隐藏命令。整renderer重建资格在遍历cores前固定，避免首core发布后误跳其余同mask快照。point16从选中进入Moving后归rollback保留，取消保exact旧快照；成功提交转给copy，完整128core包含point后合并，不让Fixed旧point长期抢占后续candidate。

确认按轻量 bbox 筛 scene 对手、排除 Moving 自身，给原唯一 worker 一份(session,transaction,sceneRevision,candidate,previous)纯值请求。后台查整个真实重叠和完整对象成员，返回完整新 masks／空实例 IDs。Host 核三身份仍匹配后一次应用 masks／origin／最新顺序和退休；预览／失败／取消不留部分提交。Mask 只增、永不露底复活，按局部格位／对象集合需量增长；Tile、Wall、Liquid、Actuator各位及四色Wire独立，对象ID只在该instance内有效。

Committing 期间固定实例因读取或图形解释失败退休，Host 先取消整笔编辑、恢复移动原位置，再释放故障引用；worker 在途计算和已发布旧回执都不能提交。当前事务回执若遇 sceneRevision 失配也显式结束事务，不留 Committing 占用动作门。成功原子应用内部的空实例退休不触发这条取消路径。

## 唯一 worker、模板共享与公平

LibraryState 提供 RequestProjectionOpen/Window/Source(s)、ClearProjectionWindow/Source、ReleaseProjection、CloseProjection、Request/CancelProjectionCommit 与相应 Take 回执。每模板唯一 Index／ProjectionDirectory；多实例只持引用，最后引用退休才释放 reader 与该模板 raw blocks。无每实例线程／8MiB缓存。普通 List／Create／Delete 优先取得服务，Open／Window／Overlap／Source四路轮转并有批次让步；Save 已受理边界不被取消读触及。

未完成 Open 最多32条背压，存量 refs 不限数量；window active+pending最多32、每identity latest、FIFO。Opened／window／source回执分身份，总32条及32MiB正文加384B单项source封装／summary引用槽的共享DTO背压，单window原32MiB能力不缩，Take唤醒；无新需求不忙轮询。全模板 decoded raw 共8MiB／至多64块，保守计费128+cells×64+objects×128，Open对象引用校验也借全局cache，避免32个iterator各乘一份8块cache。旧普通保存validator仍保原私有cache。

last-ref退役标志独立参与worker工作谓词；释放一批reader期间到达的新退役不能随普通wake被消费后遗留，且不依赖新操作／Take回执才释放。删除失败恢复先保留原窗口供绘制，未Opened时移动资格仍为Checking；旧窗口不代证当前世界。Open及原位置观察就绪后要求新点击才进入Moving。取消与晚回执按原identity恢复Fixed命令，不依赖相机／coverage变化。

窗口先消费当前需求已有cache hits，再读miss，65块／63驻留反例无需涨8MiB常数；无用旧请求可退休，已读immutable blocks保留。Host每instance单pending core，不因精确view每格变化替换仍有用结果；回执只要该core仍在当前coverage就按当前mask应用，world/session退出或明确取消则退休。

完整Open继续核root/meta/index/hash、旧v1顺序／引用／对象footprint；目录构建O(N+B)不代表全部旧完整验证总成本。ProjectionDirectory仅每块first/last(Y,X)及object Id范围，O(B)，不保存整正文或对象metadata字典；匹配供源另保每对象的纯整数成员数量和实际成员块号，计入模板共享SourceIndexBytes。按X/Y二分命中块，整重叠查询跳过块前空行并复核跨块末行，不因百万行稀疏bbox逐空行扫描。实际窗口读块hash，不每次重验全index；object元数据按块首末Id二分及块内二分。

## 有界 source cores 与命令增量

Host默认128×128局部source core，加真实视觉／邻接halo，core／segment以source坐标稳定对齐；同模板远距窗口分别请求，不粗并巨大bbox。每帧最多4个新window admission、场景轮转且候选优先；每instance只一笔在途。超worker DTO预算按FailureCode缩core128→64→32→16并保模板引用，极小范围仍过密时停止原样重试，移动coverage后可重新退让，不退休实例或变模板尺寸cap。

Host scene retained effective windows总32MiB、derived commands按每条80B计总64MiB。回执核身份后对含halo的完整window按当前永久mask产生不可变effective DTO，保bounds／完成事实、未mask层及有效Tile引用的整件metadata，再按构造器重算bytes。commit新mask时替换受影响快照，Moving copy／restore不原地改旧window；shared8MiB保原始模板块。Renderer先stage replacement命令及净增bytes，两预算均容纳才一并发布；拒绝释放局部stage，不覆盖现有有效core。完成空、预算拒绝和未读分开，只有完成空允许向下命中。

普通缺core采用先到驻留，不驱逐仍在coverage的resident；容量不足记录该实例／core／mask／demand的denied，稳定同需求不重读／重build。candidate及一个用户明确点击的16格point core可有限抢占普通core，普通不能反逐；hover不提升优先，点读到货仍要求新点击才选择。DTO与commands同步RemoveCore，完整core包含point时合并ownership。coverage／mask／候选或point需求变化及实际Trim／remove／cancel／retire／compact释放才重试，Pump／Draw／completion本身不推进capacity epoch。预算不足仅提示部分可见内容暂未加载，不宣称全显，不用涨常数或永久冻空替代收敛。

离屏清窗口／段并撤在途需求，保轻量实例／模板引用。上述分别是DTO payload估算与retained commands，不是进程内存峰或整个scene heap；窗口／List／Array复制、segment邻接样本、hash、Open每iterator当前≤2048记录及32KiB缓冲、查询目录O(B)、下述共享位置／层位索引、mask需量与GPU借用分别计。无实例／候选／在途时不周期扫库或读盘，允许必要O(instanceCount) bbox粗筛。

BlueprintProjectionRenderer按16×16 source段保存完成窗口的纯值命令，比较真实局部cells／objects和一格邻接，仅重建进入／变化段；mask改变同样按段比较，origin不入key。每窗不Clear整个命令cache，离屏trim历史段。全局Wall→Liquid→Tile→特殊本体→Wire/Actuator pass保持，避免分段家具外延被后画墙遮住；晶塔本体去重。缺少的邻接是unknown，不当空气永久定边；raw窗口带完整halo后发布，masked邻接从有效内容重新派生。

优先新 core 真实超预算时，先对已有不可变窗口／Segment 引用作局部 victim 规划，普通可容纳窗口仍走原快路径，ordinary receipt 不取得驱逐权。raw 严格按现窗口共享身份去重，commands 复用 Extra 位置去重且只更新受影响 owner；incoming stage 也剔除同 owner victim。只有两个预算都可满足才实际移除并发布最终 stage，再以最终容量 revision 记 victim denial。不可满足时只拒绝 incoming 并保留相对真实未变状态的原净成本，不改旧 resident、renderer commands、命中与容量 revision；不靠实际驱逐后重读恢复，也不每帧清 denial 或扩预算。

## 资源与失败

WorldLayer组合所有已就绪Fixed与唯一候选，沿既有GameViewMatrix／ReverseGravitySupport；轮廓裁view后转像素，不扫全bbox。命中反向提交顺序，在完成core中二分cell再应用mask；空气／masked层不抢目标，NotLoaded不选穿。半砖／坡看tile内坐标。Hover与点击共享同一目标。

纹理只在graphics线程按distinct key借原版资源；paint请求ready后不固化fallback。设备身份变化不使用旧device纹理，不Dispose原版借用资源，不因此重读正文。不调用有world／生态／实体副作用的DrawSingleTile/GetTileDrawData/TileObject.DrawPreview作产品API，不替换Main.tile或Player，不烘巨大RT。

库删除在唯一worker先停asset新读／释放Index再走原可靠墓碑流程。Host退休所有引用并保存仅用于确定precommit失败的旧scene快照；仅 DeleteProvenUncommitted 恢复，Unknown／Protected不盲复活。恢复先保全旧 identity／origin／order／mask／窗口，Host 每次 Pump 最多四笔 Open admission；背压 false 保留在轻量待受理队列，未完成 Open 仍最多32，不能变成实例恢复上限。重新验证前不确认与该实例重叠的编辑，明确移除／session退出会退休相应资格。可靠失败重Open后复用验证未变的窗口。单instance移除不影响同模板其它引用，rename仅meta。错误回执按session／identity退休；图形解释错误停止故障instance并按上述规则终结受影响确认，正常资源等待不假坏资产。实际证据及未测边界回交付记录。

## 世界匹配与当前完成证明

[#138](https://github.com/Kuroneko2020/JueMingR/issues/138) 按所有者明确委托实现[匹配行为](../功能介绍/蓝图世界投影行为合同.md#世界匹配移动资格与完成退休)，不迁移 v1 格式。Features 的 WorldMatchModel／Comparer 只比较纯值；Host 的 WorldMatchSource复用采集门与对象 decoder，一次 TryRead 只复制一格，TryDescribeTarget只解释保存值，不暗读完整对象。结构等价、组内同件证明、目标完整成员 raw 布局各有责任，捕获用 raw 稳定性不能替代跨建筑等价。

Open 在既有完整校验中为每个有格内容的物理块建立 SourceRange：原始层数、依赖外框和同模板共享的不可变位置／层位索引。外框仅作粗筛；精确索引不包含任何 CaptureCell 正文、观察到的 Tile 或世界值。普通稀疏位置按排序坐标保存，每点8B；不同层位时另2B，确有对象ID时另4B。相邻同层行段可压成矩形，几何树按节点32B另计，固定对象／数组开销保守计128B。对象Tile位置与整个footprint／扩展依赖合为每ObjectId唯一矩形叶，其它层仍独立；不能同时保点路由与重叠extent而把同一store送两次，也不能按整root去重掉后续真实store。可靠原版开门用已存Direction和OriginX的一致性取得hinge，左右两种源的合法union恒为hinge±1三列；两列源不能再左右各扩一列，无关第四列只在粗bbox内。异常metadata保守fallback并由语义门拒绝未知。DEBUG的SourceIndexBytes与O(blocks)查询目录、8MiB解码缓存分别计费；它是模板共享的静态索引，不乘实例数，也不宣称整个进程只占8MiB。

Source 通路与 viewport 的 Latest 槽分离，同一 reader／8MiB raw cache 和总请求／回执配额共享。一个identity仍最多一笔source运输请求；每请求最多64个有限逻辑需求，常规批目标256KiB，返回装下的合法前缀。首件超过批目标时单独服务并保原单window32MiB能力，未回子项不算完成；批满不退休合法模板。每子项保逻辑range、实际ObjectId、原请求ObjectId、offset／next／complete及独立window；旧单项API沿同一通路，旧回执属性只指首项。普通项交付当前物理块剩余源记录，不以过滤后格数代替原始offset；逻辑对象请求只带整件Tile，显式正ObjectId入口仍保旧完整全层语义。

worker先用已验证metadata与实际成员计数决定前缀，再将本批所需的真实物理块取union，一块只扫描一次并按ObjectId分发。普通同格其它层用WithoutTile独立留下；跨块对象成员从实际块号合并，不按巨大bbox扫无关块。共享window引用只计一次，回执目录／描述符、metadata字符串、summary两个克隆引用数组（每槽保守8B）、构造list容量与ToArray重叠都分别计费；summary字符串仍共享模板，不重复复制。加载根最多16个MissingPayload类别、UnreliableReasons不落v1根，因此完整最坏运输为32MiB+256B封装+128B引用槽，Host reservation用同一公开常量。构造按有限记录／计划／块yield，保List、Save、Delete及其它投影lane服务。取消serial在发布锁内再核，旧运输不能清掉同identity新请求。

Host全场景最多4个在途／就绪／部分采样工作槽；每在途请求按完整最大回执33,554,816B预留，就绪后按唯一window、Host目录与描述符实际估算收缩，源与预留总门为两份最大回执加16KiB槽开销。运输和世界采样分开选择：一个批可供多个对象在同一Update连续完成，大项保各自部分进度，至多4份采样list、metadata对象／私有数组、结果dictionary及witness另按实际容量计量；这些组件估算和共享cache／索引／已发布观察证明分别报告，不称整个进程内存峰。每次逻辑选择只检查这4槽及每槽至多64子项，已退休引用从临时选择数组立即清掉；不为每件小对象重新扫描全部待源实例。无实例时全清，晚回执丢弃；普通块仍保持按物理块顺序局部性，稀疏空洞不扫描。

已保存v1根要求UnreliableObjectCount为零，可靠整件成员少于2048；当前合法普通块与单对象源在256KiB批目标内。大于软目标首件的单独服务仍保留为旧32MiB协议能力的静态边界，不把无法打开的uncertain根当作已实测大对象，不改变该安全门或格式。

Failed回执的IdentityRetired表达worker实际已经撤销引用的事实，与FailureCode和viewport generation分开。viewport窗口预算退让仍保identity并按既有缩窗重试；source／模板广播失败即使恰好同名window-budget、generation为0，也必须按致命身份清理。Moving的candidate与scene restore共identity，Host先按identity释放活动source槽和优先引用，结束该编辑且不重建失效restore，再沿正常退休链释放其watch／显示／命中／窗口。普通Cancel仍重建原restore；同模板其它实例逐一消费对应失败，不Clear不同模板，晚source／commit不能恢复失效身份。

物理SourceRanges与逻辑MatchRanges分开：每物理块至多一个普通层证明，每个对象的Tile只有一个完整证明owner，跨块尾成员不重复计数。普通证明去掉对象Tile，保同格墙线等独立层；对象主回执直接带这一件全部目标Tile成员及metadata，不再先anchor后二次申请，Batch与对象比较引用同一个不可变DTO。完整对象只决定一次结构结果，逐成员计数／显示沿有界源游标消费，不能把整件结果再重复计Tile；依赖格与halo不入分母。模板共享点／矩形索引与对象ID到组内ordinal路由，不在每实例持全正文。无对象块复用原几何，额外逻辑几何与路由独立计入SourceIndexBytes；每实例仅持轻量逻辑摘要，离屏不分配空Visual字典。原生watch仍按物理块，不随家具数量增加；仅含较早owner尾成员的空组不注册。混合尾组的interest与路由均按它实际拥有的证明二筛，不能让尾成员真写触发空路由再误撤普通兄弟。

每个固定实例以 session／instance／origin／mask 为位置身份，按逻辑范围持当前覆盖、有效层数、Match／Unknown数、变化stamp与有界游标；不与sceneRevision共用变化版本。世界读取留游戏线程，Host.Update在既有Pump之后按updateTick仅领一次配额，目前最多256次真实读格、256个源游标步骤和64次逻辑调度，masked／空层跳过也扣源步骤；Take最多64次；本token前后两次source admission共用64次尝试及4笔新申请，范围查找亦有限。已有批内子项完成后沿剩余配额继续，无就绪项或无状态进展即返回，不等worker、不零读忙转。Poll不领世界配额，Draw只消费已发布结果；这些是实施预算，不是产品容量或统一延迟承诺。完整分母严格是TotalLayerCount减永久mask.RemovedLayerCount，主格每层只计一次；完整对象依赖和halo不重复计数。

模板source与世界样本分别持有资格：session／模板revision/hash／实例／range／请求token决定不可变source归属；raw资格只在targets到达、真正开始采样时取得，不沿用发文件请求时的stamp。相关变化只撤该项过期样本、局部计数和未发布witness，合法source／在途请求／同批稳定兄弟继续；批内游标使被反复撤销的首项让出兄弟。身份退出、origin／mask重建或fatal身份退休才清对应全部运输与采样。不能把运输批、物理观察组或文件token当作共用世界版本。

实际采样服务采用普通场景轮转与最多隔次的显式移动优先；成功优先服务不推进普通游标，成功普通服务转到实际被选实例的后继，跳过待源项不虚耗普通位置。source admission有独立普通游标和交替优先门：实际普通请求成功后保它的后继，不能把整圈容量扫描的尾部当成下一起点；若有限前缀完全无普通成功，则按实际扫描位置继续下一Update，scene不设实例数cap，超过64的尾部也不能丢。未入工作槽的移动priority也参加有限source准入，优先成功不消耗普通准入后继，待源不会占世界服务。删除较早scene项同步左移两个游标以保后继身份。大项每Update受相同配额并保部分采样；若4槽均忙而有新实例等待，只对非pending、无活动样本、曾raw重启且只余一个源子项的工作让出槽，已完成兄弟证明仍保留，稳定大项不为腾槽丢进度。唯一在途Door seed的有限3×3续接先收口，再开始另一门seed，不新增observer所有者。

SceneIndex只是由scene次序派生的调度位置，不是工作或模板身份。DeleteProvenUncommitted恢复旧副本时，首个Add之前按恢复前scene/count分别取得普通采样与source准入的后继对象；恢复并按CommitOrder排序后，只在该重排边界按work.Owner的实际引用重算最多4槽的位置，并分别找回两个后继，空scene或已失去的锚点从0开始。不能凭AssetId／相同Identity将旧work绑定恢复副本，也不在每次采样选择中全scene搜索。存活work、token、Pending、源段／请求集合、read／部分世界采样、证明／需求、子项游标及两套优先轮转原样保留；确实不在scene的owner先取工作快照再沿逐身份释放链处理。普通append、单项Remove、移动提交的remove+append及Clear继续使用原入口；显示窗口游标没有相同的工作身份缓存，不参与这次协调。

BlueprintWorldChangeObserver只服务当前范围watch。原版字段写入前按真实packed位差得到Tile／Wall／Liquid／Actuator／各线色变化位，先范围外框，再由共享索引按实际坐标、变化层位和当前永久mask二筛；对象额外成员只贡献尚有效的Tile依赖。空洞、其它格的目标层、非目标层和永久消除的层不制造pending或撤证明。这个纯值查询不读世界、文件或scene。Watch6以固定ordinal位表累积精确DirtyRoutes／PendingRoutes；每次真实写按原位置和层直接路由，不能把矩形union与层OR的笛卡尔积当精确事件。DrainRoutes只消费位表，pending期间仍拒绝当前性，finally重发实际已标位，不重新用union扩出中间兄弟。Host只消费这一通路，不混用兼容的旧Drain矩形接口。

实际运行态持续改raw frame与Main.tileFrame绘制数组不同。已经完整Match的固定footprint对象可在游戏线程由现完整样本生成不可变frame/layout witness：重核canonical建筑、成员完整布局及原metadata，保存小型合法phase表和行偏移，不保CaptureCell或世界DTO。原写栈仅用已捕获坐标、字段及old／new纯值核旧值链与全成员phase；根原版事务正常Finalizer收口、全部覆盖且同态、没有嵌套异常／交错writer／其它语义改变时，才可延续这个既有canonical证明。真实raw版本、dirty与pending始终变化，所有在途原始成员样本仍取消重取；不可变source本身不因这类世界变化失效，证书不能产生首个Match。没有证书、缺成员、涂层／类型／结构改变及未知身份沿硬失效。

门改变type与1×3／2×3占位，使用独立的三种合法pose证书。Host在同256预算内补铰链±1的3×3上下文，复用当前已读的3／6格，仅增加6／3格；所有格均经同一section与身份门且必须被watch涵盖。CaptureSource在同一次实际取格复制最小Tile写状态，保inactive格真实残留字段，机械CaptureCell／格式不变。证书仅保9个小标量状态和每row固定外观；最终完整closed／left-open／right-open才延续。闭门每行随机槽分别合法，开门目标若两列外观不同仍可与自身Match，但不能据此延续到会丢掉翼外观的闭门状态。未用翼可以是真实其它Tile，合法单侧开门不要求两翼空；其它有效目标的写照独立ordinal撤销，不能被门证书吞掉。

ordinary frame通常不参与普通Tile语义，却会影响门下一次占位的raw旧值链。因此已有Door witness及唯一正在读取的Door seed都须接收其范围内真实raw frame变化，不能因当时type0／1而漏记，也不能让同块普通Tile重核。Host在第一次hinge读之前注册同锁的BeginDoorSeed租约，最多一个；发布证书之后及所有取消／失效／session退出均统一释放。无证在途的变化仍撤读样本，不能先读旧seed再在同stamp下发布新证书。这个窄兴趣不在原版写栈读取其它格或metadata。

写源安装按锁定`.8`的实际Tile字段写载体和运行时可达关系选择：Main直接WorldGen调用、运行WorldGen内部call／ldftn及实际构造的GenAction写叶，保留夜晚陨石和后台hardmode链，排除仅新世界生成pass可达的写者。Tile及接收Tile的短mutator先于caller安装，避免caller先JIT把未插桩setter内联。升级原版必须重核该边界，不能把方法计数当完整性证明。Hook保留原版array读取与store旧字段取值，ordinary-frame门也读取当前type／Main.tileFrameImportant；“证书求值无世界读取”不等于原版栈不读Tile。普通地形在该flag为false且源适配不比较raw frame时不撤普通证明，门证书／在途seed的额外raw依赖另按上文保护。重要家具结构帧、类型、形状与外观仍失效。Main.tileFrame绘制动画数组不是内容epoch。

原版调用栈内的Tile→坐标关联每scope最多256项，另保最近一次实际读点；每线程最多保留16个scope池槽。超过关联上限不截断原版循环、不因只读或同值写而dirty。仅在真实字段变化且有限关联／最近读点均无法定位时，按此前实际读到的活range及变化层摘要保守撤相关证明；这可能扩大同层复核范围，不能冒称仍为精确逐点。正常接收循环的后续写通过最近读点继续精确定位。Leave清Tile／摘要引用，最后watch或session退出原子清包括已闲置后台线程在内的池槽；活动调用仅保留到其finally。资源清理代次不作为世界变化版本。

section获得、整Tile替换／身份替换按实际读取资格保守失效；Main.tile／sectionManager换对象会重建绑定的观察适配与账本。真正后台TransformWorld以原版在途计数及委托lease保护，写源开始前没有watch、写中新增watch也不能采样。既有WorldTileObservation的身份revision和视图geometryRevision均不当作内容epoch。完成和操作资格通过observer同锁的TryRunStable，再核全部相关range stamp，阻止最后核对与退休之间穿入未处理写入。

Host对对象先取完整目标成员，再按canonical建筑选择当前实际世界矩形逐格证明，实际读取bounds必须被该range watch涵盖；门开闭的额外列属于此依赖。未读／不可读／不完整保持Unknown。初次完整采样建立的各范围证明，在后续写入边界由observer同步撤销或由完整witness维护；所有范围可在同一最终时刻共同有效，无须强制再读整份source／世界第二遍。最终沿同一个observer稳定锁核全部range的当前资格、pending、session／固定身份／origin／mask、正的准确分母和Match／Unknown，不能只看最后range或总数。中途硬变化撤旧摘要并重排，不拼历史成功；已具完整证明时，纯显示补读／文件需求不单独延后退休，正常退休会取消它。稳定缺失／冲突场景无dirty或显示需求不再读世界；主动未知移动检查可提出有界重核。离屏范围与相机活动没有依赖。

Renderer命令在按语义层生成时保cell与Tile／Wall／Liquid／各线色／Actuator位；绘制pass不替代语义位。Match跳过相应命令，Conflict着红，几何、源邻接和永久mask不变。深绿／黑等原版涂料纹理会把乘色tint的红通道压掉，因此冲突层另借既有MagicPixel画独立红色细边；每格／层仅末片段有标记，坡面不会逐条重复，所有边集中同一pixel pass，避免每格切换纹理。不创建涂料图集、GPU读回缓存或其它拥有资源。Host仅为当前驻留窗口保结果值，窗口退出清相应显示明细，完整覆盖摘要仍在。只读facade由Host同一游戏线程在Update发布不可变cell结果，Draw不写；不在每次源进度后复制全部可见表造成首次覆盖平方成本。位置相关结果不进入共享模板cache。

Move／Remove入口分别保原编辑／输入互斥；选中实例的hover、点击、最终确认和提交共用当前移动资格。Moving候选不匹配退休，原restore继续观察；最终提交在稳定锁内核原位置确实无Match。Following不自动退休，合法确认先完成永久覆盖，再成为固定实例参与匹配。完成退休仅作用scene中固定实例，Committing期间延后，到安全出口重新核origin／mask／epoch；实际复用单实例释放链，不用revision=false绕开取消保护。清hover／point／手势后不将旧点击转给下层；旧source回执、删除失败恢复与迟到commit不能复活已完成身份。工程、图形、普通包、实际安装、真人、主客机及FPS证据仍分别回任务和交付记录。

## 材料与实际施工接缝（#140 候选）

composition 注入唯一 HostItemBrowser.Knowledge.Native 放置目录，目录独立发布 PlacementRevision 的纯值描述。BlueprintMaterialSteps 的 SameBody／RequiredSteps 共用于计料与施工，最终 BlueprintWorldMatchComparer 不变。动态材料仅有查看或施工 demand 时，随原 Match 的同次采样更新范围贡献；对象每个原读顺带更新 BlueprintObjectBodyProof 和后处理 reducer，本体计一次，不新增世界／source 配额，也不等材料就绪才退休。每范围旧／新贡献按 64 步游标加减到单实例与全部 totals；失效先撤当前性，晚身份不能重挂，行发布也有界移交 list。Pending／Exact／Unresolved 独立于 Match。

有 Fixed scene 而放置目录正在重建，或 scene 中 Match owner 尚未建立时，动态材料撤旧 Exact 并保持 Pending；全部范围不把暂时空 totals 当成需求零，Match owner 初始化立即撤上次 publication。这只约束材料发布，不阻原 Match 推进或自然退休。目录语言事件重新发布名称与 revision，放置身份仍按同一原版 Item／style／alternate 解释。

主背包 0–49 每个被需求的 game tick 只观察一次，槽资格借 HostTools.BuildInventoryEligible；不变时复用同一不可变 snapshot。真实使用再核 slot、Item 引用、type、正 stack、保护与 inventoryChestStack。额外自动饰品来源只属于一次原版动作的有限依赖，不加入主动取材库存口径。静态材料 worker 缓存 16 项／2MiB，8 等待加 1 活动；它与原 raw 8MiB、目录、贡献和临时对象分别计量。Create／Discard／Delete 先关闭同源材料句柄，不占 accepted command 或 Preview 代次；取消保活动 owner 至 worker 安全点。

HostBlueprintAutoBuild 从原范围采样消费每范围一个候选及 Cursor，不持完整世界正文或第二完成表。相同 eligibility epoch 遍历完即停；前检失败前移并让其它 range／实例服务，真实库存、位置、作用距离、有效动作门或相关世界变化重新唤醒。动画期间可保有一个就绪事实供原 combat／extraction handoff 查询，但只有 Choose 在原版动画、itemTime、channel、reuseDelay、release 和 selectedItemState 条件满足后申请使用。

放置支撑不属于最终目标层。相同 physical watch 另持按原 proof ordinal 的有限 build dirty 位与 SupportStamp；原共享 source 几何将真实变化查询扩一格，映射到相关普通层／整件候选，关闭施工时旁支撑不产生兴趣。type、墙体、active／Inactive／half／slope 及液体可撤原放置资格，支撑漆色和运行帧不反复唤醒；未知位置压力路径仍保守处理。只重启相关 range 的候选游标，借同一 source／世界预算补采样，不改 Match 版本或完整 witness。候选与跨 tick read 同时核 SupportStamp 和该 range WakeRevision，store→drain 或旧 read 收尾不能吞掉新支撑；未变材料贡献仍保留。这些有限版本是局部资格，不是全世界变化 epoch、第二观察者或动作队列。

ToolIntent 的 Build 是原四域之外的独立第五调度域。ItemOperationOwnership 仍只有一个 use token；主来源保持 0–49，原自动油漆／涂层和致动器可能挑到的真实有限附带槽，作为同 token 的依赖掩码保护。ToolUse 借原选槽 override，在 TrySyncingInput／ItemCheck 的既有作用域提供一次合法 press、目标坐标及必要方向；不制造 release，不重置时间，不复制 Item 或恢复已消耗 stack。临时方向仅在本 scope 仍拥有写值时归还；会因 ChangeDir 移动滑轮的条件先拒绝，不移动玩家。

整件候选复用同一次完整空 footprint 证明；原 TileObject.CanPlace 正常选 alternate／random 后，PlaceIt 前核其实际几何与 canonical 建筑身份，再允许原放置。没有额外 CanPlace 预演，避免原版 random／Preview 缓存副作用。普通块／墙额外资格只做常量范围检查。原 PlaceThing_Walls_FillEmptySpace 最多补四个邻洞，加目标本身最多消耗五件；ToolUse 按此真实上界核主来源。自动装饰可能逐成员换到后续堆，有限候选依赖涵盖这些真实可能来源；既有 ItemPendingGuards 只为本次 owned native consumer 放行，未相关槽仍受保护。世界 observer 的真实写入撤全部相关范围，不手动假报一个格完成。

材料反查与实际放置描述分别承担职责。原版 GetTileData(Tile) 对部分 StyleMultiplier／alternate 会反解为根元数据，canonical 捕获的 Origin／Direction 因而可能不同于实际 writer。材料只按 frame、完整尺寸及唯一耗材身份反查，保留实际 descriptor 的 style／alternate／direction／origin；不能拿 canonical 元数据假消歧或覆盖操作字段。施工仍将这次原版 CanPlace 的实际结果归一后与完整目标 SamePlacement 对照，错误朝向／样式拒绝；原版同帧同几何的等义 alternate 不因编号不同而被拒绝。Flexible wand、需另造底材等尚未开放的执行路径继续等待，不用材料统计支持冒充基础执行支持。

当前锁定 .8 原件已核：Player.PlaceThing／Tiles／Walls 在自然 ItemCheck 内检查互动距离、支撑、noBuilding 和时序；TileObject.Place 承担完整家具与后置 Hook。普通 Tile／Wall 的 packet17、对象 packet79 经服务端当前 section 等原版检查后处理并转发，通常不向发起者另发成功 ACK；不造统一等待或猜测超时。容器 Chest.AfterPlacement_Hook 发 packet34 的 action0／2／4，服务器返回实际 index 或 -1，MessageBuffer.GetData 在主线程先处理世界再结束相同坐标／style／session 的当前责任。这一个显式回执在未收口时阻止相关实例退休；移除旧实例仍保坐标责任至原回执或 session 结束，避免晚包认作同位置新请求。普通分支不存在独立 ACK 时不建立永远 pending。这里只证明已核原版机制与相应工程消费者，真人房主／客机另记。

选择移动／移除、采集、确认、mask／origin 更换、关联删除、身份退休与 session 结束撤对应准备候选；原版已发生的效果不回滚。ToolUse 的 token／selection intent 与幂等 postfix／finalizer 沿原出口收尾。异常、来源非法增加／替换或消耗后无可确认本体时，保护本次真实源并保未知目标，关开偏好不能解除保护。BuildBlocksRetirement 协调同身份的实际 native use；未决 packet34 还暂缓 bbox 与其已预测本体相交的新实例退休，避免 RemoveAll 后的新图把旧请求的本地预测当成已获受理。此常量粗相交门只延后退休，不创造 Match、不阻普通目标施工；显式原回执或真实 session 结束释放责任，完整当前全属性 Match 仍由原稳定锁出口退休。

共享输入 owner 在 AfterMapping 消费指针／热键尾之前冻结当次地图／相机转场请求，BeginUpdate 即清除旧事实。材料窗与 F5 据此撤控件和 armed，并继续承担真实释放尾；观察不恢复已经被拥有的 trigger，也不直接写原版地图状态。独立的后续世界请求才重新经过 CopyInto 与原版地图出口。自动玩法门与主动编辑门继续分开，普通查看不因模态指针占用而关闭自动建造偏好。
