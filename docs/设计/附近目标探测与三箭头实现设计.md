# 附近目标探测与三箭头实现设计

- 性质：五项接受合同的有限实施设计；实现与实机接受分开。
- 依据：[行为合同](../功能介绍/附近目标探测与高亮功能行为合同.md)、[实体显名与样式配置](实体显名与样式配置实现设计.md)、[状态所有权](总体架构与状态所有权.md)。
- 需求接受基线：PR #58 合并 `409c59fa09fe67d0444f52ad9c63e0556f07931f`；[实现任务 #59](https://github.com/Kuroneko2020/JueMingR/issues/59)。

## 状态与数据边界

沿用唯一 `SingleFeatureRuntime` 和 `ItemSessionProbe`。独立 WorldTargetFeature 拥有候选、分步扫描与只读输出；HostWorldTargets 拥有一份不可变偏好文档和 Host/绘制适配。它不依赖显名开启，不接 NPC 快照。死亡沿用世界观察有效/物品动作许可分开，任何本批停显不取消其它操作。

Host 在 Main.Update postfix 的原版玩家装备刷新完成后只读 `accOreFinder`。无能力或全关清空候选并停止 tile 读取，用户开启意图和 RGB 不变。原版信息文字隐藏不是能力门；不另算饰品/队友共享。普通客机每个必要 tile 要通过 `sectionManager.TileLoaded`，区段未知或 null tile 返回不可读，绝不调用会新建 tile 的 GetTileSafely 或原版破坏/生成方法。

Platform 传递值类型的 tile/frame/激活事实、当前附近矩形和可读状态身份；不向后台传递游戏对象。Feature 完整对象解析只做有限四格读取，输出类别、原点、样式和实际显示矩形，绘制只消费输出与当前 RGB。颜色与时间均不触发重新扫描。

## 附近扫描与立即失效

观察范围由相机与逆游戏缩放得到实际屏幕附近世界矩形，并向外留92世界像素以涵盖仍有箭头可见的原点（最大龟中心偏移19+半对角线36.25+绘制外扩36<92）；否则主体刚出屏会提前丢标。完整性识别另读必要四格，可越过发现矩形；世界层仍按每件完整外扩裁切。超出有效世界/异常巨大视口拒绝；单次附近矩形最多512×512格，容量随当前范围有限增长，不截断前N目标。

一个共享发现游标按行遍历附近区域，每更新最多完成本轮面积的八分之一（向上取整）。轻微移动不反复重置同一未完成行程：当前行程最多八次更新完成，下一轮使用最新范围；已有候选立即按当前范围复核和裁出。传送到不相交区域、实际屏幕尺寸/缩放变化、世界读状态身份变化立即清空候选和进度，不排旧区域长队列。Host提供真实几何revision，不能把floor/ceil引起的±1格宽度交替当作缩放，否则正常平滑移动会饿死后排行程。连续轻微移动的新边缘最长相邻两轮可见，不会永久饥饿。

每次有效更新对已有对象做有限四格当前复核，消失/错误样式/区段不可读本次立即撤掉，不等发现游标或TTL。共享本次读取缓存合并复核与发现的重复格；内容逐更新清空，容量受附近矩形加完整性余量限制。退出清空候选、内容与进度，容器保留有界峰值容量，不随旅行累计坐标。候选按原点唯一，替换重新解析，不保留旧框/连通分组。全关、无能力、会话结束、失败清空输出和扫描工作。高密度成本取决于实际确认对象数量，不能用每帧附近全扫代替对象复核。

## 世界层与动画几何

复用现有单个世界呈现 Hook 及菜单/无世界/全屏地图/隐藏UI/拍照门，提取两真实消费者共用的窄 gate；显名与目标各自局部失败隔离，后续原版UI、F5、Notes始终继续。箭头不命中输入，不创建晚层回退。

对象中心由显示矩形得到。依据所有者对首包的实测反馈，当前三个圆周基准仍相隔120°、顺时针7秒一圈，垂直正弦浮动改为2.7秒、振幅6世界像素（峰峰12）。生命水晶/果/魔力水晶箭头24px，龟/蛋28px；半径改为显示矩形半对角线+12世界像素，分别约34.63/48.24/38.17px，比首包缩近约4～5.5px。24×16原始箭头及细暗描边按比例放大，颜色完全不透明，不含框/角/粒子/文本箭头。

所有对象共用本次时间三角函数，原点坐标和类别派生16档稳定相位；环绕与浮动各用不同组合，借固定系数作角度合成，不逐箭头求时间三角函数。相邻完整对象不再齐步运动，一圈后浮动相位不重置；这不是保证所有瞬间无重叠的避让系统。同坐标/类别重扫或改变列表顺序、调色、开关F5不跳相位。相位只从当前对象事实计算，不增加缓存、Timer或持久化。全被裁出时不计算时间相位，颜色和动画不增加tile读取。

浮动仍只叠加世界Y，位置浮动后重新指向固定中心；倒重力同时镜像位置、方向和相位。为了更大、更近，撤去旧测试要求的“尖端全时刻在保守外接圆之外”；保持固定半径，避免以动态径向推开掩盖垂直浮动。当前参数保护目标中心区域，最不利时可进入含透明边角的保守显示矩形约数像素，真实贴图边缘、邻物遮挡和生命果风摆仍须画面判断，不声称严格无像素交叠。裁切外扩为半对角线+36，覆盖半径12、浮动6及最大28px箭头的完整旋转包围半径（小于17px），对应观察余量92。生命果WindForVisuals全状态最大偏移未由静态证据证明。

时间只读 `Main.gameTimeCache.TotalGameTime.Ticks`，整数先对周期取模再转角，避免每小时7秒相位跳变及长运行精度漂移。当前 IL 字段 `04000A8C` 为 public/static GameTime；DoUpdate `06000D19:0006–0008` 在入口保存传入时间，之后调整Elapsed保留Total。暂停/恢复按游戏累计时间直接求相位，不逐帧追赶、不因扫描/F5/调色重置。

位置、方向在同一世界坐标推导后整体应用相机与倒重力，再交原版 Game layer 的 ZoomMatrix；UI缩放不重复加入。倒重力下仍保证最终屏幕顺时针和上下运动。裁切使用包含完整箭头/浮动的外扩矩形，允许实际屏外裁切，不能挪动中心。

一份小型自有箭头纹理由简单几何生成并复用，不依赖字体。游戏线程按实际设备创建，设备切换/退出明确释放自有资源，不释放原版字体/pixel。一个箭头一处SpriteBatch.Draw，借用调用者批次，不 Begin/End/改变矩阵、混合或裁切；无目标不计算逐对象动画或创建资源。

## 颜色与公共快捷键

沿原信息页五行及顺序接命令、状态、配置、小键盘。仅增加窄 StyleTarget 适配：三显名具有颜色与字号，五目标只有颜色；同一 StylePopup/StyleEditor/输入owner，颜色-only布局不计算/占用字号行。HSL草稿真实释放提交，完整六位HEX一次提交；切目标/关闭/失焦取消草稿，已提交保存继续。恢复本项默认色只改RGB，不影响开关/绑定/其它目标或任何显名字号。

五项不可变设置独立存储 `JueMingRData/config/features/world-targets.json`，格式/版本与显名文件独立，仅含五项 enabled/rgb。默认全关及颜色FF69B4/7CFC00/66CCFF/FFC460/9370DB。复用PreferenceDocument与AtomicFileDocument，内存提交、后台有界合并、未来字段/冲突/失败保护和有限反馈；无坐标、相位、字号或草稿落盘。

增加五个显式稳定动作ID `world-targets.life-crystal.toggle`、`world-targets.life-fruit.toggle`、`world-targets.mana-crystal.toggle`、`world-targets.sleeping-digtoise.toggle`、`world-targets.chillet-egg.toggle`，调用与信息行相同命令。原七项注册/绑定不变，默认不绑定新项；公共层不写死12。无探测能力仍允许开关、配置与录入，实际观察保持能力门。继续现有可靠绑定完成语义和冲突提示，不追加启动重查。

## 实施顺序与验证边界

先写完整/残片/相邻对象、能力/移除、时间/指向/布局等有意义反例并观察红测；随后贯通生命水晶的Host→Feature→世界层→信息行→保存→快捷键，再同批接齐四项。复用真实Host加载夹具和隔离配置根，不启动游戏/服务器或访问真实用户正文。

验证覆盖五种合法/非法帧、视口半件、复制品/巨石/物品反例、未知区段、同坐标替换、连接/传送/缩放、全关/无能力/无目标/密集成本；多时刻三箭头、指向/重力/缩放/资源退出与后续UI；五色独立与原三显名/七快捷键/Notes保护；存储冲突、未来字段与延迟回调。静态原版字段时点与夹具能力断言不能升级为饰品共享/实机多人通过。

图形环境可用则使用既有原版XNB资源夹具生成少量时间帧并实际查看；设备创建前已分类不可用则记录待补，不能把实际绘制/输入失败当环境问题。独立只读完整增量审查后，从干净提交顺序重复构建完整WorldTargets开发profile，核对产物，按精确旧包恢复/新包安装安全门交付并保留；实施PR不合并，等待所有者实测。
