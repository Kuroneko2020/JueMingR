### 标记的状态、需求与资源

CombatTargetMarker独立于16384路径笔画池。Prepare只接受CombatSelection当前完整身份的可受击部件与可见位置，借NPC当前netOffset；没有第二次选敌、未来末端或守卫标记。Host.Enabled/Poll/SampleMouse/Update与Selection.RetireTarget遵守标记消费者，Cache.Required只由真实未来需求决定。

### 覆盖补齐的实施与验证顺序

`HostCombatObservation` 是独立 Runtime Feature。游戏线程先从合法物理输入样本保存真实鼠标，再在完整世界更新后用 `NativeNpcObservation` 一次扫描必要候选/当前 NPC 区域；碰撞与路径分别按需求启用。选敌完整身份为 session、实际对象引用、slot、generation、type、netID，距离到区域，LOS只排序。`CombatSelection` 不写 NPC 或 Facing 状态。相机、缩放、逆重力只参与意图与绘制转换，不让临时虚拟光标反馈成选敌中心。

当前形状包括矩形并集、原版平头线段、圆/非对称椭圆、扇形、目标条件胶囊和不连接间隙的离散点集。虚线表示目标/视线条件或已说明的近似，不把未知特殊分支自动当普通矩形。一般样本初始8形状按需扩至160；点集独立惰性复制最多65536点；事件池最多原版弹体上限的4倍，异常超量轮换并显示限制，不无限增长。持续形状按当前子步退休；瞬时事件在下一次合格Draw遍历后消费；屏外或达到笔划预算的事件也随该遍历退休，避免相机回看时重放旧攻击。缺Draw最多4个更新，过期/容量丢弃显示统一限制，退出统一清理。

`NpcPredictionSource` 复制所选NPC及必要前后关联链的标量，按原版槽次序推进；分节链从真实头部取得固定目标，活跃玩家矩形按值复制且稳定时复用。Platform的`NpcTrajectory`公开完整身份、CompletedWorldUpdate采样阶段/tick、版本、逐时运动矩形、含已观测网络平滑偏移的普通ReceiveBounds和ProjectileReceiveBounds（414专用8px外扩）、速度/阶段/受击与伤害资格、传送断点、前提和截断原因；不可变发布，消费者不拿可变工作缓冲。Features的运动/生命模型只接独立值，不调用活AI/Update、浅Clone、随机、生成/网络或原版有副作用碰撞scratch；局部地形最多复制4096个实际查询tile值。真正缺依赖/未实现效果/未知目的地在对应决策处停止，已知坡形、液体和buff到期不再统一截断。

`NpcPredictionCache` 一目标、最多200必要实体、最多120步、4个显式需求槽。读取只返回结果，等价采样只重新发布采样身份并共享已冻结点数组；首次/运动延续仍从工作缓冲复制，旧消费者不可被覆盖。加长只延续尾部，实际新样本与前一预测首步严格一致时滚动补尾；x86微小浮点差异也保守重建，不放宽生产相等条件。实体状态、阶段、退场时间、buff、前提与已读地形负责失效，同tick也核实际变化；一个消费者取消不清掉其它需求，世界退出清全部。失败不发布半结果。

世界层Prepare只消费当前几何/时间线，缓存有界屏幕线段，Draw不选敌、不推进AI、不查盘。使用既有GameViewMatrix世界投影与裁切，屏外原点的长线先按整体裁切；资源只用原版MagicPixel/字体。A蓝/B绿/C黄/D红/E紫，近似虚线；路径每30步和末端标记，传送不连线，显示必要前提/截断说明。

F5卡片和两显示行使用真实测量布局与统一裁切/命中；半径草稿仅在鼠标中心可编辑，释放可靠提交一次，失焦/切页/隐藏/字体皮肤与投影变化取消且保留物理释放尾。两个主开关注册于既有Hotkeys冻结前，使用同一设置命令与已提交反馈。独立配置schema不保存运行态、不更改现有战斗/输入/工具/钓鱼配置。

## 职责与阶段

`Features/Combat` 保存独立选项/文件语义、有限选敌计算与服务器结束账本，不引用游戏对象。`TerrariaHost/Combat` 是原版事实和操作适配，使用现有 Input、Items、Tools 钩子和 Runtime。F5 只有控件与滑块草稿；worker 只接 immutable 选项，不持游戏对象。没有 Combat ToolKind、UTC 动作队列、后台预测器或全武器插件系统。

| 所有者 | 责任与生命周期 |
| --- | --- |
| HostCombat | 在公共 UI 已消费实际输入后采样；装配八个公共命令、配置和能力；Session 结束清动作/方向/报告；报告 Poll 位于 enabled lane 外以保证关闭和退出能清理 |
| CombatUse | 一个真实来源、一份操作 token、一个模拟步节奏决定。快捷栏保护真实槽；鼠标 58 仅占输入 lease，允许原版合法 clone，不伪装 0—49 库存来源 |
| CombatInputScope | 在原版 ItemCheck/已知 Projectile AI 范围借 controlUseItem/controlUseTile/Main.mouseLeft。只撤回仍为自身值的暂写；正常原版 release/channel 结果不回滚；自身补写且未消费的 release 标志在异常/中断时撤回 |
| CombatHandoff | 仅在真实可交接边界向现有工具、提炼或一次快捷物品借用让路；保留原武器保护直到实际归还。以借用 token 匹配旧物理残留，借用输出的新 pulse 仍属于借用 owner |
| CombatFacing | 独立目标/方向消费。手动左右优先，无需求或不合格物品先早退；自动决定有 10 模拟 tick 防抖，目标/武器/provider 身份失效立即撤旧决定 |
| GoblinHitHooks | 两个原版 friendly 读取的窄替换；保留 native 后续命中门。独立 Harmony owner，两处同时装好才 Ready；安装失败只撤自己的补丁，回调失败锁存失效而不打断原版 |
| CombatReports | 单人最多 3 个近期 tracker 引用；客户端固定 200 NPC 身份/有限组计数和六个事件位。报告使用 SessionPlayer，死亡不清战斗；世界/角色对象/模式/socket/generation 变化才重建 |

`TrySyncingInput` 的已有工具 prefix 明确优先执行借用残留消除，再由被授权 owner 提交 pulse。ItemCheck prefix 建作用域，完整原版 AutoReuseLogic 执行后才补真实 Ready 时缺失的 release；Started/真实创建建立结果。后续已跟踪 AI 可消费同模拟步的 press/release，不重新推进计时。末尾、异常、失焦、停止、会话退出均收作用域；迟到回调的 scope/token 不属于新动作就不能清新动作。

共享 `Projectile.AI` 入口按当次 `ProjectileLease` 中的实际 scope 或正工具 token 收尾，并保存取得时的 owner；不按收尾时谁 Active 猜归属。战斗 scope 经 `out` 在首次临时输入写入前交给 Hook，Prefix 借出途中失败也由该次 Finalizer 即时清理。Postfix/Finalizer 先消费同一回执，不能重复通知或清理新操作。没有 scope 的调用不进入战斗收尾；工具消费端同时拒绝零、负数、不匹配和空闲编号。战斗异常退役自身动作和使用权；钻头异常仍保留真实来源未知保护、取消与等待原版合法选槽的归还责任，不提前清空工具状态。

右键战斗的取得、节奏和换槽在原版 `LookForTileInteractions` 后才提交；普通鼠标未开启智能光标也能优先开箱、开门。借用期间保留真实 tile 输入至该裁决，已发生交互按 borrower/token 取消尚未消费的 pulse（快捷物品须退休），无交互才临时抑制旧右键；不回滚原版交互和释放标志。有效客户端右键机会将原版 `TrySyncingInput` 本体延后执行一次，使用同 Harmony 的 reverse patch 保留原版差异比较、13 报文及已同步快照，不重复执行其它 owner 的 prefix。延期凭玩家、模拟步和会话匹配，帧末/异常/会话结束撤销；不合格或关闭路径保持原同步时点。

配置 `Ready` 表示可以接受下一次写入，`CanRun` 表示已确认配置仍可运行；等待 worker 保存不撤销已生效的武器动作或报告观察。保存成功关闭当前策略则立即收回其动作，保存失败按既有不可用语义停止；从不在磁盘结果确认前采用草稿。

快切 Select 只是申请；确认 selectedItem 且无缓冲后记录新来源并开始额外间隔。它不保存或恢复初始槽。投射物凭原对象、槽、key、owner 和当前武器跟踪，948→947 是原版水变体的明确窄例外；不找任意本地链球后备。命中回执来自真实 StrikeNPC 正返回，表示本地接受而非服务端 ACK/确切掉血；碰撞来自实际 movement collision 输入与结果，停滞按 GameUpdateCount 计数。

物品释放类在实际 Started 后，下一模拟步 `itemAnimation>1 && itemTime==0` 即释放；同一步决定缓存避免刚起手就在重入时松手。固定 .8 的 Shoot 会把剩余动画交给 itemTime，早松保留总冷却但让其与飞行重叠；旧 `itemAnimation==2` 把等待全部放在投出之前，下一把按下过早召回刚投出的剑。入口动画 1 会被 AutoReuseLogic 消耗，不能作为释放窗口，也不为此绕过原版自动重用。合法装备最高攻速下目录最短动画可达 3，下一步入口 2 仍能释放。实际 Ready 后才申请 Select，不提前排队换槽截断当前释放；燧石/冰川之牙的投射物蓄力分支不共用此门。

## 独立转向和未来瞄点

无自瞄时保留 Z 默认 Nearest 的实际影响：36 格 hitbox 范围，最多 32 个近候选、4 个廉价威胁预选、6 个采样点；不引入 LOS、运动预测或发射求解。目标过滤独立于稀有指引、捕捉和工匠可受击。读取可共享 NpcObservation，但策略不合并。ChangeDir 后只报告实际读回。

`Facing.TargetProvider` 默认 null，仅可返回带 session、NPC 对象/slot/type/netID/generation 和模拟步的目标。新有效来源可立即替换独立目标；过期/撤销回到独立策略，失败不该授权方向写入。提供者不因本消费者调用而启动求解器。

`CombatAim.Provider` 默认 null；只有本次明确允许的动作阶段才创建请求。请求带真实 player/weapon/slot、session/selection/operation、当前步、阶段及必要的 projectile/key。结果必须回指本次请求且坐标有限，调用后再次核真实动作身份；其它使用 owner 从不调用它。

| 原版消费阶段 | 当前最小接缝 | 禁止推论 |
| --- | --- | --- |
| ItemRelease | 当前快切物品在合法释放 ItemCheck 内临时借 Main.mouseX/Y | 不覆盖普通连点、工具、钓鱼、快捷用物或蓝图目标 |
| FlailRelease | 当前本地链球 ai[0]==0 且 channel 已释放的 AI | 不改速度/AI，不为自瞄额外追踪释放后弹体 |
| FlintCharge | 5462 的原版投射物 ai[0]==0 蓄力阶段 | 释放后依原版已存方向，不宣称释放时才改鼠标能改向 |
| GlacierCharge | 6153 保持 channel、ai[1]==0 且原版每三步读取瞄点的阶段 | 原版负责方向/速度更新，提供者不直接写投射物 |

借点沿已有 ReverseGravitySupport(world-screenPosition) 坐标域，作用域结束条件恢复仍由自己占有的鼠标坐标。无提供者不分配请求、不查敌人、不准备弹道；失效或抛错结果走原手动点。隔离提供者证明阶段/失效/恢复，不装入产品。没有通用 Kill Hook 或普通武器瞄准功能。

## 报告状态与网络

单人 StopTracking 回调只置 dirty，Poll 在真实模拟步读取至多 3 条；首次基线不请求。客户端一次有界基线后，仅消费原版 GetData 已完整应用的 23/7 消息；按 generation/slot 读取原版应用结果，不把本地 life<=0、预测 inactive 或名字当结束身份。组合组全部已知成员结束才触发；六事件位只在已应用世界信息后更新。

`NotInvoked → Pending → Invoked → Observed/Unknown` 区分发送前与调用后。客户端新结束两步合并；尚未调用且连接不可用可有限等待，15 步复查、最多 300 步；超过时放弃本次机会，未来新结束可重新触发。进入原版请求出口后无论是否抛错都不自动重发；socket 内部吞错也记 Unknown。实际原版报告显示仅说明观察到报告，没有 request ID，不能借它取消另一场新 Pending。原版统计按名字分组与 R 会话身份分离。

观察回调捕获自身失败并锁存对应不可用，避免截断原版已经发生的伤害/消息处理；不吞原版异常，不在回调栈内热卸补丁。局部安装失败和 Dispose 逐目标撤自己的 Harmony owner，失败仍尝试其它目标，不撤外国 owner。

## 成本、验证与维护

- 五策略关闭或启用无按键先早退，不找 NPC；固定目录不反射扫描全物品。投射物只在需要且 ownedProjectileCounts 表示已有来源时发现一次，之后按身份直接读取。无提供者的 aim 接缝不建请求。
- 转向关闭、无使用意图、不合格物品和明确手动方向不做选敌；需要独立决定才读取 NpcObservation。Debug 计数置于实际候选读取之前，含不活动槽，不能隐去空表读取。
- 报告关闭不枚举；稳定单人列表不重复读取/格式化。客户端一次基线读取后按真实消息更新，不每 tick 扫 NPC/Recent；真实命令原版格式化/广播不被伪称零成本。
- 配置 worker 沿用单文档串行可靠完成；UI 31 个数字标签按字体准备，拖动不保存，真实释放一次保存。字体、皮肤、几何、缩放、滚动和取消使旧草稿无效；左键及 Escape 取消尾部不能进入后续原版输入。

`combat-host` 由新增领域/Host/F5 战斗文件和 NativeCombat/CombatNetworkFixture 选中。共享输入/Items/Runtime/F5/存储及 tools-host 反向包含本组；本组执行 CombatChecks、CombatCpu、CombatFacingCpu、CombatHitsCpu、CombatReportCpu、CombatUiCpu、CombatObservationCpu、CombatCosts 和 ShortFeedbackCpu。完整共享链仍执行 G09/G10/恢复/处理的现有消费者。显式 CombatVisual 使用真实 XNB 与隐藏 XNA 设备；CombatRelease 检验真实 Release 载荷原版链。正式入口仍是 build.ps1 和完整 ContinuousProcessing 开发包，不新增打包平台。

测试断言以原版效果和输入归属为主，工作量证明有限读取/停止，不声称 FPS 改善。实际联网、所有者操作和硬件表现留真实验收；动态执行及未覆盖范围记录在 #110。
