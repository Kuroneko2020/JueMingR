# 死亡记录、世界天数与地图死亡点实现设计

对应 [实施任务 #81](https://github.com/Kuroneko2020/JueMingR/issues/81) / [PR #82](https://github.com/Kuroneko2020/JueMingR/pull/82)。四项实现及直接死因、紧凑详情修订已在候选 `5b42a1c4d1fe3b8b335a31716001d81e0aea1ca3` 获[所有者正式接受](https://github.com/Kuroneko2020/JueMingR/issues/81#issuecomment-5684334418)，具体使用与接受边界见[行为合同](../功能介绍/死亡信息死亡详情世界天数与死亡点常驻行为合同.md#12-r-开发实现与使用边界)。六个项目、唯一完整 Runtime、原版 1.4.5.8 和既有用户数据根不变。

## 职责与接线

| 位置 | 责任 |
| --- | --- |
| `Platform/DeathHistory` | 不含游戏对象的死亡事实、有限查询结果、机械档案字节端口 |
| `Features/DeathHistory` | 唯一死亡接纳与查询 owner、功能专用磁盘索引和格式、后台顺序提交、显示偏好 |
| `Features/WorldTime` | 有效贡献标量累计、完整天数、加载增量及保存修订；不复用死亡计数 |
| `Infrastructure/DeathHistory` | 根文档复用 `AtomicFileDocument`；不可变页的有界读写、哈希、排他归属，不解释业务字段 |
| `TerrariaHost/DeathHistory` | 可靠身份装配、实际死亡窄 Hook、当次原句安全冻结及全屏地图适配 |
| `TerrariaHost/WorldTime` | 实际 `Main.time += Main.dayRate` 贡献处的窄 Hook |
| `TerrariaHost/F5`、Hotkeys、Composition Root | 地图行、`DeathHistoryPopup` 列表/全文/数量、弹窗互斥、公共快捷键、注册及最终退出；不接管历史业务 |

Host 与完整 Runtime 共用同一个 `ItemSessionProbe`。死亡和计时回调可能早于 `Main.Update` postfix 的 Session 通知，先按该 probe 的引用 token 保留有限值，通知到达后仅接入同 token。可靠持久身份只在准入时计算：本地/云角色文件路径 × 世界 GUID；沿用开箱观察的 SSC、角色引用与客户端连接前置检查，使用独立版本域，既不读存档全文也不猜名称合并。迟到结果携带 pair、代次和请求修订。

## 实际事实与时间

`DeathSourceHooks` 精确核验固定程序集、`Player.KillMe` 签名及唯一 `dead=true` / `GetDeathText` 调用点。线程局部嵌套 scope 只在实际 false→true 写入时获得 EventId；完成和异常收尾幂等，取消、重复 dead 和其他玩家不产生记录。位置与 UTC 时间在这个边界冻结。捕获原版已经产生的 `NetworkText`，深复制有界文本树后才格式化，不再次生成死因，不修改原对象、随机数、广播或墓碑。

依所有者体验反馈，新事实同时保留完整原句和可选直接死因。直接死因只按固定 `.8` 已生成树的精确 key、参数数量及冻结名称提取：NPC/弹射物/玩家来源，以及摔落、溺水、岩浆、石化、燃烧、中毒、混沌等原版类别。不按翻译后的俏皮句子猜测，不在查看时再查实体槽；自定义/未知/超长直接原因退回原句，分类异常也不丢弃已经成功冻结的原句。石化包含初次石化伤害与石化坠落，不能统一误称摔落；混沌包含三种随机文案。名称和原句保持记录时语言，直接原因前缀沿用当前中文界面。

`WorldTimeSourceHooks` 只观察实际加法写入贡献；匹配唯一 IL，保留原运算和控制流。入口/出口 rate、钟面跳变和网络赋值都不当作贡献。稳定回调只判断 token 并累加标量。累计值、显示整数 `floor(total/86400)` 和单调保存期限独立；冻结后仍提交先前 dirty，结束时交接已观察尾数。

## 有界历史与提交

实际落点为 `records/deaths/<pair>/root.json` 及同目录不可变 `pages`，时间为 `records/playtime/<pair>.json`，显示偏好为 `config/features/death-markers.json`。不预写默认值，不导入 Legacy，不接触安装载荷的文件归属。

完整事实保存在不可变页，功能专用有界磁盘树索引维护事件身份、UTC/稳定并列顺序和有效位置的发生顺序。页大小、树深、缓存、批次、未决事实与会话租约均有明确上限；节点更新只复制受影响路径，不能每次死亡重写全史。先写完并核验新页，再用既有原子根文档提交引用。根是唯一已提交版本；未引用页与备份是恢复材料，不自动补成已成功历史或删除。

单个领域后台 owner 负责读取、格式验证、排序索引与提交；公共锁只交接有限状态和引用。启动必要验证可随历史增长，但逐页、可取消且不把 N 条一次性交给游戏线程。稳定前台只持有计数/状态、当前六条、选中原句和最多 1024 个地图轻量候选。详情按规范 EventId 的 UTC 前缀升序、GUID 稳定并列；地图按独立的发生序号先取最近 K 个有效位置，再裁切。二者不共享错误的排序语义。

索引叶最多64项、分支最多32项、节点层级0–12、缓存128页；每页不超过1 MiB，完整原因不超过262144个 UTF-16 单位，直接死因最多1024个单位。根格式 `JueMingR.Deaths` version1，事件头/索引页仍为version1；文本页新写version2并兼容读取version1，旧页不重写。两个字段均严格校验版本、长度、完整性及尾随字节；事件幂等比较包含直接死因。旧程序不能读取新文本页，会按未来版本保护，不能把程序回退当作数据回退。物理页名使用完整SHA-256的无填充base64url及两位十六进制分片；短随机临时文件与目标同目录，避免冗长后缀碰到原版进程的Windows路径上限。缺根但有残页按恢复异常保护，不擅自接续或清理。

每个档案最多64条在途/未确认事实，最多8个档案租约及8个预留的身份交接槽（每槽64条）。身份迟到前接纳的尾部按同pair的FIFO退休交接，当前事件不得越过旧尾部。绑定后满载明确拒绝新接纳并提示可能缺记，不能把返回成功的事件永久藏在不可查询队列中；完整性提示按pair或尚未归属的会话token隔离。Host首个Runtime通知前另有最多32条短交接和一个时间标量。明确未提交最多3次尝试，未知提交停止重放。时间最多8个退休worker、32个退休会话；达到32个失败pair停止新接纳，已接纳尾部仍结算，失败结果集合最多63。同pair依序交接，成功最终回执清除旧可恢复失败。停止返回仅证明线程退出，不能代替保存成功状态。

加载中、可靠空、历史失败、未来格式、明确未提交和未知提交分开；未知总数不显示本次增量冒充总数。事件不能放进最新设置槽。已知未提交有限重试，未知提交保护并停止重放；队列满和保存失败如实反馈。正常结束在既有有限总预算内排空，超时后的 I/O 与锁仍由后台拥有，不承诺强退无损。时间使用独立小文档及累计修订，旧完成不能清除新增量。

## 具体界面与地图

地图页保留原指引行，增加“死亡信息：次数 / 详情”“世界天数：整数”和“死亡点常驻 / 配置 / 开启 / 关闭 / 快捷键”。沿用 `F5RowLayout`、`F5ControlRenderer` 和公共名称提示；动态计数不进入永久固定文本字典。

一个 `DeathHistoryPopup` 状态 owner 管理数量、列表和全文，复用现有字体、`UiSurface`、按钮及输入尾缘。数量窗紧凑显示标题“死亡点常驻”、标签“地图显示数量”和 128/256/512/1024 四项，默认 256；同值不提交，关闭不撤销已选偏好。与其他模态互斥。

列表标题下直接显示时间与直接死因，不显示列标题和点击提示，窗口宽度上限560、按实际记录条数收紧高度；加载/失败/未保存仍有状态行。固定六条逻辑页，底部为合计、页码、上一页、下一页、关闭。时间按死亡时保存的偏移显示年月日时分秒，省略时区尾缀，绝不转成查看时所在时区。显式打开最早页；新记录不跳末页，选中项保存 EventId。点击原因在原弹窗切换只读完整原句，保留时间、返回和关闭；Esc 全文回列表、列表关闭。旧记录缺少直接死因时显示原句，不猜测补写历史。小视口只滚内容，不缩字，头尾保持可达。正文走纯字体安全文本和增量换行，完整原句不进入富文本解析；全文采用同一正文宽度，增量排版期间窗口高度固定。布局/字体/页/滚动变化使旧按下失效，失焦、地图强制关闭及 F5 尾缘交由壳层收尾。

地图使用独立可注销的 `MapIconOverlay.Draw` 窄适配，限定原版 `Main.MapIcons` 和全屏地图，复用实际上下文及 `MapDeath` 资源。死亡图标专用几何按原版锚点/偏移、地图倍率和 UI 图标倍率分别计算，绘制/裁切/命中共用。原版该帧确实画出的同一 EventId 不重画；坐标相同的其他事件仍保留。重叠选择最新命中，只有实际 hover 才取并缓存短提示，全文留详情。不开启、不显示即不投影/命中/排版；不新增地图点击动作，不吞拖动/缩放/ping，不释放共享资源。

地图查询和绘制共用 `Map.Active` 资格，hideUI或适配失败也撤销K需求；已发布1024候选在当前选择128时立即受128约束。资源身份在壳层处理松手前刷新；同尺寸换字体/皮肤也取消旧按下。正文增量排版不改变固定底部按钮的操作代次；一行小视口的滚轮步长为一行，确保选项和全文逐行可达。

R 绘制的地图点悬停也显示保存的本地时间和直接死因短文；原版自己的最近死亡点仍由原版负责。短文与全文共用同一事实，只有完整原句建立全文阅读缓存。

## 自动验证与未覆盖边界

- `tests/DeathHistory`：真实隔离文件与格式保护、跨会话FIFO、页失败不冒用旧结果、最终时间保存回执、P=6/K四档与N=128/8192的工作量及稳定引用。
- `NativeDeathExecutionChecks`：固定 `.8` 的真实死亡/时间IL受控执行，保留原版guard、dead写入、已生成文本、实际time加数及昼夜边界；隔离无关玩法副作用。覆盖原句/RNG、取消/重复/重入/异常、睡眠×旅行倍率、冻结和直接设时。
- `NativeDeathHostChecks` / `NativeDeathInputChecks`：完整profile真实接纳、首个postfix前交接、死亡不换Session、重入/换world、真实偏好保存再读，以及F5物理按下释放和字体/失焦/大地图退出。
- `NativeDeathMapLoopChecks`：N=1040、四档各20轮实际生产循环；仅替换GPU资源尺寸与末端绘制，保留K上限、投影、裁切、命中和需求。另核对原版同帧标记身份/嵌套收尾、关闭零工作。此检查不证明像素或实际SpriteBatch兼容。
- `DeathPopupChecks`：列表/全文/返回页、迟到查询、事件身份变动、数量同值、小视口和CRLF；`death-host`组随正规构建和完整包自动执行。有限负对照令markers缓存每次失效，正规build因重复准备失败退出；恢复原始字节后继续正式检查。

首版原资源预览因 `GraphicsAdapter.Adapters.Count=0` 未执行。紧凑界面修订时重新尝试，已能枚举2个适配器，但 `GraphicsDevice` 构造抛 `DeviceLostException`；独立、未加载Terraria/R的XNA隐藏窗口设备前置检查也得到同一异常。设备未创建成功，XNB加载及预览正文均未执行，不推断具体系统/RDP原因。所有者已接受本批实际使用体验；全部图形、字体/材质、完整地图原生层共存、实际GPU状态、真实多人与FPS仍无逐项通过证据，CPU隔离和源码复核也不替代这些结论。动态构建、包、安装来源及实际合并结果由#81/#82记录。

## 接受与证据复用

收口只最终化接受文档，复用与接受候选匹配的构建、自动工作量和独立审查证据，新增文档差异做窄检查与独立复核。保留当前安装及全部用户数据、旧包、证据和恢复材料，不因文档提交或 squash 身份变化重建、重装或改写回执。安装来源 SHA 与实际合并 SHA 分开记录，接受不扩大上述验证范围，也不授权下一功能或发布。
