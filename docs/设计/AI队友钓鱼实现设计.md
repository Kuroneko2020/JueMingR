# AI 队友钓鱼实现设计

对应[行为合同](../功能介绍/AI队友功能行为合同.md#钓鱼模式)和[任务 #193](https://github.com/Kuroneko2020/JueMingR/issues/193)。构建、实测和支持拓扑的证据分别回任务核实。

## 运行态和控制

HostCompanions.FishingActivity 以在役 Actor 保存每次启用时记录的站位或座椅标识、到位与搜索结果、真实入液状态。移动、站稳、坐下和自卫复用已有动作仲裁。活动期间导航目标来自钓位，跟随轨迹不向该人物继续投递。原版碰撞和支撑决定实际停靠点，站稳或坐稳后不再用普通导航朝向覆盖姿势。虫洞到达回执进入同一生命周期出口。关闭、死亡和退役先撤下新动作资格，再处理在途原版动作、借件和本 Actor 浮漂。

钓鱼活动从共享的敌怪与投射物空间索引读取每个身体的近程危险。普通接触体沿实际速度和短步原版地形碰撞判断，穿墙实体沿观察到的运动判断。读取原版当前敌怪接触框与敌弹伤害资格，排除停伤阶段和仅指向其他玩家的实际危险。敌弹撞地后的反弹、爆炸和阶段变化等待新的原版观察。敌弹的投射物键只能证明出生身份，只有本地原版出生接点保留了同一敌怪实例和代次时，才把发射者列入这名队友的反击候选。远端无法确认发射者时保留避让。候选、近身意图和原版 ItemCheck 前的最终出手同时受具体目标资格约束。短程投影使用当前伤害框和速度，不推演敌怪 AI 或未来弹幕形状。

CompanionFishingWater 按钓位附近实际入口距离搜索，在半径 20 格内选入口，另外计算该入口连通的原版水量。搜索、试算和有效抛法以钓位与真实世界输入为依据，未确认的地形不能解释为缺水。CompanionFishingCast 按当前原版浮漂运动和碰撞检验合法入液，原版物品消费、浮漂生成及入液确认各自提供事实。座具由实际 Tile、坐姿和占用决定，原版自行结算坐姿渔力。

## 原生动作及来源

HostCompanions.FishingLine 和鱼类 Hook 依据实际 Player、投射物和 Actor 激活路由本次抛收。已消费收竿同批处理该 Actor 的浮漂，真正物品来源落到原版发放和实际库存变化。过滤纯规则与真人共用，候选和原版规则从该队友的环境、天气、任务资格及漂的位置观察。多人物进入原版方法时，必要的全局状态临借限定在本 Actor 的调用边界。声呐例外仅授权当前活动与该人物主背包的原生喝药。

HostCompanions.FishingGear 通过原版 TrySwitchingLoadout 切组并读回实际组。配装借件按源、目标组及真实装备引用结算，自动配装服从玩家当前选择，自动换装继续按合法候选选择。用物、持物草稿、补给、武器以及已发出的钓鱼动作仍共用有限的物品边界。专用存鱼按本次原生产物、合法实际源槽、附近同类箱和提交结果计算，由原版人物及其连接分别发送。

运行中的自卫先确认具体敌怪、武器可达性、原版使用资格和下一个可用持物时机，再把钓鱼装备交还给原来的配置。恢复日常装备后等待原版人物更新实际属性，武器沿原版 ItemCheck 继续。单纯避让、等待攻击位置、常规补给以及原钓位因地形变化需要收线重抛时保留钓鱼装备。危险短暂变化时维持本次装备交接，攻击输入每次仍核当前目标。危险持续消退且原版武器动画、持续使用和缓冲选槽全部结束后，原钓鱼活动才重新接管持物。

## F5 和档案

稳定窗口内的「配置」增加「常规／钓鱼」。两列功能行和键按钮复用 F5RowLayout。过滤编辑器共用显示、编辑、搜索和预设机制，各实例的编辑状态、列表选择和保存逻辑独立。钓鱼子页将当前 OwnerId 与 ProfileId 交给运行态作为收竿、切杆的暂停资格。它不影响首抛、允许重抛或其他角色。离页清除页面绑定与草稿。保存匹配当前人物、档案代次和未变的偏好快照，旧回执不会关闭后来打开的草稿。

不可变的 FishingOptions、FishKey 和格式 codec 放在 Platform，继续使用现有 Features.Fishing 命名空间，避免反向引用 Features 或重复实现存储格式。FishFilter 决策保留在 Features。档案 v7 在原字段和原版人物流之间附加传送设置与有界名单文档。旧版本加载后补默认配置，下一份真实修订经过同一 worker 和原子替换。运行态、钓位、浮漂和页面草稿不落盘。六项快捷键沿现有 GUID 动态身份和删除流程，钓鱼启停的反馈来自实时活动状态。

多人终止时，可能已提交但尚无权威回包的存鱼操作，把精确主背包槽位写入同一档案修订并保持原生库存字节。正常回包和明确未发送的操作不留下隔离。普通改偏好及恢复行为继续保留该证据；加入和离线物品访问直接检查档案。清空配置或删除时沿原确认流程。旧档缺少该字段时默认无未确认槽位。

## 验证范围

本次原生 CPU 专项 CompanionFishingUiCpu、CompanionFishingWorldCpu 和 CompanionFishingLineCpu 覆盖页面、钓位和原生钓鱼，另按实际影响检查档案、真人钓鱼、药水、多人及输入传播。CPU 证据、窗口实际像素、真实包启动、Steam 双机与 FPS 分别记录。

CompanionFishingLineRelease 复用同一原生钓鱼夹具，加载普通 Release Host 后比较关闭及两名队友稳定钓鱼的实际更新。记录样本数、耗时和分配。采样包括输入、运行时推进、两名队友的原生人物更新、活跃投射物更新及夹具循环。
