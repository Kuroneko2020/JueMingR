# 钓鱼与配装实现设计

对应 [行为合同](../功能介绍/钓鱼与配装行为合同.md) 与 [#107](https://github.com/Kuroneko2020/JueMingR/issues/107)。这是 G10 的有限实施设计，不是新全局输入、装备、目录或事务框架；进度与运行证据只记任务。

## 职责和状态

`Features/Fishing` 承载不依赖 Terraria 的不可变设置、四份名单及作用域预设、特殊类别过滤、装备目录与选择规则、名字规范。`FishingSettings` 沿现有 DocumentWorker，唯一文件 owner 负责 `config/features/fishing.json`；可靠保存完成才发布 Value，明确失败保留旧值，未知和外部冲突保护文件。没有 Legacy 导入。持久设置不含鱼漂、选槽、装备对象、草稿或运行时错误。鱼获两种显示及样式沿 Information 现有唯一设置/渲染，不复制第二个信息窗。

`TerrariaHost/Fishing` 分别承担原版只读目录/当前水域、真实鱼漂会话及原版钓鱼调用、专用存放资格、临时装备、改名和钓鱼页呈现。Host 组合生命周期并提供窄命令，不吸收这些业务为巨型 Runtime。列表编辑捕获模式/匹配/session epoch和保存命令 ID；旧回执不得清除新草稿，失败保留选择。真实候选和图标按视区呈现，Draw只消费准备结果。

## 只读原版边界

锁定 EXE、MVID 和局部原件身份见[调查 §15](../功能介绍/全功能调查专题/钓鱼与配装.md#15-当前原版证据与可复查性)。读取当前 `Main.FishDropsDB` 的有序规则，能力门核 `_rules` 的真实类型及 `MeetsConditions(FishingContext,bool)`；只对只读上下文执行条件，枚举所有 PossibleItems 并遵守 stopper。不得调用会使用 Random 的 GetDisplayableDrops、TryBuildFishingContext、PrepareFishingContext或实际 FishingCheck 作预览。全目录只在有搜索需求时准备，译名和查询版本独立失效。

当前钓点由真实本机鱼漂和原版水体扫描语义得到；手持竿、鱼饵54—57再0—49、饵料包、任务资格和当前有效装备分别读取。水体变化须有有限复核，不能仅缓存坐标；显示缓存不能授权咬钩动作。实际过滤读取本次 localAI/ai与声呐状态，不用候选目录替代真实咬钩。

## 动作与来源

复用 Tools 的 ToolUse 原版选槽/输入/ItemCheck短租约，为钓鱼独立动作种类作窄扩展，不能把 G10重抛映射到捕捉开关。实际模拟时钟使用 GameUpdateCount。FishingBorrow token有效期间 G10不产生第二份重抛；受控重抛更新共享原抛点，手动选择与受控恢复分开。

FishingPull/FishingCast/FishingCut 与 G09 工具共用自动准入，贯通 Session 选择、ToolUse 消费和租约保留。CanRunAutomaticActions 要求本帧原版更新阶段、后台 CanUpdateGameplay 且非暂停；CanRetainAutomaticIntent 允许无模拟空更新保留安全意图。后台忽略焦点和 Draw 遗留 mouseInterface，不写回原版标志。F5、文本、箱子、鼠标拿物和真实来源仍复核；回焦重新走原输入隔离。存鱼同时打通 HostFishing 与共享 Items 领域/出口，不能只放宽钓鱼门。

`SelectedItemState.Select` 只提交缓冲，`CanChangeSelectedItemImmediately` 只表示允许下一次切换，均不证明原竿已恢复。ToolUse 记录本次原槽归还请求，在原版兑现前保留相同代次、选择意图和来源的短租约；新的手动选择立即撤销其权限。切杆不产生虚拟使用，原版 Pick 回调或已回原槽才退役；0/1/3 次未采样外层更新不能把它变成手动结束。钓鱼会话开始/结束只在身份沿向现有 LocalShortFeedback 发布一次，自动拉抛、借网与切杆共享同一 token；松露虫开始状态取实际原版鱼饵条件，召唤标记仍保持未知普通候选。

一次拉竿记录被覆盖的本机原鱼漂完整身份集合；原版使用会收全部本机漂。Only actual native-use confirmation permits interpreting a matching product, and neither confirmation nor disappearance proves an item. `AI_061_FishingBobber_GiveItemToPlayer` 的因果范围接现有 ItemSourceHooks；内层 GetItem 分别记录原版真实产物与直接落袋量；全部溢出仍只在本次完成边界捕获已存在的合法同类库存，没有旧物不等未来拾取。不依赖会被QuickSpawnItem丢失的source，也不追溯临时世界槽400。专用存放资格进入既有物品处理优先序，共用精确源组与 ItemNearbyStorage；普通 maxStack门与钓鱼资格分开。

配装在实际消费前核原版权限、对象和所有权。组切换走 TrySwitchingLoadout并读回；逐件受控交换核合法源/目标、装备冲突和双方真实引用，保持收藏并立即验证守恒，正常原版同步继续负责网络发送，不伪造ACK。归还记录只认原对象和仍属于本次的受控格；相关容器变化重新求解，手动接管不回写。

F5Shell 为 Tools、FishingEquipment、存鱼和其它纯自动功能统一提供自动业务及鼠标租约准入，复用同一份玩家、文本、容器和物品安全条件；仅壳层可证明其自身 mouseInterface 租约。前台应用与普通归还均须实际物理左右键释放，不能把被菜单消费后的映射 false 当作松开；死亡/退出沿用各自边界。F5 开窗的额外限制只通过 CanFishingInterface 作用于 G10 收竿、重抛及切杆，Session.Ready、ToolUse 的选择刷新、实际消费及在途保留共同复核；G09 借网补抛和新工具种类默认不受此限制。没有应用记录的准备状态也须随钓鱼身份退役，但不产生归还提示；正常归还或玩家明确接管整组时清理自己的等待结果，未知与未还记录仍保留。

正常成堆渔具通过原版 `PickupItemIntoMouse` 拆一件，并立即落在同来源容器的安全空格，再进入现有交换记录。原版 armor 保存不记录堆叠数量，禁止整堆入装备栏；无同源空位就等待。拆分、交换和归还非阻塞使用原版 `Player.IOLock`，避免后台保存读到中间数量。拆出单件归还到预留格，不强制与剩余原堆合并。较晚的收藏/共享/受控格意图接管整条升级链；关闭虚空访问或转到其它装备组时仍保留原记录。退出仅尝试安全精确逆交换，未还结果保留到下次可显示时机；旧物品记录绝不跨角色重试。

改名由独立单次命令走当前 PlayerFileData.Rename及SavePlayer；预检明确文件身份和云提供者。所有者新决定取消多人/SSC 提前禁止；原版自身的跳过保存仍如实成为部分结果。窄保存作用域核实际玩家文件出口；本地只读解密名字及完整加密块，云端核本次原版Write的返回值和完整字节读回。不得在生产中调用LoadPlayer验证：它会重置全局旅行能力，只有隔离夹具可使用它回读。原版可能静默跳过写入或忽略云Write false，因此无异常不是成功。多人本机名字确已改变后发送一次原版消息4，普通客户端差异同步不包含名字，不能等待它自动传播；发送失败单独说明，不改写本地保存事实，不重试，不声称服务器确认。部分失败保留准确结果，不替换当前玩家、不重写R身份；确认角色内容不等于地图、成就或跨设备云同步均已确认。

## 输入、成本与验证

自动钓鱼功能提示为“收竿后自动在原位抛竿；f5菜单开启时不生效”。候选、关键词和预设浮层共用按钮上下定位，当前页面控件为锚点；滚动只重新投影，字体/缩放/视口变化重排并撤销旧按下，不重查已缓存的预设内容。

接入 F5 的 Attach、BeforeInput、文字owner、ProcessInput、Pointer/Wheel tail、Prepare、Draw、Hint、Close/Focus/Session 全链。共享文本编辑器处理中文/IME，不复制键盘采样。功能普通行不为正常等待预留状态行；最多三列精确名单/候选、可滚动预设浮层使用最终同一几何命中。实际滚动与遮挡是不同事实。

视觉可用性与保存命令准入分开：异步保存保留相邻按钮外观，可靠回执前仍拒绝第二次写入，受保护设置和关闭过滤名单操作才灰显。浮层按实际内容决定高度并限于视口，预设图标/关键词胶囊按字体与宽度缓存换行，只投影可见内容。主 F5 外点关闭必须使用当前几何，关闭按下与释放都归浮层，不能穿透。改名预检等待不占菜单状态行；只有真实保存读回成功后发布头顶短提示，失败仍可回看。

页面提示由 FishingPresentation 独占一次显示和单调时钟期限，特殊规则外框下方完整换行，6 秒后退出布局。命令回执发布新提示，业务错误仅在来源变化时发布；每帧读取同一错误不重新计时。不删除 Host/Settings/Rename 的原因以实现隐藏，不增加通知历史或持久化。输入浮层的校验仍留在编辑器附近；页面过期只使布局失效一次，稳定帧复用布局。

预设浮层仅保留外框及轻分隔，标题、作用域、名称/内容、辅助操作各有层级。名称和内容共用原整组应用命中区，独立删除列不会落入应用区；关闭固定在题头。精确图标不画独立按钮底板；关键词宽度留足字形与取整余量，超宽词条优先按 Unicode 文本元素分行；仅单个组合/ZWJ 元素自身超宽时退到 Unicode 标量边界，不拆 UTF-16 代理对、不省略字符。分行和尺寸只在准备阶段更新，Draw 继续使用准备结果；字体、语言、预设源或可用宽度变化时失效。

无消费者且无尾部责任时在目录/鱼漂/水体/装备读取前返回。稳定查询不重新全量解名、排序；稳定装备不重算候选；时钟、容器、语言、设置、条件和资源变化分别失效。调试工作量断言记实际扫描/规划/文件提交处，正常正式包不加常驻详细观察器。

验证以行为合同为独立期待：精确类别/特殊例外、四作用域与预设保存失败、长名字进位/拒绝；完整 .8 Player.Update/ItemCheck 拉抛与产物，0/1/3空外层更新不改模拟节奏；借网重复/晚到、装备共享/手动接管/恢复、存放优先级与晚回包；真实资源和不同宽度/缩放的 F5/文本/弹层；相关邻项及正式工作量选组。受审完整候选按现有 Debug/Release与同工作区重复构建、完整包和安装安全门交付。自动、图形、多人、所有者体验的结论保持分开。
