# 连续加工实现设计

本设计描述 [G08 #99](https://github.com/Kuroneko2020/JueMingR/issues/99) 已接受实现的职责与机制，随 [PR #100](https://github.com/Kuroneko2020/JueMingR/pull/100) 合并进入 `main` 生效。[行为合同](../功能介绍/连续加工行为合同.md)记录本次接受及实机复测延期边界；最新修订未实机复测。实现、原始验证、文档最终化、真实合并和保留安装身份分别由 Issue 承载，不将源码接受或文档收口写成新一轮运行通过记录。

## 证据与方案

基线main为 `4b989aa2f349039defc7e3b9a87305f8deb71cad`，冻结Legacy为 `6ac6356c0c564f43284590c168855e96c50e13f7`。原版以合法1.4.5.8 EXE（SHA-256 `960A03BFF6050CF7BE16DFC1A7B19E10FC2C4F8F835A6A3B135A50DD9E6BA2F3`）及已有定向提取件为依据。原版源码、依赖和原始运行证据不进入Git或包；.6/.7资料不代替当前签名。

采用各业务的即时有界操作，保留唯一公共输入、Runtime会话与现有来源/占用边界。固定八袋加清理窗口无法提供真实公平性；把整个长按包装成AutomaticOperation会同时关闭来源且扩大保护旁路，均不采用。不新增公共任务队列或长期加工账本。

## 职责及接口

| 位置 | 唯一职责 |
| --- | --- |
| Features/Processing | 三个自然配置域的不可变值、严格codec和可靠提交状态，不引用Terraria或其它Feature私有状态。 |
| Platform/Items | 既有槽/账户占用器中的独立加工作用域；不新建无实际消费者的Platform/Processing目录或调度平台。 |
| TerrariaHost/Processing | 三业务各自的原版对象/方法适配、动作前复核、确切消费作用域和呈现；装配类只接线。 |
| 既有Items | 完整因果来源、有限兼容整栈机会、实际槽/账户占用、原版出售/存储/丢弃；仅扩展本批真实交点。 |
| 既有Input/F5/Hotkeys/Storage | 唯一样本和手势消费、公共控件/绑定、可靠文件worker；不拥有加工规则。 |

普通加工与G05/G07按实际源槽、选槽/使用阶段、材料和钱币账户协调；G06主动取出意图不由加工清除，币不进入普通来源。未知占用与偏好开关分离，开关、失焦循环和改名单不解除未知结果。

## 开袋与下游时序

长按意图与消费租约分开。意图保护当前仍准备使用的真实袋/钥匙免于下游选择，但不作为占58槽出售写域的长期事务；当次原版调用独占确切袋、实际黄金钥匙来源及必要相交范围，完成或异常后分别收口。出售可能因原版拒绝恢复全部58个引用，因此每次开袋必须重新选取并核对真实对象，不让旧请求跟随替换物。

受控开袋有确切当前请求范围，ItemSourceHooks.OpenBefore和Consume的手动事实只对该范围区别处理；普通Handle/拖拽/手动交易继续原语义。不清CausalDepth、普通ManualSlot/Materials、pending或未知保护。受控范围不用AutomaticOperation，真实Grant/GetItem照常捕获。

每次同步调用完整退出后才能调度卖/扔/存，禁止在GrantItems/GetItem内递归下游。已接受实现每个有效Update最多一次开袋、一次已具资格的下游实际尝试；下游选槽采用公平轮转，防低槽持续新增饿死高槽。没有固定清理等待，不等待清空。既有真实原版隔离序列用于核对有限时序及工作量，不外推为无限吞吐或FPS结论。

原版拒绝且确定无副作用可等待真正相关条件变化；已知缺钥匙不每帧调用原版。普通商店允许主包开袋，原始物理手势经公共输入归属过滤，不从另一个OS源复活已消费输入。原版单次入口与自动入口必须在实际输入阶段互斥，命中控件以当前有效UI事实为准。

TryOpenContainer完整外层消费判据、GrantItems结果与GetItem实际增量继续决定取得来源；满包世界溢出不算失败，稍后Pickup为独立来源。每次新取得可重新捕获合格整栈，但旧机会不能为自动堆叠授权无来源的替换或箱子取回。出售、丢弃直接按当前合格名单库存判断，仍接收来源完成后的即时唤醒，避免只开卖/扔时退回普通6 tick观察节奏；来源异常保护与有限堆叠机会不变。

锁定 .8 的两个特殊事实：ItemID.Sets.OpenableBag保留58项，但3861/3862也在Deprecated中，Item.SetDefaults尾段会将其变空；完整集合检查与56项可正常构造袋的真实开奖须分别报告。Player.FindItem(type, collection)的数量谓词读取inventory同索引槽，黄金锁盒ConsumeItem的虚空分支确实调用它；自动操作绑定这个实际返回的钥匙，不能自行换成较宽的银行搜索或偷偷修原版。证据分别为已有ItemID提取件的集合、Item.SetDefaults尾段及Player.FindItem/ConsumeItem定向提取，并以锁定程序集隔离验证。

## 提炼与重铸

提炼候选范围来自当前ExtractinatorMode，完整机器归一及逐格校验复用窄Tile事实。无材料不查机器；有材料时缓存可用对象，每次动作前重验，完整空结果按有界周期/位置变化刷新。选择及鼠标仅借用真实ItemCheck阶段，保留原版动画、使用时间、消费和DropItemFromExtractinator出口；以精确提炼分支护栏阻止目标消失后落入放置。归还前核对操作代次、原版选择变化与玩家新输入，失败不回写旧库存。

重铸在有效物理按下的Update冻结物品、NPC、名单版本、语言及原词缀/价值；有当前报价时直接认领，没有报价时保留最初按下位置，允许跳帧后的实际按钮Draw补认领；初始点和当前点都须命中同一有效按钮。待认领期间每次Update复核初始词缀/价值及缩放/视口，变化后恢复也不重用旧按下。按钮外按下后滑入、真实释放、身份变化、停止尾部和未知结果不能重武装；Draw只认领手势，不自动扣款。词缀目录按游戏/语言版本缓存；完整字符串逐项解析，不拼接拆分。适用性需同时满足原版类别与属性乘数/四舍五入限制，不执行随机Prefix预判；普通物品名不参与词缀身份。

正常费用严格遵循 .8 原版按钮外层：`long(value)*stack`，有折扣时double乘0.8截整，再float乘当前购物系数截整，最后除3；原版BuyItem成功才进入ReforgeItemInReforgeSlot。付款和随机改词缀构成一次受控操作，不仅Hook免费内层，也不在原版外层扣费之后再付一次。每次复核物品/会话/NPC/名单和账户；账户占用与护士独立，不借护士许可。

DrawInventory的窄IL观察点原样保留原版hit bool并记录该次实际局部报价/矩形；自动操作只在Update推进，要求报价帧、物品、折扣/购物系数、UI尺寸/缩放与当前物理命中仍相符，每份观察至多使用一次。原版按钮唯一BuyItem调用点在扣费前拒绝已归本功能的长按；普通手动付款继续原调用，不在Draw新增自动业务循环，也不重置原版reforgeCooldown。原版内层只在较好词缀结果时写入60，准入冷却由外层手动按钮检查；已认领的自动Update不等待该字段，仍每Update最多一轮，并按自选目标停下。

跨阶段尺寸身份使用PlayerInput.OriginalScreenSize，不能用在UI Draw中已缩放的Main.screenWidth/Height与Update直接比较。提炼改选机器部件时同步借用鼠标与tileTarget；原版产物位置读取MouseScreen。DropItemFromExtractinator正常返回只证明原版生成/请求调用结束，不能证明世界槽可拾取、服务器确认或已经入包。

同词缀正常返回仍算一次真实滚动。自动命中后当前输入尾部继续被消费，换物/改名单/离界面终止旧授权；真实释放才开始下一次。已匹配初始物品不认领自动滚动，保留手动一次。未知付款/随机结果保留真实状态及相交保护，不补偿重放；声光反馈异常也不能重执行。

## 配置、界面与生命周期

ProcessingPanel追加物品页的两条普通行；ReforgePanel在杂项页收税行后拥有完整字符串名单和独立文字草稿，复用TextEditInput/SingleLineEditView。输入框、添加按钮和开关键在同一行；双击输入框才取得文字租约。完整词缀名单用与自动丢弃相同的47×34横排小格展示，格内按实际字形尺寸居中显示词缀名，长名称悬停查看；悬停格子的右上角显示18×18删除叉号，普通名单保留移动按键；移除绑定完整名称、偏好版本与投影身份。杂项页合并收税和名单高度后只做一次最终滚动约束，避免前一块高度将长名单滚动拉回。动态词缀和草稿使用非固定文案测量通道，并按内容/光标/组合文字/布局变化缓存。三项开关键经公共HotkeyRegistry注册，默认没有绑定。

开袋/提炼开关与重铸开关/完整目标按自然配置域保存，复用PreferenceJson/DocumentWorker/AtomicFileDocument及原件保护。关闭和删除先撤销执行资格，新许可按既有可靠保存边界发布。原版引用、借用token、缓存、失败结果不落盘。

Items页和Misc页使用现有行/提示/主滚动与公共绑键，重铸文本只在编辑时申请文字租约。名单布局按内容/字体/视口/缩放代次复用；同代次按下释放才提交。普通等待/保存不改变高度。切页、Esc、失焦、Session结束取消旧UI手势并收尾仍拥有的输入。
