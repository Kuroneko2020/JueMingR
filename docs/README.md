# JueMingR 文档入口

本文件只导航现有正式文档。产品定位查[根 README](../README.md)，项目、Git 与只读 Legacy 边界查[根 AGENTS](../AGENTS.md#项目边界)。

## 先找到当前任务

[总跟踪 Issue #7](https://github.com/Kuroneko2020/JueMingR/issues/7)路由当前任务和 PR；目标、权限与阻塞回对应任务 Issue。启动按 [AGENTS](../AGENTS.md#跨会话冷启动)，本入口只帮助找到正文。未合并任务使用指定分支或提交，主线、候选、实际安装和验收分别核对。

## 按能力找合同与证据

玩家查[使用指南](功能介绍/玩家使用指南.md)，按能力进入[功能索引](功能介绍/功能索引.md)的合同与设计，按技术症状进入[经验索引](AI经验笔记/索引.md)。当前能力由相应正文说明，任务状态与候选、包、安装事实回原 Issue/PR；本入口不复制第二份能力状态表。

复杂辅助瞄准的必要恢复线索查[阶段入口](计划/辅助瞄准阶段文档.md)，蓝图的历史交付和暂停恢复线索查[蓝图记录入口](计划/蓝图真实采集与蓝图库交付记录.md)。两者只对相应主题按需读取，旧命令和旧交付不授权现在执行。
