# JueMingR 文档入口

本文件只列出当前实际存在的正式文档分类和事实路由。

## 当前正式分类

- [`规范/`](规范/)：长期有效的项目规则。当前入口为 [文档治理规则](规范/文档治理规则.md)、[Legacy 平替与行为契约规则](规范/Legacy平替与行为契约规则.md)、[技术平台与兼容规则](规范/技术平台与兼容规则.md) 和 [性能治理规则](规范/性能治理规则.md)。
- [`决策/`](决策/)：重要选择及其理由。当前入口为 [ADR-0001：文档体系与受控演进](决策/ADR-0001-文档体系与受控演进.md)、[ADR-0002：Legacy 平替策略与行为契约方法](决策/ADR-0002-Legacy平替策略与行为契约方法.md)、[ADR-0003：原版同进程加载路线与兼容策略](决策/ADR-0003-原版同进程加载路线与兼容策略.md)、[ADR-0004：跨会话连续性与稳定起步路线图](决策/ADR-0004-跨会话连续性与稳定起步路线图.md) 和 [ADR-0005：性能治理采用风险触发与分层证据](决策/ADR-0005-性能治理采用风险触发与分层证据.md)。
- [`计划/`](计划/)：保存已经批准、在相应活动期内有效的高层计划、阶段目标和退出条件，不保存动态任务状态。当前入口为 [稳定起步路线图](计划/稳定起步路线图.md) 和 [最小工程治理试运行计划](计划/最小工程治理试运行计划.md)；前者负责高层阶段，后者只在试运行活动期内有效，动态进度仍在 GitHub Issue。

## 查找事实

- 查长期有效规则：[`规范/`](规范/)
- 查 Legacy 行为恢复、平替与差异验收方法：[Legacy 平替与行为契约规则](规范/Legacy平替与行为契约规则.md)
- 查产品运行平台、游戏版本、Windows、渠道、多人和安装恢复边界：[技术平台与兼容规则](规范/技术平台与兼容规则.md)
- 查性能风险触发、性能证据、功能关闭成本、缓存、测量工具和性能检查边界：[性能治理规则](规范/性能治理规则.md)
- 查文档类型、权威、生命周期和结构演进：[文档治理规则](规范/文档治理规则.md)
- 查为什么作出重要选择：[`决策/`](决策/)
- 查稳定起步前的大方向、阶段依赖和退出条件：[稳定起步路线图](计划/稳定起步路线图.md)
- 查当前最小工程治理试运行方式：[最小工程治理试运行计划](计划/最小工程治理试运行计划.md)
- 查当前阶段、当前任务和阻塞：[稳定起步总跟踪 Issue](https://github.com/Kuroneko2020/JueMingR/issues/7)
- 查具体任务状态：对应 GitHub Issue
- 查历史代码变化：Git
- 查发布变化：未来的 Release/Changelog
- 查原始日志和临时材料：本地目录；这些材料不属于正式事实源

## 结构边界

未来分类只在出现真实文档职责后，通过专门任务、项目所有者批准和 ADR 增加。当前结构不是永久结构；若事实证明其他组织方式更合适，应受控调整。

普通任务不得自行重组文档目录。当前尚不存在 `设计/`、`验证/`，不得把它们写成现有入口，也不得为未来可能的用途预建空目录。
