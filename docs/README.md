# JueMingR 文档入口

本文件只列出当前实际存在的正式文档分类和事实路由。

## 当前正式分类

以下知识分类与读取责任依据 [ADR-0013（Accepted）](决策/ADR-0013-单工作区操作偏好与项目知识分层.md)，整理结果与长期语义已获所有者接受，随本次合并进入 `main` 生效。现有规范、设计和已接受诊断退出条款继续有效。

- [`AI经验笔记/`](AI经验笔记/索引.md)：按主题整理的机制知识、失败原因与证据边界，纳入 Git；历史经验不自动成为产品合同。
- [`功能介绍/`](功能介绍/功能索引.md)：当前 R 用户说明和显著标识的 Legacy 行为参考，纳入 Git；精确技术合同仍由设计承担，动态状态仍查 Issues。

- [`规范/`](规范/)：长期有效的项目规则。当前入口为 [文档治理规则](规范/文档治理规则.md)、[工程治理规则](规范/工程治理规则.md)、[Legacy 平替与行为契约规则](规范/Legacy平替与行为契约规则.md)、[技术平台与兼容规则](规范/技术平台与兼容规则.md)、[性能治理规则](规范/性能治理规则.md)、[测试与审计规则](规范/测试与审计规则.md) 和 [版本、配置与发布规则](规范/版本配置与发布规则.md)。
- [`设计/`](设计/)：描述当前系统或功能如何组织、模块与接口如何协作，以及状态和生命周期由谁负责。当前入口为 [总体架构与状态所有权](设计/总体架构与状态所有权.md)、[可重复构建与项目骨架](设计/可重复构建与项目骨架.md)、[最小原版加载链验证](设计/最小原版加载链验证.md)、[代表性纵向切片一：群系显示](设计/代表性纵向切片一-群系显示.md)、[F5 控制界面样板与 UI 基础](设计/F5控制界面样板与UI基础.md) 和 [配置持久化与用户数据布局](设计/配置持久化与用户数据布局.md)。
- [`决策/`](决策/)：重要选择及其理由。当前入口为 [ADR-0001：文档体系与受控演进](决策/ADR-0001-文档体系与受控演进.md)、[ADR-0002：Legacy 平替策略与行为契约方法](决策/ADR-0002-Legacy平替策略与行为契约方法.md)、[ADR-0003：原版同进程加载路线与兼容策略](决策/ADR-0003-原版同进程加载路线与兼容策略.md)、[ADR-0004：跨会话连续性与稳定起步路线图](决策/ADR-0004-跨会话连续性与稳定起步路线图.md)、[ADR-0005：性能治理采用风险触发与分层证据](决策/ADR-0005-性能治理采用风险触发与分层证据.md)、[ADR-0006：测试与审计采用分层验证与独立判定](决策/ADR-0006-测试与审计采用分层验证与独立判定.md)、[ADR-0007：版本、配置与发布采用分层身份和显式迁移](决策/ADR-0007-版本配置与发布采用分层身份和显式迁移.md)、[ADR-0008：工程治理采用风险分级与仓库原生流程](决策/ADR-0008-工程治理采用风险分级与仓库原生流程.md)、[ADR-0009：Legacy 用户数据导入按功能评估且不构成平替义务](决策/ADR-0009-Legacy用户数据导入按功能评估且不构成平替义务.md)、[ADR-0010：总体架构与状态所有权](决策/ADR-0010-总体架构与状态所有权.md) 和 [ADR-0011：可重复构建与项目骨架](决策/ADR-0011-可重复构建与项目骨架.md)。
- [`计划/`](计划/)：保存已经批准、在相应活动期内有效的高层计划、阶段目标和退出条件，不保存动态任务状态。当前入口为 [稳定起步路线图](计划/稳定起步路线图.md)。

## 查找事实

- 开发、审查、交付先读[单工作区与安装交付偏好](规范/工程治理规则.md#单工作区与安装交付偏好)；同工作区重复构建与旧工作树脚本的执行边界见[构建设计](设计/可重复构建与项目骨架.md#单工作区重复构建一致性)。
- RDP 无人值守环境与 #42 本次图形延期授权见[操作偏好补充](规范/工程治理规则.md#rdp-工作方式与本次图形延期交付)和[验证分层](规范/测试与审计规则.md#显示环境受限时的验证分层)；该开发候选许可不扩大为真实图形失败、未来任务或正式发布可自动跳过。
- 当前任务 → [功能索引](功能介绍/功能索引.md)的对应能力 → 正式设计 → [经验索引](AI经验笔记/索引.md)的相关机制；有新发现时按[项目知识的整理与维护](规范/文档治理规则.md#项目知识的整理与维护)同步受影响主题。
- 需要原始资料时，按[本地参考资料使用说明](设计/本地参考资料使用说明.md)找到被忽略的 `references` 中具体版本与主题。不是每轮全读，也不从资料里的旧指令恢复任务授权。普通克隆缺少原件时按该说明判断哪些工作可继续、哪些结论须等待证据。

- 编码与代码审查必读：[工程治理规则](规范/工程治理规则.md)，包括[关键注释与同次交付](规范/工程治理规则.md#关键注释与同次交付)。新增条款已获接受，自合并进入 `main` 后生效；现有有效规则继续适用。
- 查五个底线及领域读取入口：[根 AGENTS](../AGENTS.md#五个底线入口)；查补充理由、成本和接受边界：[ADR-0012（Accepted）](决策/ADR-0012-关键注释同次交付与五个底线路由.md)。
- 查事实变化时由谁同步注释、设计、规则、路由和 Issues：[文档治理规则的同步责任](规范/文档治理规则.md#同一任务的同步责任)。

## 结构边界

未来分类只在出现真实文档职责后，通过专门任务、项目所有者批准和 ADR 增加。当前结构不是永久结构；若事实证明其他组织方式更合适，应受控调整。

普通任务不得自行重组文档目录。当前尚不存在 `验证/`；不得为未来可能的用途预建空目录。
