# JueMingR 文档入口

本文件只列出当前实际存在的正式文档分类和事实路由。

## 当前正式分类

- [`规范/`](规范/)：长期有效的项目规则。当前入口为 [文档治理规则](规范/文档治理规则.md)。
- [`决策/`](决策/)：重要选择及其理由。当前入口为 [ADR-0001：文档体系与受控演进](决策/ADR-0001-文档体系与受控演进.md)。

## 查找事实

- 查长期有效规则：[`规范/`](规范/)
- 查为什么作出重要选择：[`决策/`](决策/)
- 查任务动态状态：GitHub Issues
- 查历史代码变化：Git
- 查发布变化：未来的 Release/Changelog
- 查原始日志和临时材料：本地目录；这些材料不属于正式事实源

## 结构边界

未来分类只在出现真实文档职责后，通过专门任务、项目所有者批准和 ADR 增加。当前结构不是永久结构；若事实证明其他组织方式更合适，应受控调整。

普通任务不得自行重组文档目录。当前尚不存在 `设计/`、`计划/`、`验证/`，不得把它们写成现有入口，也不得为未来可能的用途预建空目录。
