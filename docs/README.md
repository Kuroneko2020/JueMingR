## 先找到当前任务

[总跟踪 Issue #7](https://github.com/Kuroneko2020/JueMingR/issues/7)指向当前任务与 PR；具体目标、权限和阻塞以对应任务 Issue 为准。未合并任务读取 Issue/PR 指定分支或提交的文档与实际差异；`main` 已交付内容、分支进展、本机安装分别核对，不能从本入口推定现装或验收结果。

**候选 ADR-0018（Proposed，未生效）**：[分层冷启动](../AGENTS.md#跨会话冷启动)拟按任务缺口展开读取，已定位的小修/文档修改/只读核对直接进入相关合同与规则小节，新领域再展开背景；接受并合并前仍按 [ADR-0004 第 6 条](决策/ADR-0004-跨会话连续性与稳定起步路线图.md#决策)的现行协议。完整候选及保留边界见 [ADR-0018](决策/ADR-0018-按任务恢复上下文与协作流程收敛.md)。

复杂辅助瞄准任务保留[阶段文档](计划/辅助瞄准阶段文档.md)作为决定、接口、资料和恢复线索入口；当前任务状态回到 Issue/PR 核实，`main` 阶段记录不代表未合并分支。第一批接受、限制与历史交付来源由[第一批收口](计划/辅助瞄准阶段文档.md#aim-first-batch-closeout-20261009)、其链接的历程和 [#112](https://github.com/Kuroneko2020/JueMingR/issues/112)承载，不在本文件复制多轮包/安装流水。
