# 本轮实测卡

候选安装后由你正常启动游戏，先确认能进入、F5 能打开并正常退出；随后按熟悉的角色/世界继续体验。

1. 叶绿连弩配普通箭，朝中远处目标或移动敌怪开火。应有随距离/运动变化的提前量与抬高，准星手动放向另一侧也应朝所选目标攻击。
2. 漩涡击碎者配普通子弹，再换幻象/幽灵凤凰持续攻击。留意主弹方向、连续出手和特殊阶段；松手、换武器或打开 F5 后应及时交回控制。
3. 北极或黑曜石剑鱼分别试近处和较远敌怪；近处本体与远程子弹都应有合理方向。多发散射、附加追踪弹及碎片允许近似，不承诺逐发必中。
4. 切换最近/清线与玩家/鼠标中心，并分别开关 NPC 路线和瞄准。清线应优先可达者；路线应保持正常曲线，普通/省力悠悠球和哨兵放置维持原用法。

有异常时回传武器/弹药、目标与大致距离、当时开关，以及方便时的一小段画面。自动隔离验证不代替你的体验、现场 FPS 或多人结果。
