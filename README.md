# JueMingR

决明 R（JueMingR）是面向原版 Terraria 的客户端辅助工具，不依赖 tModLoader，围绕实际游玩需求持续提供、改善和扩展便利功能。

决明 R 支持原版普通好友联机：通过 Steam 好友加入、自己开房（Host & Play）、加入朋友的房间，以及通过内网穿透连接或使用自建原版服务器，都属于支持范围。只需在想使用辅助功能的客户端安装 R，服务器和队友无需安装。除明确限制的个别能力外，已实现功能在房主和客机上都应实际可用；世界与物品变化仍遵循原版网络和服务器的最终结果。具体操作、能力限制与已验证范围见[玩家使用指南](docs/功能介绍/玩家使用指南.md)及相应功能合同。

JueMingR 延续 JueMingZ 的使用初衷，在独立工程中吸收旧版有价值的功能、有效交互、游戏机制知识和失败教训，重建可持续维护和发展的实现。完整恢复旧版对用户有意义的能力仍是当前建设的重要目标；同时，可以根据实际需求和所有者明确授权，在恢复期间改进体验、开发新能力。旧版功能清单不构成 R 的最终范围，完整平替也不是产品发展的终点。“独立完整重写”描述的是 R 与 Z 的工程关系。

JueMingZ 永久冻结，仅作只读参考。JueMingR 不在编译或运行时依赖旧项目，也不要求保留其错误行为、内部耦合和技术债。定位与演进边界见 [ADR-0015](docs/决策/ADR-0015-产品定位与能力演进边界.md)及 [Legacy 规则](docs/规范/Legacy平替与行为契约规则.md#一目的与适用范围)。

玩家从 F5 界面进入功能，操作说明见[玩家使用指南](docs/功能介绍/玩家使用指南.md)，按能力查[功能索引](docs/功能介绍/功能索引.md)。F5 的分类入口不代表所有 Legacy 功能已经迁移；具体能力、默认值、数据与安全边界由对应合同说明，候选交付、实际安装和所有者接受由原任务记录分别证明。

配置和功能数据按[用户数据布局](docs/设计/配置持久化与用户数据布局.md)保存在已验证游戏安装同级的 `JueMingRData`。安装恢复和卸载默认保留用户数据；损坏、未知版本和外部冲突按各功能合同保护原件。笔记、蓝图、足迹等能力的实际数据边界查各自合同，不从目录建议推定已实现。

开发从 [AGENTS.md](AGENTS.md) 确认边界与任务，再沿[文档入口](docs/README.md)取得适用要求。当前阶段和具体任务由[总跟踪 Issue #7](https://github.com/Kuroneko2020/JueMingR/issues/7)路由；本首页不维护候选、包、安装或多轮接受流水。

Legacy 恢复或跨功能研究先查[全功能调查总报告](docs/功能介绍/全功能调查总报告.md)，按本次能力进入相关专题。调查是固定版本证据，现行行为与实施授权仍查功能合同和任务 Issue。
